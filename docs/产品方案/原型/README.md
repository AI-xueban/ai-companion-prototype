# HiveMate 师生共创平台原型

2026-11-12第三轮：教师工作台与现有React学生平板联动。学生功能已实现在`apps/student/`，教师工作台沿用本目录的评审原型；未迁移到原有`components/Teacher/`。原第二轮“独立学生网页、学习树、金币页”已由本轮替代。

## 启动和预览

1. 在`apps/student/`启动Vite：`npm run dev -- --host 127.0.0.1 --port 3019 --strictPort --base /tablet/`。
2. 用Python执行`build_preview.py --output <预览目录>/outputs/HiveMate交互原型.html`。
3. 用Python执行`preview_server.py --directory <预览目录> --port 8765`。
4. 打开`http://127.0.0.1:8765/outputs/HiveMate交互原型.html`。右上角选择学生，整页进入同源的`/tablet/?hivemateEmbed=1`；教师按钮返回原教师工作台。

预览代理绑定本机地址，转发3019端口的`/tablet/`请求。两端同源，使用本地存储互通演示数据。不能将这个教师HTML单独离线打开当作完整交付，也不代表跨设备已接通。未改变原学生端构建配置及五Tab结构。

## 学生与教师验证路径

1. 平板首页左侧“学习广场”进入新页面；“我的星迹→我的作品”查看个人投稿。独立学生学习树、金币模块移除，金币继续使用原平板的钱包与明细。
2. 广场分为全部内容、学生作品、教师学习资源，支持年级、班级、科目筛选。只有审核通过的学生作品和教师明确开放的学习版进入广场。
3. 创作先选一个或多个科目。解析投稿只能选择本人完成并已记录的题目或作业；没有来源则引导完成练习或班级作业。AI创作无需关联题目。
4. 完成新班级作业后可选为解析来源；现有统一QuizPage有效提交后记录已做题。没有把历史页面中的示例条目批量认定为完成记录。
5. 学生提交后显示“审核中”；切换教师→反馈与投稿审核。本班任一所选科目老师或班主任可以通过/退回，其他班级和无关联科目教师看不到待审正文。
6. 通过后切回平板广场查看。示例10金币通过既有rewardService与onRewardGranted结算，遵守既有每日总上限150，同一作品不重复奖励；不是新增钱包或新的已确认运营规则。
7. 教师资源详情可选择“向学生学习广场开放学习版”。学习版投影只含学习字段，不带教案备注和教师答案。浮力资源示例支持400→450cm³、4.0→4.5N的可操作预览。

## 本轮验证结果

- TypeScript无输出检查通过。
- Vite生产构建通过（本机Node使用8GB堆上限；既有大资源包警告保留）。
- 7项实际服务规则检查通过：必选科目、未完成来源拒绝、科目匹配、来源归属、合法来源待审、多科AI待审、奖励上限与幂等。
- 浏览器通过：真实平板切换、两个入口、分类筛选、无来源空态、提交作业后投稿、AI多科目、审核前不可展示、有权教师审核、他班不可审核、审核后展示与原钱包850→860、学习版互动参数。
- 已保存五张第三轮截图；未提交、部署或修改现有管控规则。

## 原型边界

身份切换与审核授权是本机前端演示，正式接口仍需按登录人、当前班级和任教关系鉴权。AI草稿是可编辑示例，没有调用真实模型；选择附件只保存文件名，没有上传媒体或实现播放。班级归属使用演示学生与班级信息；未完成学校班级接口、全历史作业迁移、家长原生小程序联调、离线同步或跨设备持久化。生产使用还需要将公开学习版与教师私有原稿在服务端隔离。
