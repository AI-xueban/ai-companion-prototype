## 本轮问题与用户已明确的方向

学生可能无法持续联网，也不愿为平台另外撰写结构化报告。老师仍应能布置作业；学生另外可以自愿上传题目讲解、作业讲解或自定义作品，通过现有金币激励丰富学习广场。家长小程序学情、平板学生端与教师端已经是产品基础，本轮讨论怎样将它们连接为平台。

本方案将“教师作业线”和“学生自主贡献线”分开组织，再按同一学生、班级、任务、作品和奖励记录汇合。完成作业不以公开投稿为条件。自主投稿也不以老师布置任务为前提。

2026-11-12 同轮补充：用户明确教师还需备课、用AI创作互动课件、上传已有教研文件、在仅教师可见的资源广场按教材章节检索，并将他人资源复用或保存到自己的教学空间。完整产品据此扩展为教师资源生产复用线、教师作业线、学生自主贡献线；具体设计见末尾补充。

## 产品定义与参与方式

定义：以现有AI学伴为载体，老师组织日常作业，学生自愿贡献讲解和作品，平台审核分发并通过既有金币奖励贡献，家长与老师看到同一学习过程的不同视图。

学生贡献入口：

1. 单题讲解：题目图片配本人录音、短视频或图文，讲一个关键思路即可。
2. 作业讲解：从整份作业中选题或总结方法；不默认公开整份原始作业和个人信息。
3. 自定义作品：上传作文、绘画、手工作品、实验展示等已有成果，不要求必须由AI生成。

必要输入尽量限制为“选择文件、写标题、选类别”；可选关联学科、题目、任务或知识点。建议支持一分钟左右的讲解，但不强迫统一时长，也不把精美排版当成合格条件。

普通学生可以只完成作业、看精选讲解；愿意分享的学生投稿；优质贡献者逐步获得认可。不能以全员每日创作为内容增长假设。

## 两条独立业务线与一个平台底座

作业线：教师发布 → 学生平板接收或家长小程序查看 → 线下完成 → 在线提交／家长代传 → 教师反馈 → 学生订正 → 家长查看进度。

贡献线：学生从题目、错题、作业或个人作品出发 → 拍照／录音／导入 → 保存草稿 → 联网上传 → 检查与审核 → 发布广场 → 奖励结算 → 归入个人成果 → 被同学学习或教师复用。

汇合点是任务关联、知识标签、学生身份与学习事件。例如某生完成老师作业后自愿录一道题的讲解，该作品关联原任务；老师可把优质讲解推荐给有同类问题的同学，学生家长看到“作业完成”和“讲解获反馈”两条记录。独立兴趣创作可以没有任务关联。

底座至少统一以下对象：

| 对象 | 要解决的问题 |
| --- | --- |
| 平台学生身份与角色关系 | 平板、小程序、教师端都围绕同一学生，设备不作为学生身份；共享设备隔离账户草稿 |
| 作业任务与提交 | 不同端读取同一任务与状态，保留操作者、提交版本、作业作者与家长代传关系 |
| 作品与审核 | 独立于作业提交，有作者、来源、展示版本、可见范围与审核状态 |
| 学习事件 | 学习、提交、订正、投稿、审核、讲解被选用等事件供不同报告聚合 |
| 金币账本 | 共用余额、规则、流水、限额与重复结算校验；按服务端确认的奖励事件发放 |

原始事件、教师视图、家长视图共用事实来源，但不同指标不能混算。投稿数、获币数、浏览数均不能直接等同于知识掌握或分数提高。

## 网络受限时的产品规则

- 能接学校网络但不能访问公网：提供学校允许的服务域名和内容范围，依赖学校批准的连接条件，不假设可自由访问互联网。
- 暂时断网：可先在线下做作业、在设备本地拍摄或导入；拟新增持久草稿、待上传队列及联网重试。未成功同步显示“待上传”，不能冒充已提交或已发布。
- 家中没有平板：由家长小程序查看任务、拍照代交，亦可扩展代传学生作品，作者与操作者分开。
- 完全没有网络和允许的同步通道：无法实现跨端发布与同步，只能保留线下成果，待有连接时补传；不承诺全离线平台。
- AI润色、生成标题、知识标签推荐等联网后再使用；不用AI也能投稿，不能把实时AI作为上传前置。

本地草稿、断点续传、学生作品代传都是新增建议；当前示例代码中的本地文件保存不等于这些能力已全部实现。

## 金币与审核规则建议

沿用一个金币账户，增加“有效投稿”“精选讲解”等新奖励来源，不单开创作钱包。金额和频次待核验现行规则后确定，不直接沿用旧文档80或擅自改当前150。

初期建议“合格发布的小额基础奖励＋质量精选的额外奖励”，上传文件本身不发币，浏览量和点赞量不直接折算金币。同一作品不同版本、删后重传和多端重试不能重复入账；作业完成奖励与有效讲解奖励为不同事件，需各自真实满足条件。设投稿子额度并核对如何计入全站上限，避免挤占日常学习奖励。审核延迟导致跨日奖励时，界面显示待结算与到账日期，不默默吞掉应得奖励。

审核优先处理基础内容安全、清晰可读与原创贡献；学科讲解另检查明显知识错误。运营／内容审核承担基础筛选，老师只对班级精选、存疑学科内容或明确分配的队列复核。试点限制每日审核量，并记录单条耗时，不能将所有开放投稿无上限转给任课老师。AI只能辅助查重、转写和标注疑点，不作为唯一裁判。

错误讲解支持反馈、修改、更新展示版本；正常撤下作品不自动追缴金币。确认抄袭或刷币才按核定规则处置，并记录原因与复核渠道。首期以班级和校内展示为主，跨校精选另设授权流程。

## 学习树与学情如何自然形成

作业与订正进“我的学习记录”，投稿与作品进“我的成果”；按学科／知识标签关联现有教材节点，兴趣作品走主题分类。先能查询、回看与导出，再考虑树形展示。一次录题讲解形成表达学习的证据，但不直接修改现有知识掌握状态。

家长查看：本周完成作业、订正、贡献作品、收到的评价与金币来源。教师查看：哪些知识点有优秀学生讲解、哪些学生仍需指导、哪些作品可选为课堂素材。学生查看：作品、版本、收藏参考、审核状态、奖励流水。不给家长默认开放私人AI对话。

## 最小验证与建设顺序

第一步先验证学生愿不愿分享：在现有学生界面增加上传与作品列表原型，支持图片配音、视频、自定义图片作品；使用审核后发币流程，不先做复杂编辑器和可视化树。用一班、1—2位老师、小规模运营支持验证真实上传门槛、投稿质量、审核时间和后续再次投稿。

第二步打通真实跨端事实：统一身份映射、任务与作品存储、审核、金币账本及学习事件。验收必须使用不同设备／不同会话：教师发任务，学生收到；家长代交，教师看到；学生投稿，后台审核；到账后学生刷新金币，家长看到贡献记录。刷新和重试不重复奖励，退回作品不能进入广场。

第三步扩充推荐与积累：优秀讲解关联题目／错题／任务，学生可在遇到困难时看到相关讲解；教师精选形成下一次教学资料；个人成果按节点呈现学习树。AI用于辅助整理，不要求全员AI生成作品。

观察指标：被邀请学生中有效投稿比例、首次投稿操作时间、退回原因、再次投稿、内容被实际打开和被老师选用、审核耗时、单件有效内容的金币与人工成本、跨端状态一致性。是否学会仍由作答与教师评价检验。未核对现有正式后端前，不复用上一版从零开发的预算与排期。

## 教师资源生产与复用线补充

### 用户已明确的需求

教师可在平台备课和借助AI创作互动课件，也可上传已在WorkBuddy等外部工具中制作的作品或已有教研文件。教师资源广场仅教师可见，可按不同教材、章节查找。教师可以收藏、复用，或保存到自己的教学空间。本条来自用户2026-11-12本聊天最新消息，属于产品方向要求，尚未实施。

### 产品结构

完整形态为“教师教学空间＋教师资源广场、学生个人空间＋学生学习广场，以教学任务联动”。教师广场承载教学资源，学生广场承载学生讲解与作品，拥有各自权限与审核规则。家长继续在已有小程序查看孩子作业、学习和贡献记录。

教师内容循环：创作或上传 → 保存私有教学空间 → 预览／试用 → 自愿发布教师资源广场 → 他人检索 → 收藏／另存副本 → 修改与授课 → 继续沉淀。

师生连接：教师选择资源的学生可用部分 → 关联一个课前／课中／课后任务 → 指定班级或学生可访问 → 学生完成学习和作业、自愿上传自己的讲解 → 教师选用优质学生讲解作为教学参考。教师广场不因某资源用于授课而向学生开放，教案、答案、教师备注等也不自动随之下发。

### 教师教学空间

教师端新增“我的教学空间”，组织我创作的、我上传的、收藏的和另存副本的资源，支持按教材目录或自定义文件夹整理、按标题搜索、继续编辑、课堂预览和关联作业。资源可关联多个章节；跨学科项目保留主题分类，不强迫每个文件只属于一节课。

平台内AI创作入口接收教学目标、年级、教材章节、现有资料和期望形式，生成可预览草稿。老师试用、修改、确认后保存或发布。首期原生生成收敛到少量稳定互动形式，例如配对练习、分步讲解与随堂选择反馈；外部工具的复杂互动成果可先通过导入承接。首期不承诺任意自然语言都能稳定生成任何课件。

已有资源支持上传PPT、PDF、文档、图片、音视频以及可交互资源包。各类型分别标明“可预览、可下载、可编辑、可二次创作”的实际能力；上传文件不等于可原生编辑，源文件缺失时不承诺可直接修改。外链作品可登记为链接资源，但应标记联网要求和访问条件，不能把外链保存等同于已存入平台。

### 教师资源广场与教材定位

检索维度至少为学段／学制、学科、年级、教材版本、册次、教材修订版本或年份、章节／课时，再叠加资源类型与教学用途。教材目录与现有BOOK-001尽量共用数据源；教师检索可跨教材，不得改变学生“我的课本”中的个人教材设置。

教材章节使用稳定目录标识进行关联；跨版本的同知识主题可作为推荐关系，但不能仅凭相同章节名称认定完全匹配。广场显示适用教材、作者、互动预览／封面、资源类型、源文件与编辑能力、联网要求、更新版本和允许的复用方式。资源详情可查看教学用途、使用步骤、必要素材及引用来源。

### 收藏 另存副本 与教学引用

| 操作 | 语义 | 版本规则 |
| --- | --- | --- |
| 收藏 | 保存原作入口，便于再次找到 | 看到原作的可用版本；原作撤下时说明不可用，不承诺永久访问 |
| 另存副本 | 在作者允许的范围内复制到私人教学空间 | 创建独立资源ID，记录原作者、来源资源和来源版本；修改不覆盖原作；再分享取决于授权 |
| 关联任务或课堂使用 | 给特定教学任务选用一份学生可访问的内容 | 固定使用的版本和资料范围，避免作者更新后正在进行的课堂或作业发生变化 |

发布、复制、二次创作、再次分发和学生访问分别校验权限。教师专享广场需服务端核验教师身份与资源范围，不能只隐藏前端入口。教研原稿不默认归平台所有。

### 互动课件的产品边界

互动资源包需要一个可实际试用的预览／授课入口，预览与平台账号、钱包、私有数据隔离；导入资源的外部依赖、素材、运行能力需检查，不能让上传内容直接获得平台操作权限。此处为新增产品与实施要求，并非声称当前已有运行沙箱。

课堂使用分为“教师投屏单机互动”与“学生设备参与、作答回传”，首期优先承接前者。一个HTML课件可以点击运行不代表自动具有学生账号、全班实时同步或学情回流；后者需要统一任务和交互事件协议后再接入。

网络受限时，对具备授权和完整本地素材的课件提供课前缓存／下载的建设选项；依赖云模型、外部API或远端素材的课件需明确在线要求，不承诺所有作品离线可用。缓存资源依然遵守学校内容管控与授权，不绕过既有管控。

### 教师与学生激励分别处理

学生投稿沿用已有金币体系方向。教师资源先以个人教学资产、节省备课时间、署名、收藏复用和教研认可形成价值；用户未要求教师金币或付费交易，本轮不将学生奖励规则扩展至教师，不新增教师付费市场承诺。

### 新增范围与验证顺序

第一阶段验证两位教师间的资源流转：A上传或AI生成一个课件 → 关联明确教材章节 → 仅教师可见地发布 → B按章节找到并预览 → 有权限时另存副本 → B修改自己的副本 → 固定版本用于一次真实授课／任务。

同时验证学生不能搜索教师广场、可以访问老师明确下发的教学视图；原作者更新不影响已固定版本的任务；副本保留来源；无源文件时正确显示不可编辑；外链失效时有提示。课堂投屏与学生实时参与分别验收，不混称完成。

第二阶段再连接学生自愿讲解、金币和家长贡献记录；个人教学资源按教材结构积累成资源树，学生成果按知识点形成学习证据。完整平台共用身份、教材目录、资源版本、任务、权限与学习事件，避免为每个端复制一套内容。

仍待确认：首批原生AI课件模板、可导入包规格、复制与再分发授权、教师身份审核、学校／跨校可见范围、离线使用条件、首期是否包含学生设备实时互动。当前分支教材说明可作为目录规则入口，但本轮没有核验生成引擎、互动运行或资源广场已有实现。

## 第三轮：现有学生平板接入（2026-11-12）

本节为用户最新要求与本轮原型实施记录，覆盖前文“教师资源不进入学生广场”“独立学生网页、学习树、金币页”以及“未改原型”的阶段描述；前文作为方案演进保留。

学生身份现在进入现有React平板。首页增加学习广场入口，“我的星迹”增加我的作品；不新增独立学习树或金币模块。学生可选择本人在平板实际完成并已记录的题目/作业进行解析投稿，也可使用AI示例创作。创作前必选一或多个科目，待审内容不展示。本班任一匹配科目老师或班主任可审核，多科目不要求逐科会签（本轮实施口径，待用户验收）。

学习广场增加学生作品/教师学习资源分类及年级、班级、科目筛选。教师明确开放学习版后，学习资源才可被学生找到，教师私有教研原稿、备注和答案不随之公开。已打通同一浏览器来源下作业提交→解析投稿→有权教师审核→公开展示→原金币钱包结算的演示链路。

教师端仍为独立评审工作台，学生端已修改真实工程；尚未接入正式教师身份与班级接口、媒体存储、真实AI生成、跨设备同步或原生家长端。详细现行流程与限制见`apps/student/docs/v2.0/05-产品地图与流程/学习广场与作品创作.md`；启动及验收路径见`docs/产品方案/原型/README.md`。类型检查、生产构建、7项规则检查与浏览器核心流程通过，本轮未提交、部署，待用户验收。

## 广场可见性文案修正（2026-11-12）

用户最新明确教学资源广场学生也可见，因此原先“教师广场仅教师可见”的描述作废。教学资源广场面向师生，学生通过平板“教师学习资源”分类浏览。原型去掉“仅教师可见”标记及发布反馈中的排他表述，保留学习资源与私人教案备注/答案的内容范围区分。
