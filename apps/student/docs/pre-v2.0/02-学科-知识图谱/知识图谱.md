## 1. 背景与目标

学科远征增加**知识图谱**视图：按当前课本加载章/节 scope 内的知识点，支持切换，并与掌握度、薄弱点、练题闭环联动。

| 目标 | 说明 |
|------|------|
| 看得懂 | 单屏节点规模控制在可读范围（甜区约 6–20） |
| 找得到 | 分学科默认 scope，左栏「切换章节」开箱即用 |
| 用得上 | 点击可练点 → 诊断卡 → 练题 → 图谱刷新 |
| 可扩展 | 左栏框架统一，右栏按学科分渲染器 |

**本期不做**：整书全局大图、真实学情 API、教师端编辑、54 册全量接入。

## 2. 产品方案总览

### 2.1 三科对照

| 学科 | 默认 Scope | 画布 | 切换粒度 |
|------|-----------|------|---------|
| **语文** | 整单元 | 能力域气泡图 | 单元 / 单篇课文 |
| **数学** | 课时（优先 ≥6 节点） | 左→右关系树 | 章 → 课时 |
| **英语** | Unit（优先 ≥8 节点） | 语法·语音 + 词汇双气泡 | Unit 平铺 |

**统一规则**

- Scope **仅在左栏 `ChapterScopePicker` 切换**；画布内无课文 chip 条
- 底层数据来自 `knowledge_tree` + `catalog_tree`；**展示按学科选 scope 与渲染器**
- 语文/英语共用 `bubbleMapLayout.ts`（比例尺寸 + 错落布局）

### 2.2 节点规模参考

| 节点数 | 策略 |
|--------|------|
| 0 | 空态 + 引导 |
| 1–5 | 仍展示（语文单篇常见）；数学/英语不强制升 scope |
| 6–20 | 理想可读区间 |
| 21+ | 缩小 scope（英语禁止 Module 默认） |

## 3. 分学科实现

### 3.1 语文 · 能力气泡图

**定位**：按「能力域」组织，符合「这单元学了什么能力」的心智模型。

**组件**：`ChineseUnitLessonBubbleView` → `ChineseSkillMapView`

| 项 | 规则 |
|----|------|
| 默认 scope | 整单元（无 `sectionId`） |
| 切图 | 仅 `knowledge_tree`；`catalog_id` 匹配单元 scope；**不读** `catalog_tree.knowledge_points[]` |
| 分组 | 可练节点沿 `parent_id` 找顶层 `KnowledgeNode` 为能力域（`createScopedGroups`） |
| 大圆 | 原子多 → 圆大；`computeGroupBubbleSizes` 比例缩放 |
| 位置 | 错落绝对定位；2 组时少原子左下 (28%,68%)、多原子右上 (62%,30%) |
| 圈内 | 节点 `name` + 五态色；整单元多课文时可选灰色 `catalog_name` |
| 点击 | KP/TP → 诊断卡；能力域大圆 → 仅高亮 |

**Picker**：点单元名 → 切整单元并关闭 Sheet；Chevron 展开课文；**无「整单元概览」行**。

### 3.2 数学 · 左→右关系树

**定位**：课时级「一张图讲清一个技能块」。

**组件**：`ScopedKnowledgeGraph` + `layoutKnowledgeGraph()`

| 项 | 规则 |
|----|------|
| 默认 scope | 上次课时 → 第一个 ≥6 节点课时 → 第一个非空课时 |
| 切图 | `catalog` 挂载 + `knowledge_tree` 子树；祖先最多补 **1 层** KN |
| 布局 | 左→右确定性树；兄弟纵向排布；**无虚线簇圈** |
| 节点 | theme 虚线圆环 / knowledge 实心圆 / testing **菱形** |
| 手势 | 双指缩放、拖拽；进入 `zoomToFit` |
| 点击 | KP/TP → 高亮簇 + 诊断卡；KN → 仅高亮簇 |

**Picker**：章展开 → **仅课时列表**；**无「整章概览」**。

### 3.3 英语 · Unit 双气泡

**定位**：Unit 内区分语法·语音与词汇，避免 Module 级过载。

**组件**：`EnglishBubbleMapView`

| 项 | 规则 |
|----|------|
| 默认 scope | 第一个 ≥8 节点 Unit → 第一个非空 Unit |
| 切图 | **仅** `catalog_tree.knowledge_points`；不用 `knowledge_tree` 子树 |
| 分组 | 纯英文 TP → 词汇；含中文 KP/TP → 语法·语音 |
| 过滤 | 字母桶 A/B/C、跨 Unit 分类节点 |
| 布局 | 同语文 `bubbleMapLayout`；**不渲染边** |
| Unit 名 | 仅左栏展示，画布内不显示 |

**Picker**：全书 Unit 平铺；排除 Revision / Project / 综合测试。

## 4. 页面布局与交互

### 4.1 信息架构

```
SubjectMap (mapMode === 'pro')
├── TopStatusBar：学习路径 | 知识图谱 + 语数英切换（无滑动提示文案）
├── 左栏 ~272px
│     ├── 卡片 A：章节选择
│     ├── 卡片 B：当前掌握度
│     └── 卡片 C：薄弱点 / 无薄弱引导
├── 右栏：白卡片画布 + 右下角 KnowledgeGraphShapeLegend
├── ChapterScopePicker（Bottom Sheet）
├── DiagnosisCard
└── BottomNav
```

### 4.2 左栏三卡片

| 卡片 | 要点 |
|------|------|
| A | 副标题课本名；主标题见 `findScopeLabel()`；点击开 Picker |
| B | 环形图 + 五态明细；仅统计当前 scope 可练点 |
| C | `{N} 个薄弱知识点` 或学科差异化无薄弱文案 +「前往 · 下一范围」 |

### 4.3 ChapterScopePicker

| 学科 | 结构 | 行点击 |
|------|------|--------|
| 语文 | 单元 → 课文 | 点单元名 = 整单元；Chevron 仅展开 |
| 数学 | 章 → 课时 | 点章名仅展开；点课时选中 |
| 英语 | Unit 平铺 | 点 Unit 选中 |

选中项右侧显示「当前」badge。切换后：loading → 左栏 + 画布同步刷新 → 写入 `kg-last-scope-{textbookId}`。

### 4.4 画布通用规范

**形状图例**（`KnowledgeGraphShapeLegend`，右下角）

| 学科 | 图例 |
|------|------|
| 语文 | 能力域 / 能力点 / 课文（多课文来源时） |
| 数学 | 主题 / 知识点 / 考点（菱形） |
| 英语 | 语法 / 词汇 / 知识点 |

仅说明形状；掌握五态在左栏。图例区预留 `pb-12`。

**平板触控**：不依赖 hover / `title`；点击后选中环持续可见。

### 4.5 点击与练题闭环

```
可练点点击 → DiagnosisCard → 练题
  → sessionStorage[kg-return-node-{textbookId}]
  → 返回图谱：恢复 scope、高亮节点、刷新掌握度（localStorage overrides）
```

| 对象 | 行为 |
|------|------|
| 语文原子点 | 选中 + 诊断卡 |
| 数学/英语 KP·TP | 选中 + 高亮簇 + 诊断卡 |
| KN / 能力域 | 仅高亮，不弹卡 |
| 画布空白 | 取消选中 |

## 5. 数据与切图

### 5.1 演示数据

路径：`data/knowledge_trees/demo/{subject}_{grade}_{term}_{textbookId}.json`

| 学科 | ID | 版本 |
|------|-----|------|
| 语文 | 4686 | 部编版 4 上 |
| 数学 | 2964 | 北师大 4 上 |
| 英语 | 5275 | 沪教牛津深圳 4 上 |

加载：`loadTextbookTreeBySubject()` · 切图：`buildScopeGraph()` · 配置：`data/demoTextbooks.ts`

### 5.2 原始结构（摘要）

```ts
interface TextbookKnowledgeTree {
  catalog_tree: RawCatalogNode[];       // 目录 + knowledge_points 挂载
  knowledge_tree: RawKnowledgeTreeNode[]; // 关系树（parent_id, catalog_id, type）
}
// type: KnowledgeNode | KnowledgePoint | TestingPoint
```

### 5.3 切图 `buildScopeGraph`

```
1. 收集 scope 内 catalog_id
2. 取节点：
   - 语文：knowledge_tree 中 catalog_id 命中 + 子树
   - 数学：catalog 挂载 + knowledge_tree 命中 + 子树
   - 英语：catalog 挂载 → refine（过滤字母桶等，清空 links）
3. 补祖先：语文完整链；数学最多 1 层 KN
4. 建边 parent_id → child；mock 五态 + localStorage 覆盖
```

### 5.4 默认 Scope `resolveDefaultScope`

| 学科 | 规则 |
|------|------|
| 语文 | 上次单元 → 默认第一单元（**无 section**） |
| 数学 | 上次课时 → ≥6 节点课时 → 第一个非空课时 |
| 英语 | 上次 Unit → ≥8 节点 Unit → 第一个非空 Unit |

### 5.5 运行时节点字段（摘要）

| 字段 | 用途 |
|------|------|
| `nodeType` / `displayRole` | 分层视觉、点击分流 |
| `isPracticable` | KP/TP 为 true → 可开诊断卡 |
| `catalogId` / `catalogName` | scope 命中、语文来源文案 |
| `status` | 五态色（mock + overrides） |

定义见 `knowledgeGraphTypes.ts` · 服务见 `services/knowledgeTreeService.ts`

## 6. 掌握度与统计

| status | 文案 | 色值 |
|--------|------|------|
| mastered | 已掌握 | `#34C759` |
| reviewing | 复习中 | `#FFD60A` |
| weak | 未掌握 | `#FF3B30` |
| exploring | 探索中 | `#94A3B8` |
| unknown | 待识别 | `#BAE6FD` |

| 指标 | 公式 |
|------|------|
| 掌握率 | `mastered / (total - unknown)`，四舍五入 |
| 薄弱点 | `status === weak`，取前 5 |
| 统计节点 | 可练点；语文额外要求含 catalog 挂载 |

## 7. 技术架构

### 7.1 组件树（主应用）

```
KnowledgeGraphView
├── ChapterScopePicker
├── DiagnosisCard
├── [语文] ChineseUnitLessonBubbleView → ChineseSkillMapView
├── [数学] ScopedKnowledgeGraph
└── [英语] EnglishBubbleMapView
```

气泡布局：`bubbleMapLayout.ts`（`computeGroupBubbleSizes` · `computeStaggeredPositions` · `atomAnchors`）

### 7.2 关键源码

| 路径 | 职责 |
|------|------|
| `KnowledgeGraphView.tsx` | 主入口、分科路由、图例 |
| `ChapterScopePicker.tsx` | 章节 Sheet |
| `ChineseSkillMapView.tsx` | 语文气泡 |
| `EnglishBubbleMapView.tsx` | 英语气泡 |
| `ScopedKnowledgeGraph.tsx` | 数学关系树 |
| `bubbleMapLayout.ts` | 气泡尺寸与错落 |
| `KnowledgeGraphLegend.tsx` | 形状图例 |
| `knowledgeTreeService.ts` | 切图、默认 scope、统计 |
| `knowledgeGraphLayout.ts` | 数学左→右树布局 |
| `chineseGraphGroups.ts` | 语文能力域分组 |
| `SubjectSwipeSwitcher.tsx` | 顶栏学科切换 |

### 7.3 配置开关（当前生效）

| 常量 | 值 | 含义 |
|------|-----|------|
| `KG_SCHEME_E_ENABLED` | `true` | 数学树形布局 + 三层视觉 |
| `KG_CHINESE_TREE_ONLY_ENABLED` | `true` | 语文仅 knowledge_tree 切图 |
| `KG_MAX_THEME_ANCESTOR_DEPTH` | `1` | 数学祖先补齐层数 |

### 7.4 持久化

| Key | 内容 |
|-----|------|
| `kg-last-scope-{textbookId}` | 上次章/节 |
| `kg-mastery-overrides` | 练题后掌握态 |
| `kg-return-node-{textbookId}` | 练题返回高亮（sessionStorage） |

### 7.5 渲染技术

| 学科 | 技术 |
|------|------|
| 数学 | `react-force-graph-2d` + Canvas 自定义节点（含菱形考点） |
| 语文/英语 | React + CSS 绝对定位气泡 |

> Demo 控制台保留「语文图谱方案实验室」，**主应用固定**单元/课文能力气泡，不暴露方案切换。
