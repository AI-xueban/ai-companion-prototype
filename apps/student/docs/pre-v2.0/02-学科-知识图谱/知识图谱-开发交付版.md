# 知识图谱 · 开发交付版

> **产品**：AI学伴 · 学科远征（`mapMode: pro`）  
> **用途**：给开发实现与联调使用，统一知识图谱展示规则、交互行为、数据口径与验收标准。  
> **版本**：v1.0 · 2026-06-22  
> **状态**：以当前已落地方案为准。

---

## 1. 目标与范围

知识图谱视图用于按当前课本的章 / 节 / Unit 加载知识点，展示掌握状态，并支持「点击节点 → 诊断卡 → 练题 → 返回刷新」闭环。

| 目标 | 说明 |
|------|------|
| 看得懂 | 单屏节点规模控制在可读范围，理想区间约 6-20 个节点 |
| 找得到 | 分学科决定默认 scope，统一通过左栏「切换章节」选择 |
| 用得上 | 可练点可打开诊断卡并进入练题，练后刷新掌握度 |
| 可扩展 | 左栏框架统一，右栏按学科使用不同渲染器 |

**本期不做**：

- 整本书全局大图
- 真实学情 API 全量接入
- 教师端图谱编辑
- 54 册全量生产接入

## 2. 页面结构

```text
SubjectMap (mapMode === 'pro')
├── TopStatusBar：学习路径 | 知识图谱 + 语文 / 数学 / 英语切换
├── 左栏 ~272px
│   ├── 卡片 A：章节选择
│   ├── 卡片 B：当前掌握度
│   └── 卡片 C：薄弱知识点 / 无薄弱引导
├── 右栏：白卡片图谱画布 + 右下角形状图例
├── ChapterScopePicker
├── DiagnosisCard
└── BottomNav
```

### 2.1 顶栏

- 左侧：`学习路径 | 知识图谱`
- 居中：`语文 | 数学 | 英语`
- 支持点击 / 滑动切换学科
- 不展示「左右滑动切换学科」等提示文案
- 切换学科后：加载该科演示课本 → 计算默认 scope → 刷新左栏与画布

### 2.2 左栏三卡片

| 卡片 | 内容 | 规则 |
|------|------|------|
| 章节选择 | 副标题为课本名，主标题为当前 scope 名 | 点击打开 `ChapterScopePicker` |
| 当前掌握度 | 环形图 + 五态明细 | 仅统计当前 scope 内可练点 |
| 薄弱知识点 | `{N} 个薄弱知识点` 或无薄弱引导 | 点击薄弱点可高亮并打开诊断卡 |

### 2.3 右栏画布

- 白色卡片承载学科图谱
- 右下角显示 `KnowledgeGraphShapeLegend`
- 图例只说明形状，不重复展示掌握五态
- 平板触控优先，不依赖 hover / `title`
- 点击后选中环持续可见，直到切换节点或点击空白

## 3. 三科展示策略

| 学科 | 默认 scope | Picker 结构 | 画布形态 |
|------|------------|-------------|----------|
| 语文 | 整单元 | 单元 → 课文 | 能力域气泡图 |
| 数学 | 课时，优先选择节点数 >= 6 的课时 | 章 → 课时 | 左到右关系树 |
| 英语 | Unit，优先选择节点数 >= 8 的 Unit | Unit 平铺 | 语法 / 词汇双气泡 |

统一规则：

- scope 只通过左栏 `ChapterScopePicker` 切换，画布内不提供课文 chip 条
- 切换 scope 后：loading → 左栏统计刷新 → 画布刷新 → 写入 `localStorage[kg-last-scope-{textbookId}]`
- 节点数 6-20 是理想展示区间
- 节点数 0 时展示空态
- 节点数 1-5 仍展示，数学 / 英语本期不强制升 scope
- 节点数 21+ 时优先缩小 scope，英语禁止默认到 Module

## 4. ChapterScopePicker 规则

| 学科 | 结构 | 行为 |
|------|------|------|
| 语文 | 单元 → 课文 | 点击单元名 = 切整单元；Chevron 仅展开课文；无「整单元概览」行 |
| 数学 | 章 → 课时 | 点击章名仅展开；点击课时选中；无「整章概览」 |
| 英语 | Unit 平铺 | 点击 Unit 选中；排除 Module / Revision / Project / 综合测试 |

选中项右侧显示「当前」badge。

## 5. 语文 · 能力气泡图

**定位**：按「能力域」组织，表达「这个单元学了什么能力」。

**组件**：`ChineseUnitLessonBubbleView` → `ChineseSkillMapView`

| 项 | 规则 |
|----|------|
| 默认 scope | 整单元，无 `sectionId` |
| 数据源 | 仅使用 `knowledge_tree`，通过 `catalog_id` 匹配单元 scope；不读取 `catalog_tree.knowledge_points[]` |
| 分组 | 可练节点沿 `parent_id` 找顶层 `KnowledgeNode` 作为能力域 |
| 大圆尺寸 | 按组内原子数比例缩放，原子越多圆越大 |
| 大圆位置 | 错落绝对定位；2 组时少原子左下，多原子右上 |
| 圈内展示 | 节点 `name` + 五态色；整单元多课文时可选灰色 `catalog_name` |
| 点击 | KP / TP 打开诊断卡；能力域大圆只高亮 |

---

## 6. 数学 · 左到右关系树

**定位**：课时级「一张图讲清一个技能块」。

**组件**：`ScopedKnowledgeGraph` + `layoutKnowledgeGraph()`

| 项 | 规则 |
|----|------|
| 默认 scope | 上次课时 → 第一个 >= 6 节点课时 → 第一个非空课时 |
| 数据源 | `catalog` 挂载 + `knowledge_tree` 子树 |
| 祖先补齐 | 最多补 1 层 `KnowledgeNode` |
| 布局 | 确定性左到右树，兄弟节点纵向排布 |
| 节点视觉 | theme 虚线圆环；knowledge 实心圆；testing 菱形 |
| 不展示 | 虚线簇圈、更深层学科分类、整章概览 |
| 手势 | 支持双指缩放、拖拽平移；进入时 `zoomToFit` |
| 点击 | KP / TP 高亮簇并打开诊断卡；KN 只高亮簇 |

---

## 7. 英语 · Unit 双气泡

**定位**：Unit 内区分语法 / 语音与词汇，避免 Module 级过载。

**组件**：`EnglishBubbleMapView`

| 项 | 规则 |
|----|------|
| 默认 scope | 第一个 >= 8 节点 Unit → 第一个非空 Unit |
| 数据源 | 仅使用 `catalog_tree.knowledge_points`；不使用 `knowledge_tree` 子树 |
| 分组 | 纯英文 TP → 词汇；含中文 KP / TP → 语法·语音 |
| 过滤 | 过滤字母桶 A/B/C、跨 Unit 分类节点 |
| 布局 | 与语文共用 `bubbleMapLayout.ts` |
| 边 | 不渲染 parent 边 |
| Unit 名 | 仅左栏展示，画布内不显示 |

## 8. 节点点击与练题闭环

```text
可练点点击
  → 选中高亮
  → 打开 DiagnosisCard
  → 进入练题
  → sessionStorage[kg-return-node-{textbookId}]
  → 返回知识图谱
  → 恢复 scope、高亮节点、刷新掌握度
```

| 对象 | 行为 |
|------|------|
| 语文原子点 | 选中 + 打开诊断卡 |
| 数学 / 英语 KP 或 TP | 选中 + 高亮簇 + 打开诊断卡 |
| KN / 能力域 | 仅高亮，不弹诊断卡 |
| 画布空白 | 取消选中 |

## 9. 图例与掌握状态

### 9.1 形状图例

| 学科 | 图例项 |
|------|--------|
| 语文 | 能力域 / 能力点 / 课文（整单元多课文来源时） |
| 数学 | 主题 / 知识点 / 考点（菱形） |
| 英语 | 语法 / 词汇 / 知识点 |

### 9.2 掌握五态

| status | 用户文案 | 色值 |
|--------|----------|------|
| `mastered` | 已掌握 | `#34C759` |
| `reviewing` | 复习中 | `#FFD60A` |
| `weak` | 未掌握 | `#FF3B30` |
| `exploring` | 探索中 | `#94A3B8` |
| `unknown` | 待识别 | `#BAE6FD` |

统计口径：

- 掌握率：`mastered / (total - unknown)`，四舍五入
- 薄弱点：`status === weak`，取前 5
- 统计节点：仅统计可练点，即 `KnowledgePoint` / `TestingPoint`
- 语文统计额外要求节点含 catalog 挂载

## 10. 数据与默认 Scope

### 10.1 演示数据

| 学科 | 课本 | 数据文件 |
|------|------|----------|
| 语文 | 部编版 4 上 | `data/knowledge_trees/demo/1_4_上册_4686.json` |
| 数学 | 北师大 4 上 | `data/knowledge_trees/demo/2_4_上册_2964.json` |
| 英语 | 沪教牛津深圳 4 上 | `data/knowledge_trees/demo/3_4_上册_5275.json` |

### 10.2 原始结构

```ts
interface TextbookKnowledgeTree {
  catalog_tree: RawCatalogNode[];
  knowledge_tree: RawKnowledgeTreeNode[];
}

// node type: KnowledgeNode | KnowledgePoint | TestingPoint
```

### 10.3 切图 `buildScopeGraph`

```text
1. 收集当前 scope 内 catalog_id
2. 按学科取节点：
   - 语文：knowledge_tree 中 catalog_id 命中 + 子树
   - 数学：catalog 挂载 + knowledge_tree 命中 + 子树
   - 英语：catalog 挂载 → refine 过滤 → 清空 links
3. 补祖先：
   - 语文：补完整链
   - 数学：最多补 1 层 KN
4. 建边 parent_id → child
5. 注入 mock 五态 + localStorage overrides
```

### 10.4 默认 Scope `resolveDefaultScope`

| 学科 | 规则 |
|------|------|
| 语文 | 上次单元 → 第一单元，无 section |
| 数学 | 上次课时 → 第一个 >= 6 节点课时 → 第一个非空课时 |
| 英语 | 上次 Unit → 第一个 >= 8 节点 Unit → 第一个非空 Unit |

## 11. 技术入口

### 11.1 组件树

```text
KnowledgeGraphView
├── ChapterScopePicker
├── DiagnosisCard
├── [语文] ChineseUnitLessonBubbleView → ChineseSkillMapView
├── [数学] ScopedKnowledgeGraph
└── [英语] EnglishBubbleMapView
```

### 11.2 关键源码

| 路径 | 职责 |
|------|------|
| `KnowledgeGraphView.tsx` | 主入口、分科路由、图例 |
| `ChapterScopePicker.tsx` | 章节选择 Sheet |
| `ChineseSkillMapView.tsx` | 语文气泡 |
| `EnglishBubbleMapView.tsx` | 英语气泡 |
| `ScopedKnowledgeGraph.tsx` | 数学关系树 |
| `bubbleMapLayout.ts` | 气泡尺寸与错落布局 |
| `KnowledgeGraphLegend.tsx` | 形状图例 |
| `knowledgeTreeService.ts` | 切图、默认 scope、统计 |
| `knowledgeGraphLayout.ts` | 数学左到右树布局 |
| `chineseGraphGroups.ts` | 语文能力域分组 |
| `SubjectSwipeSwitcher.tsx` | 顶栏学科切换 |

### 11.3 当前生效开关

| 常量 | 值 | 含义 |
|------|----|------|
| `KG_SCHEME_E_ENABLED` | `true` | 数学树形布局 + 三层视觉 |
| `KG_CHINESE_TREE_ONLY_ENABLED` | `true` | 语文仅按 `knowledge_tree` 切图 |
| `KG_MAX_THEME_ANCESTOR_DEPTH` | `1` | 数学祖先补齐层数 |

### 11.4 持久化

| Key | 内容 |
|-----|------|
| `kg-last-scope-{textbookId}` | 上次章 / 节 / Unit |
| `kg-mastery-overrides` | 练题后掌握态覆盖 |
| `kg-return-node-{textbookId}` | 练题返回高亮节点，使用 `sessionStorage` |
