> **产品**：AI学伴 · 学科远征（`mapMode: pro`）  
> **版本**：v1.0 · 2026-06-18  
> **用途**：说明**当前已落地**的交互与呈现方案。  
> 数据模型、文案清单、跑批分析见：[`知识图谱.md`](./知识图谱.md)、[`知识图谱-展示文案.md`](./知识图谱-展示文案.md)

## 1. 页面结构

```
TopStatusBar
  ├── 左侧：学习路径 | 知识图谱
  └── 居中：语文 | 数学 | 英语（可滑动/点击切换，无提示文案）

Body
  ├── 左栏 ~272px
  │     ├── 卡片 A：章节选择 → ChapterScopePicker
  │     ├── 卡片 B：当前掌握度（环形图 + 五态）
  │     └── 卡片 C：薄弱知识点 / 无薄弱引导
  └── 右栏：学科画布（白卡片 + 右下角形状图例）

BottomNav（全局）
```

**切换链路**

- 换学科 → 该科演示课本 + 默认 scope → 刷新左栏统计与画布
- 换章节 → 更新 scope → 同步刷新 → 写入 `localStorage[kg-last-scope-{textbookId}]`

## 2. 三科策略总览

| 学科 | 默认 scope | 左栏标题 | Picker | 画布 |
|------|-----------|---------|--------|------|
| **语文** | 整单元 | 单元名 | 点单元名切整单元；Chevron 展开课文列表；**无「整单元概览」行** | 能力域气泡图 |
| **数学** | 课时（优先 ≥6 节点） | 章名 · 节名 | 章展开 → 课时列表；**无「整章概览」** | 左→右关系树 |
| **英语** | Unit | Unit 名 | Unit 平铺；不含 Module / Revision / Project | 语法·语音 + 词汇双气泡 |

**统计口径**：左栏掌握度、薄弱点仅计 `KnowledgePoint` / `TestingPoint`（`isPracticable`）。

## 3. 通用交互

### 3.1 章节选择（ChapterScopePicker）

1. 点击左栏卡片 A → 打开 Bottom Sheet「切换章节」
2. 选中 scope → loading → 左栏 + 画布同步刷新
3. **语文**：画布内**无**课文 chip 条，scope 仅能通过 Picker 切换

### 3.2 节点 / 原子点点击

| 对象 | 行为 |
|------|------|
| 可练点（KP / TP） | 选中高亮 + 打开 `DiagnosisCard` → 练题 |
| 结构节点（KN / 能力域大圆） | 仅高亮，不弹诊断卡 |
| 画布空白 | 取消选中 |

练题返回后：恢复 scope、高亮该节点、刷新掌握度（mock 写 `localStorage`）。

### 3.3 画布形状图例

- 组件：`KnowledgeGraphShapeLegend`，画布**右下角**紧凑浮层
- **只说明形状**，掌握五态已在左栏展示

| 学科 | 图例项 |
|------|--------|
| 语文 | 能力域 / 能力点 / 课文（整单元多课文来源时） |
| 数学 | 主题 / 知识点 / 考点（菱形） |
| 英语 | 语法 / 词汇 / 知识点 |

### 3.4 平板触控

- 触控优先：不依赖 hover、`title` 悬停
- 点击后**选中环持续可见**，直至点其他位置

### 3.5 顶栏学科切换

- 支持滑动 / 点击切换
- **不展示**「左右滑动切换学科」等提示文案
- 切换后竖线扫光 + 图谱刷新

## 4. 语文 · 能力气泡图

**组件**：`ChineseUnitLessonBubbleView` → `ChineseSkillMapView`  
**布局**：`bubbleMapLayout.ts`

| 项 | 规则 |
|----|------|
| 数据源 | 当前课本 `knowledge_tree`；用 `catalog_id` 匹配单元 scope；**不读** `catalog_tree.knowledge_points[]` |
| 分组 | 沿 `parent_id` 找顶层 `KnowledgeNode` 作为能力域；圈内为 KP / TP |
| 大圆尺寸 | 按组内原子数比例缩放：多 → 大，少 → 小 |
| 大圆位置 | **错落绝对定位**，禁止左右并排；2 个时少原子左下 (28%, 68%)、多原子右上 (62%, 30%) |
| 圈内展示 | 仅节点 `name` + 掌握色；整单元多课文时可选灰色 `catalog_name` |
| 原子点排列 | `atomAnchors` 稳定错落 |

## 5. 数学 · 左→右关系树

**组件**：`ScopedKnowledgeGraph` + `layoutKnowledgeGraph()`  
**开关**：`KG_SCHEME_E_ENABLED = true`

| 项 | 规则 |
|----|------|
| 切图 | `catalog` 挂载 + `knowledge_tree` 命中子树；祖先最多补 **1 层** KN |
| 布局 | 确定性左→右树；兄弟纵向排布；**禁拖拽** |
| 节点视觉 | theme 虚线圆环 15px / knowledge 实心圆 10px / testing **菱形** 6px |
| 不展示 | 更深层学科分类、虚线簇圈 |
| 手势 | 双指缩放、拖拽平移；进入时 `zoomToFit` |

---

## 6. 英语 · 双气泡图

**组件**：`EnglishBubbleMapView`  
**布局**：与语文共用 `bubbleMapLayout.ts`

| 项 | 规则 |
|----|------|
| Scope | 仅 Unit；**永不**升到 Module |
| 切图 | **仅** `catalog_tree.knowledge_points`；不用 `knowledge_tree` 子树（避免字母桶污染） |
| 分组 | 纯英文 TP → 词汇；含中文 KP/TP → 语法·语音 |
| Unit 名 | **仅左栏**展示，画布内不显示 |
| 大圆 | 尺寸、错落规则同语文；过滤字母桶与跨 Unit 节点 |
| 不渲染 | parent 边 |
