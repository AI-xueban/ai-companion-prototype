# 知识图谱呈现粒度 · 数据分析报告

> **分析范围**：深圳教材清单下 54 本课本（语数英 × 小初 1–9 年级 × 上下册）  
> **数据来源**：`知识图谱/knowledge_trees/knowledge_trees/` 全量 JSON  
> **分析日期**：2026-06-16  
> **目的**：为「按单元/章」还是「按小节」呈现知识图谱，提供数据依据与竞品参考

---

## 一、Executive Summary（结论先行）

| 维度 | 建议 |
|------|------|
| **总体策略** | **分学科默认粒度**，而非全学科统一；UI 统一为「章 → 节」二级切换，但**默认打开的 scope 因学科而异** |
| **语文** | ✅ **默认按「单元/章」**；节级 55% 为空，平均仅 3 节点，小节图谱常「空图或单点」 |
| **数学** | ✅ **默认按「小节/课时」**；节级中位 4–7 节点，6–15 节点占比高，最符合图谱可读甜区 |
| **英语** | ✅ **默认按「Unit/小节」**；Module 级平均 55 节点过载，Unit 级平均 ~16 节点更合适 |
| **兜底规则** | 当前 scope 节点数 `< 5` → 自动上卷到章；`> 35` → 提示切到小节或开启「聚合视图」 |
| **竞品对齐** | 科大讯飞偏 **「章节图谱 + 颜色掌握度 + 先修箭头」**；学而思偏 **「原子知识点网状图 + 路径规划」**，底层粒度更细，但展示时会**按学习场景折叠** |

**一句话**：数据不支持「一刀切按章」或「一刀切按节」——**数学/英语用小节，语文用章；产品上用同一套切换器，智能决定默认打开哪一层。**

## 二、你的数据长什么样

每本课本 JSON 含两层结构：

```
catalog_tree          →  教材目录（章/单元 → 节/课/Unit）
knowledge_tree        →  学科知识关系树（KnowledgeNode → KnowledgePoint → TestingPoint）
                         通过 catalog_id 挂到具体课文位置
                         通过 parent_id  表达父子/层级关系
```

节点类型分布（三科差异极大）：

| 学科 | 平均总节点 | KnowledgePoint | TestingPoint | 关系树深度 |
|------|-----------|----------------|--------------|-----------|
| 语文 | 432 | 138 | 257 | ~5 层 |
| 数学 | 1,042 | 471 | 411 | ~6 层 |
| 英语 | 4,912 | 147 | **4,713** | ~5 层 |

> **关键发现**：英语图谱的「节点膨胀」主要来自 **单词/考点级 TestingPoint**，不是语法树本身。Module 级图谱会显得「密密麻麻」，但大部分是词汇点，学生认知上更适合在 Unit 内消化。

## 三、全量 54 册 · 章 vs 节 节点规模

基于与原型相同的 scope 切图算法（catalog 挂载点 + knowledge_tree 子树 + 祖先链补齐），统计 **实际渲染到画布上的节点数**：

### 3.1 章/单元级（573 个章样本）

| 分位数 | 节点数 |
|--------|--------|
| 中位数 P50 | **12** |
| P75 | 24 |
| P90 | 62 |
| 最大值 | 179 |
| 节点 > 80（过载） | 36 册章（6.3%） |

**解读**：半数以上的章，全章图谱只有 **≤12 个节点**——对小学生来说，一屏可读、关系清晰，**章级展示在规模上是友好的**。

### 3.2 小节/课时级（2,498 个节样本）

| 分位数 | 节点数 |
|--------|--------|
| 中位数 P50 | **4** |
| P75 | 7 |
| P90 | 17 |
| 最大值 | 154 |
| 节点 = 0（空节） | **992（39.7%）** |
| 节点 1–5（过少） | 740（29.6%） |
| 节点 6–20（甜区） | **582（23.3%）** |
| 节点 > 80（过载） | 3（0.1%） |

**解读**：

- **近 70% 的小节** 节点 ≤5 或为空 → 按节展示会出现大量「空图/两点一线」，**体验差、学生无法理解「图谱意义」**。
- 仅 **约 23%** 的小节落在 6–20 节点的「可读性甜区」→ 小节并非普适默认，但在 **数学、部分英语 Unit** 上表现最好。

## 四、分学科深入（决定默认粒度的核心）

### 4.1 语文（18 册汇总）

| 指标 | 章级 | 节级 |
|------|------|------|
| 平均节点 | **12** | 3 |
| 典型最大值 | ~20 | ~14 |
| 空 scope 占比 | 极低 | **空节 544/980 ≈ 55%** |
| 6–15 节点的小节数 | — | 112 |

**四年级上册示例**（8 个单元）：

| 单元 | 章级节点 | 节均节点 | 最大单节 |
|------|---------|---------|---------|
| 第一单元 | 12 | 2 | 5 |
| 第三单元 | 23 | 4 | 12 |
| 第四单元 | 27 | 4 | 15 |

**语文数据特征**：

- 知识点多挂在 **「语文园地」「习作」** 等复合栏目，目录节（如「1 观潮」）本身 **常无独立 knowledge_points**。
- knowledge_tree 偏 **文学常识、作家作品、写作技法** 等横切分类，与课文目录 **弱对齐**。
- 学生心智模型是 **「这单元学了什么」**，不是「这一课的字词图谱」。

**→ 建议：默认「单元/章」；节仅作目录导航，不作为默认图谱 scope。**

---

### 4.2 数学（18 册汇总）

| 指标 | 章级 | 节级 |
|------|------|------|
| 平均节点 | 20 | **6** |
| 典型最大值 | ~38 | ~17 |
| 空 scope | 50 空章 | 空节 239/1017 ≈ 23% |
| 6–15 节点的小节 | — | **336** |

**四年级上册示例**（11 章）：

| 章 | 章级节点 | 节均 | 代表小节 |
|----|---------|------|---------|
| 一 认识更大的数 | 19 | 7 | 数一数 9 节点 |
| 三 乘法 | 15 | 6 | 卫星运行时间 10 节点 |
| 六 除法 | 20 | 6 | 各课时 6–10 节点 |

**数学数据特征**：

- 目录与 knowledge_tree **对齐最好**：几乎每课时都有 KnowledgePoint。
- 章级 15–25 节点仍可读，但 **小节 6–10 节点** 更接近「一张图讲清一个技能块」。
- 存在「整理与复习」「总复习」等 **0 节点空章**，需 UI 过滤或合并。

**→ 建议：默认「小节/课时」；章级作为「本章地图概览」（缩略聚合视图）。**

### 4.3 英语（18 册汇总）

| 指标 | Module/章级 | Unit/节级 |
|------|------------|-----------|
| 平均节点 | **55** | **16** |
| 典型最大值 | ~75 | ~42 |
| 空 scope | 极少 | 空节 209/501 ≈ 42% |
| 16–30 节点的小节 | — | 92 |
| 31+ 节点的小节 | — | 89 |

**四年级上册示例**（4 Module × 6 Unit）：

| Module | Module 级节点 | Unit 均节点 | 最大 Unit |
|--------|--------------|------------|-----------|
| Module 1 | 61 | 12 | 24 |
| Module 3 | 81 | 17 | 36 |

**英语数据特征**：

- **Module 级必过载**（60–80 节点 + 大量单词 TestingPoint）→ 不适合默认画布。
- **Unit 级 ~12–17 节点** 是最佳平衡；部分 Unit 仍达 30+，需折叠「词汇群」。
- 空节多因 **Review / Project** 等栏目无图谱挂载。

**→ 建议：默认「Unit/小节」；Module 仅作章节选择器分组，不直接渲染全 Module 图谱。**

## 五、美观与学生可理解性 · 设计阈值

结合信息可视化与 K12 认知负荷研究（一般单屏可舒适追踪 **7±2 个主概念，总量 15–25 元素上限**）：

| 节点规模 | 体验 | 建议 |
|---------|------|------|
| 0 | 空图 | 隐藏图谱，展示「本课暂无知识点映射」+ 课文摘要 |
| 1–5 | 过稀 | 不上卷则显示列表态，而非力导向图 |
| **6–20** | ✅ 甜区 | 默认图谱模式：节点 + 有向边 + 掌握色 |
| 21–35 | 可接受 | 图谱 + 默认折叠 L3 TestingPoint（尤其英语词汇） |
| 36–60 | 过载 | 强制小节 scope 或「聚合卡片」（按 KnowledgeNode 合并） |
| 60+ | 严重过载 | 仅展示结构树/大纲模式，不展示全网状图 |

**关系边可读性**：

- 你的数据以 **parent_id 父子边** 为主，同 scope 内平均边数 ≈ 节点数 − 根节点数，结构偏 **树/DAG**，适合 **左→右分层布局**（参考你提供的原型图），比纯力导向更易理解先修顺序。

## 六、竞品逻辑对照

### 6.1 科大讯飞（学习机 / 智慧课堂）

| 维度 | 做法 | 与你们数据的关系 |
|------|------|----------------|
| **呈现单位** | 公开材料强调「**一个章节的知识点图谱**」；测学练闭环在章节内完成 | 与 **语文默认章级** 一致；数学若按章也勉强可用（~20 节点） |
| **视觉** | 网状图 + **颜色标记掌握度** + **先修/后置箭头** | 与当前五态色 + 有向边方案一致 |
| **交互** | 少量测评后更新图谱 → 点击薄弱点 → 微课 + 针对练 | scope 应稳定在「一次测评可覆盖的范围」→ 偏小节更合理（数学/英语） |
| **分层** | T20 等机型有 **基础/进阶/拔高分层图谱** | 可在同一小节内按 KnowledgeNode / KnowledgePoint 分层折叠 |

**讯飞启示**：**展示 scope 与学习闭环 scope 一致**——测评 10 题能覆盖的范围，就是图谱默认范围；这更接近 **数学/英语的小节**，而非语文的整个单元。

### 6.2 学而思（精准学 Pro / 学习机）

| 维度 | 做法 | 与你们数据的关系 |
|------|------|----------------|
| **底层** | **原子级知识图谱**，网状结构，父子 + 前后置关系 | 对应你们的 knowledge_tree 全树，不能一次全展示 |
| **展示** | 精准学 Pro：**按学习路径动态展开**，基础/标准/备考模式切换 | 等价于「同一课本多种 scope + 渐进 disclosure」 |
| **模式** | 行业常见三态：**大纲（章节目录） / 导图（层级） / 图谱（网状）** | 章→节切换器 = 大纲；scope 内 DAG = 图谱 |
| **目标** | 找弱项 → 推荐路径 → 消灭红点 | 英语需在 Unit 内做词汇聚合，否则红点过密 |

**学而思启示**：**底层原子化、展示场景化**——不要问「按章还是按节」，而是 **「默认场景用哪一层，其余层可下钻」**。

### 6.3 竞品 vs 你的数据 · 对齐矩阵

| 学科 | 讯飞倾向 | 学而思倾向 | 你的数据最优 | **推荐默认** |
|------|---------|-----------|-------------|-------------|
| 语文 | 章节图谱 | 路径动态展开 | 章 12 节点 / 节 3 节点 | **章** |
| 数学 | 章节图谱 | 原子 + 路径 | 章 20 / 节 6–10 | **节**（章作概览） |
| 英语 | 章节图谱 | 原子网状 | Module 55 / Unit 16 | **Unit/节** |

## 七、产品方案建议（可直接进 PRD）

### 7.1 推荐：「智能默认 + 统一切换」双轨

```
课本
 └── 章/单元（Picker 第一级，始终可见）
      └── 节/课时（Picker 第二级，可选）
           └── 图谱画布（当前 scope）
```

**默认 scope 规则（伪代码）**：

```
if subject == 语文:
  default = 章
elif subject == 数学:
  default = 当前进度节 || 章内第一个 nodes>=6 的节 || 章
elif subject == 英语:
  default = 当前 Unit || 章内第一个 nodes>=8 的节
if nodes(default) < 5:  default = 上级章
if nodes(default) > 35:  折叠 TestingPoint 或提示切小节
```

### 7.2 三种展示模式（借鉴学而思三态，一套数据）

| 模式 | 适用 | 数据源 |
|------|------|--------|
| **大纲模式** | 快速切换章/节，看掌握度条 | catalog_tree |
| **图谱模式** | 当前 scope 6–35 节点 | scope graph |
| **列表模式** | 节点 <6 或英语词汇聚合 | knowledge_points 列表 + 状态色点 |

### 7.3 不建议的做法

| 做法 | 原因 |
|------|------|
| 全学科默认按节 | 语文 55% 空节，学生会看到大量空白 |
| 全学科默认按章 | 英语 Module 60+ 节点，视觉噪音极大 |
| 整本书一张大图 | 英语 2867 节点，数学 971 节点，失去「图谱」意义 |
| 仅 catalog 挂载点、不补 knowledge_tree 祖先 | 关系断裂，图不连通（当前 prototype 已补齐） |
