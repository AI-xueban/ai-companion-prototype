## 1. 模块定位

**入口名称**：知识图谱  
**并列模式**：学习路径 | 知识图谱（左侧竖条切换）  
**一句话价值**：按当前课本的章/节，把知识点关系画成一张图，看清掌握情况，点薄弱点就能练。

### 设计原则

| 原则 | 说明 |
|------|------|
| **看得懂** | 单屏节点控制在 **6–20 个**（可读甜区），避免图太大或太碎 |
| **找得到** | 分学科默认范围：语文看「单元」，数学看「课时」，英语看「Unit」 |
| **用得上** | 测学练闭环：点节点 → 诊断 → 练题 → 图谱刷新 |
| **可扩展** | 同一套 UI 框架适配语数英及未来更多学科 |

### 非目标（本期不做）

- 整本书一张全局大图
- 与后端真实学情 API 全量对接（原型阶段 mock 掌握度）
- 教师端图谱编辑

## 2. 页面结构文案

### 2.1 顶栏

| 位置 | 文案 / 行为 |
|------|------------|
| 左侧 | **学习路径** / **知识图谱**（竖向切换） |
| 居中 | **语文** / **数学** / **英语**（可滑动或点击切换，带波浪下划线；**无**「左右滑动切换学科」提示文案） |
| 右侧 | 用户状态栏（金币、XP 等，沿用现有） |

> 打开章节 Sheet、诊断卡等浮层时，左侧模式竖条隐藏，避免与内容重叠。

### 2.2 主区域 · 左栏（约 272px，三张卡片）

#### 卡片 A · 章节选择

| 元素 | 文案规则 |
|------|---------|
| 副标题 | 课本全名，如「小学数学 4年级上册」 |
| 主标题 | 当前范围名：语文仅单元名；数学为「章名 · 节名」；英语仅 Unit 名 |
| 交互提示 | 整卡可点，右侧 `>`，打开章节选择 Sheet |

**章节 Sheet 标题**：切换章节  
**Sheet 结构（分学科）**：

| 学科 | Picker 结构 |
|------|------------|
| 语文 | 单元列表 → 展开后显示课文；**点单元名 = 切整单元**；**无「整单元概览」行**；Chevron 仅展开 |
| 数学 | 章列表 → 展开后「整章概览」+ 课时列表 |
| 英语 | 全书 **Unit 平铺**；无 Module / Revision / Project |

---

#### 卡片 B · 掌握度概览

| 元素 | 文案 |
|------|------|
| 卡片标题 | **当前掌握度** |
| 核心数字 | **{N}%**（环形图中心） |
| 五态标签 | 已掌握 / 复习中 / 未掌握 / 探索中 / 待识别 |
| 统计范围说明（可选小字） | 仅统计当前章节/小节内的知识点 |

**掌握率计算口径（对内）**  
已掌握数 ÷（总节点数 − 待识别数），四舍五入为整数百分比。

---

#### 卡片 C · 薄弱知识点

**有薄弱点时**

| 元素 | 文案 |
|------|------|
| 主文案 | **{N} 个薄弱知识点**（N 用红色 `#FF3B30` 强调） |
| 交互 | 点击 → 图谱高亮第一个薄弱节点并打开诊断卡 |

**无薄弱点时（weak = 0）**

| 学科 | 主文案 |
|------|--------|
| 语文 | **本章暂无明显薄弱，可学下一章** |
| 数学 / 英语 | **本节暂无明显薄弱，可学下一节** |

| 元素 | 文案 |
|------|------|
| 卡片样式 | 绿色轻底（`emerald-50` 正向反馈，非错误空态） |
| 快捷按钮 | **前往 · {下一章/节名称}**（有下一范围时显示） |
| 已是最后一章/节 | 仅显示主文案，不显示按钮 |

---

### 2.3 主区域 · 右栏 · 图谱画布

| 元素 | 文案 / 行为 |
|------|------------|
| 加载中 | 居中 loading 动画，无额外文字 |
| 空态 | **该章节暂无知识点关系数据** |
| 无演示数据 | **暂无演示数据** / **当前仅接入四年级上册 · 语数英** |
| 加载失败 | **加载知识图谱失败** |
| 右下角摘要 | **{节点数} 节点 · {边数} 关系**（数学 force-graph；语文/英语气泡无关系边时可隐藏） |
| 右下角图例 | 见 §2.3.1 形状说明（画布内嵌，不含掌握五态） |
| 学科切换 | 竖向扫光动画（视觉刷新，无额外文案） |

#### 2.3.1 画布形状图例（右下角）

> 组件 `KnowledgeGraphShapeLegend`；紧凑白底浮层；掌握五态仅在左栏展示，图例**只说明形状**。

| 学科 | 图例项 |
|------|--------|
| **语文** | 能力域 / 能力点 / 课文（仅整单元且多课文来源时显示「课文」） |
| **数学** | 主题 / 知识点 / **考点**（考点图标为菱形） |
| **英语** | 语法 / 词汇 / **知识点**（圈内原子点；不用「可练」） |

**气泡布局（语文 / 英语）**

- 能力域/维度 **大圆** 按圈内原子数量比例缩放：多 → 大，少 → 小
- 多个大圆 **错落有致**，不左右并排；双气泡时少原子偏左下、多原子偏右上
- 画布内 **不提供** 课文 chip 切换条

**图谱交互（行为说明，无固定文案）**

| 操作 | 行为 |
|------|------|
| 点击节点 / 原子点 | 高亮选中（选中环持续可见）+ 可练点打开诊断卡 |
| 双指 / 滚轮 | 缩放（数学 force-graph） |
| 拖拽 | 平移（数学 force-graph） |
| 进入时 | 数学自动 zoomToFit；语文/英语气泡固定错落布局 |

### 2.4 UI 风格约束

| 项 | 规范 |
|----|------|
| 背景 | `#F5F7FA` 渐变 + 柔光 orb + 点阵（与学习路径 sync 模式一致） |
| 卡片 | 白底 90% 透明、圆角 2xl、浅边框 |
| 节点 | 圆点 + 五态色；不必强制六边形 |
| 边 | 品牌 indigo 半透明有向箭头 |
| 诊断卡 | 深色玻璃卡片，与明亮图谱背景形成对比 |

## 3. 分学科默认展示范围

> 用户首次进入或切换学科时，自动打开的范围规则（`resolveDefaultScope`）。

| 学科 | 默认打开 | 选取逻辑 | 禁止默认 |
|------|---------|---------|---------|
| **语文** | 单元 / 章 | 上次单元或第一单元 | 单篇课文（多数节点过少） |
| **数学** | 小节 / 课时 | 上次位置；否则第一个 **≥6 节点** 的小节 | 整章（仅手动「整章概览」） |
| **英语** | Unit | 上次 Unit；否则第一个 **≥8 节点** 的 Unit | Module / Revision / Project |

### 兜底规则

| 节点数 | 展示策略 | 当前实现 |
|--------|---------|---------|
| 0 | 空态 | 「该章节暂无知识点关系数据」 |
| 1–5 | 过稀 | 数学：手动选中可升到章；英语：保持 Unit；语文：直接展示 |
| **6–20** | ✅ 标准图谱 | 力导向图 + 五态色 |
| 21–35 | 可接受 | 标准图谱（P2：折叠细粒度点） |
| 36–60 | 过载 | 未强制拦截（P2：提示缩小范围） |
| 60+ | 严重过载 | 未强制拦截（P2：仅结构树） |

### 数学「升章」数据参考（28 册实测）

| 场景 | 占比 |
|------|------|
| 小节 1–4 节点，选中会升到章 | **15.4%**（小学 19.2%，初中 8.3%） |
| 默认进入（优先 ≥6 节点） | **几乎不触发升章** |
| 四年级上册演示课本升章小节 | **28.6%**（10/35） |

### 四年级上册验证样例

| 学科 | 推荐默认 scope | 典型节点数 | 禁止默认 |
|------|---------------|-----------|---------|
| 语文 | 「第三单元」 | ~23 | 单篇课文（多数 <5） |
| 数学 | 「数一数」 | ~9 | — |
| 英语 | 「Unit 1 Meeting new people」 | 12–24 | Module 1（61 节点） |

### 记忆上次位置

切换章/节后写入 `localStorage`：`kg-last-scope-{textbookId}`  
再次进入时恢复上次位置；数学/英语按分学科规则重算默认小节/Unit。

### 语文方案 C · 主题折叠（已回退，P2 备选）

> 方角卡片 + `N项` 角标折叠视觉已移除，当前始终展示全量圆点图谱。

| 状态 | 用户可见文案 |
|------|------------|
| 折叠概览 | `{N} 个主题 · 点击带「项」标记的节点可展开`（未启用） |
| 已展开 | `点击空白处或再次点击主题可收起`（未启用） |

## 5. 节点诊断卡 · 文案与闭环

**触发**：仅点击 **`KnowledgePoint` / `TestingPoint`**（`isPracticable === true`）时弹出；**`KnowledgeNode` 主题节点点击只展开子图，不弹卡**。  
**形态**：右侧滑入 `DiagnosisCard`（深色玻璃卡片）

### 5.1 状态标签（卡片顶部）

| 状态 | 标签文案 |
|------|---------|
| mastered | 已掌握 |
| reviewing | 需复习 |
| weak / not_mastered | 未掌握 |
| exploring | 探索中 |
| unknown | 未知 |

### 5.2 主操作按钮（按节点状态）

| 状态 | 按钮文案 | 样式语义 |
|------|---------|---------|
| unknown / exploring | **开始探索** | 品牌渐变 |
| weak / not_mastered | **专项攻克** | 红橙渐变 |
| reviewing | **巩固强化** | 琥珀渐变 |
| mastered | **挑战高阶** | 翠绿渐变 |

### 5.3 次要操作

| 按钮 | 文案 |
|------|------|
| 题库入口 | **我的题库** |
| 错题列表 | **错题本** |

### 5.4 测学练闭环

```
点节点
  → 打开诊断卡
  → 点「专项攻克」/「巩固强化」等
  → 进入做题页（地图/诊断卡入口：跳过视频，直接做题）
  → 完成 / 退出
  → 返回知识图谱
  → 刷新掌握度 + 节点颜色（mock 持久化到 localStorage）
  → 自动重新打开该节点诊断卡 + 图谱扫光刷新
```

**闭环对内说明**

- 练题完成后，节点状态 mock 提升（如 weak → 已掌握）
- 左栏薄弱数、环形图、图谱节点色同步刷新
- 通过 `dataVersion` 重挂载 + `kg-return-node-{textbookId}` 恢复节点选中态

## 6. 章节选择 Sheet · 文案

| 元素 | 文案 |
|------|------|
| Sheet 标题 | 切换章节 |
| 课本标识 | {课本名} |
| 章项 | {章名}，如「第一单元」「一 认识更大的数」 |
| 节项 | {节名}，如「1 观潮」「数一数」「Unit 1 Meeting new people」 |
| 整章选项（仅数学） | **整章概览** |
| 整单元选项（语文） | **无**；点单元名即切整单元 |
| 当前选中 | 高亮 + 「当前」标签 |

**切换流程**

```
用户点击卡片 A
  → 打开 ChapterScopePicker
  → 语文：点单元名切整单元 / 展开后点课文切单篇
  → 数学：选「整章概览」或某一课时
  → 英语：选某一 Unit（平铺列表）
  → loading → 刷新左栏统计 + 右栏图谱 → 写入 localStorage
```

**学科切换**：重置到该学科课本 + 按 §3 规则计算默认 scope，带横向滑入 + 竖线扫光动画。

## 8. 对外 / 帮助页话术

可用于产品介绍、新手引导、家长说明：

- **看得清**：一张图讲清「这一章 / 这一节」要掌握什么，不用翻整本书。
- **找得准**：红色节点就是薄弱点，点一下就能练，不用自己猜哪里不会。
- **学得透**：练完回来，图谱颜色会更新，进步看得见。
- **分科智能**：语文按单元看全貌，数学按课时精学，英语按 Unit 精学，不会一张图塞满整本书。

**与竞品对齐的用户感知**

| 能力 | 用户感知话术 |
|------|------------|
| 掌握度可视化 | 绿色已掌握、红色待攻克，一眼看懂 |
| 关系可读 | 箭头表示先修关系，知道该先学哪个 |
| 弱项闭环 | 点红点 → 练题 → 变绿，和讯飞/学而思一样闭环 |
| 智能默认 | 不用自己选范围，打开就是最合适的一节/单元 |

## 9. 本期范围说明

### 已支持（P0 原型）

- 四年级上册语数英演示数据（课本 ID：4686 / 2964 / 5275）
- 左栏三卡片 + 明亮风图谱画布
- 分学科 `resolveDefaultScope`（语=章，数/英=小节）
- 语文/英语气泡错落布局 + 比例尺寸
- 画布右下角形状图例（三科 variant）
- weak = 0 正向引导 + 下一节/章跳转
- 节点 → 诊断 → 练题 → 返回刷新闭环
- 章/节位置记忆（localStorage）
- 左侧模式竖条 + 顶栏学科切换布局

### 暂未支持

| 项 | 说明 |
|----|------|
| 真实学情 API | 掌握度仍为 hash mock + 练题后 localStorage 覆盖 |
| 节点 >35 聚合 | TestingPoint 折叠、词汇群聚合 |
| 列表模式 fallback | 节点 <5 时的列表态 UI |
| DAG 固定布局 | 当前为力导向图，P2 可改左→右分层 |
| 与小晤 / 远征路径打通 | 图谱 nodeId 与 sync 关卡统一（P3） |
| 全年级 54 册接入 | 当前仅 demo 三科四年级上册 |
