# 错题预览 · 本题练习情况 · 需求文档（v0.1）

> 合并：掌握程度文案规则 / 题目状态定义 / 与知识点边界 / 题目内容展示规则  
> 对应实现：`MistakePreviewResultCard`、`QuestionRichContent`、`StatusRing`  
> 关联入口：`SingleQuestionResultCard`、`QuestionPreviewModal`、`MistakeVault`

---

## 1. 背景与目标

错题预览结果卡右侧原先使用「掌握程度评估」标题，文案含「已连续正确」「7 天后提醒」等表述，存在两类问题：

1. **数据不可验证**：系统当前拿不到「连续答对 N 次」「N 天后提醒」等字段，不应展示。
2. **语义易混淆**：用户易将「本题练得怎么样」理解为「知识点是否掌握」。

**目标**：本区域仅描述**当前这道题**的练习与复习状态，与下方「关联知识点」区块严格区分。

---

## 2. 信息架构边界

```
错题预览结果卡（右侧解析区）
├── 答案摘要（你的答案 / 参考答案）
├── 讲解视频
├── 本题解析
├── 关联知识点          ← 知识点维度（健康分、图谱节点）
└── 本题练习情况        ← 单题维度（本篇需求范围）
```

| 区块 | 统计维度 | 核心指标 | 禁止混用 |
|------|----------|----------|----------|
| **本题练习情况** | 当前题目 | 本题对错次数、本题练次、本题复习状态 | 不得引用知识点健康分、图谱掌握度 |
| **关联知识点** | 知识点节点 | 健康分、变化量 Δ | 不得代表「本题是否练会」 |

---

## 3. 题目练习状态定义（`CognitiveState`）

系统对**单题**使用三档认知态，与 `StatusRing` 视觉一致：

| 状态值 | 视觉 | 中文标签（本题语境） | 产品含义 |
|--------|------|----------------------|----------|
| `GAP` | 🔴 断口环 | 待攻克 | 本题尚未掌握，或刚答错、待重做 |
| `FADED` | 🟡 双层环 | 待复习 | 本题进入间隔复习周期 |
| `MASTERED` | 🟢 实心环 / 「本题已掌握」徽章 | 本题已掌握 | 本题在错题本中标记为已掌握，或答题结果页判定本次正确 |

> **注意**：`CognitiveState` 类型注释虽写「与知识图谱挂钩」，但在错题预览卡中**仅表示单题状态**，不读取图谱节点数据。

### 3.1 状态来源（按入口）

| 入口 | 状态如何产生 |
|------|----------------|
| **答题结果页** `SingleQuestionResultCard` | 本次答对 → `MASTERED`；本次答错 → `GAP`（仅二档，无 `FADED`） |
| **错题本** `MistakeVault.mapMistakeToQuestion` | `new` → `GAP`；`reviewing` → `FADED`；`mastered` → `MASTERED` |
| **题库 mock** `QuestionItem.cognitiveState` | 静态字段，按题配置 |

### 3.2 与错题本 `MistakeItem.status` 映射

| 错题本状态 | 中文 | 映射 `CognitiveState` | 记忆复习语义（参考） |
|------------|------|------------------------|----------------------|
| `new` | 待攻克 | `GAP` | 答错重置，今日攻克 |
| `reviewing` | 待复习 | `FADED` | Stage 1/2/3，明天 / 3 天 / 7 天复习 |
| `mastered` | 已掌握 | `MASTERED` | 30 天防遗忘抽查 |

## 4. 「本题练习情况」区块 UI 规范

### 4.1 固定文案（标签层）

| 元素 | 文案 | 说明 |
|------|------|------|
| 区块标题 | **本题练习情况** | 不用「掌握程度评估」 |
| 副标题 | **仅统计本题的作答记录** | 明示统计范围 |
| 掌握徽章 | **本题已掌握** | 仅 `MASTERED` 时显示，不用「已掌握」 |
| 对错统计 | **本题错: N次** / **本题对: N次** | 前缀「本题」 |
| 圆环中心 | **N** + **本题练次** | N = 对错次数之和 |

### 4.2 数据字段

| 字段 | 来源 | 说明 |
|------|------|------|
| `practiceStats.correct` | 父组件传入 | 本题累计答对次数 |
| `practiceStats.wrong` | 父组件传入 | 本题累计答错次数 |
| `question.cognitiveState` | 题目对象 | 三档状态 |
| `question.userAnswer` | 题目对象 | 用于判断「本次作答」是否正确 |

**父组件传参约定**：

- `SingleQuestionResultCard`：传入真实 `attemptStats` 对错次数。
- `QuestionPreviewModal`（`source="mistake"`）：**不得硬编码** `{ correct: 1, wrong: 0 }`；应传错题本真实统计或默认 `{ 0, 0 }`（待后续接入）。

## 5. 说明文案规则（优先级从高到低）

文案函数：`getQuestionPracticeReason(state)`。  
**先判断本次作答，再按状态分支。**

### 5.1 优先级 1：本次作答（覆盖状态）

| 条件 | 说明文案 |
|------|----------|
| 有 `userAnswer` 且本次答错 | 本题本次作答有误，建议先看解析，再做几道变式巩固。 |

### 5.2 优先级 2：按 `CognitiveState` + 历史次数

| 状态 | 附加条件 | 说明文案 |
|------|----------|----------|
| `MASTERED` | `correctCount > 0` | 本题累计答对 {N} 次，可按计划复习。 |
| `MASTERED` | `correctCount === 0` | 本题已标记掌握，可按计划复习。 |
| `FADED` | — | 本题进入复习周期，建议尽快巩固以防遗忘。 |
| `GAP` | `wrongCount > 0` | 本题已累计错 {N} 次，建议重做并多练变式。 |
| `GAP` | `wrongCount === 0` | 建议通过变式多练几道同类题，巩固本题。 |

### 5.3 禁止出现的表述

以下表述**当前无可靠数据源**，不得在「本题练习情况」中使用：

| 禁止表述 | 原因 |
|----------|------|
| 已连续正确 / 已连续 N 次正确 | 无连续正确 streak 字段 |
| 连续 5 次正确 | 同上 |
| 7 天后将提醒复习 | 复习日程未传入本组件（`deadlineLabel` 在错题本有，但未接入） |
| AI 正在分析你的薄弱点 | 无实时分析结果 |
| 巩固相关知识点 | 易与「关联知识点」区块混淆；应改为「巩固本题」 |
| 完全掌握该知识点 | 属于知识点维度 |

## 6. 题目内容展示规则（`QuestionRichContent`）

错题预览左侧题干区同步约定，避免重复编号与图文割裂。

### 6.1 题干区

| 规则 | 说明 |
|------|------|
| 图片 + 文字合并 | 使用 `QuizStem`，同一卡片内展示，不拆成「图一块、字一块」 |
| 分区标签 | 阅读类 →「阅读材料」；其余（含图片题）→「题目」 |
| 有图 + 有小题 | 小题列表上方显示「作答小题」 |

### 6.2 子题序号

| 规则 | 说明 |
|------|------|
| 去重编号 | `question` 已以 `（1）` / `(1)` / `1.` 开头时，**不再**叠加 `1. 2. 3.` |
| 无内置序号 | 自动加 `1.`、`2.`、`3.` 前缀 |

示例：

- 数据：`（1）第 3 层有…` → 展示：`（1）第 3 层有…`（✓）
- 错误：`1. （1）第 3 层有…`（✗，双重编号）

## 7. 与知识图谱的关系（明确不做的事）

| 项目 | 本题练习情况 | 知识图谱 / 关联知识点 |
|------|----------------|------------------------|
| 统计单位 | 单道题 | 知识点节点 |
| 健康分 | 不使用 | 使用（当前为 mock，待接真实数据） |
| 状态枚举 | `GAP` / `FADED` / `MASTERED`（3 档） | `unknown` / `exploring` / `weak` / `reviewing` / `mastered` 等 |
| UI 位置 | 解析区靠下 | 独立「关联知识点」列表 |

**原则**：两套体系可「关联展示」，但**不得互相替代**。用户在本题区块看到的掌握结论，只代表这道题。

## 8. 验收清单

- [ ] 区块标题为「本题练习情况」，副标题为「仅统计本题的作答记录」
- [ ] `MASTERED` 显示「本题已掌握」徽章，非「已掌握」
- [ ] 对错次数带「本题」前缀；圆环为「本题练次」
- [ ] 文案中无「连续正确」「N 天后提醒」「知识点掌握」类不可验证表述
- [ ] 本次答错时，优先显示「本题本次作答有误…」
- [ ] `correctCount` / `wrongCount` 与文案中数字一致
- [ ] 「关联知识点」与本题区块语义不重叠
- [ ] 子题无 `1. （1）` 双重编号
- [ ] 图片题题干图字同卡展示
