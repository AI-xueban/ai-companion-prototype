## 0. XP vs 金币（一页读懂）

> **对内讲解 / 评审用。** 经验回答「学得好不好、成长快不快」；金币回答「愿不愿意把学习成果拿出来分享或兑换」。

### 0.1 一句话

| | **经验 XP** | **金币 Coins** |
|---|-------------|----------------|
| **像什么** | 学习「成长值」 | 可花的「零花钱」 |
| **主要用途** | 等级、联赛、今日学习目标 | 爱心捐赠、许愿池、装扮商城 |
| **发放频率** | 高（几乎每次有效学习） | 低（里程碑触发） |
| **通胀风险** | 低（主要影响等级感） | **高**（必须日 cap + 消耗出口） |

- **XP**：你学了多少、成长了多少 → **可以大方发**
- **金币**：你攒了多少、能捐能兑 → **必须吝啬发**

### 0.2 怎么获得（v1）

**经验（主成长货币）**

- 测验 / 答题：按题公式 `题数 × 10 × 难度 × 表现`
- 视频有效观看 ≥80%：+15～25 XP（不发币）
- 微课首次完成：+25～35 XP
- 错因标注、变式订正等纠错链：+5～10 XP

**金币（兑换 / 公益货币）——不按题发**

| 场景 | 金币 | 频次 |
|------|------|------|
| 完成今日任务 | +10～20 | 每任务 1 次 |
| 当日首次满分 | +10 | 每日 1 次 |
| 每日攻克 | +20 | 每日 1 次 |
| 变式订正对 | +10 | 同题每日 1 次 |
| 微课首次完成 | +5 | 每课 1 次 |
| 成就 / 见面礼 | 50～300 | 一次性 |

**不发金币：** 普通视频、按题答题过程、AI 解题、重复刷同一套题。

### 0.3 为什么要两套货币？

若只用一个数（全用金币）：

1. **通胀**：做题就给币 → 很快囤满 → 捐赠 / 商店失去意义  
2. **动机错位**：学生为「攒币」刷题，而非为「学会」  
3. **公益难控**：金币能捐能兑，必须稀缺；经验只服务成长，可高频

```
学习行为 → 主要给 XP（鼓励多学）
         → 偶尔给金币（鼓励坚持、攻克、满分）
金币出口 → 捐赠 / 商店 / 许愿池（消耗掉，经济才健康）
```

### 0.4 为什么日上限是 80？

80 是文档中的**默认控通胀参数**（后台可调，非写死）。

- **作用**：全站每人的「金币水龙头总阀门」，防止一天刷出大量可捐可兑资产  
- **量级**：活跃学生认真学一天，合理获得约 **40～70** 币；上限 **80** 封顶  
- **和出口匹配**：捐赠 / 商店主力价多在 50～200 币 → 约 **1～3 天**能捐一次或兑一次，有积累感又不爆仓  
- **对比**：早期 Mock 曾用 1000/天，等于无上限，与「小额、稀释、防通胀」矛盾  

**注意：** 日 cap 只限制**金币**，不限制经验；经验今日目标可设为 600 / 2000 等，与金币无关。

### 0.5 易混点（评审拍板用）

| 问题 | 结论 |
|------|------|
| 「积分」叫什么？ | 统一 **金币**；经验叫 **XP**，不再混用「积分」 |
| 看视频给什么？ | 普通视频 **只 XP**；微课 **XP + 最多 5 币** |
| AI 解题给什么？ | v1 **都不给**；激励放在测验 / 攻克 / 变式 |
| 每题给金币吗？ | **否**（与「金币不按题发」一致；勿与 XP 公式混用） |
| 重复刷题？ | XP ×0.5；**金币不再发** |

### 0.6 学生端体现在哪

| 位置 | 经验 | 金币 |
|------|------|------|
| 测验结果页 | 「经验 +N」 | 「金币 +N」（若有） |
| 奖励动效 | 蓝色闪电、数字滚动 | 金色硬币、今日 X/80 |
| 顶部状态栏 | 今日 XP / 目标 | 余额 |
| 联赛 / 成长 | 用 XP | — |
| 公益 / 商店 | — | 扣金币捐赠或兑换 |

### 0.7 日 cap 反推表（按出口价格校准）

> 用当前原型里的**捐赠档位 + 商店 / 许愿池主力价**，反推「攒够要几天」与「日 cap 设多少」。  
> 公式：`所需天数 ≈ 出口价格 ÷ 日均获得金币`（日均受日 cap 与实际学习行为双重约束）。

#### 0.7.1 当前出口锚点（原型真值）

| 类型 | 档位 / 商品 | 金币价格 | 来源 |
|------|-------------|----------|------|
| **爱心捐赠** | 快捷档 | **50 / 100 / 200 / 500** | `GrowthProfile` 捐赠区（默认 100） |
| **折算** | 100 币 = ¥1.00 | — | 后台 `DONATION_RULES` |
| **装扮商城** | 入门（羽毛笔等） | **100** | `OUTFIT_CATALOG` |
| **装扮商城** | 主力（眼镜 / 福尔摩斯等） | **150～200** | `OUTFIT_CATALOG` |
| **装扮商城** | 中档（猫耳 / 爱因斯坦等） | **300** | `OUTFIT_CATALOG` |
| **装扮商城** | 高阶（哪吒 / 博士帽等） | **500～1000** | 部分需等级 / 成就解锁 |
| **许愿池** | C 位体验卡 | **200** | `CoinStoreModal` |
| **许愿池** | 零食大礼包 | **300** | `CoinStoreModal` |
| **许愿池** | 课外图书 | **500** | `CoinStoreModal` |
| **兑换门槛** | 商店起兑 | **≥100** | 后台全局规则 |

#### 0.7.2 三种典型「日均获币」假设

| 画像 | 日均获币 | 典型一天 |
|------|----------|----------|
| **轻度** | **~25** | 完成 1 条今日任务（+15）+ 偶尔满分（+10） |
| **标准活跃** | **~50** | 今日任务 + 每日攻克（+20）或满分 + 变式（+10） |
| **拉满** | **80** | 触达日 cap（任务 + 攻克 + 满分 + 微课等叠满） |

#### 0.7.3 反推：运营目标 → 建议日 cap

| 运营目标 | 出口价格 | 期望攒够天数 | **反推日 cap**（≈价格÷天数） | **当前 80 cap 下**（按标准活跃 50/天） |
|----------|----------|--------------|-------------------------------|--------------------------------------|
| 最低捐一次 | 50 | 2 天 | **25～30** | **约 1 天** |
| 默认捐一次（100） | 100 | **3 天** | **33～35** | **约 2 天** |
| 捐中档 | 200 | 3～4 天 | **50～67** | **约 4 天** |
| 捐高档 | 500 | 7～10 天 | **50～72** | **约 10 天** |
| 商店入门兑换 | 100 | 3 天 | **33～35** | **约 2 天** |
| 商店 / 许愿池主力 | 200 | 4 天 | **50** | **约 4 天** |
| 许愿池中档 | 300 | 5～6 天 | **50～60** | **约 6 天** |
| 稀有兑换 / 捐顶档 | 500 | 7～10 天 | **50～72** | **约 10 天** |

**读表：**

- 若核心目标是 **「标准学生约 3 天能捐 100 币」** → 日 cap 设在 **35～50** 更贴目标；**80** 会让活跃学生 **约 2 天**就捐得起，节奏更快、币更「便宜」。  
- 若核心目标是 **「主力消费 200 币，约 4 天一次」** → 日 cap **50** 刚好；**80** 约 **4 天**也合理 → **80 与 200 币主力价匹配较好**。  
- **500 币**属长周期目标（捐顶档 / 稀有品），即使用 80 cap 也需 **约 1～2 周**，符合「大奖项」定位。

#### 0.7.4 建议日 cap 方案（评审可选）

| 方案 | 日 cap | 适合节奏 | 风险 |
|------|--------|----------|------|
| **A · 偏紧** | **60** | 捐 100 ≈ 2～3 天（活跃）；200 ≈ 4 天 | 学生易觉「攒得慢」 |
| **B · 当前默认（推荐）** | **80** | 捐 100 ≈ 2 天；200 ≈ 4 天；500 ≈ 1～2 周 | 与主力出口平衡；需监控全站发放量 |
| **C · 偏松** | **100** | 捐 100 ≈ 1～2 天；200 ≈ 3 天 | 通胀压力↑，捐赠 / 商店需同步抬价或加稀缺 |

**v1 维持 80 的理由（综合 §0.7.3）：**

1. 与 **200 币主力价**（装扮 / 许愿池入门）的 **4 天节奏**吻合  
2. 高于活跃日均 **~50**，认真学有「触顶感」但不憋屈  
3. 低于早期 Mock **1000**，控通胀底线清晰  
4. 后台 `COIN_GLOBAL_RULES.dailyTotalLimit` 可热调，无需改学生端逻辑  

**调参时务必联动：** 日 cap ↑ 的同时，考虑捐赠高档 / 商店高价 / 许愿池稀缺度是否同步，否则只发不耗仍会通胀。

## 1. 总原则

采用 **Learn-to-Earn**：学生在任务流中完成有效学习行为，获得 **经验（XP）** 与 **金币（Coins）**。

| 货币 | 定位 | 发放策略 |
|------|------|----------|
| **XP** | 主成长货币（等级、联赛） | 按题/按有效学习结算，频率可较高 |
| **Coins** | 兑换向（捐赠、许愿池、装扮） | **小额、低频、强日 cap**，防通胀 |

**核心约定（已确认）：**

- **金币不按题发**；按里程碑场景发（任务完成、满分、攻克、成就等）。
- **普通知识点视频**：只发 XP，不发金币。
- **知识点微课**：发 XP + 首次完成 **+5 金币**（计入日上限）。
- **AI 解题 v1**：不发金币、不发 XP（辅导工具；激励放在变式题链路）。
- **单用户每日金币总上限：80**（所有场景合计）。

## 2. v1 范围：做 / 不做

### 2.1 必做

| 模块 | 内容 |
|------|------|
| **统一结算引擎** | 所有发放入口调用 `grantReward`；写流水、更新余额、校验日 cap |

| **学生端结果展示** | 测验/攻克/视频达标：XP/金币明细；顶部余额与账户一致 |
| **内部管理对齐** | 「获取规则」场景表、日上限 80、流水 `scene_id` 映射 |

### 2.2 明确不做（v1）

| 项 | 原因 |
|----|------|
| 普通视频发金币 | 易刷；与任务/做题激励重复 |
| AI 解题发币 / 发 XP | 难防刷；变式题已覆盖纠错激励 |
| 每题固定发金币 | 与防通胀策略矛盾 |
| 签到大额发币 | 未纳入 v1；若 v2 做须计入 80 cap |
| 真实后端全量 API | 原型阶段：结算逻辑 + Mock 流水即可 |
| 公益月报 CMS、公告排行等 | 与结算无关，另立项 |

### 2.3 已有能力（接上线，不重做）

测验 UI、错题本/错因/变式 UI、捐赠与商店扣币、内部管理 5 菜单骨架、见面礼——改为走统一入账即可。

## 3. 经验（XP）规则

### 3.1 测验 / 答题（主场景）

```
XP = 题数 × 基础XP × 难度系数 × 表现系数
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 基础 XP | **10 / 题** | 后台可调 |
| 难度系数 | 易 1.0 / 中 1.2 / 难 1.5 | 按题目 `difficulty` |
| 表现系数 | 正确率 ≥90% → ×1.1；满分 → ×1.2 | 二者取高，不叠加 |

### 3.2 额外 XP 场景

| 场景 | XP | 频次 |
|------|-----|------|
| 错因标注 + 完成解析浏览 | +5 | 同题每日 1 次 |
| 变式题答对（纠错链） | +10 | 同题每日 1 次 |
| 知识点视频首次有效完成 | 15～25 | 每视频终身 1 次（按片长分档） |
| 微课首次有效完成 | 25～35 | 每微课每日最多 1 次 |
| 成就一次性 | ≤100 | 每成就 1 次 |

**视频 XP 分档：**

| 片长 | XP |
|------|-----|
| &lt; 3 分钟 | 15 |
| 3～8 分钟 | 20 |
| &gt; 8 分钟 | 25 |

**微课 XP：** 在视频档位基础上 +5；若含小测且正确率 ≥60%，再 +5（上限 35）。

### 3.3 反刷与公平性

| 规则 | 处理 |
|------|------|
| 超时提交 | 整卷 XP **×0.9**（-10%） |
| 正确率 &lt; 20% | 仅发 **保底 30 XP**，提示「建议先复习再挑战」 |
| 重复刷同一套题 | 第 2 次起 XP **×0.5**；**不发金币** |
| 同套题判定 | 按 `quiz_set_id`（评审后可改为题目集合 hash） |

#### ① 完成今日任务 · `task_complete`

| 项 | 说明 |
|----|------|
| **是什么** | Dashboard「今日」计划里，**完整做完一条学习任务**后的里程碑奖励（不是看视频、做题的每一步各发一次币）。 |
| **完成条件** | 1. 该任务在今日计划中状态变为 **已完成**；<br>2. 任务要求的**全部子步骤**均达标（见下表）；<br>3. 该 `task_id` **生涯首次**领金币（同一任务重复点完成不发）。 |
| **子步骤判定（按任务类型）** | **标准学习流**（视频+测验）：有效观看 ≥80%（若任务含视频）+ 随堂测验**已提交**（不要求满分）；<br>**纯测验任务**：测验已提交；<br>**阅读类任务**：阅读页标记完成或达到最低阅读时长。 |
| **奖励** | **+10～20 金币**（可按任务难度 / 时长在后台配置区间内浮动）。 |
| **不发币情况** | 只做了子步骤（如只看视频、只做了几道题）但未整条任务完成；同一 `task_id` 已领过。 |
| **与 XP 关系** | 子步骤（做题、看视频）各自结算 XP；任务完成 **额外** 发本场景金币。 |
| **学生端反馈** | 任务卡片变「已完成」+ 奖励动效中展示「今日任务 +N 金币」。 |

---

#### ② 当日首次满分 · `perfect_score_daily`

| 项 | 说明 |
|----|------|
| **是什么** | 当天**第一次**在任意一次有效测验中拿到 **100% 正确率** 的额外奖励。 |
| **完成条件** | 1. 提交一套测验（随堂测、地图关卡、任务内测验等，**不含**每日攻克独立流里的重复刷）；<br>2. `correctCount === totalCount`（全对）；<br>3. **非重复刷题**（同 `quiz_set_id` 第 2 次及以后整卷不计）；<br>4. 当日尚未领取过本场景。 |
| **奖励** | **+10 金币**（固定）。 |
| **频次** | **每日最多 1 次**（当天第二次满分不再发币，仍可获得 XP）。 |
| **不发币情况** | 正确率 99% 及以下；重复刷同一套题；今日已领过。 |
| **学生端反馈** | 测验结果页「金币 +10」+ 动效；流水类型「学习激励」。 |

#### ③ 每日攻克 · `daily_conquer`

| 项 | 说明 |
|----|------|
| **是什么** | 错题本入口 **「每日攻克」** 专用挑战，做完一整套错题复习后的奖励。 |
| **完成条件** | 1. 从错题本进入 **每日攻克** 流程（非普通错题练习）；<br>2. **提交**攻克卷（题量 **`min(待攻克队列, 5)`**，原型暂固定 5 题 Mock）；<br>3. 不要求全对（提交即算完成攻克流程）；<br>4. 当日尚未领取过本场景；<br>5. 非重复刷同一 `quiz_set_id` 的金币通道（攻克卷独立 `quiz_set_id`）。 |
| **奖励** | **+20 金币**（固定）。 |
| **频次** | **每日 1 次**（同一天再次进入每日攻克并完成，不再发币）。 |
| **不发币情况** | 普通错题练习、变式单题练习（走其他场景）；今日已领。 |
| **学生端反馈** | 攻克结果页 + 奖励动效「每日攻克 +20」。 |

#### ④ 变式题订正 · `mistake_remedial`

| 项 | 说明 |
|----|------|
| **是什么** | 错题 **纠错闭环**：先认错题因，再通过变式题验证是否真会了。 |
| **完成条件** | 须 **按顺序** 满足：<br>1. 在错题详情对某题 **标注错因**（选择或填写）；<br>2. **浏览**该题解析（解析页停留 ≥ 若干秒或滑到底，具体秒数可配置）；<br>3. 完成关联 **变式题 1 道** 且 **答对**；<br>4. 同一 `mistake_id` / 题目 **当日第 1 次** 走完全流程。 |
| **奖励** | **+10 金币** + **+10 XP**（XP 见 §3.2，金币走本场景）。 |
| **频次** | **同题每日 1 次**（多道错题可各领 1 次，但受日 cap 80 限制）。 |
| **不发币情况** | 只标注错因未做变式；变式做错；同题今日已领；AI 解题会话本身不触发。 |
| **学生端反馈** | 变式题答对后 Toast / 动效「订正成功 +10 金币」。 |

---

#### ⑤ 微课首次完成 · `micro_lesson_first`

| 项 | 说明 |
|----|------|
| **是什么** | **微课**（含视频 + 可选课后小测）首次有效学完，给的 **小额金币**（普通知识点视频 **不发币**，只发 XP）。 |
| **完成条件** | 须同时满足 §5.1 视频有效观看规则：<br>1. 有效观看进度 ≥ **80%**；<br>2. 有效时长 ≥ **60 秒**（短片 ≥50% 时长）；<br>3. 倍速 ≤ **1.5×**，前台播放；<br>4. 若为微课：课后小测 ≥1 题且 **正确率 ≥60%**；<br>5. 该微课 `lesson_id` **当日首次** 完成（重复看只 XP 不发币）。 |
| **奖励** | **+5 金币** + **+25～35 XP**（XP 按 §3.2 微课分档）。 |
| **频次** | 每微课 **每日最多 1 次** 金币。 |
| **不发币情况** | 普通视频课；未达 80% 有效观看；倍速过快；同课今日已领。 |
| **学生端反馈** | 达标 Toast「+XP」；点「随堂测验」离开微课时结算金币 + 动效。 |

| **完成条件** | 达成指定成就条件后 **自动发放**（每成就终身 1 次）。v1 首期成就： |

### 4.1.2 场景叠加与优先级（同一次学习行为）

一次行为可能同时满足多个场景，**分别入账、合计受日 cap 80 约束**：

| 示例路径 | 可能触发的金币 |
|----------|----------------|
| 今日任务（含测验）首次满分完成 | 任务 +10～20 + 满分 +10 |
| 每日攻克 + 当日尚未满分 | 攻克 +20（满分 +10 若攻克卷全对且今日首次） |
| 微课首次 + 任务完成 | 微课 +5 + 任务 +10～20（视频 XP 另算） |
| 重复刷同一套题满分 | **仅 XP（减半）**，金币 **0** |

**结算顺序建议：** 先算 XP → 再按场景依次尝试发币 → 最后校验日 cap 截断。

---

### 4.1.3 不发金币（再次强调）


- 普通知识点视频（`video_complete` 仅 XP）
- 按题答题（测验过程本身）
- AI 解题会话
- 重复刷同一套题

### 4.2 全局控通胀

| 规则 | 值 |
|------|-----|
| 单用户每日金币总上限 | **80** |
| 超出上限 | 当日剩余场景 **只发 XP 或不发**（不滚动到次日） |
| 流水 | 每笔入账带 `rule_version` + `scene_id` |

### 4.3 与「今日任务」的关系

- **视频/微课奖励** ≠ **任务完成奖励**。
- 看完视频：仅拿 §3.2 视频/微课 XP（+ 微课可选 5 币）。
- **整条今日任务**（如看视频 + 做题均完成）：再触发 `task_complete` +10～20 币。

### 4.4 成就（v1 首期）

| 成就 | 金币 | XP |
|------|------|-----|
| 首次满分 | 50 | 30 |
| 连续 7 天学习 | 100 | 50 |
| 错题本清空 | 150 | 80 |
| 首次捐赠（可选） | 0 | 20 |

> 联赛晋级沿用 `league_promote` +30 币。

## 5. 视频 / 微课：有效完成判定

### 5.1 触发条件（须同时满足）

| 条件 | 要求 |
|------|------|
| 有效观看进度 | ≥ **80%** 视频时长 |
| 最短有效时长 | ≥ **60 秒**（片长 &lt;2 分钟则 ≥50% 时长） |
| 播放状态 | 前台播放；**切后台暂停计时** |
| 倍速 | ≤ **1.5×** 计入进度；&gt;1.5× **不计** |
| 拖拽 | 未播放段落不计入有效进度 |

### 5.2 微课附加条件

- 若有课后小测：至少 1 题且 **正确率 ≥60%**。

### 5.3 重复观看

- 同一视频/微课：重复观看 **不发 XP、不发金币**（除非运营单独配置复习奖励，v1 不做）。

## 6. 学生端交互（v1 最小）

### 6.0 奖励获得动效（已实现原型）

| 时机 | 动效 |
|------|------|
| 测验提交结算后 | 全屏 `RewardGainOverlay`：经验/金币数字滚动、粒子飞散、今日金币进度 |
| 每日攻克完成 | 同上 |
| 视频有效观看达标后点「随堂测验」 | 同上（Toast 仅提示达标，不重复弹币动画） |
| 见面礼领取 | 同上 |

**演示控制台（右下角齿轮）快捷入口：**

- **满分测验奖励**：动效 + 测验结果页
- **每日攻克 +20 币**：动效（跳转错题本）
- **视频观看奖励**：动效（模拟 80% 达标）

**真实流程演示：**

1. Dashboard → 今日任务（数学）→ 播放视频至 80% → 点「随堂测验」→ 答完题提交  
2. 错题本 → 每日攻克 → 做完提交  
3. 学科地图 → 直接做题（跳过视频）→ 满分可触发 +10 币  

### 6.1 视频播放器

| 元素 | 说明 |
|------|------|
| 进度提示 | 进度条旁：「有效观看 62% / 需 80%」 |
| 达标反馈 | Toast：「+20 XP，继续加油」（数值按实际结算） |
| 未达标退出 | 提示：「再看 X 分钟即可获得奖励」 |
| 动效约束 | **不要**每 10 秒弹金币动画 |

### 6.2 测验 / 攻克结果页

- 展示 XP 明细（基础 / 难度 / 表现 / 惩罚）。
- 若有金币：单独一行「金币 +N」，并显示「今日金币 45/80」。
- 文案统一 **「金币」**，不使用「积分」。

### 6.3 AI 解题

- v1 无奖励 Toast；可选轻提示「完成变式题可获得额外奖励」引导至错题链。

## 7. 结算引擎（技术约定）

### 7.1 统一入口

```ts
grantReward({
  userId: string;
  scene: string;       // scene_id
  refId: string;       // quiz_set_id | video_id | mistake_id | ...
  ruleVersion: string;
  payload: {
    questionCount?: number;
    difficulties?: number[];
    correctRate?: number;
    durationSec?: number;
    isRepeat?: boolean;
    isOvertime?: boolean;
    effectiveWatchRatio?: number;
  };
}): RewardGrantResult
```

### 7.2 返回结构（供 UI）

```ts
interface RewardGrantResult {
  xp: number;
  xpBreakdown: { label: string; value: number }[];
  coins: number;
  coinBreakdown: { scene: string; value: number }[];
  coinsToday: number;
  coinsDailyCap: number;
  skippedReasons?: string[];  // 如「日上限已满」「重复刷题不发币」
}
```

### 7.3 流水类型（对齐后台账户流水）

| 流水 type | 对应 scene |
|-----------|------------|
| 任务奖励 | `task_complete` |
| 学习激励 | `perfect_score_daily`, `daily_conquer`, `mistake_remedial`, `micro_lesson_first` |
| 成就奖励 | `achievement`, `league_promote`, `welcome_gift` |
| 爱心捐赠 | （扣减，已有） |
| 商店兑换 | （扣减，已有） |
| 人工调整 | 运营补发 |
