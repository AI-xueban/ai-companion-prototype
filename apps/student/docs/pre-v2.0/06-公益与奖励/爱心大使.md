# 公益爱心大使 · 风控处理说明（v1.2）

> **主需求文档：** [公益爱心大使-需求文档.md](./公益爱心大使-需求文档.md) **v2.0**（§7 风控摘要 + §5.3 筛选）  
> **本文件定位：** 运营同学用的 **风控抽屉操作手册**，不重复信息架构与 IA。  
> **对应原型：** `InternalAdminApp.tsx` → 总览与风控 → 异常列表 → 处理

---

## 1. 设计原则

v1 只做 **三个主操作**，运营 **三选一** 即可结案，不再区分「处置区 + 复核结论」两套按钮。

| 原则 | 说明 |
|------|------|
| 一抽屉结案 | 不再跳转到第二个「单笔捐赠」抽屉 |
| 三选一 | 每个工单只选一种处理方式 |
| 观察用列表 | 「挂起观察」暂不单独做按钮，待复核工单留在列表中即可 |

---

## 2. 什么时候会出现「待复核」？

产品文案为 **待复核**（非「待审核」），会在 **两个地方** 出现，不要混为一谈。

### 2.1 捐赠记录 · 风控审查 = 待复核

| 项 | 说明 |
|----|------|
| **含义** | 捐赠 **已成功**（捐赠结果 = 成功），但捐赠 **模式可疑** |
| **设计** | 不在学生端拦捐赠，先入账，后台再标待复核 |
| **在哪看** | 捐赠与爱心池 → 捐赠记录；或工具栏「异常捐赠」 |

**常见触发（满足任一，阈值可配）：**

- 24 小时内捐赠 **>3 次**
- 相邻两笔间隔 **<30 分钟**
- 24 小时内 **≥2 笔** 且累计 **≥500 金币**
- 捐赠金额与当日正当入账不匹配
- 关联已有 **刷金币** 风控单

**典型组合：** 捐赠结果 = **成功** + 风控审查 = **待复核**（如 Mock：Sarah / RK002）

---

### 2.2 总览与风控 · 异常列表 · 状态 = 待复核

| 项 | 说明 |
|----|------|
| **含义** | 系统生成 **风控工单**，等运营在「风控处理」抽屉里三选一 |
| **在哪看** | 总览与风控 → 异常列表 → 操作「处理」 |

**两类工单：**

| 异常类型 | 管什么 | 典型原因 |
|----------|--------|----------|
| **刷金币** | 金币 **怎么进来** | 1 分钟入账 ≥3 次、入账与学习行为不匹配等 |
| **异常捐赠** | 金币 **怎么捐出去** | 捐太勤、间隔太短、短窗累计过大等 |

## 3. 「风控处理」抽屉：字段说明

| 字段 | 含义 |
|------|------|
| **用户** | 被标记的学生 |
| **异常类型** | **刷金币** 或 **异常捐赠** |
| **风险分** | 0–100，越高越优先处理 |
| **账户金币余额** | 打开抽屉时该生账户剩余金币 |
| **原因** | 系统命中的规则说明 |
| **疑似异常获取** | 仅 **刷金币**；建议扣回的金币数 `abnormalCoins` |
| **关联捐赠** | 仅 **异常捐赠**；只读列表 |

**关于「疑似异常获取 = 0」：** 表示 Mock 尚未填入扣减估算；优先用 **确认正常** 或 **限制获取 7 天**。

## 4. 案例：王磊 · 刷金币（RK003）

| 字段 | 值 |
|------|-----|
| 用户 | 王磊 |
| 异常类型 | 刷金币 |
| 风险分 | 65 |
| 账户金币余额 | 280 |
| 原因 | 学习激励入账频次异常偏高 |
| 疑似异常获取 | **80 金币** |
| 列表状态 | 观察中 |

**运营怎么选：**

| 按钮 | 适用 |
|------|------|
| 确认正常（误报） | 核实后属正常活跃 |
| 限制获取 7 天 | 可疑但先不扣币 |
| 扣减并结案 | 确认刷币，扣回 80 金币并关单 |

## 5. 三个主操作（按钮）

### 5.1 确认正常（误报）— 通用

工单状态 → **误报**，关单。关联捐赠记录的「风控审查」可同步为 **已确认 / 正常**。

### 5.2 限制获取 7 天 — 刷金币

状态 → **已处理**；冻结该生 **金币获取**（`freezeEarn`）。不自动扣币。

### 5.3 扣减并结案 — 刷金币

按 **疑似异常获取** 扣减账户金币，写 **人工调整** 流水，状态 → **已处理**。

### 5.4 限制捐赠 7 天 — 异常捐赠

状态 → **已处理**；冻结 **捐赠**（`freezeDonate`）。

### 5.5 退款并结案 — 异常捐赠

关联捐赠单退款，状态 → **已处理**；是否回滚称号 **需人工决策**（v1 不自动）。
