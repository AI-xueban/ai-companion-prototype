## 2. 流程阶段

| 阶段 | 说明 |
|------|------|
| 答题 Practice | 左做右答；顶栏题号可跳题（练习模式） |
| 提交总结 Summary | 表现卡 + 点评 + 知识点健康分 |
| 单题复盘 Review | 右栏 Tab：解析 / 相似题 / AI 1对1 |
| 消灭错题 Remedial | 错题子集重练，提交后即时反馈 |
| 动态推题 Stepping | unknown 知识点，做一道推一道 |

## 4. 推题算法 6.1

### 调用入口

- 首页每日任务 · **知识点刷题卡**
- 知识点状态 = `unknown`
- 演示：演示控制台 → **unknown 动态推题**

### 参数

| 参数 | 值 |
|------|-----|
| TargetCount | 6 |
| L1RetryLimit | 2（L1 仍错后再推 1～2 道） |
| Unknown U_Level | 默认 L2，按年级微调 |
| 首题 | `max(L1, floor(U_Level)-1)` |
| Combo ≥ 2 | +1 档，最高 L5 |
| 答错 | -1 档，最低 L1 |

### 年级 → U_Level

| 年级段 | U_Level |
|--------|---------|
| 1–3 年级 | L1 |
| 4–7 年级 | L2（默认） |
| 8–9 年级 | L3 |
| 高中 | L3–L4 |

### 终止条件（优先级）

1. 答满 6 题 → 总结页  
2. 连续错 3 次 → 强干预  
3. 非星轨 + L1 缓冲用尽 → 微课介入  
4. 星轨日课时间耗尽 → 结束（L1 仍错继续推 L1）

### 实现文件

- `services/questionSteppingService.ts`
- `components/Quiz/SteppingQuizPage.tsx`
