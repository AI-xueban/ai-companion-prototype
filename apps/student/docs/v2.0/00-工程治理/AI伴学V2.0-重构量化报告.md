## 4. Bug 与技术缺陷修复

### 4.1 可明确计数的缺陷

共修复 5 类已确认缺陷：

1. 联赛成员点击崩溃：补齐 `selectedCompareUser` 和 `setSelectedCompareUser`，成员对比详情可正常打开。
2. 今日任务抽屉未定义信号：清除 `taskDrawerOpenSignal` 的无效引用。
3. 版本号错误：设置页从错误的 `v0.4.0` 改为读取统一配置 `v2.0.0`。
4. 产品身份错误：浏览器标题、HTML 语言、登录与教师端品牌统一为“AI伴学V2.0”。
5. 残留调试行为：删除学科服务向本机 `127.0.0.1:7245` 发送调试日志的两段代码。

### 4.2 TypeScript 技术债务

- V0.6：`npx tsc --noEmit --pretty false` 检出 166 条 TypeScript 编译错误。
- V2.0：`npm run typecheck` 为 0 条错误。
- 这 166 条属于编译期问题，不等同于 166 个独立用户 Bug；其中包含真实缺陷、类型不完整以及已删除旧模块中的历史错误。

### 4.3 异常恢复

- 新增应用级错误边界。
- 单个未处理异常不再只留下白屏，用户可看到明确的恢复入口。

## 5. 功能与交互优化

| 功能 | V0.6 状态 | V2.0 优化 |
|---|---|---|
| 平板舞台 | 尺寸和缩放逻辑散落在 `App.tsx` | 固定 2400×1600，由统一配置和 `useTabletScale` 管理 |
| 演示控制器 | 5 处重复实例 | 合并为 1 处实例，重复挂载减少 80% |
| 演示数据 | 多组浏览器状态各自残留 | 增加“重置演示数据”，覆盖 15 类精确键/前缀规则，并同步重置内存状态 |
| 角色切换 | 教师端、内部管理按钮在当前浏览器回归中未完成切换 | 已加入切换后自动收起逻辑，但运行回归仍未通过，列为待修复项，不计入已完成提升 |
| 今日任务选择 | 只显示 `2/3`，禁用原因不明确 | 明确显示“还需选择 1 个任务”；选满后提示可以开始 |
| 今日任务语义 | 选中只靠颜色和边框 | 增加 `aria-pressed`、动态状态播报和确认按钮关联说明 |
| 首页图标操作 | 键盘、语音、拍照、消息等按钮名称不完整 | 补充可访问名称、展开状态和键盘操作语义 |
| 底部导航 | 当前页只靠颜色 | 增加 `aria-current="page"` |
| 设置开关 | 部分区域是可点击 `div` | 改为语义按钮/开关并增加 `aria-checked` |
| 星际联赛 | 成员详情崩溃且中英文混用 | 修复详情，统一“本周数据、学习时长、专注得分、连续学习”等中文文案 |
| 动态推题 | 显示“unknown 动态推题” | 修正为“数学动态推题” |
| 生产演示入口 | 演示入口始终参与运行 | 通过环境配置控制，生产构建默认关闭 |
| 构建检查 | 只有开发、构建命令 | 增加 `typecheck` 和 `check` 固定质量门禁 |
