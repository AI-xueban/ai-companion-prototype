# AI学伴全校设备管控产品需求文档

版本：v3.07 ｜ 更新：2026-11-05

## 1. 需求概述

### 1.1 目标

本文说明学校管理员在教师端的全校设备管控、学生端响应及跨端共用业务规则。微信小程序的三类角色、页面与交互需求统一维护于[《微信小程序设备管控需求文档》](https://fcnw5yd4oj1w.feishu.cn/docx/Qcxdd67fIowvDOxLEl4cATd6ny2)。本期包含五个模块：

1. 柜机借用管控：设置学校借出时间与临时禁借，班主任管理关联班级的学生禁借。
2. 使用时长管控：限制学生使用设备的时长和可用时段。
3. 智阅作业管控：按科目设置答案和解析的查看权限；解析沿用当前页面名称「详解」。学校管理员统一设置全科目，班主任可逐科设置，任课老师仅可设置当前有效任教科目。
4. 万象视界管控：设置学生能否进入万象视界。
5. 锁屏管控：学校管理员可对全校或年级临时锁屏，也可单独解除；解除后执行当前日常锁屏设置。

### 1.2 权限边界

| 教师端角色 | 数据范围 | 可操作内容 |
|-|-|-|
| 学校管理员 | 所属学校及年级；最深到年级 | 使用五类管控，操作全校、年级。借用可设置每周、日期规则及临时禁借，不直接操作具体学生；管理员锁屏为临时锁屏。 |

微信小程序的学校管理员、班主任及任课老师权限已迁移至[小程序需求的角色权限表](https://fcnw5yd4oj1w.feishu.cn/docx/Qcxdd67fIowvDOxLEl4cATd6ny2#doxcnRjMVvQXJcivwRmEBuTggfc)。本文涉及老师规则的条目用于定义共用优先级与执行逻辑，不表示教师端向老师开放入口。

- 教师端全校设备管控仅学校管理员可见、可操作，班主任和任课老师不显示入口。学校管理员是当前学校的最高管理角色，权限失效由平台管理员处理；移动端角色权限及页面交互参见[小程序独立需求文档](https://fcnw5yd4oj1w.feishu.cn/docx/Qcxdd67fIowvDOxLEl4cATd6ny2)。
- 前端角色判断只控制入口和功能展示。每次查询或修改必须由服务端校验教师与学校、班级、学科及有效学期的关联。
- 老师不得查看或修改无有效关联的班级和学生；班级关系失效后立即失去对应权限。

### 1.3 管控范围与规则优先级

- 学校管理员按模块和操作范围设置规则，各模块独立生效。
- **生效范围**

  - 借用、使用时长、智阅作业、万象视界和锁屏可同时生效。
  - 借用每个年级只保留一份每周安排，可设置多条不重叠的全天禁借日期规则；使用时长按星期设置，每年级每个星期只能有一条规则，已有星期不可重复新增，逐条编辑和删除按对应模块规则处理。智阅作业和万象视界修改当前权限状态。
- 使用时长、万象视界通过「本次修改哪些学生？」选择修改范围；智阅作业通过「本次如何修改？」选择修改方式：修改所选范围的全部学生，或保留老师已设置的内容、只修改其余内容。使用时长保留班主任设置，智阅作业和万象视界保留老师设置；具体判断方式见各模块。
- 是否保留老师设置按模块独立判断：使用时长按学生及星期，智阅作业按学生及科目，万象视界按学生当前设置。
- 学校管理员维护每周、指定日期借用规则，日期规则优先；学校临时禁借与班主任学生禁借独立生效，均可阻止新借出。班主任不配置时间规则，不设借用权限开关。
- 万象视界允许学校和有权限的老师调整学生使用状态，以该学生最后一次成功修改的结果为准。学校选择保留老师设置时，跳过这些学生。
- 新增学生的普通规则执行当前学校规则，不追溯历史批量操作；临时锁屏按当前所在班级的临时状态继承，班级已局部解除则不受临时锁屏限制。
- 学生转班后，借用时间规则及临时禁借跟随新班级，已有学生禁借保留并由新班主任接手。其他普通规则按以下规则处理，不继承新班级老师历史批量配置；

  - 使用时长无其他规则时执行全校默认。
  - 临时锁屏单独处理：立即跟随当前所在班级的临时状态，不携带原班级临时状态。
  - 日常锁屏按转班规则重新计算，无日常设置默认未锁屏。

### 1.4 核心术语

| 术语 | 含义 |
|-|-|
| 操作对象 | 学校管理员本次选择的全校或年级；批量操作为已勾选的年级。 |
| 影响学生 | 操作对象展开后实际被修改的去重学生 |
| 学校规则 | 学校管理员为指定范围保存的配置。使用时长无其他配置时执行固定默认值；各模块覆盖方式见对应章节。 |
| 当前生效规则 | 按日期、管控范围和最新成功操作计算后，学生实际执行的规则 |
| 展示范围 | 规则行或当前停用状态对应的年级范围 |

## 2. 通用交互

### 2.1 页面与操作范围

- 教师端五个管控Tab并列展示在「全校设备管控」中，仅学校管理员可见。管理员最深管理到年级，不进入班级或学生页面。
- 规则采用横向列表，不按年级制作方形卡片，不显示小学/初中分组、序号、班级数、分页、搜索、状态筛选或「查看班级」。对象年级为主标题，配置内容为次级信息，操作在右侧。
- 相同规则合并年级名称，例如「四、五年级」。使用时长只读取学校保存的年级规则，不实时比较学生或班主任的实际规则；智阅出现部分学生权限时，相关年级独立列示，不用「规则有差异」等标识代替实际权限。
- 借用上方为「全校借用管控」，下方一个「借用规则」模块内平铺指定日期和每周固定规则。使用时长、智阅各一个规则列表；万象、锁屏各一个全校管控模块。
- 主页面不切换卡片批量选择模式。新增、编辑及停止/恢复操作在居中弹窗中选择年级，全选复选框文案为「全部」；全选只包含当前可操作年级，禁用项不被勾选。至少选择一个年级才能保存或进入下一步。
- 新增借用每周和使用时长规则时，已有规则年级标「已有规则」且禁选。默认规则不算已设置的人工规则。全部年级已有规则时，提示「全部年级已有规则，请编辑或删除后新增」，隐藏参数和保存按钮，仅可取消或关闭；此空态不影响编辑。
- 借用、使用时长、智阅编辑均预选本条原年级并回填参数，可增加或取消年级。原范围继续可选，其他已有人工规则年级禁选（日期规则按重叠校验）。新增勾选范围应用本条规则；取消的原范围移除本条，保留其他规则。使用时长、智阅的保留老师设置方式也适用于移除范围。
- 仅改变所选年级也属于未保存修改。调整年级保留已填参数，同时保留原范围和新增对象的版本快照；最终提交校验新旧范围。全部取消不能保存；借用、时长、智阅取消最终确认返回保留输入和选择的表单；锁屏取消最终确认返回主页面，不执行变更。
- 临时停止借用、临时锁屏只由管理员手动开启和解除，不自动到期。无学生年级不可选，无对象不提供可执行操作。

### 2.2 弹窗、必填项与保存

- 设置和确认均为居中弹窗：独立标题及右上角关闭、可滚动内容区、固定底部按钮。设置弹窗通常最大760px，确认通常最大480px，窄屏保留边距；不使用抽屉。锁屏保留原卡片式选项、锁屏图标和危险操作按钮，但结构一致。
- 必填项统一加红色*：年级/设置范围、借用星期及日期、使用时长星期与三项时长、智阅答案/详解、可编辑的万象状态，以及需要选择的修改方式或锁屏操作。只读目标状态和可选时段不标必填。
- 校验失败保留表单并显示必要提示。先校验年级；使用时长和智阅仍为默认配置时优先提示无需新增/修改，不要求继续选择覆盖方式。其他必填及数值校验见对应模块。
- 使用时长、万象的「本次修改哪些学生？」及智阅的「本次如何修改？」位于参数下方、按钮上方。必选且初始不选择，明确修改全部或保留老师设置的含义。
- 五种管控的页面、设置和确认均不展示学生人数，只保留年级范围；内部统计及校验继续执行。不重复展示「请选择年级」、范围人数摘要卡和控件已表达的禁选说明。全占用空态、校验错误和需要理解的覆盖选项保留。万象不展示当前允许/禁止人数或保存前变更人数卡。
- 使用时长保存确认保留一行影响范围及规则摘要，不展示学生人数和重复年级标签，不附加「包括班主任设置」。借用确认保留范围和规则摘要，不追加取消适用年级或已有规则提醒。
- 设置成功才更新配置；失败不写入，不允许部分成功或强制覆盖。设备离线不阻止服务端保存，联网后同步最新有效配置。
- 万象设置和锁屏操作的取消直接关闭不保存；其他有未保存修改的设置关闭沿用放弃提醒。默认填入按钮只改表单，保存确认后才应用。

### 2.3 反馈、记录与并发

- 成功轻提示仅显示执行结果，如「已停止借用」「借用规则已保存」「规则已删除」「已解除临时锁屏」「已恢复使用万象视界」。不附带规则解释、权限变化、人数或日期状态。
- 填入默认值提示「已填入默认设置」，无实际变更提示「无需修改」。失败、必填及冲突提示保留必要原因和下一步。
- 轻提示顶部居中，含状态图标及关闭按钮；成功绿色、失败/校验红色、冲突或权限橙色、指引蓝色。普通约4.5秒、填入默认值约3秒，可手动关闭。
- 五种管控均无「操作记录」「最近操作」入口、记录弹窗或历史回滚。已有底层成功操作数据不因移除展示而清空；填写、取消、校验失败不生成成功记录。
- 浏览或打开编辑不提示版本冲突。借用、时长、智阅在最终确认提交时校验，万象在保存时校验。借用校验学校配置版本；时长/万象校验学生对应模块版本；智阅按学生及科目版本校验。调整范围时，新旧对象均校验，其他模块变化不阻止保存。
- 任一相关配置、来源或版本已变化，整批不保存。显示「相关设置已被其他人修改，本次未保存，请重新设置。」刷新相关数据后重新核对；不能比较值相同就绕过版本检查。

### 2.4 无数据与异常处理

演示控制台只保留「学校暂无年级」「操作对象发生变化」「设置已被他人修改」及恢复正常入口。学校暂无年级在使用时长页面演示，冲突在编辑最终提交时演示；模拟入口精简不等于取消实际异常处理。

| 场景 | 展示和处理 |
|-|-|
| 学校暂无年级 | 保留页面和Tab，规则区显示无年级缺省提示，不允许无对象设置。 |
| 年级无可操作学生 | 不允许选择；列表有对应缺省提示，不提供该范围操作。学校管理员不进入班级空态页。 |
| 加载失败 | 显示失败及重试入口，不伪装为无配置。 |
| 保存失败 | 提示「保存失败，请检查网络或稍后重试。已填写的内容已保留。」保留配置和表单。 |
| 对象关系变化 | 整批不保存，关闭设置、刷新并清空选择，提示「所选范围的学生或班级已变化，请重新选择后设置。」 |
| 配置版本变化 | 整批不保存，刷新相关模块，提示重新设置。 |
| 管理员权限失效 | 停止查看和修改，显示无权限并提示联系平台管理员。 |

## 3. 柜机借用管控

### 3.1 职责与生效条件

柜机借用管控只决定设备能否从柜机借出，不限制借出后的使用时长。禁止借用不影响正常归还。

- 学校管理员设置全校、年级的每周规则和指定日期规则，操作临时禁止借用，最深到年级，不选择班级或具体学生。
- 班主任默认可管理当前关联班级的学生禁借，支持单人、批量禁止和解除；不设置借用权限开关，不配置每周或指定日期规则。任课老师不提供借用管控。
- 学校临时禁止借用时，受影响班级不能新借出；班主任已禁止的学生也不能新借出。
- 未被上述禁借限制的学生，优先执行当天有效的学校指定日期规则；没有有效日期规则时执行每周规则。
- 未设置任何借用规则时，默认均可借用；学校临时禁借和班主任禁借优先。当天没有有效日期规则且未设置每周规则时，默认可借；已设置每周规则但当前星期或时段未覆盖，以及命中指定日期全天禁止，均不能借出。

### 3.2 每周固定借用规则

- 每年级只能有一份完整每周规则。入口「新增每周规则」，行内「编辑」「删除」；新增仅选无每周规则的年级，编辑带入原年级及参数。编辑时可调整适用年级，取消的原年级移除本条，其余规则不变。
- 标题为红色*「选择星期」，右侧说明「时段不设置则全天可用」，不加句号。按时段组设置，一组可选一天或多天；每组至少一天，星期不能跨组重复，其他组已占星期禁选。
- 时段可不设置：所选星期全天可借。设置时段后仅时段内可借；未选星期不可借。空白时段行保存时忽略，只填写起止一端则提示补全。
- 一组可有多个时段，结束晚于开始，不跨日，不重叠。删除用图标，「添加时段」在本组最后一行删除图标后；可删完全部时段，无时段时保留添加入口。多余组可删除，删除组同时移除该组星期。
- 相同时段星期编辑时合为一组，可拆分为每日不同安排。历史配置打开不自动改写；保存时收敛为全年级的一份每周安排，不保留本条中移除的星期。日期规则及学校/学生禁借保持不变。

### 3.3 指定日期借用规则

- 一个年级可有多条日期规则，但日期范围不得重叠；同一日期可用于不同年级。
- 日期规则仅提供「所选日期全天禁止借用」，默认固定为全天禁借，不提供按时段借用或其他方式选项。
- 新增时设置开始和结束日期，包含起止日期，可为同一天；开始日期不得早于学校当天，结束日期不得早于开始日期。尚未过期的规则可编辑起止日期，开始日期可保留过去日期，但结束日期不得早于学校今天，仍须满足日期顺序和冲突校验。
- 选择一个、多个或全部年级保存。任一所选年级已有日期规则与本次日期范围相交，包括首尾日期同一天，均阻止整批保存，提示「所选日期已有规则，请重新选择」。保留表单、选择和原有规则，不进入覆盖确认、不允许强制覆盖；必须修改日期或年级选择后重新保存。
- 编辑日期规则时排除正在编辑的该条规则，仍与所选年级其他日期规则校验。最终提交再次检查日期与数据版本，拒绝部分成功。
- 规则新增成功后作为管控安排生效，不展示生命周期状态；学校时区今天超过结束日期后自动删除，不保留过期规则。学校时区当天落在所选日期范围内时执行全天禁借，其余日期按每周规则执行；学校临时禁借和学生禁借继续优先。
- 未过期的日期规则可编辑、删除；过期规则自动清理，不能重新保存已过期的日期范围。新增及编辑按钮为「保存规则」。历史非全天禁借日期规则不因打开页面自动变动，再次编辑保存时转为全天禁借并在确认摘要中说明。
- 当天不在规则指定日期范围内，或规则被删除后，按每周规则执行；未设置每周规则时默认可借用，其他禁借状态仍有效。
- 结束日期按学校时区Asia/Shanghai且包含当天，次日零点后属于过期。自动删除真实配置并持久化，不只是从列表隐藏；仅删除过期日期规则，不改每周规则、未过期日期、学校停止状态或学生禁借。清理有实际变化才更新配置版本，重复清理不重复写入，不弹成功提示或生成人工操作记录。
- 原型在读取配置、页面恢复可见/焦点及页面停留每分钟检查时清理，后台暂停后重新打开也会补清理。正式实现应由服务端按学校时区定时清理，不依赖管理员在线；配置版本改变时，正在编辑的旧表单提交仍按冲突流程处理。

### 3.4 学校停止及恢复借用

- 主模块标题「全校借用管控」。全校当前全部停止时，主按钮为「全校恢复借用」；否则为「全校停止借用」。按实际停用范围切换，不以全校会话是否存在决定按钮。
- 已停止范围在模块内单独列一行：年级主标题合并后缀，如「四、五年级」，次文「已停止借用」，右侧「恢复借用」。无停止范围则无此行；局部恢复后移除已恢复年级，全部恢复后行消失。
- 停止入口打开年级选择，默认勾选尚未全部停止的年级，已停用年级置灰且未选中。恢复入口及全校恢复均先选年级，默认勾选已有停止限制的年级，未停用年级置灰且未选中。全选只含本次可操作范围；一个也不选不能确认。
- 弹窗只选择范围，不再提供停止/恢复操作单选或额外操作说明。停止和恢复仍进入最终确认；取消确认返回原选择，成功关闭。
- 停止确认说明「将禁止所选范围内的学生借出，已有借用规则保留」；恢复确认说明「解除临时禁借后，按当前有效的借用规则执行」。
- 只阻止新借出，不影响归还或已借设备的使用，不改每周、日期或班主任学生禁借。管理员仍可维护时间规则，保存规则不解除停止限制。
- 全校会话进行中可单独恢复或再次停止部分年级，局部解除后相关班主任可立即继续管控，不等待全校结束。未解除班级仍只读，提示「学校正在临时禁止借用，暂时无法修改」，提交时也校验。
- 局部解除保留其他范围及全校会话；全校结束或恢复全部剩余停止范围时清除全校临时限制及局部例外。刷新、退出不自动恢复。班主任学生禁借始终独立保留。

### 3.5 班主任学生禁借共用规则

- 班主任按当前关联班级查看学生，单个或批量禁止借用、解除禁借；禁借立即生效，持续到当前有权限的班主任手动解除，不设置日期或自动到期。
- 学校临时禁借期间只读；所在班级解除后恢复操作，无须等待全校临时管控结束。
- 解除学生禁借后按学校当前有效的时间规则执行，不代表学生此刻一定可借。
- 班主任更换后，新班主任接手关联班级的已有学生禁借，不限定原操作人解除。
- 学生转班后，已有学生禁借保持原状态，由新班主任接手；每周、日期和学校临时禁借跟随新班级。
- 新增学生不继承班主任历史批量禁借，执行当前所在班级的学校规则与临时状态。
- 本节定义跨端共用业务规则，本次教师端原型仅实现学校管理员入口；不新增班主任或任课老师入口。

### 3.6 页面及规则介绍

- 上方全校借用管控，下方一个「借用规则」大模块；标题「借用规则」右侧统一放「新增日期规则」「新增每周规则」；内部先指定日期规则，再每周固定规则，平铺而非Tab，各类型仅在有已保存规则时展示分区及列表。无数字优先级标签，不展示年级卡片或独立全校时间规则汇总。
- 只列已保存规则，同内容合并适用年级。年级加粗，日期或完整星期/时段为次级文字，右侧编辑、删除。日期升序展示未过期的已保存规则，无生效中/待生效/已失效标签；每周完整展示，不限制两条或设置查看更多。
- 指定日期标题右侧说明「禁止借用日期」，每周标题右侧「每周可用时间」；新增用文字按钮，学校停止/恢复为主按钮。无配置时隐藏对应分区标题、列表及空态；两个类型均未设置时，标题及右侧新增按钮保留，模块下方列表区域居中显示「暂无规则，可新增日期或每周规则」。删除或自动清理至该类型无规则后也隐藏该分区。
- 顶部浅灰条：「生效优先级：全校停止借用 ＞ 指定日期规则 ＞ 每周固定规则；无规则时默认可借。」末尾说明图标点击打开「借用规则」只读弹窗，右上角关闭或「我知道了」退出。
- 规则介绍文案如下，关闭不改变配置：

| 项目 | 文案 |
|-|-|
| 全校停止借用 | 所选年级不可借用，需手动恢复。 |
| 指定日期规则 | 这些日期全天不可借用，每周规则暂不生效。 |
| 每周固定规则 | 按所选星期和时段借用；不设时段则全天可借。 |
| 默认借用 | 学校停用和禁止借用日期除外，没有每周规则时可随时借用。 |
| 底部提示 | 班主任禁止借用的学生由班主任解除后按照学校规则借用 |

- 日期新增/编辑的红色*「适用日期」右侧显示「所选日期全天禁止借用」，输入下无重复解释。选择年级下不显示类型/人数摘要。
- 保存确认保留范围及摘要，不再提示哪些年级已有规则、不说明取消适用年级、不追加临时/学生禁借保持不变。每周保存摘要仅列所选星期及配置时间，每段时间后加「可借用」；全天已含可借用时不重复，不再追加规则解释。按日时段文字已含星期时，不再拼接一次适用星期，保存/删除确认与列表复用同一摘要。
- 删除最后规则时提示默认可借；仍独立执行学校停止及学生禁借。日期重叠时不进入确认，不提供覆盖；最终提交再次校验版本与日期冲突，整批执行。

### 3.7 柜机借用拦截

- 本节为柜机借用拦截弹窗，不是借出后设备的锁屏。统一标题为「暂时无法借用」，仅提供「我知道了」按钮，无操作1分钟后关闭。
- 先判断学校临时禁借或班主任学生禁借，再判断当天有效日期规则，最后判断每周规则。没有当天有效日期规则且未设置每周规则时默认可借，不展示缺少规则的拦截弹窗。
- 弹窗中的日期、星期及时间由该学生当前所在班级的规则生成，图片中的日期与时段仅为示例，不可写死。
#### 3.7.1 每周规则拦截

当前未命中学校或班主任禁借、没有当天有效日期规则，且不在每周允许星期或时段内时，展示每周规则弹窗。

展示该学生所在班级的完整每周借用规则，包含所有已设置的星期及其全部时段，未设置时段的星期显示全天可借用；逐日的全部时段分行展示，不只展示今天或下一次可借时段。文案为「现在还不能借用哦，请在【完整每周规则】时间内再来借吧」。


![每周规则拦截](images/cabinet-borrow-weekly.png)

#### 3.7.2 指定日期规则拦截

日期规则弹窗只展示当前命中的一条日期规则，不罗列全部日期安排。仅当学校时区当天处于该规则指定日期范围内时拦截，不因规则保存成功而禁止范围外的借用。

图示为指定日期全天禁借：显示「以下日期范围内暂不可借用」、该规则的起止日期及「请在上述日期范围以外再来借用」。包含起止日期；该日期范围外仍按其他有效规则及禁借状态判断，不保证一定可借。

指定日期规则仅有全天禁借，不再提供按时段允许借用的弹窗分支。

学校临时禁止该学生所在班级借用，或班主任禁止该学生借用时，展示禁借弹窗。文案为「当前学生编号不可借用」「如有疑问，请联系管理员」，不展示星期、日期或可借时段。

该提示优先于时间规则。学校临时禁借由学校解除，班主任学生禁借由当前关联班主任解除；界面不提供学生自行解除的入口。

## 4. 使用时长管控

### 4.1 页面与默认规则

- 顶部浅灰说明：「可按年级设置使用时长和可用时段，未设置时执行默认规则。」列表标题「使用时长规则」，右侧「新增自定义规则」。直接编辑/删除，不先打开中间列表弹窗。
- 列表先显示人工学校规则：相同星期及参数合并年级，年级为主、参数为次，右侧编辑/删除。末尾「默认规则」标题灰色，无按钮、不可操作；无单独学校规则的年级合并到默认行。
- 默认固定周一至周日、连续60分钟、休息15分钟、每日累计180分钟、不限时段。无总开关，不提供默认规则编辑/删除。
- 单独设置后年级从默认行移除，删除其全部学校规则后重新加入；全校都有人工规则则隐藏默认行。已设规则年级未覆盖的星期仍执行默认值，展示移除不改变兜底逻辑。

### 4.2 参数与表单

| 必填项 | 规则 |
|-|-|
| 选择年级 | 新增只选无学校规则年级；编辑预选原范围，可加入无规则年级；其他已有规则年级禁选。 |
| 选择星期 | 每组至少一天，可多天共用一组；星期不能跨组重复，其他规则占用的星期禁选。 |
| 连续使用时长 | 正整数分钟，达到后进入休息。 |
| 休息时间 | 正整数分钟，连续使用到上限后必须休息。 |
| 每日累计时长 | 正整数分钟，不短于连续使用时长。 |

- 每日可用时段可不设置，全天可用；设定后仅时段内可用，仍受三项时长限制。标题右侧「不设置则全天可用」，无句号。
- 星期与借用相同：普通紧凑复选框横排「周一」至「周日」，窄屏自然换行；不使用大块选项框。
- 删除时段用图标，添加在本组最后一行删除后，可删完，无时段保留添加。填写时段须起止完整、结束晚于开始，不跨日、不重叠。
- 新增初始全周60/15/180、不限时段，一组起步；可多组、每日不同或多天相同。填入默认设置仅填表单，保留不可选星期，不立即保存。
- 新增保存时所有组仍为60/15/180且无时段，提示「当前仍为默认规则，无需新增」，不新增人工规则；仅改变星期分组也不新增重复默认值。参数或时段有实际变化才继续。此限制不自动清理历史规则，也不阻挡编辑现有规则。
- 全部年级已有规则时，在选择年级下提示「全部年级已有规则，请编辑或删除后新增」，其他参数、填默认及保存均隐藏。编辑不受该空态影响。
- 不展示重复范围人数卡、默认星期/重复新增说明。可选时段不标必填，星期、三项数字和修改方式标红*。

### 4.3 编辑范围、覆盖和保存

- 每年级每天最多一条学校规则，无指定日期规则。编辑自动回填参数、勾选原范围；原条目星期可继续选择，其他已占星期不可选。
- 勾选的新范围应用编辑后规则；取消的原范围移除本条学校规则，其他规则保留，对应空余星期回默认。新旧范围都校验版本，目标星期冲突整批不保存；取消或失败不改变原配置。
- 「本次修改哪些学生？」必选，初始不选：修改所选范围所有学生，替换班主任在所选星期设置；或保留班主任设置、修改其他学生。按学生及星期判断，老师保存默认值也算已设置；保留方式同样用于移除原范围。
- 保存一次校验全部组，编辑可拆多组，原条目只替换一次。确认只显示一行影响范围和最终摘要，不显示人数、重复年级标签或「包括班主任设置」。
- 班主任默认可调整关联班级学生的时长，不设学校授权开关；任课老师无时长权限。学校年级配置独立保存，不被班主任调整回写，不实时汇总实际学生差异。
- 学校保存年级规则并按修改方式更新学生实际配置。保留老师时，学校规则仍保存，老师受保护星期不变。删除学校规则只移除该条学校配置，班主任已另改内容保留。删除确认中的补充文案按用户原文为「删除后指定默认设置」。
- 旧数据仅一次性迁入可识别学校来源规则，不迁入班主任配置、不清空学生状态，不推测被覆盖的历史。后续独立维护学校配置。

### 4.4 计时和学生端处理

- 连续使用、休息、每日累计、跨日、换设备、不可用时段及学生端提示沿用现有已开发规则，本期不重新定义计算口径。
- 保存立即生效，沿用当天已用时长；达到新上限立即限制。离线设备联网同步最新规则。

## 5. 智阅作业管控

### 5.1 页面与默认权限

- 顶部浅灰说明：「可按年级设置查看答案和详解的权限，默认均不允许。」标题「智阅作业管控」，入口「设置全校权限」。
- 人工权限行在前，相同配置合并年级，年级为主、答案/详解权限为次；右侧「修改权限」「删除」。部分学生状态的年级单独展示，不以差异标签代替实际权限。
- 默认行放最后，灰色「默认规则」且不可操作，展示未做人工设置、答案及详解均不允许的年级。人工保存即便与默认值相同也按人工配置识别，不误合入默认。
- 删除人工规则需确认，成功后该行范围恢复两项不允许，归回默认行。取消、失败、版本冲突均不改权限；默认行无删除入口。

### 5.2 设置、编辑与范围

- 全校入口在表单选择年级，答案、详解均必选。默认范围仍为两项不允许时保存提示「当前仍为默认规则，无需修改」，不新增人工设置。把已有允许改回不允许是实际变更，仍允许保存。
- 修改权限预选原年级、回填权限，可加入默认范围的年级；其他已有人工规则年级禁选。取消原年级后移除本条并恢复默认，新增所选范围应用新权限。
- 新旧范围一并校验版本，未选年级不能保存；修改年级保留已填权限，仅改范围也有未保存提醒。取消最终确认返回原表单选择。
- 下方「本次如何修改？」必选且初始不选：「全部修改」应用到所选学生所有科目、替换老师设置；「保留老师设置」按学生及科目跳过老师已设内容、修改其余。保留方式同样作用于取消原范围。
- 点击保存核对范围、权限和修改方式，再确认并生效。不展示默认规则介绍、重复范围人数卡；固定默认填入按钮只填两项不允许，仍需保存。

### 5.3 科目与跨端共用规则

- 权限按学生及科目独立生效，答案与解析互不影响；解析在教师页面沿用「详解」名称。未设科目默认均不允许。科目来自学校配置和当前对象适用科目，不固定列举。
- 学校管理员不显示科目选择，统一所选年级全部适用科目，不受兼任教师科目限制；班主任可按本人关联班级的科目分别设置，不限本人任教科目；任课老师仅有效任教班级及本人任教科目。
- 同一老师不同身份分别校验。设置某科不改变其他科，学生打开作业只读取该学生该科权限。保留老师设置按学生及科目判断，不能因数学被设置就跳过该学生语文。
- 同一学生同一科目按通过版本校验的最后成功结果执行；跨端学校、班主任、任课老师都受关联关系和科目权限校验，前端隐藏不能代替服务端校验。
- 当前学校管理员原型仍用不分科目的演示数据；文档的逐科存储、老师逐科权限属于开发需求，不代表本次原型已实现或验收。小程序具体流程见独立需求。

## 6. 万象视界管控

### 6.1 教师端

- 顶部浅灰说明：「可按全校或年级停止、恢复使用万象视界；保存时可选择是否保留老师的设置。」替代原「全校」层级标题，不显示标题旁允许/禁止人数。
- 一个「全校万象视界管控」模块。默认主按钮「全校停止使用」；实际全校都禁止时为「全校恢复使用」。下方合并已停止年级，右侧「恢复使用」；无禁止范围则不显示该行。包含部分学生时明确标注，不误作全年级停用。
- 停止、恢复均先选年级，默认选可变更范围，已经处于目标状态的年级置灰不选；全选仅可操作范围，未选不能下一步。
- 下一步显示固定目标状态和设置范围，不再次选择停止/恢复。下方「本次修改哪些学生？」必选且初始不选：修改所选范围所有学生，替换老师此前状态；或保留老师设置、修改其他学生。
- 设置弹窗不显示当前允许/禁止人数及变更人数说明卡。按选择计算没有实际变化时禁用保存，实际统计不因隐藏而取消。点击保存一次执行，取消关闭不保存。
- 这是实际使用权限修改，不新增临时限制层。学校及有权限老师可先后调整，以该学生最后一次成功修改为准；保留老师设置时跳过老师来源，仅实际写入对象更新状态和来源。
- 不影响其他模块。学校临时锁屏期间老师仍可调整万象权限，设备解除锁屏后执行最新结果。

### 6.2 学生端

- 老师锁定后，消息中心新增「万象视界已锁定」消息。
- 学生点击万象视界时不能进入，并显示锁定提示。
- 学生已经在万象视界内时，立即弹出强制提示。弹窗只有「我知道了」按钮，点击后退出万象视界。
- 老师解锁后，消息中心新增「万象视界已解锁」消息，不显示弹窗；学生可以再次进入。
- 演示控制台提供「万象视界锁屏」，位于「教师端手动锁屏」左侧，用于模拟以上流程。

## 7. 设备锁屏管控

### 7.1 教师端

- 顶部浅灰说明：「可按全校或年级临时锁屏；解除后执行当前日常锁屏设置。临时锁屏期间，相关班级老师不能调整锁屏。」管理员控制临时限制，老师管理日常锁屏，两类状态独立。
- 一个「全校锁屏管控」模块。按当前实际覆盖，全校均临时锁屏时主按钮「全校解除临时锁屏」，否则「全校临时锁屏」；不以会话存在与否决定按钮。
- 模块内合并展示已临时锁屏年级及解除入口，无锁屏范围则不显示。含部分学生时标注实际状态，不展示逐年级卡片或重复列表。
- 开启、解除均先选择年级，默认可操作范围，已处于目标状态年级置灰不选，全选只含可操作范围；不选不可确认。随后进入最终确认，取消不提交。
- 年级选择、临时锁屏设置及最终确认都用独立标题/关闭、滚动内容、固定底部按钮；保留锁屏卡片选项、图标和危险确认按钮样式。成功提示只显示「临时锁屏已开启」或「已解除临时锁屏」。
- 全校开启时保存全校会话和班级临时状态，不改日常锁屏；可单独解除或重新锁定年级。局部解除只改所选范围，不结束全校会话，对应班级老师立即恢复原有日常管控权限，其余仍受限。
- 即使全部年级逐一解除，也不等于结束原全校会话；当前均解除的班级都可继续老师日常操作。全校结束入口需清除本次全部临时限制及局部例外，不复原历史快照、不保留下级独立临时锁。
- 解除只撤销管理员临时限制，执行每名学生当前日常状态，无设置默认未锁屏；因此解除临时锁屏不保证设备立刻解锁。
- 学校仍临时锁定的班级，班主任和任课老师不能修改日常锁屏，提示「该班正在临时锁屏管控中，暂时无法修改锁屏状态。」提交时再次校验。局部解除后可操作，不扩大原有授权范围；老师不能自行解除学校限制。
- 刷新、退出、局部解除不结束会话。新增学生及转班学生立即按当前所在班级临时状态继承，已解除班级不受限制，不要求开启前名单或补造快照。
- 离线恢复按最新有效状态同步，不重放已结束指令；重复请求幂等。借用、时长、智阅和万象的设置操作不被临时锁屏禁止。

### 7.2 学生端锁屏页

- 锁屏页使用不透明背景覆盖学生端全部内容、底部 Tab 和更多应用入口。
- 顶部展示「学习守护｜老师已锁屏」、小晤、网络和反馈按钮。
- 页面提示设备已被老师锁定，并展示当前时间。
- 学生不能自行解锁；保留「退出登录」和「归还设备」。
- 小晤提示：「老师开启了锁屏，先休息一下，等老师解锁后再继续吧～」。

## 8. 开发要求

- 教师端全校设备管控接口只允许所属学校的学校管理员访问；跨端接口按角色校验学校归属及有效班级关系，小程序具体权限以其独立需求文档为准。
- 服务端按角色限制可操作模块与数据范围，不能仅依赖前端隐藏入口。
- 前端提交操作对象、模块、动作和配置。借用时间规则和临时禁借按班级保存；使用时长、万象视界按所选范围展开为去重学生；智阅作业按「学生＋科目」展开并去重，人数按学生去重。临时锁屏保存学校会话及班级临时状态；返回本次实际变化范围与人数。
- 服务端记录操作来源、角色、操作人姓名及手机号、时间、实际范围和变更内容，用于追溯实际成功变更；小程序修改正常生效和同步，学校管理员页面不提供操作记录入口。
- 来源按模块独立记录。使用时长按学生和星期；智阅作业按学生和科目；万象视界按学生当前权限。学校选择保留老师设置时跳过老师来源的对象，保留原权限、来源及最近操作；学校实际写入的对象来源更新为学校。
- 服务端为各模块分别维护版本：借用使用学校级配置版本，时长、万象视界使用学生对应模块的版本，智阅作业使用「学生＋科目」版本。最终提交时校验并整批写入；版本变化不能仅靠比较当前值判断，修改后再改回也属于变化。
- 服务端分开保存日常锁屏、班级临时状态、学生当前班级及全校会话。

  - 按目标班级当前临时锁屏状态校验老师操作权限；已解除班级可操作，仍锁定班级不可操作，最终提交时再次校验；
  - 仅局部锁屏时只限制受影响范围。
  - 新增、转班即按当前班级继承临时状态。
  - 解除只撤销管理员临时限制，执行日常设置；
  - 无日常设置默认未锁屏，不回写过期历史快照。
  - 万象视界最终保存通过冲突校验后，按最新成功保存结果执行。
- 列表、详情和汇总状态读取同一份结果数据。
- 配置持久化，页面刷新后保留。
- 规则保存后在线设备同步最新状态；离线设备恢复联网后按当前有效规则和临时锁屏状态同步，不补执行已解除的临时锁屏指令。

## 9. 验收重点

1. 五个Tab都按全校/年级规则或状态列表展示，不出现班级下钻、逐年级卡片、学段分组、分页或记录入口。
2. 学校停止借用和班主任学生禁借均阻止新借出，不影响归还。日期全天禁借高于每周；未设时段的所选星期全天可借，未选星期不可借；无当天日期规则且无每周规则默认可借。
3. 停止、恢复先选年级，禁选目标已达成范围；局部恢复只移除该范围，全恢复后停用行消失，默认范围/人工范围显示正确。
4. 借用每周每年级一份，支持共享星期组和每日不同，日期多条但包含起止日的交集均拒绝。日期规则不显示生命周期标签，过期后自动删除，结束日期当天仍保留并执行禁借。
5. 新增每周或时长时全部年级已配置，只有年级区和统一提示，无参数及保存。编辑原规则不受此空态影响。
6. 借用/时长/智阅编辑均预选原范围，可迁移年级；取消原范围移除本条、保留其他配置，老师保护方式继续生效。新旧范围冲突或对象变化整批不保存。
7. 时长三项、星期及修改范围必填，可用时段可选；星期横排紧凑，日期/数字有校验。空时段全天仍受时长上限约束，保留既有学生端计时。
8. 时长及智阅人工规则在前，灰色默认规则在末尾、不可操作。单独设置年级移出默认，删除后恢复，范围为空隐藏；教师实际调整不回写学校时长规则。
9. 时长新增仍默认参数/无时段时提示「当前仍为默认规则，无需新增」；智阅仍默认权限时提示「当前仍为默认规则，无需修改」，不生成冗余人工配置。
10. 智阅修改权限与删除可用，删除后恢复两项不允许；按学生及科目的开发规则、学校全科目及老师授权范围分别验证，不能把演示数据视作逐科功能已实现。
11. 万象停止/恢复先选年级，保留老师选择有效，无变化不能保存；消息、入口拦截、浏览中强制退出沿用规则。
12. 锁屏只解除临时限制，执行当前日常状态；局部解除老师立即恢复权限，不等待会话结束。全校结束清理例外，不回滚老师新设置；新增/转班跟随当前班级状态。
13. 必填红*、统一弹窗结构、默认填入不等于保存、取消保留或放弃行为符合对应流程；成功提示仅结果，无人数/权限解释。
14. 四张借用拦截/学生锁屏示意图保留；借用周规则展示完整时段或全天，日期显示当前适用范围，学生禁借不显示借用时段。
15. 配置刷新后保留，服务端角色/关联/版本校验有效，离线联网执行最新配置，不补执行已解除限制。

### D. 参数校验

- 星期至少选择一天，不能跨组重复；已占星期不能再次新增。
- 三项时长须为正整数，每日累计不短于连续使用时长。
- 非空时段须起止完整、结束晚于开始、不跨日、不重叠；借用完全空白行忽略。
- 日期起止必填、结束不早于开始；新增开始不早于学校当天，编辑已有日期不受新增起日限制，但结束日期不可早于今天，仍校验日期顺序、重叠及版本。
