# AI学伴全校设备管控产品需求文档

版本：v2.12 ｜ 更新：2026-10-15 ｜ 本期：教师端 · 学校管理员

## 1. 目标与入口

学校管理员可统一设置本校学生的平板借用时间、智阅作业权限、万象视界权限及锁屏状态，并支持批量操作和学生单独调整。

入口：教师端「全校管理 → 全校设备管控」，与「全校设备使用」同级。包含借用管控、智阅作业管控、万象视界管控、锁屏管控四个 Tab，仅可操作所属学校。

### 1.1 阅读说明

- 产品重点确认第 3～6 节的业务规则及附录文案；开发同时依据第 2 节通用交互和第 7.1 节实现要求；测试依据第 7.2 节逐项验收，并覆盖附录中的提示、确认和校验文案。
- 原型用于说明页面布局和交互；当原型演示数据与本文业务规则不一致时，以本文规则为准，开发或测试发现不一致需先同步产品确认。

| 术语 | 本文含义 |
| --- | --- |
| 操作对象 | 管理员在当前层级勾选的年级、班级或学生 |
| 影响学生 | 操作对象展开后实际被修改的去重学生；年级、班级本身不直接保存配置 |
| 规则／配置 | 按学生保存的借用规则、作业权限、万象视界权限或锁屏状态 |
| 当前生效结果 | 按开关状态、日期优先级及最后一次成功操作计算出的学生实际状态 |
| 汇总数据 | 年级、班级列表中的人数、规则摘要和差异说明，由其下学生当前配置实时汇总 |

## 2. 通用操作

### 2.1 层级与选择

| 当前位置 | 展示内容 | 进入下一级 |
| --- | --- | --- |
| 全校 | 年级列表 | 点击年级 |
| 年级 | 当前年级的班级列表 | 点击班级 |
| 班级 | 当前班级的学生列表 | 点击学生或「查看并设置」 |
| 学生详情 | 当前模块的个人配置、操作记录 | 可单独设置 |

- 提供面包屑和返回上一级按钮。切换模块保留当前年级、班级位置。
- 切换层级、模块、借用规则类型、搜索或筛选时，清空勾选；列表回到第一页。
- 列表批量操作按钮始终可见。未勾选时点击，按当前层级提示「请先选择所要操作的年级／班级／学生」，不进入设置或确认流程。
- 勾选后只操作选中对象，支持本页全选和跨页勾选。主列表显示选中数量、影响学生数及「取消选择」。
- 设置抽屉自动带入操作对象；顶部展示所选对象名单及影响人数，名单过长时内部滚动，不再次选择年级、班级。
- 顶部全校按钮始终影响全校，不受列表搜索、筛选或勾选影响。
- 万象视界、锁屏的列表未勾选时展示两个方向的操作；勾选后状态一致时只显示反向操作，状态不同时保留两个。

### 2.2 生效与操作记录

- 配置按学生保存。批量操作写入选中范围内每名学生，未选学生保持原值。
- 全校、年级、班级、学生之间不设固定优先级；后续成功操作覆盖对应配置。借用规则按第 3 节的日期冲突规则处理。
- 保存按钮为「保存并生效」。保存、覆盖、删除及权限操作均二次确认，显示操作对象、影响人数和结果；取消不修改配置。
- 用户确认后进入提交状态，操作按钮不可重复点击；接口成功后再更新列表、汇总数据和操作记录，接口失败时保留原配置并提示失败原因或重试。
- 四个模块的学生列表均提供「最后操作人」「操作时间」两列，借用的两个子 Tab 均展示；无记录时显示「—」。
- 操作人格式为「学校管理员（手机号）」，读取当前用户资料中的手机号，不以邮箱账号替代。学生详情同步展示操作记录。

### 2.3 列表展示

| 模块 | 年级、班级列表的业务字段 |
| --- | --- |
| 每周固定借用规则 | 适用星期、借用时段、覆盖人数、说明 |
| 指定日期借用规则 | 适用日期、借用方式、借用时段、覆盖人数、说明 |
| 智阅作业 | 查看答案、查看详解 |
| 万象视界 | 权限状态、已开放人数 |
| 锁屏 | 锁屏状态、已锁屏人数 |

- 学生列表展示个人配置及操作记录，不显示覆盖人数、差异说明；保留学生姓名、编号。
- 支持当前层级的名称搜索和状态筛选；学生支持姓名、编号搜索。筛选只改变列表，不改变配置。
- 默认每页 10 条，可选 20、40 条；超过一页时显示页码、上一页、下一页，序号跨页连续。
- 状态说明紧随标题，用文字和状态点展示；表格可横向滚动，操作列固定。手机端可正常浏览、选择和提交。

## 3. 借用管控

### 3.1 全校开关与生效顺序

借用管控决定学生能否从柜机借出平板。

| 全校状态 | 借用结果 | 页面 |
| --- | --- | --- |
| 关闭 | 不受借用时间限制 | 显示「开启借用管控」；隐藏规则区域，已有规则保留 |
| 开启 | 只能在个人有效规则允许的时段内借用；无有效规则时禁止借用 | 显示「关闭借用管控」及规则区域 |

开启后，按学生和当天日期判断：

1. 有指定日期规则：仅执行该规则，不叠加每周规则。
2. 无指定日期规则：执行对应星期的每周固定规则。
3. 两类规则均不适用，或不在允许时段内：禁止借用。

指定日期规则到期或删除后，自动恢复执行当天对应的当前每周规则；没有每周规则时仍禁止借用，无需管理员重新配置。

### 3.2 新增与编辑

规则分为「每周固定借用规则」「指定日期借用规则」两个子 Tab，只显示当前类型的新增按钮及规则。学生详情默认跟随外层选中的类型。

| 字段 | 每周固定借用规则 | 指定日期借用规则 |
| --- | --- | --- |
| 操作对象 | 当前勾选的年级、班级或学生，自动带入 | 同左 |
| 适用日期 | 星期一至星期日多选，至少选择一天 | 开始日期、结束日期，包含起止日，可为同一天 |
| 借用方式 | 固定按时段借用，不显示选择项 | 按时段借用／全天禁止借用 |
| 借用时段 | 至少一组完整起止时间，可添加多组 | 按时段借用时必填；全天禁止时不填写 |

- 时间校验：结束晚于开始；同一规则的时段不得重叠，允许相邻，暂不支持跨日。开始时刻允许借用，结束时刻停止。
- 日期校验：结束日期不得早于开始日期。星期不提供每天、工作日、周末快捷项。
- 「添加时段」位于最后一组时间选择后。
- 学生详情支持新增、编辑、删除个人规则；编辑时对象固定，不提供复制。

### 3.3 冲突与删除

冲突按同一学生、同类规则、同一天判断，不以借用时段是否重叠判断。

| 新旧规则 | 保存处理 |
| --- | --- |
| 每周规则与每周规则 | 提示冲突人数；确认后覆盖重叠星期，其余星期保留 |
| 指定日期与指定日期 | 提示冲突人数；确认后覆盖重叠日期，其余日期保留 |
| 每周规则与指定日期 | 分别保留，指定日期优先生效 |

- 保存确认展示对象、影响人数、日期和时段；有冲突时明确提醒覆盖。取消则整批不写入。
- 列表「删除借用规则」删除选中对象在当前子 Tab 下的全部规则；学生详情的删除只影响该学生的当前一条规则。
- 删除指定日期规则后执行当前每周规则；删除同类新规则不恢复此前被覆盖的旧规则。
- 删除确认需说明影响对象、人数、规则条数及删除后果。

### 3.4 规则摘要与差异

- 年级、班级列表展示已配置组中适用人数最多的一组规则，最多预览两条；更多内容通过「查看全部」进入详情。
- 日期、借用方式、时段分列展示。覆盖人数显示「X/Y 人」：X 为当前展示方案的适用人数，Y 为当前范围总人数。
- 其他学生配置不同时，说明显示「另有 N 人配置不同」；全部未配置时显示「0/Y 人」，参数和说明显示「—」。
- 配置一致时提供「查看借用规则」，不一致时提供「查看差异」，打开只读抽屉。列表摘要不代表规则优先级或最近一次年级、班级设置。
- 仅比较当前规则类型，按实际星期、日期、借用方式和时段分组，忽略规则 ID、保存批次和选择顺序；相同内容合并展示。
- 多组命名为「借用规则 1、2……」，未配置学生单列「未设置借用规则」；仅有一组已配置规则时显示「统一借用规则」。各组人数合计等于当前范围人数。
- 「查看学生」展示对应名单，支持姓名、编号搜索及分页；涉及多个班级才显示班级筛选。返回不改变主列表的勾选和位置。

## 4. 智阅作业管控

- 两项独立权限：「查看答案」「查看详解」，默认均不允许。
- 「设置权限」为选中对象统一赋值；个人或配置一致时回显当前值，配置不一致时两项以不允许作为本次设置的初始值。
- 「恢复默认」将选中学生的两项权限均设为不允许。学生详情可单独设置。
- 年级、班级汇总显示「全部允许／部分允许／全部不允许」；部分允许时补充「X/Y 人」，学生行只显示个人允许或不允许。

## 5. 万象视界管控

标题后显示「X 名学生已开放，Y 名学生已禁止」，统计当前层级全部学生，随权限更新，不随列表勾选或筛选变化。

| 全校权限状态 | 顶部全校按钮 |
| --- | --- |
| 全部开放 | 全校关闭权限 |
| 全部禁止 | 全校开放权限 |
| 部分开放 | 全校开放权限、全校关闭权限 |

- 支持全校、选中范围及学生单独开放或关闭；关闭后学生仍保留在列表，可通过状态筛选查找。
- 学校管理员和老师的最新成功操作决定个人权限，不设身份优先级。学生详情只显示与当前状态相反的操作。
- 学生无权限进入时弹窗：标题「暂时无法进入万象视界」；内容「当前暂未开放万象视界使用权限，请联系老师」；按钮「我知道了」。关闭后停留原页面。

## 6. 锁屏管控

### 6.1 学生端锁屏页面

| 锁屏来源 | 标题 | 说明 | 解除条件 |
| --- | --- | --- | --- |
| 教师端手动锁屏 | 设备已被老师锁定 | 当前暂时无法使用设备，请等待老师解除锁屏。 | 仅教师端解除，学生端不能自行解锁 |
| 低电量自动锁屏 | 设备电量过低，已自动锁屏 | 请连接充电器，电量恢复后再继续使用设备。 | 达到安全电量后自动解除；若同时存在教师端手动锁屏，仍需老师解除 |

- 两种页面沿用统一布局：顶部展示锁屏来源，中部展示当前时间、状态与说明，底部提供「退出登录」「归还设备」。
- 演示控制台提供「低电量锁屏」「教师端手动锁屏」两个入口。本期低电量仅演示学生端页面，设备阈值检测和自动解锁逻辑仍按第 8 节作为后续需求。

标题后显示「X 名学生已锁屏，Y 名学生未锁屏」，统计当前层级全部学生，随锁屏状态更新，不随列表勾选或筛选变化。

| 全校锁屏状态 | 顶部全校按钮 |
| --- | --- |
| 全部未锁屏 | 全校锁屏 |
| 全部锁屏 | 全校解除锁屏 |
| 部分锁屏 | 全校锁屏、全校解除锁屏 |

- 支持全校、选中范围及学生单独锁屏或解除锁屏，按最新成功操作生效；学生详情只显示反向操作。
- 锁屏独立于借用权限：允许借出时仍可借出，借出的平板可能处于锁屏状态。
- 解除手动锁屏不解除低电量等其他原因触发的锁屏。本期只做即时操作。

## 7. 开发与测试验收

### 7.1 开发对接

- 服务端校验学校管理员身份及学校归属；配置持久化，刷新后保留。
- 前端提交操作对象类型及 ID、模块、动作和配置内容；服务端展开为去重学生范围，并返回实际影响人数。前端不得用当前页可见数据代替完整选中范围。
- 服务端按学生执行冲突校验和批量更新，记录操作人、手机号、操作时间、操作范围及变更内容；列表和详情读取同一份结果数据。
- 成功响应后刷新当前层级的个人配置、人数统计和差异分组；失败响应不写入操作记录，也不提前改变页面状态。
- 对接设备权限校验、锁屏指令及下发结果；离线处理见待确认项。当前原型用于确认交互，以上接口和设备执行需开发接入。

### 7.2 关键验收场景

验收数据至少包含 3 个年级、40 个班级、1200 名学生，并准备全部一致、部分不同、全部未配置三类状态。每个场景同时检查页面结果、刷新后结果和学生实际权限；涉及人数时按去重学生统计。

| 场景 | 预期结果 |
| --- | --- |
| 未勾选，点击任一列表批量按钮 | 提示先选择当前层级对象，不打开设置或确认流程，不改变数据 |
| 勾选年级或班级后保存，再单独修改一名学生 | 批量设置只影响选中范围，个人修改后上层统计和差异同步更新 |
| 借用管控关闭后重新开启 | 关闭时不限制借用且隐藏规则；重新开启后原规则仍在 |
| 每周规则生效期间增加节假日禁止借用规则 | 指定日期全天禁止；到期或删除后自动恢复当前每周规则 |
| 保存同类同日冲突规则后取消／确认 | 取消整批不写入；确认只覆盖重叠日期，其他日期保留 |
| 全校仅部分学生开放或锁屏 | 显示准确的正反状态人数及两个全校按钮，任一操作均确认全校影响范围 |
| 学校与老师先后调整同一学生 | 最后成功操作决定万象视界权限或手动锁屏状态 |
| 修改学生借用规则 | 两个借用子 Tab 均可查看最后操作人及时间，操作人括号内为手机号 |
| 使用 40 个班级、1200 名学生操作 | 层级浏览、跨页选择、搜索筛选及手机端操作可用 |

## 8. 后续事项

### 8.1 已记录需求

- 小程序开放给老师管理自己的班级，沿用按学生生效及最新操作规则。
- 低电量自动锁屏：初始阈值 10%；未归还且耗尽电量关机时，需先充电再开机归还。教师端管控优先，设备端后续实现。

### 8.2 待确认

| 事项 | 需明确的内容 |
| --- | --- |
| 低电量与作答保护 | 达到还是低于 10% 触发、归还提示、充电解锁条件、锁屏时作答保存与恢复 |
| 权限拦截 | 学生已进入万象视界后被关闭权限如何处理；答案和详解权限适用哪些页面 |
| 设备下发 | 离线设备的重试、执行结果及失败提示 |
| 学生变动 | 新增或转班后的初始配置，既有批量设置是否追溯应用 |

## 附录：交互文案模板

### A. 动态值口径

花括号内为动态值，展示时替换为实际数据，不显示花括号。

| 动态值 | 取值口径 |
| --- | --- |
| {对象类型}、{已选数量} | 对象类型为当前列表的年级、班级或学生；数量为已勾选对象数 |
| {范围} | 全校；已选 X 个年级／班级；已选 X 名学生；个人操作为「班级 · 姓名」 |
| {影响人数} | 本次操作实际影响的去重学生数；全校操作取全校学生数 |
| {覆盖人数}、{总人数} | 当前展示借用规则组的人数、当前层级全部学生数；全部未配置时覆盖人数为 0 |
| {差异人数} | 当前范围总人数减去展示借用规则组人数；大于 0 时显示差异提示，无差异显示「—」 |
| {冲突人数} | 至少存在一条同类同日冲突规则的去重学生数，不是冲突规则条数 |
| {规则条数} | 所选学生当前类型规则条数之和；同一规则应用给 30 名学生时，按 30 条学生规则计数 |
| {适用日期}、{借用时段} | 星期用「、」连接，指定日期用「开始日期 至 结束日期」；时段用「08:00–12:00」，多组用「、」连接，全天禁止时为「全天禁止借用」 |

### B. 列表、抽屉与反馈

| 场景 | 文案模板 |
| --- | --- |
| 未勾选时点击批量按钮 | 请先选择所要操作的{对象类型} |
| 未勾选时操作区常驻提示 | 请先选择{对象类型} |
