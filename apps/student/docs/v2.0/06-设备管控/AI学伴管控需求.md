# AI学伴全校设备管控产品需求文档

版本：v2.96 ｜ 更新：2026-10-30

## 1. 需求概述

### 1.1 目标

本文说明学校管理员在教师端的全校设备管控、学生端响应及跨端共用业务规则。微信小程序的三类角色、页面与交互需求统一维护于[《微信小程序设备管控需求文档》](https://fcnw5yd4oj1w.feishu.cn/docx/Qcxdd67fIowvDOxLEl4cATd6ny2)。本期包含五个模块：

1. 柜机借用管控：设置学校借出时间与临时禁借，班主任管理关联班级的学生禁借。
2. 使用时长管控：限制学生使用设备的时长和可用时段。
3. 智阅作业管控：按科目设置答案和解析的查看权限；解析沿用当前页面名称「详解」。学校管理员统一设置全科目，班主任可逐科设置，任课老师仅可设置当前有效任教科目。
4. 万象视界管控：设置学生能否进入万象视界。
5. 锁屏管控：学校管理员可对全校或年级临时锁屏，也可单独解除；解除后执行当前日常锁屏设置。

### 1.2 权限边界

| 教师端角色 | 数据范围 | 可操作内容 |
|-|-|-|
| 学校管理员 | 所属学校及年级；最深到年级 | 使用五类管控，操作全校、年级。借用可设置每周、日期规则及临时禁借，不直接操作具体学生；管理员锁屏为临时锁屏。 |

微信小程序的学校管理员、班主任及任课老师权限已迁移至[小程序需求的角色权限表](https://fcnw5yd4oj1w.feishu.cn/docx/Qcxdd67fIowvDOxLEl4cATd6ny2#doxcnRjMVvQXJcivwRmEBuTggfc)。本文涉及老师规则的条目用于定义共用优先级与执行逻辑，不表示教师端向老师开放入口。

- 教师端全校设备管控仅学校管理员可见、可操作，班主任和任课老师不显示入口。学校管理员是当前学校的最高管理角色，权限失效由平台管理员处理；移动端角色权限及页面交互参见[小程序独立需求文档](https://fcnw5yd4oj1w.feishu.cn/docx/Qcxdd67fIowvDOxLEl4cATd6ny2)。
- 前端角色判断只控制入口和功能展示。每次查询或修改必须由服务端校验教师与学校、班级、学科及有效学期的关联。
- 老师不得查看或修改无有效关联的班级和学生；班级关系失效后立即失去对应权限。

### 1.3 管控范围与规则优先级

- 学校管理员按模块和操作范围设置规则，各模块独立生效。
- **生效范围**

  - 借用、使用时长、智阅作业、万象视界和锁屏可同时生效。
  - 借用每个年级只保留一份每周安排，可设置多条不重叠的全天禁借日期规则；使用时长按星期设置，每年级每个星期只能有一条规则，已有星期不可重复新增，逐条编辑和删除按对应模块规则处理。智阅作业和万象视界修改当前权限状态。
- 使用时长、万象视界通过「本次修改哪些学生？」选择修改范围；智阅作业通过「本次如何修改？」选择修改方式：修改所选范围的全部学生，或保留老师已设置的内容、只修改其余内容。使用时长保留班主任设置，智阅作业和万象视界保留老师设置；具体判断方式见各模块。
- 是否保留老师设置按模块独立判断：使用时长按学生及星期，智阅作业按学生及科目，万象视界按学生当前设置。
- 学校管理员维护每周、指定日期借用规则，日期规则优先；学校临时禁借与班主任学生禁借独立生效，均可阻止新借出。班主任不配置时间规则，不设借用权限开关。
- 万象视界允许学校和有权限的老师调整学生使用状态，以该学生最后一次成功修改的结果为准。学校选择保留老师设置时，跳过这些学生。
- 新增学生的普通规则执行当前学校规则，不追溯历史批量操作；临时锁屏按当前所在班级的临时状态继承，班级已局部解除则不受临时锁屏限制。
- 学生转班后，借用时间规则及临时禁借跟随新班级，已有学生禁借保留并由新班主任接手。其他普通规则按以下规则处理，不继承新班级老师历史批量配置；

  - 使用时长无其他规则时执行全校默认。
  - 临时锁屏单独处理：立即跟随当前所在班级的临时状态，不携带原班级临时状态。
  - 日常锁屏按转班规则重新计算，无日常设置默认未锁屏。

### 1.4 核心术语

| 术语 | 含义 |
|-|-|
| 操作对象 | 学校管理员本次选择的全校或年级；批量操作为已勾选的年级。 |
| 影响学生 | 操作对象展开后实际被修改的去重学生 |
| 学校规则 | 学校管理员为指定范围保存的配置。使用时长无其他配置时执行固定默认值；各模块覆盖方式见对应章节。 |
| 当前生效规则 | 按日期、管控范围和最新成功操作计算后，学生实际执行的规则 |
| 汇总状态 | 根据范围内学生当前配置实时统计的结果 |

## 2. 通用交互

### 2.1 层级和选择


- 教师端学校管理员仅管理全校及年级，最深到年级。五类管控只展示年级卡片，不提供班级页面、学生列表、年级标题跳转或「查看班级」入口。
- 柜机借用管控不展示「小学／初中」学段标题，年级卡片按一年级至九年级连续排列；其他四个模块保留现有学段分组。
- 全校统一设置借用规则通过「设置全校借用规则」先选择年级，再进入同一规则管理页；使用时长、智阅权限和万象使用状态分别通过「设置全校使用时长规则」「设置全校权限」「设置全校使用状态」进入年级多选，全选后统一设置；全校临时禁借和全校临时锁屏保留顶部直接入口。
- 单个年级设置影响该年级全部学生；批量设置影响全部已选年级。编辑已有规则时统一应用到当前整个年级，不再只修改原先拥有该规则的班级。各模块已有的「保留老师设置」选项继续按对应模块规则执行。
- 历史配置不因打开页面而被清空或自动统一；管理员保存后按本次规则统一所选年级，借用每周规则允许确认后修改已有年级安排，日期规则仍不允许重叠；其他模块的未涉及星期及配置保持原设置。
- 五个模块不展示「有差异」「不一致」「规则一致」等配置比较标识；仍保留实际使用权限、临时禁借、临时锁屏状态及影响人数。
- 柜机借用不再进入卡片批量勾选模式，先选择年级再进入规则页，支持全选，不额外展示已选年级数和影响学生数摘要；未选年级时「下一步」不可用。使用时长、智阅作业、万象视界通过各自「设置全校…」按钮进入年级多选，支持全选，未选择年级时设置按钮不可用。锁屏不提供批量操作按钮或年级多选，仅保留顶部全校操作及卡片单年级操作。
- 使用时长、智阅作业和万象视界的批量模式中，整张年级卡片点击或键盘空格／回车只切换勾选；隐藏单项按钮和最近操作。使用时长、智阅作业、万象视界点击「退出设置」或切换模块，均退出多选并清空勾选。
- 设置面板和确认弹窗显示年级名称及人数，不提供班级选择器。底层为执行规则展开为班级或学生，不代表管理员可直接选择班级。
- 临时禁借、临时锁屏由管理员手动开启和解除，不设置自动到期。

- 全校设备管控的规则列表、规则编辑、权限设置及记录等浮层统一使用居中弹窗，不使用侧边滑出布局。设置类弹窗宽屏最大760px，详情类可扩展至960px，确认类最大480px；窄屏保留边距。长内容在内容区滚动，标题和底部按钮保持可见。嵌套确认仍覆盖当前表单，取消后保留已填内容。

### 2.2 保存和操作记录

- **保存结果**

  - 借用时间规则和临时禁借按所选年级展开为班级保存，学生按当前班级执行；使用时长、万象视界按范围展开为学生后去重保存；智阅作业展开为「学生＋科目」后去重保存。学校管理员页面仍按学生人数显示范围，不将科目数累加为人数。
  - 临时锁屏单独保存全校管控状态和班级临时状态，不覆盖日常锁屏。
  - 解除临时锁屏后执行日常设置，无日常设置时为未锁屏。
- 万象视界通过居中弹窗设置，点击「保存」执行；临时锁屏通过弹窗选择开启或解除，并确认执行。
- 使用时长、智阅作业和万象视界的范围选择放在设置内容下方、操作按钮上方，使用时长和万象视界标题为「本次修改哪些学生？」，智阅作业标题为「本次如何修改？」。选项需说明修改全部和保留老师设置的影响；使用时长按所选星期保留班主任设置，智阅作业按学生及科目保留老师设置，万象视界保留老师设置过的学生。
- **轻提示样式**

  - 统一在顶部居中显示，包含状态图标、文字及关闭按钮。
  - 成功用绿色，校验或保存失败用红色，冲突或权限限制用橙色，操作指引用蓝色。
  - 普通提示约4.5秒消失，填入或恢复默认的成功提示约3秒消失；均支持手动关闭。
- **表单校验**

  - 点击保存或确认时检查必填项和参数；校验失败显示红色提示并保留已填内容。
  - 使用时长和万象视界先检查修改范围是否选择，再检查其他必填项。
  - 使用时长可用时段为空表示全天可用；指定日期固定全天禁止借用，无须填写借用时段。
- 临时锁屏弹窗和万象视界弹窗的「取消」直接关闭，不保存，也不再次确认。其他关闭方式沿用未保存提醒。
- 接口成功后更新列表、汇总状态和操作记录；失败时保留原配置并提示原因。
- 柜机借用管控不展示「最近操作」或「操作记录」入口，也不提供记录弹窗。其余四类管控的年级卡片左下角默认收起「最近操作」，展开后显示当前对象范围内对应模块最近一次成功操作的内容、操作人和时间；无记录时不展示入口。
- **记录来源**

  - 教师端操作记录只收录教师端学校管理员的操作。
  - 小程序操作不进入该列表，但仍按业务规则同步配置和最近操作信息。
- **操作记录入口与内容**

  - 使用时长、智阅作业、万象视界和锁屏的全校页面顶部提供「操作记录」，点击打开本模块全校记录弹窗。
  - 说明为「仅记录教师端学校管理员的操作，每个模块显示近100条记录」。
  - 上述四个模块统一采用记录卡片，依次显示操作内容、操作对象、操作人和时间。智阅操作数据同时记录科目范围：管理员为全科目，老师为本次所选科目，修改前后按学生科目记录，避免将单科操作解释为全科目变更。操作对象取保存时记录的具体范围；修改前后默认收起，点击「查看修改前后」展开。
- 操作记录只读。表单内的默认设置按钮仅填写默认值，保存后才修改实际配置。
- **记录生成**

  - 成功保存规则、变更临时禁借或临时锁屏后生成记录。
  - 仅填写表单、填入默认值、取消和校验失败不生成记录。
  - 各模块独立保留最近100条记录。
- **最终保存冲突校验**

  - 借用打开设置时记录学校借用配置版本；使用时长、万象视界记录所选学生对应模块的版本；智阅作业记录本次涉及的「学生＋科目」版本，学校管理员全科目操作覆盖所选学生的全部适用科目。
  - 浏览列表和打开编辑时不提示冲突；编辑过程中保留已填内容、不打断。借用、时长、智阅仅在最终确认提交时检查并提示；万象视界在弹窗点击「保存」时检查并提示。
  - 检查配置及设置来源是否变化，其他模块的变化不阻止本次保存。
  - 借用配置版本变化时本次不保存；使用时长、万象视界任一所选学生对应模块发生变化时整批不保存，包括原本准备跳过的学生；智阅作业按本次所选「学生＋科目」校验，其他科目的变化不阻止单科保存，全科目操作中任一适用科目变化则整批不保存。
- 版本冲突时不允许部分成功，也不允许强制覆盖。
- 冲突时关闭设置、刷新数据，显示橙色提示「相关设置已被其他人修改，本次未保存，请重新设置。」管理员重新打开并核对后才能保存。
- 万象视界学校和老师可先后调整，以实际修改学生的最新保存结果为准；被跳过或状态无需变化的学生保留原状态和最近操作记录。
- 批量保存采用整批成功或整批失败；设备离线不影响服务端保存，设备恢复联网后同步最新规则。

### 2.3 列表


- 五个模块只展示所属学校的年级卡片，不分页，不提供搜索、状态筛选、每页数量、序号及班级数量。宽屏三列、中等宽度两列、窄屏一列。
- 年级名称为静态标题；卡片直接预览规则或权限状态，不标注配置差异或一致性。借用规则按内容合并展示；使用时长仅展示学校管理员保存的该年级规则，不汇总班主任或学生的实际配置。
- 借用和使用时长卡片最多预览两条规则；超过预览数量时，通过查看更多进入当前年级规则弹窗。
- 使用时长弹窗仅展示学校管理员保存的年级规则及系统默认兜底；不展示班主任来源，不实时比较班级或学生配置是否一致。编辑以整个当前年级为范围，删除该年级对应的学校规则。班主任调整不回写学校年级规则。
- 未配置的星期执行系统默认规则，不提供删除系统默认规则的操作。新增规则默认全周60／15／180分钟且不限可用时段。
- 智阅卡片分别展示答案和详解的权限，万象视界展示使用状态，锁屏展示管理员临时状态；这些实际权限／临时状态不属于配置差异标识。
- 使用时长、智阅作业、万象视界和锁屏卡片左下角的最近操作默认收起；单项设置按钮靠右。没有学生的年级保留卡片及缺省提示，不允许设置或批量选中。
- 星期按实际配置合并显示；连续三天及以上使用区间，一至两天或不连续星期逐项列出。

### 2.4 无数据与异常处理

**操作对象发生变化：**打开设置后，学生转班、移出学校或班级被删除等导致所选对象发生变化，最终提交时应再次校验。发现变化则整批不保存，关闭设置、刷新对应列表并清空选择，显示橙色提示「所选范围的学生或班级已变化，请重新选择后设置。」管理员重新选择后再设置。

| 场景 | 展示和后续操作 |
|---|---|
| 学校暂无年级 | 保留页面标题、模块切换和层级导航，在年级列表内显示「学校暂无年级」，提示先完善年级信息；不提供无对象的批量设置。 |
| 年级暂无班级 | 保留页面结构，在对应年级的班级列表内显示「该年级暂无班级」，提示先添加班级，可返回全校。 |
| 年级暂无学生 | 保留该年级卡片并显示「该年级暂无学生」，不显示操作按钮，批量模式不可选中；学生加入后再设置。 |
| 列表加载失败 | 当前模块显示加载失败缺省页，提示检查网络，提供「重新加载」。加载成功后恢复列表；不能误显示为暂无数据。 |
| 保存失败 | 设置弹窗保留已填写内容，顶部显示红色提示「保存失败，请检查网络或稍后重试。已填写的内容已保留。」管理员可重试或取消；原配置和操作记录不变。 |
| 设置被他人修改 | 最终提交时校验，整批不保存，关闭设置并刷新对应模块列表；显示橙色提示「相关设置已被其他人修改，本次未保存，请重新设置。」重新核对后再设置。 |
| 管理员权限失效 | 停止查看和修改全校管控，直接显示无权限缺省页，提示联系平台管理员。 |

## 3. 柜机借用管控

### 3.1 职责与生效条件

柜机借用管控只决定设备能否从柜机借出，不限制借出后的使用时长。禁止借用不影响正常归还。

- 学校管理员设置全校、年级的每周规则和指定日期规则，操作临时禁止借用，最深到年级，不选择班级或具体学生。
- 班主任默认可管理当前关联班级的学生禁借，支持单人、批量禁止和解除；不设置借用权限开关，不配置每周或指定日期规则。任课老师不提供借用管控。
- 学校临时禁止借用时，受影响班级不能新借出；班主任已禁止的学生也不能新借出。
- 未被上述禁借限制的学生，优先执行当天有效的学校指定日期规则；没有有效日期规则时执行每周规则。
- 未设置任何借用规则时，默认均可借用；学校临时禁借和班主任禁借优先。当天没有有效日期规则且未设置每周规则时，默认可借；已设置每周规则但当前星期或时段未覆盖，以及命中指定日期全天禁止，均不能借出。
- 全校页面说明：「未设置借用时间时，学生可随时借用；设置后，按规定时间借用。」
- 解除说明：「学校临时禁借期间，相关学生不可借用。解除后，按当前借用安排执行；班主任单独设置的禁借仍需班主任解除。」

### 3.2 每周固定借用规则

- 时段说明：「多天可共用一组时段，也可分开设置。未选的星期不可借用。」

- 每个年级只保留一份完整每周规则。「设置全校借用规则」先打开「选择年级」弹窗，已有规则的年级也可勾选，支持全选；没有学生的年级仍不可操作。已有规则标识可保留，不展示禁止重复新增提示。保存时列出所选范围内已有每周规则的具体年级，提示「X年级、Y年级已有规则，是否确认修改？」；取消不写入、保留表单，确认后整份更新这些年级的每周安排，原来没有规则的所选年级保存为新安排。
- 采用时段组设置。每组可选择一天或多天，所选星期共用该组全部时段；例如周一至周五共用一组，周六单独一组。每天不同时可分别设置七组，每天相同时可放在同一组。至少一组，且每组至少选择一天、填写一组完整时段。未选择的星期不可借用，已选择日的时段外不可借用。
- 每组支持多个时段，结束时间须晚于开始时间，不支持跨日；同组时段不能重叠。星期只能属于一组，其他组中已被占用的星期禁选；先从原组取消该星期，才能移入另一组。最后一个时段不能删除，多余时段和多余时段组可删除；删除整组同时取消该组全部星期。
- 已有每周规则时显示「修改每周规则」和「删除」，不再提供新增入口。编辑回填原有安排，相同时段的星期合并成组，不同的分别展示；编辑成功后更新该年级整份每周安排，不保留本次移除的星期。日期规则、临时禁借和学生禁借不变。
- 历史数据打开时不自动重写；历史多份每周安排的年级确认修改后收敛为一份，不需先删除。旧统一时段规则编辑时将适用星期合并为一组，保存后仍按每天实际时段执行。

### 3.3 指定日期借用规则

- 一个年级可有多条日期规则，但日期范围不得重叠；同一日期可用于不同年级。
- 日期规则仅提供「所选日期全天禁止借用」，默认固定为全天禁借，不提供按时段借用或其他方式选项。
- 新增时设置开始和结束日期，包含起止日期，可为同一天；开始日期不得早于学校当天，结束日期不得早于开始日期。已有规则可直接编辑起止日期，不按当前日期限制哪些字段可编辑；保留历史日期也可保存，仍须满足日期顺序和冲突校验。
- 选择一个、多个或全部年级保存。任一所选年级已有日期规则与本次日期范围相交，包括首尾日期同一天，均阻止整批保存，提示「所选日期已有规则，请重新选择」。保留表单、选择和原有规则，不进入覆盖确认、不允许强制覆盖；必须修改日期或年级选择后重新保存。
- 编辑日期规则时排除正在编辑的该条规则，仍与所选年级其他日期规则校验。最终提交再次检查日期与数据版本，拒绝部分成功。
- 规则新增成功后即生效，作为已保存的管控安排持续保留，不设置随日期变化的规则状态。学校时区当天落在所选日期范围内时执行全天禁借，其余日期按每周规则执行；学校临时禁借和学生禁借继续优先。
- 所有已保存日期规则均可编辑、删除，不按当前日期隐藏或限制操作。新增及编辑按钮为「保存规则」。历史非全天禁借日期规则不因打开页面自动变动，再次编辑保存时转为全天禁借并在确认摘要中说明。
- 当天不在规则指定日期范围内，或规则被删除后，按每周规则执行；未设置每周规则时默认可借用，其他禁借状态仍有效。

### 3.4 学校临时禁止借用

- 学校管理员可临时禁止全校或单个年级借用；不再通过借用卡片的批量模式操作。开启、解除均先确认范围和影响人数。
- 单个年级范围同时包含已禁借和未禁借班级时，只显示一个「设置临时禁借」入口。点击后在弹窗中选择「临时禁止借用」或「解除临时禁借」，显示各自将改变的班级数；选定操作后显示本次实际变化范围：覆盖完整年级时显示年级名称，否则列出具体班级。下一步只确认实际变化范围与学生人数，未变化班级保持原状。范围内状态一致时，直接显示对应的单项操作按钮。
- 临时禁借独立保存，不修改每周规则、日期规则及班主任已有的学生禁借；只阻止新借出，不中断已借出设备的使用。
- 开启全校临时禁借后，全校按钮变为「结束全校临时禁借」，不随局部解除或当前禁借人数变化。
- 全校管控期间可单独解除或重新禁止某年级；局部解除不结束全校管控，对应班级班主任立即恢复借用操作，其他仍禁借的班级继续只读。
- 受临时禁借影响的班级，班主任查看到的全班学生均为禁止借用，操作不可用，提示「学校正在临时禁止借用，暂时无法修改」。最终提交也要检查班级是否已进入临时禁借。
- 结束全校临时禁借时，清除本次全校临时限制及所有局部例外；没有全校会话时，解除年级仅影响所选范围。
- 解除文案统一为「解除临时禁借后，按当前有效的借用规则执行，保留已有的学生禁借」。
- 管理员在临时禁借期间仍可维护时间规则；保存时间规则不解除临时禁借。
- 刷新、退出登录不结束临时禁借；重新进入后状态保留。

### 3.5 班主任学生禁借共用规则

- 班主任按当前关联班级查看学生，单个或批量禁止借用、解除禁借；禁借立即生效，持续到当前有权限的班主任手动解除，不设置日期或自动到期。
- 学校临时禁借期间只读；所在班级解除后恢复操作，无须等待全校临时管控结束。
- 解除学生禁借后按学校当前有效的时间规则执行，不代表学生此刻一定可借。
- 班主任更换后，新班主任接手关联班级的已有学生禁借，不限定原操作人解除。
- 学生转班后，已有学生禁借保持原状态，由新班主任接手；每周、日期和学校临时禁借跟随新班级。
- 新增学生不继承班主任历史批量禁借，执行当前所在班级的学校规则与临时状态。
- 本节定义跨端共用业务规则，本次教师端原型仅实现学校管理员入口；不新增班主任或任课老师入口。

### 3.6 冲突、覆盖与页面操作


- 主页面只展示年级卡片，不再进入班级。每周固定和指定日期规则合并预览，不设置独立的全校规则汇总板块。
- 年级卡片按内容合并已有规则，忽略规则ID和排列顺序；不展示差异、一致性或班级明细标识。历史不同配置仍保留，保存前不自动改动。
- 每卡最多预览两条规则。只有每周规则时展示该年级一份安排；只有日期规则时按开始日期升序预览前两条；同时有两类规则时展示一份每周安排及开始日期最早的一条日期规则。不根据当前日期筛选或改变预览顺序。
- 日期预览只展示日期范围和「全天禁止借用」，不添加状态或高亮前缀。列表标题为「借用规则」，下方说明「禁止借用日期优先生效」。未预览的全部已保存规则提供居中的「还有X条，查看全部」；没有任何规则时显示「未设置借用规则」。
- 点击单个年级的「设置规则」进入同一规则弹窗，上下平铺「每周固定借用规则」和「指定日期借用规则」两个区域，不设类型Tab或切换控件。每周区域只有一份安排的维护入口：无规则时「设置每周规则」，已有时「修改每周规则」及「删除」，不提供新增每周规则按钮；批量范围内的现有安排在同一块中按适用年级列明，修改后统一到所选年级，仍每年级一份。指定日期区域按条目展示「编辑」「删除」，并始终提供「新增日期规则」。日期列表按开始日期升序排列。从已选年级、已选规则类型进入新增或编辑页时，直接以文本展示「年级 · 规则类型」和影响人数，不重复展示类型单选或年级复选控件。所有编辑表单的对象及类型都由前一步确定，只显示文本，不提供重复的年级或类型选择。规则管理页可点击「重新选择年级」，返回时保留已选年级。编辑后应用到整个年级，包含原先未设置该条规则的班级。删除仅移除该年级内对应内容的已有规则，其他规则保留。
- 「设置全校借用规则」先打开年级选择弹窗，初始未选，支持多选和全选，没有选择时「下一步」禁用；下一步进入所选范围的统一规则管理页，同时展示每周固定和指定日期区域，不先选择规则类型。每周用设置/修改维护一份安排，日期用新增及逐条编辑/删除管理多条；点击对应入口后才打开明确类型的编辑表单。取消选年级或关闭规则页均不写入配置。
- 临时禁借只在生效时显示状态，并紧跟年级名称。状态一致时提供对应开启或解除按钮，混合临时状态使用「设置临时禁借」选择操作；未开启不显示状态标签。操作范围始终是所选年级，确认显示实际变化范围和人数。
- 卡片采用浅灰规则底块，操作按钮靠右；不展示最近操作。借用卡片不再进入批量勾选模式，保留单项设置、临时禁借和查看更多。
- 弹层打开时背景不可操作；编辑有未保存修改时关闭须确认放弃。保存确认取消回到填写中的表单；最终确认成功才更新规则和记录，失败保留内容。
- 每周规则允许选择已有规则的年级，经明确确认后更新所选年级整份安排；日期规则按日期范围校验，冲突直接拒绝保存，不能覆盖或自动拆分。每周与日期规则独立保存。
- 保存确认不再展示「规则将应用到…」「本次编辑后更新整份每周安排」及「临时禁借及学生禁借保持不变」等额外说明，保留范围、人数、规则摘要、已有规则年级的修改询问及允许星期/时段提示。实际禁借状态仍不因规则保存而改变。
- 保存确认展示年级范围、影响人数及新规则摘要；所选范围已有每周规则时列出年级并提示是否确认修改；日期冲突时不进入确认。最终提交再次校验版本、日期冲突与对象关系，变化时整批不保存。每周保存说明未设置的星期和时段不可借用。
- 删除最后一条规则时提示删除后默认随时可借，已禁借学生除外；只有部分对象删除后无规则时，确认中说明实际影响范围。临时禁借和学生禁借独立保留。
- 借用页面移除顶部操作记录入口、操作记录弹窗和卡片最近操作。已有底层记录数据保留，不展示，也不因移除入口而清空；其他四个模块的记录展示不变。原型展示1—9年级，不限制实际学校年级数量。

### 3.7 柜机借用拦截

- 本节为柜机借用拦截弹窗，不是借出后设备的锁屏。统一标题为「暂时无法借用」，仅提供「我知道了」按钮，无操作1分钟后关闭。
- 先判断学校临时禁借或班主任学生禁借，再判断当天有效日期规则，最后判断每周规则。没有当天有效日期规则且未设置每周规则时默认可借，不展示缺少规则的拦截弹窗。
- 弹窗中的日期、星期及时间由该学生当前所在班级的规则生成，图片中的日期与时段仅为示例，不可写死。
#### 3.7.1 每周规则拦截

当前未命中学校或班主任禁借、没有当天有效日期规则，且不在每周允许星期或时段内时，展示每周规则弹窗。

展示该学生所在班级的完整每周借用规则，包含所有已设置的星期及其全部时段；逐日的全部时段分行展示，不只展示今天或下一次可借时段。文案为「现在还不能借用哦，请在【完整每周规则】时间内再来借吧」。

日期规则弹窗只展示当前命中的一条日期规则，不罗列全部日期安排。仅当学校时区当天处于该规则指定日期范围内时拦截，不因规则保存成功而禁止范围外的借用。

指定日期规则仅有全天禁借，不再提供按时段允许借用的弹窗分支。

学校临时禁止该学生所在班级借用，或班主任禁止该学生借用时，展示禁借弹窗。文案为「当前学生编号不可借用」「如有疑问，请联系管理员」，不展示星期、日期或可借时段。

该提示优先于时间规则。学校临时禁借由学校解除，班主任学生禁借由当前关联班主任解除；界面不提供学生自行解除的入口。

## 4. 使用时长管控

页面列表标题统一为「使用时长规则」，全校入口为「设置全校使用时长规则」。智阅作业列表标题为「智阅作业管控」，入口为「设置全校权限」；万象视界列表标题为「万象视界管控」，入口为「设置全校使用状态」。这些入口仍先选择年级再打开设置，不改变现有范围及覆盖规则。

### 4.1 全校默认规则

- 使用时长管控没有总开关，也不提供默认规则的开启、关闭或修改入口。
- 全校默认规则固定为：周一至周日、不限可用时段、连续使用60分钟、休息15分钟、每日累计180分钟。
- 未设置其他规则的学生直接执行全校默认规则。
- 管理员从年级卡片设置使用时长，或勾选后批量设置。全选年级可为全校设置规则。
- **填入默认设置**

  - 点击弹窗底部「填入默认设置」，填入周一至周日、60／15／180分钟、不限使用时段。
  - 提示「已填入默认设置，保存后生效」。
  - 可以继续修改；点击保存并完成确认后生效。

### 4.2 规则参数

| 参数 | 说明 |
|-|-|
| 适用星期 | 至少选择一天；新增时默认勾选周一至周日，可直接调整适用星期 |
| 连续使用时长 | 达到该时长后进入休息状态 |
| 休息时间 | 连续使用达到上限后必须休息的时长 |
| 每日累计时长 | 当天允许使用设备的累计时长上限 |
| 每日可用时段 | 可添加多组；不设置表示全天可用。设置后仅在这些时段内可使用，时长上限始终生效。 |

### 4.3 年级与覆盖范围

- 教师端支持年级单项及批量设置使用时长，不提供学生列表。
- 每个年级的每个星期只能有一条已设置规则。新增时，所选年级中任一年级已设置的星期均不可选；只能编辑已有规则，或删除后再新增。系统默认兜底不算已设置规则。
- 使用时长管控不提供指定日期规则。
- 新增使用时长规则时默认一组，填入全校默认参数并选中可新增的星期，不展示默认／自定义选择，所有参数可直接编辑。「填入默认设置」仅填写可选星期及默认参数，不会选中已被其他规则占用的星期。全部星期已有规则时，不可新增。

### 4.4 计时和学生端处理

- 连续使用、休息、每日累计、跨日、换设备、不可用时段及对应学生端提示，沿用现有已开发规则，本期不调整计算口径和交互。
- 开发和测试应复用现有实现，不在本期重新定义或改造。

### 4.5 设置流程与生效规则

- **规则执行**

  - 保存后立即生效，沿用当天已用时长。
  - 达到新上限时立即限制使用。
  - 离线设备联网后同步最新规则。
- **覆盖与保留**

  - 新增只允许选择尚无规则的星期，保存时再次校验，冲突时整次不保存；逐条编辑替换原条目，原条目星期可继续选择，其他规则占用的星期不可选择。删除或移除的星期回到默认兜底，可再次新增。保留班主任设置时，受保护星期不变。
  - 选择保留时，按每名学生的每个星期判断班主任是否设置过。
  - 班主任填入默认值并保存，也属于已设置。
- **班主任调整与年级展示**

  - 班主任默认可调整当前关联班级学生的使用时长，无须学校授权；不提供调整权限开关。任课老师没有使用时长调整权限。
  - 学校管理员的年级卡片和规则弹窗只读取学校管理员保存的年级规则；没有年级自定义规则的星期展示系统默认规则。
  - 班主任调整仅影响对应学生的实际执行规则，不修改学校的年级配置；学校页面不实时汇总、校验或提示班级／学生配置差异。
  - 学校保存时同时记录年级规则，并按所选覆盖方式更新学生实际配置；选择保留班主任设置时，年级配置仍记录本次学校规则，受保护学生对应星期的实际配置保持不变。
  - 删除学校年级规则时，移除该年级配置及学生仍匹配该条学校规则的配置；班主任已另行调整的配置保留，缺少其他配置的星期按默认规则执行。
  - 旧演示数据首次升级时，将仍可识别的学校来源规则一次性迁入年级配置；不迁入班主任规则，不清空学生实际配置，也不推测已被覆盖的历史学校配置。后续独立维护，不再由学生配置推导。
- **页面与保存确认**

  - 顶部展示全周60／15／180分钟、不限使用时段的默认规则说明。
  - 规则列表弹窗提供逐条编辑、删除及新增；设置弹窗依次展示范围、时长组、修改范围，编辑带入原值。每组可选择一天或多天，共用连续使用时长、休息时间、每日累计时长三项参数及每日可用时段；每天不同可分别建组，多个星期相同可共用一组。星期不可跨组重复；每组至少一天，三项参数须为正整数且每日累计不短于连续使用时长。保存一次校验并提交全部组，确认摘要逐组展示；编辑原规则可拆成多组，原条目只替换一次，不影响其他未涉及规则。
  - 点击「保存」后，确认弹窗展示操作对象、影响人数和最终规则摘要。
  - 点击「确认并生效」执行；确认弹窗只保留上述信息和操作按钮。
- **本次修改哪些学生？**

  - 位置：时长参数和可用时段下方。
  - 修改全部：标题带真实范围，例如「修改7年级的所有学生」；说明「将替换班主任在所选星期的设置。」
  - 保留选项：「保留班主任的设置，修改其他学生」；说明「班主任已设置的星期保持不变。」
  - 范围必选且初始不选择。
- 可用时段提示「不设置则全天可用。」全天可用仍受连续使用、休息及每日累计时长限制。
- 表单提供必填和数值校验、未保存提醒及保存确认。「填入默认设置」只填充表单，并提示「已填入默认设置，保存后生效」。

## 5. 智阅作业管控

- 权限按「学生＋科目」独立生效，每个科目分别设置「查看答案」和「查看详解」。本次所说的解析即页面现有的详解，不修改学校管理员页面名称。两项互不影响，未设置的学生科目默认均不允许。
- 科目取学校已配置且当前操作对象适用的科目，不固定列举学科。设置数学不改变语文等其他科目；查看某科智阅作业时只读取该学生该科目的权限。
- **角色与科目范围**
  - 教师端学校管理员可按年级单项或批量设置，最深到年级；当前教师端页面不增加科目选择，保存时统一应用于所选学生的全部适用科目。管理员范围不受其兼任教师的任教科目限制。
  - 班主任可管理本人当前担任班主任的班级及学生，按科目切换并分别设置每科的答案和解析，不受本人任教科目限制。
  - 任课老师仅可管理当前有效任教班级中自己任教的科目；可选科目随班级的任教关联确定。任教多科时可切换本人任教的科目，无权选择或提交其他科目。
  - 同一老师兼任班主任和任课老师时，按当前使用身份校验；班主任身份可设置本班各科，任课老师身份只能设置有效任教科目。老师端科目选择和操作见小程序独立需求。
- **教师端学校管理员设置步骤**
  - 原有卡片、弹窗和操作按钮保持不变；通过年级卡片或批量栏的「设置权限」打开弹窗，不新增按科目编辑入口。
  - 「查看答案」「查看详解」均必选。单项操作仅在所选学生全部适用科目的两项权限都一致时回填当前值；比较只看实际权限，不因来源、操作人、时间或版本不同而判为差异。批量设置或范围内存在学生、科目差异时，初始两项均填不允许。
  - 下方标题为「本次如何修改？」；两项必选且初始不选择。选项一为「全部修改」，说明「所选学生的所有科目都按本次设置，老师之前的设置也会替换。」选项二为「保留老师设置」，说明「每个学生已由老师设置的科目保持不变，其余科目按本次设置。」
  - 修改全部：将本次两项权限写入所选学生全部适用科目，包括老师此前设置的科目。
  - 保留老师设置：按「学生＋科目」判断来源；保留老师已设置的科目权限，其他科目按本次设置修改。不得因学生的数学被老师设置过，就跳过该学生的语文等其他科目。
  - 点击「保存」核对对象、人数、两项权限及修改范围，再点击「确认并生效」；本次统一操作的科目范围为全科目，人数按学生去重。
  - 「恢复全校默认规则」将两项填回不允许，提示「已填入默认设置，保存后生效」；仍需保存，实际应用全科目，并继续遵循所选的修改全部／保留老师设置。
- **生效、覆盖与反馈**
  - 老师的单人、批量设置都只影响当前选定科目及有权操作的学生；答案、详解设置分别生效。学校管理员全科目操作也只作用于本次所选年级。
  - 同一学生同一科目的权限，以通过版本校验后最后一次成功保存的结果为准；学校选择保留老师设置时，对受保护的学生科目不写入、不改来源。班主任和任课老师均属于老师来源。
  - 原有汇总状态继续展示全部允许、部分允许或全部不允许；汇总同时考虑范围内学生和适用科目的差异，不能只取某一科代表全科目。部分允许时展示人数；科目差异不将同一学生重复计数。
  - 学生端按当前作业的科目检查权限，不能用另一科目的允许结果放行；最终保存须由服务端重新校验角色、有效班级关系及科目权限，前端隐藏无权科目不能代替校验。
- 本次按科目需求中，学校管理员原型仅调整修改方式及确认说明的文案，不增加科目选择或改变页面结构；现有原型仍使用不分科目的演示数据，不能据此认定按科目存储和老师科目权限已经实现或验收。

## 6. 万象视界管控

### 6.1 教师端

- **业务规则：**学校管理员及有权限的老师可先后调整万象视界。学校可修改全部或保留老师设置；每次保存先通过冲突校验，以最后一次成功保存结果生效。
- **状态展示：**使用「允许使用」「禁止使用」「部分学生允许使用」。卡片展示当前范围的使用状态。学生端消息使用已锁定／已解锁。
- **万象视界入口**

  - 全校统一设置：通过「设置全校使用状态」勾选全部年级，再点击「设置使用状态」。
  - 年级卡片：「设置使用状态」。
  - 多选：点击「设置全校使用状态」，勾选对象，再点击「设置使用状态」。
- **万象视界设置步骤**

  - 居中弹窗顶部显示范围、总人数和当前允许／禁止人数。
  - 先选择「允许使用万象视界」或「禁止使用万象视界」。
  - 下方选择「本次修改哪些学生？」；状态和范围均必选，初始不选择。
  - 修改全部：标题带真实范围；说明「将替换老师此前设置的使用状态。」
  - 保留老师的设置，修改其他学生：说明「老师已设置的学生保持不变，其余学生按本次设置修改。」
  - 选择后显示实际变化和保持不变人数；没有变化时显示「当前选择无需修改。」并禁用保存。
  - 点击「保存」一次执行；点击「取消」直接关闭。
- **无需变更：**按本次范围筛选后，没有学生需要改变状态时提示无需修改，保存按钮禁用。只更新实际变化学生的状态、设置来源和最近操作记录。
- **单项与批量：**年级单项和批量操作使用同一设置弹窗；全校统一设置从全校页批量全选年级进入。全校临时锁屏期间，老师仍可调整万象视界使用状态；设备解锁后执行最新结果。

### 6.2 学生端

- 老师锁定后，消息中心新增「万象视界已锁定」消息。
- 学生点击万象视界时不能进入，并显示锁定提示。
- 学生已经在万象视界内时，立即弹出强制提示。弹窗只有「我知道了」按钮，点击后退出万象视界。
- 老师解锁后，消息中心新增「万象视界已解锁」消息，不显示弹窗；学生可以再次进入。
- 演示控制台提供「万象视界锁屏」，位于「教师端手动锁屏」左侧，用于模拟以上流程。

## 7. 设备锁屏管控

### 7.1 教师端

- **页面说明**

  - 管理员操作全校或年级的临时锁屏，老师管理日常锁屏。
  - 顶部说明：「可对全校或年级临时锁屏，解除后执行当前日常锁屏设置。」
  - 紧接说明加粗显示「仍处于临时锁屏的班级，老师暂不能调整日常锁屏。」
- 开启全校管控：点击「全校临时锁屏」并确认后，全校各班进入临时锁屏，日常锁屏设置保留；按钮变为「解除临时锁屏」。日常与临时状态分开保存，不通过覆盖日常状态实现锁屏。
- 全校按钮表示会话：全校管控进行中，按钮始终为「解除临时锁屏」，不依据当前锁屏人数切换。

  - 状态为「全校临时锁屏管控中」；
  - 存在局部解除时显示「全校临时锁屏管控中，部分年级已单独解除」。
  - 即使所有年级被逐个解除，也不等于结束全校管控；此时所有班级的老师均已恢复原有锁屏管控权限。
- **局部调整**

  - 全校管控中可单独解除或重新开启某年级的临时锁屏。
  - 局部解除只撤销该范围的临时限制，不结束全校管控。
  - 全校管控进行中，学校解除某个年级的临时锁屏后，该年级各班老师立即恢复原有日常锁屏管控权限，无须等待全校管控结束；其他仍被临时锁屏的班级继续受限。
- 卡片展示「已开启」「未开启」「部分开启」，仅统计管理员临时锁屏。
- 单年级动作：全部已开启时只显示「解除临时锁屏」，全部未开启时只显示「临时锁屏」，点击直接进入对应动作的确认。

  - 混合状态只显示「设置临时锁屏」，不使用开关，也不在页面并排放开启和解除两个按钮。
  - 锁屏年级列表标题栏不展示按钮，不提供批量勾选；统一操作使用顶部全校入口，局部调整使用年级卡片入口。
- **混合状态设置弹窗**

  - 顶部显示所选范围、学生人数和当前临时锁屏状态。
  - 选择「开启临时锁屏」或「解除临时锁屏」，初始不选择。
  - 选项下分别展示「X个班有学生未开启」「Y个班有学生已开启」。
  - 选定后展示实际变化和保持不变的人数，以及实际涉及范围，例如「其中270名学生将开启临时锁屏，其余120名学生保持不变」。完整年级可用年级名称概括，否则列出班级；班内仅部分学生状态变化时，该班仍列入涉及班级。
  - 没有变化时提示无需修改并禁用确认。
  - 点击确认一次执行；点击取消直接关闭。
- 老师操作限制按班级当前临时锁屏状态判断：仍处于临时锁屏的班级，班主任和任课老师不能修改日常锁屏；已解除的班级，有原有管控权限的老师可以继续锁屏或解锁。恢复权限不扩大老师原有管理范围。

  - 点击时提示「该班正在临时锁屏管控中，暂时无法修改锁屏状态。」；
  - 提交时服务端再次校验。
  - 借用、时长、智阅及万象视界不因此禁止操作。
- 结束全校管控：确认全校「解除临时锁屏」后结束会话，清除本次全部临时限制及局部例外，执行每名学生当前的日常锁屏设置。

  - 没有日常锁屏设置的学生默认未锁屏；
  - 新增学生无需开启前记录，转班学生按已确认转班规则处理。
  - 不得恢复本次管理员局部调整或保留下级独立临时锁。
  - 老师恢复操作，全校按钮变回「全校临时锁屏」。
- **解除确认**

  - 统一说明「解除临时锁屏后，执行当前日常锁屏设置，恢复所选班级老师的锁屏管控权限」。解除临时锁屏不代表设备必然解锁，仍需执行学生当前日常锁屏设置。
  - 全校解除说明结束管控并恢复老师操作权限。
  - 解除年级时说明：解除所选范围的临时锁屏，并立即恢复这些班级老师原有的日常锁屏管控权限；其他班级不受影响。
  - 混合状态设置弹窗按本次变更人数展示，见上方设置步骤。
- 持久化与记录：刷新、退出登录、局部解除不结束全校会话。开启、局部变更、结束均产生记录；重复请求应幂等，不修改日常设置。离线设备恢复联网后按当前班级及最新有效状态同步，不重放已结束的锁屏指令。
- 权限恢复与全校会话是否结束无关。学校重新开启某年级临时锁屏后，该年级各班老师再次受限，日常设置保留；再次解除后恢复权限。老师不能自行解除学校的临时锁屏。
- 新增、转班学生：立即跟随当前所在班级的临时锁屏或局部解除状态，无需存在于开启前名单。结束临时管控时撤销管理员临时限制，执行学生当前日常锁屏设置；没有日常设置则按未锁屏处理，不要求为新增学生补造开启前快照。

### 7.2 学生端锁屏页

- 锁屏页使用不透明背景覆盖学生端全部内容、底部 Tab 和更多应用入口。
- 顶部展示「学习守护｜老师已锁屏」、小晤、网络和反馈按钮。
- 页面提示设备已被老师锁定，并展示当前时间。
- 学生不能自行解锁；保留「退出登录」和「归还设备」。
- 小晤提示：「老师开启了锁屏，先休息一下，等老师解锁后再继续吧～」。

## 8. 开发要求

- 教师端全校设备管控接口只允许所属学校的学校管理员访问；跨端接口按角色校验学校归属及有效班级关系，小程序具体权限以其独立需求文档为准。
- 服务端按角色限制可操作模块与数据范围，不能仅依赖前端隐藏入口。
- 前端提交操作对象、模块、动作和配置。借用时间规则和临时禁借按班级保存；使用时长、万象视界按所选范围展开为去重学生；智阅作业按「学生＋科目」展开并去重，人数按学生去重。临时锁屏保存学校会话及班级临时状态；返回本次实际变化范围与人数。
- 服务端记录操作来源、角色、操作人姓名及手机号、时间、实际范围和变更内容，用于隔离教师端学校管理员操作记录；小程序修改仍正常生效和同步，但不进入教师端模块记录列表。
- 来源按模块独立记录。使用时长按学生和星期；智阅作业按学生和科目；万象视界按学生当前权限。学校选择保留老师设置时跳过老师来源的对象，保留原权限、来源及最近操作；学校实际写入的对象来源更新为学校。
- 服务端为各模块分别维护版本：借用使用学校级配置版本，时长、万象视界使用学生对应模块的版本，智阅作业使用「学生＋科目」版本。最终提交时校验并整批写入；版本变化不能仅靠比较当前值判断，修改后再改回也属于变化。
- 服务端分开保存日常锁屏、班级临时状态、学生当前班级及全校会话。

  - 按目标班级当前临时锁屏状态校验老师操作权限；已解除班级可操作，仍锁定班级不可操作，最终提交时再次校验；
  - 仅局部锁屏时只限制受影响范围。
  - 新增、转班即按当前班级继承临时状态。
  - 解除只撤销管理员临时限制，执行日常设置；
  - 无日常设置默认未锁屏，不回写过期历史快照。
  - 万象视界最终保存通过冲突校验后，按最新成功保存结果执行。
- 列表、详情和汇总状态读取同一份结果数据。
- 配置持久化，页面刷新后保留。
- 规则保存后在线设备同步最新状态；离线设备恢复联网后按当前有效规则和临时锁屏状态同步，不补执行已解除的临时锁屏指令。

## 9. 验收重点

1. 学校临时禁借、班主任学生禁借均阻止新借出；其余学生按有效规则执行，没有当天有效日期规则且未设置每周规则时默认可借；已设置每周规则但当前星期或时段未覆盖，或指定日期全天禁止时不能借用。新增或删除指定日期规则后，按学校指定日期优先于每周规则的顺序执行。
2. 日期规则新增成功后即生效，不设随日期变化的状态；当天位于规则的起止日期范围内时全天禁借，其他日期仍按每周规则判断。日期规则持续保留，可编辑起止日期或删除。
3. 未设置其他使用时长规则时，学生执行固定的全校默认规则；未设置可用时段表示全天可用，仍受连续使用、休息和每日累计时长限制。
4. 使用时长新增时直接填入全周60／15／180且不限时段，不展示默认／自定义选择。

   - 使用时长、智阅作业的批量操作先选择对象再进入配置；
   - 点击「填入默认设置」只修改使用时长表单并提示「已填入默认设置，保存后生效」，保存、确认后才生效。
5. 万象视界锁定后，入口拦截、消息通知和浏览中强制退出均符合要求；解锁不弹窗。
6. 学生端锁屏完整覆盖内容、底部Tab及更多应用。开启全校临时锁屏后按钮固定为解除；局部解除更新列表但不结束会话，对应班级老师立即恢复原有锁屏管控权限，其他仍锁定班级继续受限；结束全校会话后执行各学生当前日常锁屏设置，不回滚老师在局部解除期间的新设置。不得残留下级独立锁或恢复本次局部调整。
7. 批量设置只影响选中范围，汇总人数和操作记录同步更新。
8. 教师端无搜索和状态筛选，不提供班级、学生下钻或独立差异详情页；通过年级规则弹窗核对配置。五个模块卡片不分页；借用先选择年级再管理两类规则，使用时长、智阅作业和万象视界支持当前层级全选、整卡勾选、退出恢复单项入口；锁屏仅保留全校和单年级操作。
9. 学校管理员只能管理所属学校；班主任只能管理班主任班级；任课老师只能管理任教班级。班主任默认可禁止或解除关联班级学生借用，受学校临时禁借时只读；任课老师不能操作借用；使用时长调整权限默认关闭，仅学校开放后班主任可修改本班，任课老师始终不能修改。
10. 智阅按学生及科目隔离：各科答案与解析独立，未设置默认不允许；管理员统一全科目设置，页面不增加科目选择且修改方式文案明确；班主任可设置本班各科，任课老师仅可提交当前班级有效任教科目，伪造科目提交应被拒绝；保留老师设置按学生科目生效，其他科目不受误覆盖。
11. 除柜机借用不提供记录展示外，其余四模块的操作记录正确展示修改前后内容和操作信息，不展示「恢复此版本」，不支持历史回滚；使用时长的「填入默认设置」和智阅作业的恢复默认按各自模块规则执行。
12. 修改范围：时长按学生和星期保留班主任设置；智阅作业保留老师已设置的「学生＋科目」；万象视界保留老师已设置的学生。范围外保持不变。
13. 每名学生各模块在当前时刻按有效规则计算结果，五类管控可同时生效。柜机借用先判断学校临时禁借和学生禁借，再按指定日期优先于每周规则执行；班主任不配置时间规则。
14. 借用被拦截时，柜机根据学校临时禁借、学生禁借、不在允许星期或时段、指定日期全天禁止展示对应提示；

    - 不得出现全校借用开关关闭或要求开启总开关的提示。
    - 柜机弹窗仍只有「我知道了」按钮，并在1分钟无操作后关闭；
    - 该柜机弹窗不改成教师端toast。
15. 柜机借用不展示操作记录和最近操作。其他四个教师端模块的操作记录仅包含教师端学校管理员操作，不包含任何角色的小程序操作；分别保留最近100条，新操作展示年级范围及变更结果；已有历史记录保留当时的实际范围，只读不可手工修改或删除；临时锁屏与临时禁借的开启、局部变更、解除各记录一次成功操作。
16. 教师端交互验收：批量设置能核对所选对象，保存只影响选定范围。

    - 使用时长、智阅作业、万象视界的范围选择均位于设置内容下方；时长和万象标题为「本次修改哪些学生？」，智阅为「本次如何修改？」，并分别解释按学生／按科目的修改和保留范围。
    - 万象视界使用弹窗，状态与范围必选，保存一次执行；
    - 万象视界和临时锁屏点击取消直接关闭。
    - 填入默认设置只改表单，保存才生效。
17. 四类设置均在最终保存时校验冲突：借用、时长、智阅覆盖确认弹窗打开后的变化；万象视界覆盖弹窗打开后的变化。发生冲突时整批不保存。
18. 学生转班保留已有学生禁借，由新班主任接手；借用时间与学校临时禁借跟随新班级。其他新增、转班普通规则按当前学校规则处理，不追溯新班级老师的历史批量配置；临时锁屏则立即跟随当前班级，包含班级已局部解除的情况。结束临时管控后执行日常锁屏设置，无设置默认未锁屏。
