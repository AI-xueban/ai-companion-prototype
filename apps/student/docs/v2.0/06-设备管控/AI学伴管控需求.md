# AI学伴全校设备管控产品需求文档

版本：v2.19 ｜ 更新：2026-10-16 ｜ 适用角色：学校管理员、班主任、任课老师

## 1. 需求概述

### 1.1 目标

学校管理员通过教师端管理全校设备；班主任和任课老师通过微信小程序管理与本人有关联的班级及班内学生。本期包含五个模块：

1. 借用管控：设置设备允许从柜机借出的时间。
2. 使用时长管控：限制学生使用设备的时长和可用时段。
3. 智阅作业管控：设置答案、详解的查看权限。
4. 万象视界管控：设置学生能否进入万象视界。
5. 锁屏管控：即时锁定或解锁学生设备。

### 1.2 权限边界

| 角色 | 登录端 | 数据范围 | 可操作内容 |
| --- | --- | --- | --- |
| 学校管理员 | 教师端、微信小程序 | 所属学校及学校内全部年级、班级、学生 | 可使用全部五类管控；借用管控提供全校规则，其余管控可按全校、年级、班级和学生设置 |
| 班主任 | 微信小程序 | 本人担任班主任的班级及班内学生 | 可管理本班全部五类管控，支持全班或指定学生设置 |
| 任课老师 | 微信小程序 | 本人当前任教的班级及班内学生 | 可管理智阅作业、万象视界和锁屏；不能修改借用规则和使用时长规则 |

- 教师端仅向学校管理员开放全校设备管控入口；学校管理员也可以通过微信小程序进行管控，具体页面随小程序方案完善。
- 小程序只展示当前老师有关联的班级；班主任班级需标明「班主任」，任课班级需展示任教学科。
- 同一老师在不同班级可能拥有不同权限。担任班主任的班级按班主任权限执行，其他任教班级按任课老师权限执行。
- 前端角色判断只控制入口和功能展示。每次查询或修改必须由服务端校验教师与学校、班级、学科及有效学期的关联。
- 老师不得查看或修改无有效关联的班级和学生；班级关系失效后立即失去对应权限。

### 1.3 管控范围与规则优先级

- 学校管理员先设置学校规则，作为全校学生的基础规则。
- 每名学生每天只执行一套最终生效规则。老师后续按班级或学生保存时，规则写入对应学生并覆盖其原有学校规则；同一学生被多次修改时，以最后一次成功保存的规则为准。
- 学校管理员按全校、年级或班级修改规则时，必须选择修改范围：
  1. 「全校修改」：覆盖全校学生当前规则，包括老师此前按班级或学生修改的规则。
  2. 「仅修改老师未单独设置的学生」：只更新仍执行学校规则的学生，保留老师已按班级或学生修改的规则。
- 老师按班级批量操作涉及的学生，也视为已被老师单独设置。
- 全校借用管控总开关只能由学校管理员操作。总开关关闭时，班主任已设置的借用规则保留，但所有学生均不能借用。
- 任课老师可随时对整个任教班级或指定学生执行智阅作业、万象视界和锁屏操作，不依赖课程表。多名老师操作同一班级或学生时，以最后一次成功保存的规则或状态为准。
- 新增学生直接执行当前有效的学校规则，不重新执行历史批量操作。
- 学生转班后清除原班级规则和个人规则，执行新班级当前有效规则；新班级没有其他规则时执行学校规则。

### 1.4 核心术语

| 术语 | 含义 |
| --- | --- |
| 操作对象 | 当前勾选的年级、班级或学生 |
| 影响学生 | 操作对象展开后实际被修改的去重学生 |
| 学校规则 | 学校管理员设置、在没有班级或学生其他规则时执行的基础规则 |
| 当前生效规则 | 按日期、管控范围和最新成功操作计算后，学生实际执行的规则 |
| 汇总状态 | 根据范围内学生当前配置实时统计的结果 |

## 2. 通用交互

### 2.1 层级和选择

- 全校展示年级，进入年级后展示班级，进入班级后展示学生。
- 页面提供面包屑和返回上一级按钮；切换模块时保留当前层级。
- 切换层级、模块、搜索或筛选后，清空勾选并回到第一页。
- 批量操作仅影响已勾选对象；支持本页全选和跨页勾选。
- 未勾选对象时点击批量操作，提示先选择当前层级对象，不打开设置面板。
- 顶部全校操作始终作用于全校，不受搜索、筛选或勾选状态影响。

### 2.2 保存和操作记录

- 配置按学生保存。年级、班级操作会展开为学生后批量写入。
- 保存、覆盖、删除、恢复历史版本和权限变更均需二次确认；确认弹窗展示影响范围、影响人数、被覆盖规则和操作后的实际生效结果。
- 学校管理员按全校、年级或班级修改规则时，设置抽屉中的「修改范围」为必选项，提供「全校修改／修改当前范围全部学生」和「仅修改老师未单独设置的学生」两个选项；确认弹窗展示所选范围及实际影响人数。
- 接口成功后更新列表、汇总状态和操作记录；失败时保留原配置并提示原因。
- 学生列表和学生详情展示最后操作人、手机号和操作时间；无记录时显示「—」。
- 操作记录仅在教师端全校设备管控中向学校管理员开放；班主任和任课老师的小程序不提供查看入口。
- 每个全校级管控模块顶部提供「操作记录」入口，并说明「显示近100条记录」；系统仅保留最近 100 条。记录按模块展示操作人姓名、手机号、时间、范围、修改前内容和修改后内容；学校管理员可以查看其他老师的姓名和手机号。
- 操作记录支持「恢复此版本」。恢复范围只包含该记录当时涉及的学生和模块；恢复前需展示恢复后的规则。
- 恢复操作本身必须生成一条新记录；原历史记录不可删除或修改。

#### 2.2.1 并发保存

- 借用管控、使用时长管控和智阅作业管控打开设置页时，记录所选学生对应模块的规则版本；保存时由服务端重新校验。
- 任一所选学生的规则版本发生变化，本次整批不保存，不允许部分成功，也不允许任何角色强制覆盖。
- 发生冲突后关闭设置页、刷新当前数据，并显示橙色警告「所选学生已被其他老师修改，请刷新后重新操作」；不进入二次确认弹窗，不提供继续覆盖按钮。
- 万象视界和锁屏属于即时状态操作，以服务端最后成功处理的操作为准，每次操作均生成操作记录。
- 批量保存采用整批成功或整批失败；设备离线不影响服务端保存，设备恢复联网后同步最新规则。
- 选择「仅修改老师未单独设置的学生」时，服务端在保存瞬间重新计算实际范围，排除保存前已被老师修改的学生，并返回实际影响人数。

### 2.3 列表

- 支持名称搜索和状态筛选；学生层级支持姓名、编号搜索。
- 默认每页 10 条，可切换为 20 条或 40 条。
- 年级、班级列表展示汇总结果；学生列表展示个人配置。
- 使用时长的适用日期和规则参数合并在「当前生效规则」一列展示。
- 使用时长汇总说明使用「学生规则一致」「学生规则有差异」，列表直接展示当前生效规则。
- 当前规则按实际生效星期合并展示：连续三天及以上使用「周一至周五」「周一至周日」等区间；一至两天或不连续日期逐项展示，如「周一、周三」或「周一至周三、周五」。

## 3. 借用管控

### 3.1 生效条件

借用管控只决定设备能否从柜机借出，不限制借出后的使用时长。

| 全校状态 | 借用结果 |
| --- | --- |
| 关闭 | 所有学生均不能从柜机借出设备；已有规则保留 |
| 开启且命中学生、班级或学校允许规则 | 可在规则规定的时间内借出 |
| 开启但无有效规则或不在允许时间内 | 不能借出 |

### 3.2 每周固定借用规则

- 「适用星期」和「借用时段」均为必填项。
- 适用星期选择星期一至星期日中的一天或多天。
- 至少设置一组借用时段，可添加多组。
- 每组结束时间必须晚于开始时间，不支持跨日，时段不可重叠。

### 3.3 指定日期借用规则

- 设置开始日期和结束日期，起止日期均包含在内，可设置为同一天。
- 可选择「按时段借用」或「全天禁止借用」。
- 指定日期规则一定优先于每周固定规则，不叠加执行。
- 同一天同时存在学校和老师设置的指定日期规则时，学校指定日期规则优先于老师指定日期规则。
- 学校指定日期规则到期或删除后，重新计算该学生当天规则：仍有有效的老师指定日期规则时执行老师规则，否则执行该学生最后保存的每周规则。
- 指定日期规则过期后自动停用，并从当前规则列表移除；操作记录中继续保留。
- 恢复历史版本时，已过期的指定日期规则不能直接恢复生效，需重新选择有效日期后保存。
- 规则日期和过期时间按学校所在时区判断。

### 3.4 冲突、覆盖和页面操作

- 冲突按同一规则类型、同一天判断，与时段是否重叠无关。
- 新每周规则覆盖重叠星期，新指定日期规则覆盖重叠日期；未重叠部分保留。
- 每周规则和指定日期规则分别保存，指定日期规则优先生效。
- 教师端由学校管理员设置全校借用规则；小程序端班主任可为本班或指定学生设置借用规则。
- 班主任未设置班级或学生借用规则时，继续执行学校借用规则。
- 关闭管控时隐藏规则区域；重新开启后恢复显示原规则。
- 切换到指定日期规则时，页面明确说明其优先级和到期后的恢复方式。

### 3.5 柜机借用拦截

- 学生当前不能借用时，柜机弹窗提示：「现在还不能借用哦，请在【{可借用日期与时段}】时间内再来借吧」。
- 示例：「现在还不能借用哦，请在【周一到周五 08:10–12:10、14:00–16:30】时间内再来借吧」。
- 弹窗只提供「我知道了」按钮，点击后关闭；无操作 1 分钟后自动关闭。
- 可借用日期与时段根据该学生当前生效规则动态生成。

## 4. 使用时长管控

### 4.1 全校默认规则

- 使用时长管控没有总开关，也不提供默认规则的开启、关闭或修改入口。
- 全校默认规则固定为：连续使用 60 分钟、休息 15 分钟、每日累计 180 分钟、不限可用时段。
- 未设置其他规则的学生直接执行全校默认规则。
- 学校管理员可按年级、班级或学生设置其他规则；班主任可在小程序按本班或指定学生设置其他规则。
- 选择「恢复默认规则」时，确认弹窗必须展示上述完整默认参数。

### 4.2 规则参数

| 参数 | 说明 |
| --- | --- |
| 适用星期 | 星期一至星期日多选，至少选择一天 |
| 管控规则类型 | 必选；选择执行全校默认规则或设置自定义规则 |
| 连续使用时长 | 达到该时长后进入休息状态 |
| 休息时间 | 连续使用达到上限后必须休息的时长 |
| 每日累计时长 | 当天允许使用设备的累计时长上限 |
| 每日可用时段 | 可添加多组；不设置时表示全天可用，但仍受时长限制 |

### 4.3 年级、班级和学生规则

- 支持按年级、班级和学生批量设置，也支持学生单独设置。
- 新规则覆盖所选星期原有规则，未重叠星期继续保留原规则。
- 使用时长管控不提供指定日期规则。
- 恢复默认规则会删除所选范围的其他规则，学生重新执行固定的全校默认规则。

### 4.4 计时和学生端处理

- 连续使用、休息、每日累计、跨日、换设备、不可用时段及对应学生端提示，沿用现有已开发规则，本期不调整计算口径和交互。
- 开发和测试应复用现有实现，不在本期重新定义或改造。

## 5. 智阅作业管控

- 「查看答案」和「查看详解」仅适用于智阅作业，默认均不允许。
- 「查看答案」和「查看详解」均为必选项，两项权限可独立设置。
- 支持按年级、班级、学生批量设置，也支持学生单独设置。
- 恢复默认后，两项权限均为不允许。
- 汇总状态展示全部允许、部分允许或全部不允许；部分允许时展示人数。

## 6. 万象视界管控

### 6.1 教师端

- 支持全校、年级、班级和学生单独开放或锁定万象视界。
- 汇总状态展示已开放人数和已锁定人数。
- 当前范围状态一致时只提供反向操作；状态不一致时提供开放和锁定两个操作。

### 6.2 学生端

- 老师锁定后，消息中心新增「万象视界已锁定」消息。
- 学生点击万象视界时不能进入，并显示锁定提示。
- 学生已经在万象视界内时，立即弹出强制提示。弹窗只有「我知道了」按钮，点击后退出万象视界。
- 老师解锁后，消息中心新增「万象视界已解锁」消息，不显示弹窗；学生可以再次进入。
- 演示控制台提供「万象视界锁屏」，位于「教师端手动锁屏」左侧，用于模拟以上流程。

## 7. 设备锁屏管控

### 7.1 教师端

- 支持全校、年级、班级和学生单独锁屏或解除锁屏。
- 汇总状态展示已锁屏人数和未锁屏人数。
- 锁屏独立于借用权限；设备允许借出时，仍可能处于锁屏状态。
- 本期仅包含教师端即时锁屏和解除锁屏，不包含低电量或自动锁屏。

### 7.2 学生端锁屏页

- 锁屏页使用不透明背景覆盖学生端全部内容、底部 Tab 和更多应用入口。
- 顶部展示「学习守护｜老师已锁屏」、小晤、网络和消息状态。
- 页面提示设备已被老师锁定，并展示当前时间。
- 学生不能自行解锁；保留「退出登录」和「归还设备」。
- 小晤提示：「老师开启了锁屏，先休息一下，等老师解锁后再继续吧～」。

## 8. 开发要求

- 服务端校验学校管理员、班主任或任课老师身份，并校验学校归属及教师—班级—学科—有效学期关系。
- 服务端按角色限制可操作模块与数据范围，不能仅依赖前端隐藏入口。
- 前端提交操作对象、模块、动作和配置；服务端展开为去重学生并返回实际影响人数。
- 服务端记录操作人、手机号、操作时间、操作范围和变更内容。
- 服务端为每名学生保存当前规则来源及是否被老师按班级或学生修改，用于学校管理员选择性更新。
- 服务端为每名学生的每个管控模块维护规则版本，批量保存时进行并发校验并保证原子写入。
- 服务端计算规则时保证每名学生每天仅返回一套最终生效规则，并按“学校指定日期、老师指定日期、学生当前每周规则”的顺序处理借用规则。
- 列表、详情和汇总状态读取同一份结果数据。
- 配置持久化，页面刷新后保留。
- 规则保存后，在线设备及时同步；离线设备恢复联网后自动同步最新规则。

## 9. 验收重点

1. 借用管控关闭时不能借用；开启后只有命中规则才能借用。
2. 指定日期规则优先于每周规则，到期或删除后正确恢复。
3. 未设置其他使用时长规则时，学生执行固定的全校默认规则。
4. 年级、班级、学生的使用时长规则可正确设置、覆盖和恢复默认。
5. 万象视界锁定后，入口拦截、消息通知和浏览中强制退出均符合要求；解锁不弹窗。
6. 设备锁屏完整覆盖学生端，底部 Tab 和更多应用不可操作。
7. 批量设置只影响选中范围，汇总人数和操作记录同步更新。
8. 搜索、筛选、分页和跨页选择不改变未选学生配置。
9. 学校管理员只能管理所属学校；班主任只能管理班主任班级；任课老师只能管理任教班级，并且不能操作借用和使用时长管控。
10. 操作记录正确展示修改前后内容，恢复历史版本后生成新的操作记录。
11. 学校管理员修改规则时，可选择覆盖全校或仅修改老师未单独设置的学生，影响人数和结果正确。
12. 同一天只产生一套最终规则；学校指定日期规则优先于老师指定日期规则，所有指定日期规则优先于每周规则。
13. 借用被拦截时，柜机显示当前学生可借用日期与时段，仅有「我知道了」按钮，并在 1 分钟无操作后关闭。
14. 操作记录仅学校管理员可见，最多保留 100 条；恢复仅影响原记录对应的学生和模块，且生成新的不可篡改记录。
15. 设置页打开后若任一所选学生被其他老师修改，整批保存失败并显示指定橙色警告，不进入确认弹窗。
16. 新增学生执行当前学校规则；学生转班后清除原班级规则和个人规则，按新班级当前规则重新计算。

## 附录：关键交互文案

附录只记录容易产生歧义、必须统一或包含动态值的文案。普通标题、按钮和成功提示由页面规范统一处理，不在此逐项列出。

### A. 动态值

| 动态值 | 取值规则 |
| --- | --- |
| {范围} | 全校；已选 X 个年级或班级；已选 X 名学生；个人为「班级 · 姓名」 |
| {影响人数} | 本次实际影响的去重学生数 |
| {冲突人数} | 存在同类型、同日期冲突的去重学生数 |
| {规则条数} | 所选学生当前类型的规则总数 |
| {适用日期} | 星期列表，或「开始日期 至 结束日期」 |
| {时段} | 「08:00–12:00」；多组用「、」连接 |

### B. 必须统一的状态说明

| 场景 | 文案 |
| --- | --- |
| 指定日期规则说明 | 指定日期内优先执行指定日期规则，到期或删除后恢复每周固定规则。 |
| 使用时长汇总一致 | 学生规则一致 |
| 使用时长汇总不一致 | 学生规则有差异 |
| 万象视界入口被锁定 | 万象视界已被老师锁定，暂时无法进入 |
| 万象视界浏览中被锁定 | 万象视界已被老师锁定，现在无法继续浏览万象视界，请等待老师解锁。 |

### C. 关键确认说明

| 操作 | 必须展示的说明 |
| --- | --- |
| 开启借用管控 | 开启后仅允许在已配置规则允许的时间内借用；无有效规则时不能借用。 |
| 关闭借用管控 | 关闭后全校设备不能从柜机借出；已有规则保留。 |
| 覆盖借用规则 | 展示冲突人数，并说明只覆盖重叠星期或日期。 |
| 删除指定日期规则 | 删除后恢复每周固定规则；没有每周规则时不能借用。 |
| 学校管理员修改学校规则 | 提供「全校修改」和「仅修改老师未单独设置的学生」，展示各自影响人数和操作后的实际生效结果。 |
| 恢复默认使用时长规则 | 展示固定默认规则：连续使用 60 分钟、休息 15 分钟、每日累计 180 分钟、不限可用时段。 |
| 锁屏或权限变更 | 展示影响范围、影响人数和变更后的状态。 |
