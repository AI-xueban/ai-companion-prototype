## 1. 全局类型（`types.ts` 相关）

### 1.1 模式

```ts
type MapMode = 'sync' | 'pro';
// 本期只使用 pro → UI「课本同步学」
```

### 1.2 Task（进入 LearningFlow）

| 字段 | 课本同步学典型赋值 |
|------|-------------------|
| `id` | `{subject}-sync-...` 拼接 |
| `title` | 视频名 / 练习名 / 广告名 |
| `subject` | `activeSubject` |
| `durationMinutes` | 5–10 |
| `levelType` | `practice` |
| `aiReasoning` | `同步课堂微课` \| `同步课时练习` |
| `quizType` | 可选 |
| `syncLesson` | 可选透传 |
| `syncPracticeMark` | 一课一练回写键：`bookKey` + `practiceKey`；入口三态见下 |

常量：

- `KG_SCOPE_MICRO_LESSON` = 同步课堂微课  
- `KG_SCOPE_SECTION_PRACTICE` = 同步课时练习  
- 微课观看达标：`KG_SCOPE_MICRO_LESSON_WATCH_THRESHOLD` ≈ 45s  

### 1.3 一课一练入口状态（`syncProgressStore`）

文件：`services/syncProgressStore.ts`

| 存储 | 含义 | 入口文案 |
|------|------|----------|
| 无记录 | 当前小节未作答过任何一题 | 未练习 |
| `practiceStarted[practiceKey]` | 作答过至少一题，中途退出未提交 | 练习中 |
| `practices[practiceKey]` | 正常作答并提交完成 | 已练完 |

- `已练完` 优先于 `练习中`；提交后清掉 `practiceStarted`。
- 中途退出不保存作答。点进答题页立刻退出、一题都没作答，仍是「未练习」。

## 2. 课本同步 · Catalog 模型

文件：`data/juniorDemoCatalog.ts`

```ts
type CatalogLayout = 'unit-lessons' | 'chapter-sections' | 'unit-chapters';

interface DemoVideo { id: string; title: string }
interface DemoSection { id: string; title: string; videos: DemoVideo[] }
interface DemoLesson { id: string; title: string; sections: DemoSection[] }
interface DemoUnit { id: string; title: string; lessons: DemoLesson[] }
interface DemoCatalogBook { layout: CatalogLayout; units: DemoUnit[] }

type UiSchoolSystem = '六三制' | '五四制';
```

### 2.1 关键 API

| 函数 | 用途 |
|------|------|
| `isJuniorGrade(grade, system)` | 是否展示同步学主界面 |
| `getDemoCatalogBook(subject, grade, term, version, system)` | 取目录书 |
| `getDemoTextbookVersions(...)` | 版本列表 |
| `getDemoTerms(...)` | 册次列表 |
| `preferredVersion(subject, versions, system)` | 默认版本 |
| `getDemoMathTopics(...)` | 数学演示 topics |
| `getDemoEnglishTopics(...)` | 英语演示 topics |
| `resolveCatalogTerm(...)` | 册次归一 |
| `toDataSystem(uiSystem)` | UI 学制 → 数据学制 |

### 2.2 SubjectMap 内部统一课时视图

语数英与列表渲染共用：

```ts
{
  unit: string;      // 章/单元名
  task?: string;     // 语文活动·探究分组标题；普通单元为空
  section: string;   // 课时名
  videos: { tag: string; title: string }[];
  topicGroups?: ...; // 数学分组可选
}
```

## 3. 语数英同步视频源字段

### 3.1 语文 `JuniorChineseSyncTopic`

| 字段 | 用途 |
|------|------|
| `version` / `grade` / `term` | 过滤 |
| `catalog` | 单元 → UI `unit` |
| `task` | 语文 L1 分组小标题（有值才分组；不贴在课文行上） |
| `section` | 课时行 |
| `videos[].tag` / `title` | 路径步骤 / 播放标题 |

文件：`data/juniorChineseSyncVideos.ts`  
版本列表：`getJuniorChineseTextbookVersions`。

### 3.2 数学 `JuniorMathSyncTopic`

| 字段 | 用途 |
|------|------|
| `catalog` / `catalogLabel` | 章 |
| `unit` / `unitTitle` | 单元 |
| `topic` | 课时 |
| `videos[].label` / `name` | → tag / title |

文件：`data/juniorMathSyncVideos.ts`；提高：`juniorMathImproveG7A.ts`。

### 3.3 英语 `JuniorEnglishSyncTopic`

| 字段 | 用途 |
|------|------|
| `catalog` | Unit 名 |
| `videos[].label` / `skill` / `name` | skill→展示 tag；name→title |

文件：`data/juniorEnglishSyncVideos.ts`  
专项：`juniorEnglishSyncVocabG7A.ts` / `Speaking` / `Grammar`。

### 3.4 英语专项结构

```ts
// Vocab
EnglishVocabUnit { id, title, sections: { id, title, words: string[] }[] }

// Speaking
EnglishSpeakingUnit { id, title, lessons: { id, title }[] }

// Grammar
EnglishGrammarUnit { id, title, sections: { id, title, topics: { id, title }[] }[] }
```

### 3.5 名师广告

```ts
TeacherAdContent {
  title: string;
  copy: string;
  teachers: { name: string; image: string }[];
}
```

`getTeacherAd(subject)` → 无配置返回 `null`（不展示左栏广告）。

## 4. SubjectMap 关键 UI 状态

| 状态 | 含义 |
|------|------|
| `userGrade` | 当前年级（App） |
| `schoolSystem` | 六三制 / 五四制（App） |
