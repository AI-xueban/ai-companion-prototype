## 1. 定位

学生做两件事：

- **同步课本 / 课本同步学**：按课本章节看同步微课、做一课一练、做单元测试。
- **自主练习**：在整册书里自己勾目录出卷。

三个入口，文案不统一，这是产品决定。

| 位置 | 文案 | 作用 |
|------|------|------|
| 首页右侧 | 同步课本 | 选科后按课本章节学 |
| 底栏「学科」 | 课本同步学 | 按课本章节学的主场，只切学科；年级 / 册次 / 学制 / 版本去「我的 · 我的课本」 |
| 首页右侧；学科页右侧竖卡 | 自主练习 | 整册自选出卷 |

首页点进同步课本后的科目页，不放自主练习。自主练习只留首页卡和学科主场两处。

## 2. 页面结构

### 2.1 学科「课本同步学」

默认停在这一模式。左侧保留「个性化学习」入口，点进去走现有页面，本文不写。

```
[七年级 · 上册]  语文  数学  英语  道法 …
┌模式栏┐  名师广告 │ 教材全解（版本只读 · 章/单元） │ 自主练习
│课本  │           │ 课文 / 小节 / 技能格          │ 进入练习
│同步学│           │ 单元测试                      │
│个性  │
│化学习│  专项（英语 7–9）或 同步提高（数学）
首页 | 学科 | 错题 | 伙伴 | 我的
```

打开课时、专项、自主练习时，藏底栏和左侧模式栏。

### 2.2 首页「同步课本」

1. 点卡 → 选科。副标题只展示当前年级、册次，**不能改**。要改去「我的 · 我的课本」。
2. 点学科 → 该科教材全解。无模式栏，无自主练习竖卡。单元测试和专项仍在。
3. 科目页返回 → 选科页 → 再返回才回首页。

### 2.3 层级

| 层级 | 界面 |
|------|------|
| L1 | 教材全解 |
| L2 | 学习页、专项页、自主练习选题 |
| L3 | 视频 / 答题 |
| 弹层 | 章/单元、题量难度。年级 / 册次 / 学制 / 版本不在学科页 |

## 3. 年级、学制、册次、学科

当前跟哪本书，由五个值一起决定：**学制、年级、学科、版本、册次**。首页选科、学科顶栏、自主练习共用这一套。

**改书入口只有一处：底栏「我的」→「我的课本」。** 学科顶栏、教材全解、首页选科都不能改年级 / 册次 / 学制 / 版本。页面细则、验收见 [我的课本 · 需求说明](../../04-我的/我的课本-需求说明.md)。

### 3.1 我的课本（摘要）

入口：底栏「我的」右上角，设置按钮左侧小胶囊。展示「我的课本」+ `{年级} · {册次}`。

打开后合成一块「本学期课本」：默认浏览态，学制 / 年级 / 册次只读摘要，科目卡只展示当前版本。点「编辑」后，摘要变成学制、年级、册次三个下拉，点开小弹层再改；点科目可改教材版本。小学年级在年级下拉里置灰。五四制六年级在初中区。册次仅初中出现：上册 / 下册。不必每科都改。

| 操作 | 行为 |
|------|------|
| 选年级 | 更新年级。当前学科不在新年级列表 → 学科顶栏落到语文 |
| 选册次 | 更新册次 |
| 切学制 | 更新学制。当前年级不再是初中 → 落到该学制第一个初中年级；当前学科不可用 → 落到语文 |
| 改某科版本 | 只改这一科。学科教材全解、首页自主练习读同一份 |
| 返回 | 回到「我的」 |

学科顶栏科目 Tab 随这里的年级 / 学制立刻更新。

### 3.2 进入时怎么定位

顶栏「七年级 · 上册」、学科名、教材全解「人教版」等，**优先读后台筛到的学生个人档案**，不要用系统随便写的默认年级顶上去。

| 信息 | 首次进入 | 学生在「我的课本」改了之后 |
|------|----------|----------------------------|
| 年级 | 档案里的年级 | 写进端上记忆，学科顶栏立刻用新年级科目表 |
| 学制 | 档案里的学制 | 同上。当前年级在新学制下不是初中 → 落到该学制第一个初中年级 |
| 册次（上/下/全一册） | 档案里的册次 | 写进端上记忆 |
| 教材版本 | 档案里该科的版本 | 按学科记住，下次进这科用记住的，覆盖档案 |
| 章 / 单元、课文 / 小节 | 这本书还没切过 → **第一章** | 切过之后按「学科 + 版本 + 年级 + 册次」记住。再进来停在上次的章和课文 / 小节 |

档案缺某科版本时，用第 4.2 节默认表。  
首页选科页、学科顶栏只展示当前值，不能改。

### 3.3 学段

| 学制 | 初中年级 |
|------|----------|
| 六三制 | 七、八、九年级 |
| 五四制 | 六、七、八、九年级 |

小学：首页不放「同步课本」「自主练习」；进学科 Tab 显示「即将开放」。

### 3.4 年级胶囊

展示：初中 `{年级} · {册次}`；小学仅 `{年级}`。第一次打开用档案里的年级、册次。

**只读，不能点开。** 没有下拉箭头。要改去「我的 · 我的课本」。

首页选科页同样只展示当前值。

### 3.5 学科列表

随年级、学制变化。道法对外写「道法」。首页选科、学科顶栏都用下表。

**六三制**

| 年级 | 学科 |
|------|------|
| 七年级 | 语文、数学、英语、道法、历史、生物、地理、科学 |
| 八年级 | 上列 + 物理 |

### 3.6 切学科

- 点学科名：立刻切换。
- 左右滑（水平为主）：切相邻学科。
- 当前学科加粗并带下划线。
- 不展示「左右滑动切换学科」之类引导。

## 4. 教材版本

### 4.1 入口

在教材全解标题行：当前版本名，**只读，没有箭头**。

改版本去「我的 · 我的课本」里对应科目。册次也在那里改，不跟版本绑在同一个弹层。

### 4.2 记忆与默认

进入时先读后台学生档案里的该科版本。学生在「我的课本」亲手改过之后，按学科记住，首页自主练习、学科教材全解、学科自主练习读同一份。

档案没有、学生也没改过时用下表：

| 学科 | 六三制 | 五四制 |
|------|--------|--------|
| 语文 | 人教版 | 人教版 |
| 数学 | 北师大版 | 人教五四制版 |
| 英语 | 沪教版 | 人教五四制版 |
| 物理 | 人教版 | 鲁科五四制版 |
| 化学 | 人教版 | 人教五四制版 |
| 生物 | 人教版 | 鲁科五四制版 |
| 地理 | 人教版 | 鲁教五四制版 |
| 科学 | 浙教版 | 沪教版 |
| 其他 | 人教版 | 人教版 |

### 4.3 展示名

对外显示「人教版」。供应商内部版本名由数据侧映射，下拉不出现「统编版」。

### 4.4 换版本时的册次

当前册次在新版本没有 → 落到该版本第一本可用册次。这本书没有上/下册时用全一册。

## 5. 换书后的统一处理

年级、学科、册次、版本、学制任一变化：

1. 关掉学习页、专项页、自主练习选题页。
2. 这本书学生切过章 → 停在上次的章和课文 / 小节；没切过 → 第一章。
3. 自主练习已勾选清空。

## 6. 教材全解

首页科目页和学科页同一套。按课本章节组织，不按知识图谱。

### 6.1 标题行

从左到右：教材全解、版本、章 / 单元胶囊。

章 / 单元胶囊只展示当前父级名（章 / 单元），不带课文 / 小节。列表仍是该章全部子级，点课文 / 小节进学习页。

### 6.2 章 / 单元筛选

打开弹层时定位到当前章 / 单元。

| 操作 | 行为 |
|------|------|
| 点章 / 单元 | 弹层只列父级（章 / 单元），不展示下属课文 / 小节。点一项即切换并关弹层，主列表换成该章全部子级 |
| 生物等 catalog（单元下还有章 / 课） | 弹层同样只选单元，不展示下层章 / 课。要进某一课，关弹层后去主列表点 |
| 英语点 Unit | 无课文层，点 Unit 即选中并关弹层 |

主列表始终是当前章下全部子级。父级 / 子级叫法见第 13 节。

### 6.3 列表与底部

- 点课文 / 小节 / 课 → 进学习页。英语七 / 八年级沪教点 Section → 进学习页看视频列表，**不加一课一练**。九年级点技能格直接播视频。
- 单元测试钉在底部，测的是当前章 / Unit，不是当前这一课。文案只写「单元测试」，不写「本章」之类副标题。
- 名师广告有配置才显示，点进去播同步微课。
- 当前章/单元没有小节：缺省图 +「该章节下暂无内容」（演示可切「空态演示章节」），不弹报错。

### 6.4 专项

- 英语七～九年级底部：同步词汇、外教口语、语法精讲。没内容时进空态。
- 数学底部：同步提高。没内容时进空态。
- 其他学科没有这条。

## 7. 点进一课之后

这里说的「学习页」，就是从教材全解点进某一小节之后的那一屏：列出这一小节的同步微课，末尾一条「一课一练」。产品上没有「学习页」这几个字。

多数学科先到这一屏，再点卡片看视频或做一课一练。英语七 / 八年级沪教也进这一屏，但只列该 Section 的视频，**不加一课一练**。九年级不经过这一屏：点技能格直接播。

### 7.1 点视频、点练习分别怎样

| 点什么 | 接着怎样 |
|--------|----------|
| 同步微课 | 按这一屏上的顺序播。看满 45 秒算达标。播完见 7.2；点开后播不了见 7.8.2 |
| 一课一练 | 直接答题，不经过视频 |
| 单元测试 / 自主练习 | 不经过这一屏。入口在教材全解底部 / 自主练习卡，直接答题 |

这一屏没有同步名师课时，微课区轻提示「本小节 / 本课时 / 本课文暂无同步名师课」（按学科叶子叫法；有一课一练则保留，不另写补偿引导），细则见 **7.8.1**。

### 7.2 播完之后怎样

这一屏上的同步微课按列表顺序连在一起。点第几条，就从第几条开始播。不要播完自动跳下一集。语文大卡、数学等学 / 练列表都走这一套。英语 Section 学习页同样连播，但播完不出现一课一练。

| 这一小节 | 这一集播完之后 |
|----------|----------------|
| 后面还有同步微课 | 让学生选「重新播放」或「播放下一个」 |
| 已经是最后一条 | 提醒去做一课一练。可选「重新播放」或「进入一课一练」 |
| 只有一条 | 让学生选「重新播放」或「进入一课一练」 |

点「进入一课一练」和点页面上那条一课一练一样，直接答题。

### 7.3 同步微课怎么排

一课对应一组同步微课 + 末尾一条「一课一练」。一课一练是页面另外加上的，不是视频目录里的一条。

两种排法，干的是同一件事：列出这一课能看的视频，最后让你做一课一练。只是长得不一样。

**数学和其他非语文 / 英语学科：学 / 练两段列表，主标题用视频名**

点进小节后，看到的不是大卡，而是一份列表，上面有两个小标题，视频按标签归进去：

1. 学（知识理解、教材讲解、方法学习）
2. 练（题型训练、考试应用、易错巩固、综合训练）

每条**主标题写视频名称**（如「几何体的认识」），类型标签（如「知识精讲」）靠右小标签展示，不要把标签顶成主标题。右边是时长，点了播视频。列表最底下多一条「一课一练」。标签怎么判、进学还是进练，见 **7.4**。未命中规则的进对应科目「其他」，并进异常核对表，不要丢掉。

```
1 生活中的立体图形
学
  · 几何体的认识　　[知识精讲]
  · 有理数　　[知识梳理]
练
  · 平面图形与立体图形　　[题型讲解]
  · …　　[新课标新考法]
一课一练
```

**语文：按环节排成大卡（例外，不走「视频名优先」）**

点进课文后，看到的是几张很大的方卡，一张一个环节，例如「课前导学」「课文解读」。上面有序号和名字。点哪张播哪段视频。最后一张是「一课一练」。语文大卡以**环节名**为主，不拆成「视频名 + 类型标签」。环节名怎么判见 **7.4.3**。

```
沁园春·雪
┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
│ 1      │ │ 2      │ │ 3      │ │ 一课   │
│ 课前导学│ │ 课文解读│ │ …      │ │ 一练   │
└────────┘ └────────┘ └────────┘ └────────┘
```

**英语：七 / 八年级沪教进学习页，无一课一练**  
教材全解里点 Unit 下的 Section 行，进该 Section 的视频列表；靠右展示归类标签（见 **7.4.2**）。九年级点技能格直接播。一律不加一课一练。

### 7.4 多条标题怎么归类

视频该进哪一段、卡片上展示什么标签，只看原始 `videoTag` / 展示文案（学生看见的那几个字），按下面逻辑判，**命中即停**。

#### 7.4.1 初中段 · 其他科目（语文、英语除外）

**1. 标签匹配规则（按优先级，命中即停）**

| 优先级 | 命中条件 | 展示标签 | 说明 |
|--------|----------|----------|------|
| 1 | 「视频精讲」或「视频精讲」+ 数字 | 视频精讲 | 如视频精讲1、视频精讲22 |
| 2 | 包含「中考链接」 | 中考链接 | 优先于其他普通关键词 |
| 3 | 包含「知识梳理」 | 知识梳理 | 如《有理数》知识梳理 |
| 4 | 包含「综合提升」或「综合提升训练」 | 综合提升训练 | 如病毒_综合提升 |
| 5 | 包含「新课标新考法」 | 新课标新考法 | 保留统一展示名 |
| 6 | 包含「重难点练习」 | 重难点练习 | 保留统一展示名 |
| 7 | 包含「实验」「实验活动」「实验操作」「探究」等实验操作类词 | 实验探究 | 实验操作类统一归入此类 |
| 8 | 同时包含「真题」和「易错题」 | 真题易、错题点拨 | 双关键词优先 |
| 9 | 只包含「真题」 | 真题点拨 | 单独命中 |
| 10 | 包含「易错题」「易错点」或「易错误区辨析」，或以「易错：」开头 | 易错题点拨 | 统一归类 |
| 11 | 同时包含「知识精讲」和「题型 / 经典题型」 | 题型讲解、知识精讲 | 两个标签同时展示 |
| 12 | 包含「知识精讲」「知识点」 | 知识精讲 | 统一归类 |
| 13 | 包含「题型」或「经典题型」 | 题型讲解 | 「题型 + 经典题型」只展示一次 |
| 14 | 数学模型名称 | 知识点精讲 | 如 8 字模型、倍长中线模型、半角模型 |
| 15 | 包含「习题」或「_习题」 | 题型讲解 | 按已确认口径，不归同步巩固练 |

**2. 组合判断注意点**

| 原始标签命中情况 | 最终展示 |
|------------------|----------|
| 题型 + 经典题型 | 题型讲解 |
| 题型 + 知识精讲 | 题型讲解、知识精讲 |
| 知识精讲 + 经典题型 | 题型讲解、知识精讲 |
| 真题 + 易错题 | 真题易、错题点拨 |
| 单独真题 | 真题点拨 |
| 单独易错题 | 易错题点拨 |

**3. 学科专属规则**

| 学科 | 规则 | 展示标签 |
|------|------|----------|
| 历史 | `videoTag` 与当前课程的 unit、lesson 或小节名称一致 / 高度一致 | 课文精讲；否则 → 历史其他 |
| 道德与法治 | 同上 | 课文精讲；否则 → 道德与法治其他 |
| 地理 | 匹配课次格式「第一课、第二课、第三课、第 N 课」 | 课文精讲；未命中 → 地理其他 |

**4. 程序判断顺序**

1. 预处理标签：去首尾空格、统一全角半角、保留原始标签  
2. 判断视频精讲  
3. 判断中考链接、知识梳理、综合提升、新课标新考法、重难点练习  
4. 判断实验 / 探究类  
5. 判断真题与易错题组合

### 7.6 同步微课播放记录规则

学习页上**每一条同步微课**都有自己的播放记录，语文大卡、理科学 / 练列表、播放器里的列表都用同一套。只看当前这条视频，不看整课有没有学完。

| 播放情况 | 展示 |
|----------|------|
| 从未播过这条视频 | 未学习 |
| 播过，进度不到 80% | 学习中 |
| 进度达到或超过 80% | 已学完 |

- **进度** = 这条视频已播到的最远位置 ÷ 视频时长。1.5×、2× 等倍速都算：播到视频的 80% 处即「已学完」，不按墙钟时间另算一遍。
- 一旦变成「已学完」，再拖回去或重看，也不改回「学习中」。
- 「已学完」只是这条视频的播放记录。一课一练仍要另做，状态见 7.7。第 7.1 节「看满 45 秒算达标」管的是奖励，和这里的三态分开。

### 7.7 一课一练入口状态

学习页最后一条「一课一练」（语文末卡、理科末条、播完「进入一课一练」）用同一套三态。只看**当前这一课**有没有做过一课一练，不看视频有没有学完。英语没有一课一练，无此三态。

| 练习情况 | 展示 |
|----------|------|
| 当前小节未作答过任何一题 | 未练习 |
| 作答过至少一题，但中途退出、没有提交完成本次练习 | 练习中 |
| 正常作答并提交完成本次练习 | 已练完 |

- 点进答题页立刻退出、一题都没作答：仍是「未练习」。
- 「练习中」只记状态，**不保存作答**。再点进去仍从剩余未做抽新卷，不接着上次的题。
- 一旦变成「已练完」，再点换新卷或中途退出，也不改回「练习中」。
- 「已练完」后再点：仍显示「已练完」，从剩余未做换一套新题，不先看上次结果。

### 7.8 学习页无视频与播放异常

正式环境可能缺课包、剪辑链接失效或播放报错。下面两种分开处理：**学习页上根本没有可点的视频入口**，和**有入口但点开播不了**。

#### 7.8.1 学习页没有视频入口

**何时：** 点进某一课 / 小节 / Section 后，这一屏上没有任何同步微课（语文没有可点的视频大卡，理科 / 英语没有可点的视频行）。一课一练是否出现见下。

**展示：**

- 微课区域一行轻提示即可：文案 **本{小节/课时/课文}暂无同步名师课**（数学等用「小节」，英语用「课时」，语文用「课文」）。不写「即将开放」、不写补偿式引导。
- 不弹系统报错、不 toast 技术细节。
- 教材全解里这一课的入口**仍可点**，不要灰掉、不要改成「即将开放」藏进列表。
- 整页没有任何步骤（连一课一练也没有）时，仍可用同一套微课空态文案。

**和一课一练的关系：**

| 情况 | 怎么处理 |
|------|----------|
| 语数等本来有一课一练的学科 | 没有视频时，本页仍保留「一课一练」入口（末卡 / 末条），学生可直接练；空态文案与入口可同时存在 |
| 英语七 / 八年级 Section | 本来就无一课一练；没视频时只展示「即将开放」 |
| 英语九年级技能格直进播放 | 不经过学习页列表；播不了走 7.8.2，不要先造一页空列表 |

与第 12 节「学习页没有步骤」是同一类空态；细则以本节为准。

#### 7.8.2 有视频入口，但播不了

**何时：** 学习页（或九年级技能格）上能看到这条微课，学生点了进去，但实际播不起来。常见原因包括但不限于：

- 剪辑进库的播放链接失效、过期或被下线
- 点击后拉流 / 鉴权失败、返回错误，播放器起不来
- 地址为空、格式不对、资源 404
- 网络超时、CDN 不可用等导致加载失败

**展示（播放器内，不整页改成「即将开放」）：**

- 标题 / 提示：**暂时无法播放**
- 说明：可写「视频暂时打不开，请稍后再试或换一条看看。」不要把原始报错码、堆栈甩给学生。
- 按钮：
  - **重试**（主按钮）→ 再拉一次当前这条
  - **返回** → 回学习页（九年级技能格直进则回教材全解）
- 若列表里后面还有同步微课：可另给 **播放下一个**（可选），跳过坏链继续看下一条；跳过后本条仍显示未学完，不记「已学完」。

**原型演示：** 章列表末尾「播放异常演示章节」→ 点「播放异常演示」→ 点「链接失效 / 加载失败 / 网络超时（演示）」→ 进播放器即见本遮罩。

**不要：**

- 因为一条播不了，就把整课学习页改成「即将开放」或藏掉其他还能播的视频
- 把入口从教材全解列表里拿掉
- 因播放失败自动改写 7.6 的播放记录（未学习 / 学习中 / 已学完）；没真正播到有效进度就不晋级

**和 7.1 的关系：** 原型阶段「没有播放地址也可以点开播」仅方便演示。正式规则以本节为准：点开后若拉不到可播资源，走「暂时无法播放」，不要假装在播。

#### 7.8.3 视频未上线 / 正在上架中

**何时：** 这一课 / 小节的同步微课**元数据已在目录里**（学习路径列得出"课前导学 / 课文解读 / 视频精讲1"这些条目），但背后视频资源**还没上架 / 未过审**，后台不返回可播地址。和 7.8.1（连元数据都没有）、7.8.2（已上架但播不了）是三种不同情况，不要混用。

**判断时机：** 以"点播时拉不到可播资源"为准。原型阶段不在学习页列表阶段假装能播；正式以本条为准。

**展示（学习页直接拦住，不进播放器）：**

- 学习页用一张**和正常"学习路径"卡同高同结构**的占位卡替换原视频区：白卡、同样的 `px-5 py-4` + "学习路径"标题、内容区 `h-[212px]`，里头居中放**缺省图**（胶片图标 + 角标时钟，表示"等待上架"）+ 文案。**不**再逐条列出"课前导学 / 课文解读 / 视频精讲1"等视频卡——上线后是否真按这套环节拆分尚未确定，列出等于替未上线内容背书，干脆只给一条统一提示。
- 文案（学生口吻）：标题 **视频正在上架中**；正文 `本课视频还在准备中，上架后自动开放。可先做「一课一练」。` 不写"审图未过/审核中"这类内部话术。
- **不弹**"暂时无法播放"遮罩、**不给"重试"按钮**（不是瞬时错误，重试也拉不到）。
- 一课一练入口（末卡 / 末条）**仍保留可点**，不受视频未上线影响。英语七 / 八 Section 没有一课一练的，没视频时仍按 7.8.1 走"即将开放"。

**入口不藏：**

- 教材全解里这一课的入口**仍可点**，不灰、不藏、不改"即将开放"。
- 章 / 单元切换里这个单元也**不灰**，点进去照常列课文。

**播放记录：** 未上线视频点不进去，**不晋级**"已学完"，保持"未学习"。和 7.8.2"没真正播到有效进度就不晋级"同一条原则。

**文案口径：** 用"**视频正在上架中**"或"**视频即将上线**"，**不要**用"即将开放"（7.8.1 / §12 已把"即将开放"留给整页空态，混用会歧义）。不弹系统报错、不 toast 技术细节、不露报错码。

**范围粒度：** 按**每一课独立判断**，不要因同单元其他课未上线就把这一课也藏掉。同一课里部分已上架、部分未上架：已上架的照常可播，未上架的单独走本条，不要整课降级。

**原型演示：** 当前演示对象 = 九年级上册语文第六单元（23 曹刿论战 / 24* 邹忌讽齐王纳谏 / 25* 陈涉世家 / 26 出师表 / 27 诗词曲五首），整单元所有课文学习页全部视频未上线。配置见 `ai_friend_v2.0/data/videoPendingDemo.ts` 的 `VIDEO_PENDING_UNITS`。

## 8. 练习

三种练随时可进，不解锁。题目全部来自菁优网。做过的题不再抽。不考虑缺书，不藏入口。

展示用菁优网知识点 / 课文标题。

| 名称 | 范围 | 出题 | 入口 |
|------|------|------|------|
| 一课一练 | 当前这一课（英语没有） | 固定 5 题 / 中等 / 同步练习；再点换新卷 | 学习页最后一条 |
| 单元测试 | 当前章 / Unit | 按本章叶子抽 | 教材全解底部 |
| 自主练习 | 整册 | 按勾中的叶子抽 | 首页卡 / 学科右侧竖卡 |

三种练都可能碰到题不够。规则同一套，只是范围、默认题量、有没有设置弹窗不一样。细则写在 8.2 / 8.3 / 8.4 各自后面。

另有**硬阻断**异常（当前范围本来没题、当日总次数超限、当日本学科次数超限），不走减题量 / 升降难度，统一写在 **8.5**。

原型演示入口见 **8.6 异常数据章节**。

**怎么数「还能出几道新题」**

只数同时满足这四条的题，记为 **N**：

1. 落在这次练习的范围内（一课一练 = 这一课；单元测试 = 这一章 / Unit；自主练习 = 勾中的叶子）
2. 难度对得上当前这一档
3. 场景对得上当前这一档（一课一练固定「同步练习」）
4. 这名学生没做过

不要悄悄拿邻近难度的题来凑数。不够就告诉学生，让他减题量、降一档或升一档。

**题量下限**

设置弹窗里学生手选为 5–20。被库存打断后，允许按实际 N 出卷，N 最小为 1。没有新题（N = 0）不算出卷失败，走「没有新题」弹窗。

**空库存和「都做过了」不是一回事**

| 情况 | 判断 | 学生看到 |
|------|------|----------|
| 这个范围题库里本来就没题 | 任何难度、任何场景都是 0 题 | 走 **8.5.1**：「抱歉，当前章节下没有题目」，不能靠升/降难度变出题。入口仍在 |
| 有题，但当前难度 + 当前场景下未做 = 0 | N = 0，别的难度可能还有 | 「当前小节 / 本章没有新题了」，让他升一档或降一档 |
| 有未做题，但不够推荐量 / 不够他选的量 | 0 < N < 目标量 | 减到 N 题，或换一档难度再数 |
| 当日总组卷练习已满 100 份 | 成功进入答题已累计 ≥ 100（不限学科） | 走 **8.5.2**：进不去组卷练习，明日恢复 |
| 当日本学科组卷练习已满 60 份 | 该学科成功进入答题已累计 ≥ 60 | 走 **8.5.3**：进不去组卷练习，明日恢复 |

### 8.1 开始前弹窗

单元测试、自主练习共用。点入口先出弹窗，不直接进答题。弹窗从上到下：题量、难度、场景。

- **自主练习**标题：「开始自主练习，先选好题量、难度和场景」；底栏「暂不练习」/「开始练习」。
- **单元测试**标题：「开始单元测试，先选好题量、难度和场景」；底栏「暂不测试」/「开始测试」。
- 自主练习、单元测试题量均为 5–20；快捷选项按数值从小到大：5 / 10 / 15 / 20，若推荐量不在其中则并入同列；「推荐」以标签显示在对应题量上方。
- 难度：较易 / 容易 / 中等 / 较难 / 困难，默认中等。
- 场景写在难度下方。打开弹窗时默认选中「同步练习」。学生可改选，选定后按该场景出题。

| 场景 | 参数 |
|------|------|
| 同步练习 | 默认，打开即选中 |
| 真题 | sc |
| 好题 | gc |
| 常考题 | rc |
| 压轴题 | yc |
| 易错题 | ec |

- 预计时长按题型另给标准（待补）。没到之前，任务上的分钟数用「题量 × 1.5，最少 10」，不当定稿。
- 打开这个窗时不预判库存，题量预填推荐量，不要提前改成 N，也不要在题量下写库存说明。点「开始测试 / 开始练习」后去组卷，组完再按当前范围 + 难度 + 场景数未做题 N。命中 8.3 / 8.4 的异常时，异常弹窗盖在本窗上面；点「返回修改」只关异常窗，设置窗还在。

一课一练不弹这个设置窗。未做题够 5 道就直接答题；不够或没有新题时出异常弹窗，规则见 8.2。

### 8.2 一课一练

练的是**当前这一课**（语文一篇课文、数学一个小节、其他一课/一节/一个课题）。

**英语没有一课一练。** 七 / 八年级沪教点 Section 进视频列表，仍不加这条。九年级点技能格直接播。英语巩固走专项或单元测试。

**入口：** 只出现在点进一课之后那一屏的最后一条。教材全解列表不钉这个入口。随时可进，不解锁。

**点进去：** 学生不能选题量、难度、场景。未做题够 5 道时不弹窗，直接答题。不够 5 道、或没有新题时，先出异常弹窗，见下面 8.2.1 / 8.2.2。视频播完点「进入一课一练」也走同一套检查。

**已练完后再点：** 卡片仍显示「已练完」，再点从剩余未做里换一套新题，不先看上次结果。中途退出不保存作答；入口三态见 7.7（未作答仍是「未练习」，作答过未提交是「练习中」，提交后才是「已练完」）。

**系统按下面出题（学生看不见这些字，但组卷必须带上）：**

| 项 | 取值 |
|----|------|
| 学科、版本、年级、册次 | 当前这本书 |

| 题量 | **全学科固定 5 题**，不按叶子数浮动；被库存打断时按实际 N 出 |
| 难度 | 中等；学生在异常弹窗里升/降一档后，按新档出 |
| 场景 | 同步练习 |
| 去重 | 做过的题不再抽；再点时从剩余未做里打乱另抽 5 题 |

抽题时先拿当前难度、同步练习、未做过的题，并尽量让本课每个叶子至少 1 题。不要用邻近难度自动补齐。

做完或中途退出：回教材全解（从学科进）或该科科目页（从首页同步课本进），见第 10 节。

#### 8.2.1 不够固定 5 题

目标量固定 5。点入口时「中等 · 同步练习」未做 N 满足 **0 < N < 5** 即弹。

| 项 | 内容 |
|----|------|
| 标题 | 目前只能出 {N} 题 |
| 正文 | 当前小节「中等 · 同步练习」还剩 {N} 道新题，不够 5 道。可以先做，或换难度试试。 |
| 主按钮 | **确认按 {N} 题开始** → 用这 N 道未做立刻答题 |
| 其他 | **降低 / 提高难度再看看**（端点禁用）→ 按 8.2.3 重数；**先不练了** → 关窗停在学习页 |

换档后：N ≥ 5 → 直接出 5 题；仍不够 → 更新弹窗 N；N = 0 → 改走 8.2.2。

#### 8.2.2 本课没有新题了

| 项 | 内容 |

| 正文 | 当前小节「{难度} · 同步练习」的题你都做过了。可以换一档难度继续做新题。 |
| 按钮 | **降 / 升一档出新题**（端点禁用）；**再练做过的题**（打乱已做，尽量 5 题，不够就全出）；**先不练了** |

换档后有未做 → 按 8.2.1；仍无未做 → 改正文「{新难度} 也没有新题了」。两端都无未做时只留「再练做过的题 / 先不练了」。本课任意难度、同步练习都从来没题 → **8.5.1**。

#### 8.2.3 升一档 / 降一档

五档：较易 → 容易 → 中等 → 较难 → 困难。一次一档、不跳档，场景仍是同步练习。一课一练无设置窗，换档后当场重数 N，接 8.2.1 / 8.2.2。

### 8.3 单元测试

#### 8.3.1 / 8.3.2 题不够（推荐量或自选题量）

#### 8.3.3 本章没有新题了

| 项 | 内容 |

#### 8.3.4 升一档 / 降一档

同 8.2.3 五档规则；场景保持学生所选；不自动跳到有题的档。换档后回设置窗，等再点「开始测试」。新档当场 N = 0 时异常窗留着改正文。

### 一、底层原子知识点的状态计算逻辑

系统根据学生有无刷题数据，以及用「金币法」算出的健康分，判定底层原子知识点（如大纲四级、五级考点）的状态。

健康分计算公式：

\[
HealthScore = \frac{(N_{master} \times 100 + N_{review} \times 60 + N_{weak} \times 0)}{N_{total}}
\]

**1. 未知**

计算标准：学生尚未学习该点，系统中无该点的刷题记录。

举例：学期初，学生还没做过「二次函数图象」相关题目。因缺乏数据，状态默认为「未知」。规划个性化学习路径时，若该点是必要先修，仍会纳入路径。

**2. 探索中**

计算标准：学生已有训练记录，但题目数量**小于两道题**，数据量不足以稳定计算健康分。

**3. 待攻克**

计算标准：根据有效记录算出的健康分 **< 60 分**。通常意味着待攻克题目（\(N_{weak}\)）占比较高。

举例：学生做了 10 道「移项」题，错 8 道、对 2 道，健康分为 20 分。该知识点亮红灯，判定为「待攻克」，认知光谱环显示红色，系统推荐「专项攻克」。

**4. 待复习**

计算标准：健康分在 **60 分到 80 分之间（含 60，不含 80）**。

举例：学生将此前错题订正一次（权重 60），该点整体健康分为 68 分。黄灯标记为「待复习」，表示「懂但还不熟练，记忆可能衰退」。系统推荐「巩固强化」。

**5. 已掌握**

计算标准：健康分 **≥ 80 分**。意味着长期复习成功、连续答对（\(N_{master}\) 权重高）。

举例：学生在「合并同类项」上多次连续答对，健康分达到 95 分。绿灯标记「已掌握」，基础扎实，诊断卡解锁更高阶的「挑战高阶」。

### 二、题目的状态与判断逻辑（严格晋级状态机）

系统采用「一票否决」+「严格晋级」算法，题目共 4 个动态状态。

**1.1 四态定义与流转规则**

**状态 0：未做过**

定义：用户从未接触过该题。首次推荐时的默认状态。

行为：该状态的题目不在知识图谱题库中展示。

**状态 1：待攻克**

定义：该知识点存在「盲区」，用户答错了这道题。

判断逻辑（一票否决）：无论题目此前处于哪个复习阶段，只要用户答错一次（Result=0），立刻打回原形，状态重置为「待攻克」，复习阶段 S 归 0，并强制「明天」再推该题复习。

**状态 3：待复习**

定义：用户曾经掌握过该题，现需基于遗忘曲线进行长期复习检验。

判断逻辑（进入观察漏斗）：处于「待攻克」时答对一次（Result=1），题目进入「待复习」。该状态包含三个严格递进的复习阶段：

- 阶段 1（S=1）：第 1 次答对，下次推送间隔 +1 天
- 阶段 2（S=2）：在阶段 1 再次答对，下次推送间隔 +3 天
- 阶段 3（S=3）：在阶段 2 再次答对（进入「终轮」），下次推送间隔 +7 天

**状态 2：已掌握**

定义：用户已达到「自动化」水平，短期内无需再练。

判断逻辑（彻底清除）：仅当在「待复习」终轮（S=3）再次答对，该题才被彻底消灭，移出错题本，状态正式升级为「已掌握」。

### 三、题目与知识点的关系

题目与知识点在系统中是**「计分细胞（题目）」与「宏观指标（知识点）」的决定关系**。理解两者的关系，需要把握以下核心：

**1.1 包含与被包含的映射关系**

每一道题目在底层元数据中，都强绑定了一个或多个「原子知识点」（大纲里最小粒度的四级或五级考点）。题目是考察知识点的最细颗粒度工具。

**1.2 题目状态决定知识点「健康分」的计算关系**

知识点本身没有对错，它的健康分 (Health Score) 是由该知识点下所有「做过题目的状态」汇总计算得来的。知识点的健康分计算公式为：

\[
HealthScore = \frac{(N_{master} \times 100 + N_{review} \times 60 + N_{weak} \times 0)}{N_{total}}
\]

- 你在该知识点下刷出来的**已掌握题目数（\(N_{master}\)）**，贡献 100 分权重。
- 刷出来的**待复习题目数（\(N_{review}\)）**，贡献 60 分权重。
- 刷出来的**待攻克题目数（\(N_{weak}\)）**，贡献 0 分权重。

**总结：** 题目的晋级状态越好，它所属知识点的健康分就越高。
