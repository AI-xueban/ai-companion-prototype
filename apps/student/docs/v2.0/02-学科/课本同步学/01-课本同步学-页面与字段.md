### 5.1 语文 / 数学

**数据字段（统一到内部 syncLessons 视图）**

| UI 用途 | 语文源字段 | 数学源字段 | 内部统一字段 |
|---------|------------|------------|--------------|
| 章/单元名 | `catalog` | `catalogLabel` / `unit` | `unit` |
| 任务分组标题（语文） | `task` | — | `task` |
| 课时名 | `section` | `topic` | `section` |
| 视频标签 | `videos[].tag` | `videos[].label` | `videos[].tag` |
| 视频标题 | `videos[].title` | `videos[].name` | `videos[].title` |

点击课时标题 ≈ **名师课**。

**语文任务名（仅教材全解 L1）**

- 任务不是导航层，不进任务页，点课文名进课。
- 当前单元只要有课文带了 `task`，就把相同 `task` 的课文归到同一分组；分组标题（如「任务一 学习鉴赏」）不可点，不在每行重复贴胶囊。
- `task` 为空、且 `section` 以「任务」开头（任务二 / 任务三）→ 自己就是可点的课文行，不加分组标题、不加序号。
- 整单元 `task` 都空 → 普通课文列表，不显示任务。
- 数学、英语、catalog 不展示任务分组。

**L2 `SyncSectionPage`**

| 元素 | 文案 | 字段 |
|------|------|------|
| 返回 | aria「返回」 | `onBack` |
| 顶栏标题 | `unitTitle` | 传入的课时/section 名 |
| 分组小标题 | `topic.section` | 与 unitTitle 不同才显示 |
| path 布局（语文） | 小标题 **学习路径**；步骤显示 `video.tag` | `layout='path'` |
| grid 布局（数学） | 三段列表 + 末条一课一练 | `layout='grid'` |
| 一课一练状态 | **未练习** / **练习中** / **已练完** | `syncProgressStore`：`practiceStarted` / `practices`；见阅读版 7.7 |
| 播放 | — | `onPlayVideo` → L3，`title=video.title`，微课 |

## 7. 学习任务下发字段（L3）

从课本同步学发起 `onStartLevel` 时构造 `Task`：

| Task 字段 | 规则 |
|-----------|------|
| `id` | 学科 + 课时/视频维度拼接 |
| `title` | 视频名 / tag / 「{课时} · 同步练习」/ 广告 title / 「{word} · 单词讲解」 |
| `subject` | `activeSubject` |
| `durationMinutes` | 视频约 8；词汇 5；广告 10；练习 10 |
| `levelType` | `practice` |
| `aiReasoning` | 微课 / 课时练习（见总览 §4.1） |
| `quizType` 等 | 按关卡类型可选 |

App：微课 `forceQuizOnly=false`；一课一练 `forceQuizOnly=true`。

## 8. 切换后的联动重置

触发：`activeSubject` / `userGrade` / `textbookTerm` / `syncTextbookVersion` / `schoolSystem` 任一变化。
