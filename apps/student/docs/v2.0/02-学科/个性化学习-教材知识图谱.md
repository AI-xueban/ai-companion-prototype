# 个性化学习：教材知识图谱学习

更新：2026-11-10。适用于codex/push-student-teacher-20261020，替代本任务之前的演示掌握度和纯浏览方案。

## 页面与图谱

- 顶部原有学科位置不变。个性化学习保留知识图谱学习/主题学习两入口；主题沿用原向导、计划、关卡及历史流程。
- 图谱在左，学习情况与推荐在右。图谱顶部路径栏是唯一章节下拉入口，以章分组，只选择第二级节。
- 教材沿用我的课本的版本、年级、学期、学制；匹配不到不切换到无关教材。
- 菁优网book.Children提供教材目录，Points提供知识点。下级目录按原序组织主干，同级知识点从父目录分枝，按No去重。连线表示教材顺序/归属，不代表验证过的先修关系。
- 图谱无滚动条，支持平移与手势缩放，初始化与缩放范围均为30%～100%。

## 第一版学习流程

1. 初始所有知识点未测，不计算掌握分。推荐当前章节按原教材顺序的首个未练完点；全部练完后推荐首点复习。
2. 点击知识点或推荐按钮，进入复用VideoLesson的全屏讲解页。隐藏全局顶部学科栏、侧栏和底栏，返回时恢复。
3. 当前讲解是20秒、三段内容的原型演示，明确标注，不是真实视频文件。有效观看与播放进度满足完成条件后仅记录已观看，不推断掌握。
4. 播放结束进入一课一练，复用QuizPage、UniversalQuizView和结果页，传入该知识点显式题集overrideQuestions，不使用整科默认题兜底。
5. 提交有效练习记录已练习、答对题数和题量；结果返回原章节图谱，推荐推进到下一个未练完点。练完不等于掌握，也不要求所有题正确才记录已练习。
6. 不展示此路径的演示知识点健康分、固定能力变化或掌握评语；禁止从结果页进入不相关举一反三题集。其他业务默认行为不变。
7. 所有实际存在的知识点均可进入学习闭环：已有专属样例继续使用，其他知识点生成带当前学科、知识点名称的模拟讲解与3道流程模拟题，明确标注演示用途。

## 资源覆盖与边界

数据层data/bookKnowledgeResources.ts提供9个数学知识点样例，每点3道单选题，共27题：认识立体图形、点/线/面/体、几何体的表面积、有理数、数轴、相反数、绝对值、非负数的性质（绝对值）、有理数大小比较。匹配使用显式名称和数学学科，题目携带当前Point.No和知识点名称。样例讲解和题目为原型配套内容，不声称来自菁优网真实取题接口。

2026-11-10按用户要求补齐全部知识点的模拟流程。15份教材数据共7,540个按学科和ID去重的知识点，其中7,530个使用通用模拟资源，10个ID匹配上述9类数学样例。通用资源提供20秒三段模拟讲解和3道流程题，选项按知识点稳定排列，答案使用选项原文；题目明确标注流程模拟，不代表对应学科的真实知识训练。模拟练习完成可推进图谱学习记录与推荐，但不计算掌握度。

当前仍未接入真实视频资源、全科知识点题库和章节前测。语文英语不凭空构造Points。后续以真实资源逐步替换模拟数据。

## 学习记录

services/bookKnowledgeProgress.ts使用ai_friend_book_knowledge_progress_v1，按学科、学制、教材ID、版本、年级、学期、知识点No隔离。观看和练习分开保存，刷新后恢复；演示重置已注册该key。未学习、已观看未练、已练习三个计数互斥，总和等于当前章节唯一知识点数。学习完成率=已练习知识点数/总知识点数，标签明确不是掌握率。

奖励由原播放器/答题页及App既有handleRewardGranted回流，不直接改金币经验，也不把新练习当作每日任务。
