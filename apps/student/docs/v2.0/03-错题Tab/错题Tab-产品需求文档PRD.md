## 1. 功能定位

错题 Tab 是学生查看与复习错题的统一入口。

目标：

- 进入即可知道今日待办量，并可直接开始复习
- 可按学科进入错题列表
- 支持单题订正与学科批量订正

---

## 2. 掌握状态

| 状态 | 含义 |
|------|------|
| **待攻克** | 未过关，优先复习 |
| **待复习** | 已答对过，按间隔安排再练 |
| **已掌握** | 已过关，不计入待办 |

**待过关（待办）** = 待攻克 + 待复习。

学科入口上的数字 = 该科待过关题量。

---

## 3. 页面结构

```
底栏「错题」
 ├─ 总览（默认）
 │    · 今日复习
 │    · 按学科查看
 └─ 列表
      · 单科错题列表
      · 跨科待办列表（待攻克 / 待复习 / 全部待办）
```

进入列表后隐藏底栏；返回总览后恢复。

---

## 4. 总览

### 4.1 今日复习

| 条件 | 展示 |
|------|------|
| 错题本为空 | 「错题本还很干净」；可查看复习规则 |
| 待过关 = 0 | 「今日任务已完成」 |
| 待过关 > 0 | 「还有 N 道题待过关」；主按钮「开始复习」 |

有待办时提供快捷入口：

| 入口 | 行为 |
|------|------|
| 待攻克 | 打开跨科列表，默认看待攻克 |
| 待复习 | 打开跨科列表，默认看待复习 |
| 全部待办 | 打开跨科列表，默认看待过关 |
| 规则 | 打开复习规则说明 |

总览不展示：预计用时、今日掌握数。

### 4.2 按学科查看

| 规则 | 说明 |
|------|------|
| 学科范围 | 小学 5 科；初中 10 科 |
| 卡片内容 | 学科名 + 待过关数 |
| 空科 | 数字为 0 时仍展示，不置灰，可进入空列表 |
| 排序 | 待过关多的学科靠前 |
| 点击 | 进入该科错题列表 |

**数量校验：** 各科待过关之和 = 总览「还有 N 道题待过关」。

---

## 5. 列表页

### 5.1 顶栏

返回、标题（如「科学错题」）、共 N 道、状态下拉、筛选、编辑。

### 5.2 操作

| 操作 | 说明 |
|------|------|
| 状态筛选 | 全部 / 待办 / 未掌握 / 待复习 / 已掌握 |
| 筛选 | 按错因过滤 |
| 点卡片 | 进入单题订正 |
| 编辑 | 修改错因、取消加入错题本、标记掌握 / 撤销掌握 |
| 批量订正 | 复习当前学科全部待过关题；固定在页面底部 |

**批量订正仅单科可用。** 跨科待办列表不提供批量订正；需先进入某一学科再批量订正。

---

## 6. 复习方式

| 方式 | 入口 | 取题范围 | 上限 |
|------|------|----------|------|
| 开始复习 | 总览主按钮 | 今日应复习的待过关题 | 20 题 / 次 |
| 批量订正 | 单科列表底部 | 当前学科待过关题 | 20 题 / 次 |
| 单题订正 | 列表点卡片 | 当前 1 题 | 1 题 |

练习为全屏流程；结束后返回进入前的错题页。

---

## 7. 入库规则

| 场景 | 规则 |
|------|------|
| 作答答错 | 自动加入错题本 |
| 作答答对后仍想保留 | 手动「加入错题本」 |
| 作业批改 / 讲题留题 | 手动「加入错题本」 |
| 不想再保留 | 「取消加入错题本」（记录移出，不再出现在错题 Tab） |
| 同一题再次答错 | 更新原记录，错误次数 +1，状态回到待攻克 |

用户侧仅保留一对操作：**加入错题本** / **取消加入错题本**（不做单独「收藏」）。

错因由学生标记；可空，支持事后补标。

---

## 8. 复习推进规则

1. 答错或再错 → **待攻克**
2. 答对 1 次 → **待复习**（建议次日再练）
3. 连续答对 → 间隔延长（约 3 天、7 天）
4. 达标或手动标记 → **已掌握**
5. 掌握后可安排远期抽查（约 30 天）

正式版按上述间隔推进。若原型存在「答对即已掌握」，视为未对齐，需按本规则修正。

---

## 9. 本期范围

**包含：** 总览、学科入口、单科/跨科列表、筛选与编辑、开始复习、单科批量订正、单题订正、规则说明、加入 / 取消加入错题本。

**不包含：**

| 项 | 说明 |
|----|------|
| 错题页内拍照录题 | — |
| 能力测评题入库 | — |
| 跨科批量订正 | 须先选学科 |
| 列表预览后再练 | 见下节说明；本期列表点卡片直接进入订正 |
| 举一反三 | 见下节说明；本期不做 |

---

## 10. 已确认结论

| 议题 | 结论 |
|------|------|
| 跨科待办是否支持批量订正 | **否**。不支持跨科，须进入某一学科后再批量订正 |
| 「收藏」文案 | **不做收藏**。仅「加入错题本」「取消加入错题本」 |

### 补充说明：预览后再练 / 举一反三（本期不做）

曾规划过的两种能力，含义如下；**本期均不做**：

| 名称 | 含义 |
|------|------|
| **预览后再练** | 列表点开某题后，先看题干、答案、解析（预览页），再决定是否开始订正；不是一点卡片就进答题 |
| **举一反三** | 订正某道错题后，再推若干道同知识点 / 同类型的变式题巩固 |

本期交互：列表点卡片 → **直接进入订正**。

---

## 11. 主路径

```text
进入「错题」
 ├─ 有待办 →「开始复习」→ 练习结束 → 回总览
 ├─ 点学科 → 列表 → 单题订正 / 批量订正
 └─ 点待攻克/待复习/全部待办 → 跨科列表 → 单题订正
```

验收与埋点等细则见完整版存档。
