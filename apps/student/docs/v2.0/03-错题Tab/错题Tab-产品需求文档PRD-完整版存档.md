## 1. 背景与目标

### 1.1 背景

学生在日课、图谱练题、题库等场景答错后，错题会进入错题本。若缺少统一入口与复习节奏，薄弱点容易堆积、遗忘。错题 Tab 承担「集中查看 + 按计划消灭」的职责。

### 1.2 目标用户

- **主用户**：小学 / 初中学生（按学段展示对应学科入口）
- **次用户**：家长旁观、教研演示（原型演示）

### 1.3 产品目标

| 目标 | 说明 |
|------|------|
| **降低启动成本** | 进入 Tab 即可看到「今日该做什么」 |
| **按学科可下钻** | 快速进入单科错题列表 |
| **形成复习闭环** | 待攻克 → 待复习 → 已掌握，支持每日复习与批量订正 |
| **信息不过载** | 总览只保留主任务与学科待办数，去掉干扰指标 |

### 1.4 成功标准（可观测）

- 用户能在 3 秒内理解：还有多少待办、从哪里开始练
- 总览「待办」与各科「待过关」之和在口径上可对齐
- 完成一次「开始复习」或「批量订正」后，列表状态与数量即时更新
- 新用户空态、零待办完成态、有待办正常态三种状态可区分

### 2.1 本期（MVP / 当前原型覆盖）

- 错题 Tab 总览（今日复习卡 + 按学科查看）
- 学科错题列表 / 全局待办列表

- 错题复习规则说明弹层
- 学段学科目录：小学 5 科 / 初中 10 科

### 2.2 本期不做 / 另册

| 项 | 说明 |
|----|------|
| 错题本内拍照 OCR 录入 | 见《错题本-数据来源与逻辑》 |
| 能力测评错题入库 | 不计入错题本 |
| 预览层「本题练习情况」完整链路 | 见专项文档；列表目前直接进订正 |
| 真实服务端入库 / 写回 API | 原型为 Mock |

### 2.3 产品定稿 vs 原型差异（必读）

| 议题 | 产品定稿口径 | 原型现状 | 建议 |
|------|--------------|----------|------|
| 每日复习题量上限 | 建议定稿 **20**（与代码一致） | `DAILY_CONQUER_MAX = 20` | 文档中旧「5」废止 |
| 订正答对后状态 | 应按间隔进入「待复习」再至「已掌握」 | 答对常直接写 `mastered` | 工程需按状态机改造 |
| 「收藏」vs「加入错题本」 | 产品侧仅「加入 / 取消加入」 | UI 有「已收藏 / 收藏」 | 文案与能力需统一 |
| 预览 / 举一反三 | 列表点开可预览再练 | 点卡直接进订正，预览入口未接通 | 二期接通或明确砍掉 |
| 总览「今日掌握」「预计时长」 | 总览不展示 | 已去掉 | 保持 |

## 3. 信息架构与入口

### 3.1 全局入口

```
底栏 Tab「错题」
  └─ MistakeVault
       ├─ 总览（默认）
       │    ├─ 今日复习卡
       │    └─ 按学科查看（学科格子）
       └─ 详情列表
            ├─ 学科列表（点学科格）
            └─ 全局列表（点待攻克 / 待复习 / 全部待办）
```

### 3.2 导航行为

| 场景 | 底栏 |
|------|------|
| 总览 | 显示 |
| 详情列表（学科 / 全局） | 隐藏 |
| 每日复习 / 批量订正全屏练习 | 隐藏 |

返回：详情页左上角返回 → 回到总览。

### 3.3 学段与学科入口

| 学段 | 学科数 | 学科 |
|------|--------|------|
| 小学 | 5 | 语文、数学、英语、道德与法治、科学 |
| 初中 | 10 | 语文、数学、英语、物理、化学、道德与法治、历史、生物、地理、科学 |

- 总览学科格：**全部展示**，0 待办也不置灰，仍可进入空列表
- 排序：待过关数降序；同分按目录顺序

## 4. 核心概念与状态机

### 4.1 三种掌握状态

| 状态码 | 用户文案 | 含义 |
|--------|----------|------|
| `new` | **待攻克**（列表筛选亦称「未掌握」） | 未过关，优先消灭 |
| `reviewing` | **待复习** | 已答对过，按间隔再练 |
| `mastered` | **已掌握** | 过关；不计入待办 |

### 4.2 聚合口径

| 指标 | 口径 |
|------|------|
| **待办 / 待过关 / pending** | `new` + `reviewing`（排除 `mastered`） |
| **待攻克 / weak** | 仅 `new` |
| **待复习** | 仅 `reviewing` |
| **今日该复习 / dueToday** | 未掌握且轮到今日的题（无日期的新题默认算今日） |

**对齐关系（产品验收用）：**

```text
各科「待过关」之和  =  总览「还有 N 道题待过关」
```

### 4.3 复习状态机（产品定稿）

```text
答错入库 / 复习再错
        ↓
     待攻克 (new)
        ↓ 答对 1 次
     待复习 · Stage1（建议次日）
        ↓ 连对
     待复习 · Stage2（约 3 天）
        ↓ 连对
     待复习 · Stage3（约 7 天）
        ↓ 达标 / 用户手动掌握
     已掌握
        ↓ （可选）约 30 天后防遗忘抽查
```

规则弹层对用户的白话说明与上表一致。

## 5. 页面与交互说明

### 5.1 总览页

#### 5.1.1 今日复习卡 · 三态

| 状态 | 条件 | 展示 |
|------|------|------|
| **新用户空库** | 错题本无题 | 标题「错题本还很干净」；说明自动收录；「了解复习规则」 |
| **零待办** | 有历史题，但 pending = 0 | 「今日任务已完成」；鼓励文案 |
| **有待办** | pending > 0 | 见下表 |

**有待办态结构：**

| 元素 | 说明 |
|------|------|
| 标题 | 今日复习 |
| 副文案 | 还有 **N** 道题待过关（**不展示**预计时长） |
| 主按钮 | 「开始复习」+ 角标题量（`min(dueToday, 20)`） |
| 辅助链 | 待攻克 · 待复习 · 全部待办 · 规则 |

#### 5.1.2 按学科查看

| 元素 | 说明 |
|------|------|
| 区标题 | 按学科查看 · 右侧「N 科」 |
| 卡片内容 | 学科色图标 + 短名 + **待过关数** |
| 点击 | 进入该科错题列表（默认状态筛选 = 全部） |

---

### 5.2 详情列表页

#### 5.2.1 顶栏

| 元素 | 行为 |
|------|------|
| 返回 | 回总览，清空学科/全局列表状态 |
| 标题 | 学科错题 / 全部错题 / 「学科 · 状态」等（见 `getListTitle`） |
| 共 N 道 | 当前筛选后的列表条数 |
| 状态下拉 | 全部 / 待办 / 未掌握 / 待复习 / 已掌握 |
| 筛选 | 展开：已收藏、错因 |
| 编辑 | 开关编辑模式 |

状态色点快捷：未掌握 / 待复习 / 已掌握。

#### 5.2.2 错题卡片（compact）

- 展示：题型标签、难度、来源分类、时间、题干摘要、知识点 `#tag`
- 点击：进入单题订正（当前实现）
- 编辑态：改错因、收藏、标记掌握 / 撤销掌握（掌握需二次确认）

#### 5.2.3 底栏「批量订正」

| 条件 | 是否展示 |
|------|----------|
| 学科列表 + 当前列表存在未掌握题 | **是**（贴页面底部） |
| 全局待办列表 | **否**（原型限制；产品可二期放开） |
| 空列表 | **否** |

按钮文案：批量订正（紫渐变主按钮样式）。

### 5.3 核心流程

#### 流程 A · 每日复习

1. 用户进入「错题」Tab 总览  
2. 点击「开始复习」  
3. 进入全屏练习（`DailyConquerModal` · `mode=daily`）  
4. 完成答题与结果页  
5. 关闭后回到总览，数量刷新；底栏恢复  

**取题规则（产品定稿建议）：**

- 候选池：今日该复习的未掌握题  
- 优先级：待攻克 > 待复习到期  
- 单次上限：**20** 题  

#### 流程 B · 学科下钻 + 批量订正

1. 总览点击学科格 → 学科列表  
2. （可选）筛选状态 / 错因 / 收藏  
3. 点击「批量订正」→ 全屏练习（`mode=batch`，可跳过 briefing）  
4. 完成 → 回列表；返回 → 总览  

#### 流程 C · 全局待办查看

1. 点击「待攻克 / 待复习 / 全部待办」  
2. 打开跨学科列表，默认对应状态筛选  
3. 可单题订正；当前无批量订正底栏  

#### 流程 D · 单题订正

1. 列表点卡片 → 单题练习  
2. 1 题时可用单题结果卡展示  

#### 流程 E · 规则说明

1. 总览「规则」或新用户「了解复习规则」  
2. 弹层展示艾宾浩斯间隔说明  
3. 关闭回到原页

## 6. 数据需求

### 6.1 错题记录（逻辑实体）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 错题记录 ID |
| `questionId` / 快照 | string / object | 关联题库或题干快照 |
| `subject` | string | 学科（对齐学科目录） |
| `status` | enum | `new` \| `reviewing` \| `mastered` |
| `errorType` | string / string[] | 错因；产品定稿最多 3 项，可空=待标记 |
| `knowledgePoints` | string[] | 知识点 |
| `topic` | string | 主题/章节弱标签 |
| `questionType` | string | 题型 |
| `difficulty` | number | 难度 |
| `category` | string | 来源分类展示 |
| `stats.errorCount` 等 | number | 错次、练次、对次 |
| `stats.isStarred` | boolean | 原型收藏标；产品宜映射为「是否在本」 |
| `lastAttemptAt` / `lastReview` | string/time | 列表排序依据 |
| `dueInDays` / 下次复习日 | number/date | 间隔调度 |
| `source` | enum | 入库来源（日课/图谱/题库/作业/讲题等） |
| `isInVault` | boolean | 是否仍在错题本（取消加入=false） |

### 6.2 总览聚合

| 字段 | 计算 |
|------|------|
| `stagePending` | 当前学段学科集合内 pending 数 |
| `memoryPlan.weak` | new 数 |
| `memoryPlan.reviewing` | reviewing 数 |
| `dailyConquerCount` | `min(dueToday, 20)` |
| `subjectSummaries[].pending` | 该科 pending |

### 6.3 学科目录数据

- 来源：`getMistakeVaultSubjects(userGrade, schoolSystem)`
- 总览与统计**只统计目录内学科**的题

### 6.4 列表筛选与排序

| 维度 | 规则 |
|------|------|
| 学科 | 学科列表锁定单科；全局列表为 All |
| 状态 | all / pending / new / reviewing / mastered |
| 错因 | All 或具体错因 |
| 收藏 | `starOnly` 仅看已收藏（若保留该能力） |
| 排序 | 最近练习/错题时间降序 |

### 6.5 入库来源（产品定稿，跨模块）

| 场景 | 是否进本 | 错因 |
|------|----------|------|
| 出题作答 · 答错 | 自动加入 / 更新同一题 | 用户手动（可后标） |
| 出题作答 · 答对 | 用户手动加入 | 用户手动 |
| 作业批改 / 灵境讲题 | 用户手动加入 | 用户手动 |
| 重复答错 | 不重复建档，错次 +1，状态回待攻克 | 可改错因 |

## 10. 验收标准（测试清单）

### 10.1 总览

- [ ] 小学显示 5 科、初中显示 10 科，0 待办学科可点且不置灰  
- [ ] 「还有 N 道」= 各科待过关之和  
- [ ] 不展示预计时长、不展示今日掌握  
- [ ] 新用户 / 零待办 / 有待办三态正确切换  
- [ ] 「开始复习」角标 ≤ 20  

### 10.2 列表与筛选

- [ ] 学科下钻标题、共 N 道正确  
- [ ] 状态 / 错因 / 收藏筛选结果正确  
- [ ] 编辑模式可改错因、标记掌握（含确认）  
- [ ] 学科有待办时底部出现「批量订正」；空列表不出现  

### 10.3 练习闭环

- [ ] 每日复习 / 批量 / 单题可完成并关闭  
- [ ] 练习中底栏隐藏，结束后恢复（详情态除外）  
- [ ] （定稿后）答对后状态符合间隔复习规则，而非一律已掌握  

### 10.4 边界

- [ ] pending=0 时主 CTA 区域为完成态，不出现开始复习  
- [ ] 全局列表可打开且可返回  
- [ ] 规则弹层可开关
