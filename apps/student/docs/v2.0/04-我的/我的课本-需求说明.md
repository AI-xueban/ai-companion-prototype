| 项 | 内容 |
|----|------|
| 产品 | AI 学伴 · 学生平板 |

| 版本 | v1.0 · 2026-08-17 |
| 读者 | 产品 / 设计 / 研发 / 测试 |
| 本期 | 小学、初中均支持年级与上下学期切换 |
| 关联 | [同步课本阅读版](../02-学科/课本同步学/05-同步课本与自主练习-阅读版.md) 第 3、4、5 节 |

---

## 1. 定位

学生跟哪本书，由五个值一起决定：

**学制 · 年级 · 学科 · 版本 · 册次**

「我的课本」是这五个值里「学制 / 年级 / 册次 / 各科版本」的**唯一改入口**。学科顶栏、教材全解、首页选科只展示当前值，不能改。

学生要完成的事：

1. 先锁定本学期是谁（学制 + 年级 + 册次）。
2. 再按科目改教材版本；不必全改，只改要点的科。
3. 改完立刻作用到首页选科、学科 Tab、教材全解、自主练习。

---

## 2. 为什么做

原先年级、册次、学制、版本散落在学科顶栏和教材全解。学生容易在学的时候误切书，也分不清「这学期用哪套」和「这节课学哪章」。

产品目标：

- **改书和学习分开**：学的时候只切学科、章、课；换学期、换版本去「我的」。
- **学期先锁、版本分科**：年级 × 学制决定本学期有哪些科；每科版本独立记。
- **第一次进来就对上档案**：不要用系统随便写的默认年级顶掉学生真实年级。

---

## 3. 入口与退出

### 3.1 入口

底栏「我的」右上角，设置齿轮**左侧**小胶囊。

| 元素 | 规则 |
|------|------|
| 文案 | 「我的课本」 |
| 副文案 | 小学、初中统一为 `{年级} · {学期}` |
| 点击 | 进入「我的课本」全屏页 |
| 底栏 | 进入后隐藏；返回「我的」后恢复 |

学科 Tab、首页选科、教材全解**没有**同等入口，也不做下拉。

### 3.2 退出

| 操作 | 行为 |
|------|------|
| 点返回 | 回到「我的」主页 |
| 切底栏 | 本页打开时底栏不可见，不能从这里跳走 |

改过的年级 / 册次 / 学制 / 版本在编辑态里立刻生效，不需要「保存」。点「完成」只是退出编辑，回到只读浏览。中途点返回也保留已改的值。

---

## 4. 页面结构

```
← 我的课本
  {年级} · {册次} · {学制}          ← 页头摘要，只读

┌ 本学期课本  N 科          [编辑] ┐
│ 浏览态：学制 · 年级 · 册次只读摘要
│  [语] [数] [英] [道]
│  [史] [生] [地] [科]              ← 4 列铺满剩余高度
│  每格：图标 + 学科名 + 当前版本
│
│ 点「编辑」后，摘要变成三个下拉：
│ [学制 ▾] [年级 ▾] [册次 ▾]  [完成]
│ 点开后是贴在按钮附近的小弹层，不整页展开
│ 科目卡出现 ▾，可点开改版本
└──────────────────────────────────┘
```

默认是浏览态，学制 / 年级 / 册次 / 版本都不能点，避免误切。必须先点「编辑」才进入编辑态。打开下拉或某科版本时：半透明遮罩 + 贴在该按钮附近的小弹层。不整页跳转，也不再展开一大片芯片。

| 状态 | 学期定位 | 科目卡 | 右上角 |
|------|----------|--------|--------|
| 浏览态（默认） | 一行只读摘要 | 只展示版本，无下箭头，点了无反应 | 编辑 |
| 编辑态 | 学制 / 年级 / 册次变成三个下拉，点开小弹层改 | 出现 ▾，可改版本 | 完成 |

点「完成」或返回，都关掉版本弹层。再次进入本页仍从浏览态开始。

## 5. 首次进入怎么定位

优先读后台筛到的**学生个人学业档案**。原型用李华：

| 字段 | 档案默认 |
|------|----------|
| 年级 | 七年级 |
| 学制 | 六三制 |
| 册次 | 上册 |
| 语文 | 人教版 |
| 数学 | 北师大版 |
| 英语 | 沪教版 |
| 其余已开科目 | 见档案表；科学为浙教版 |

档案缺某科版本时，用阅读版第 4.2 节默认表。

| 信息 | 从未在本页改过 | 学生在本页改过之后 |
|------|----------------|--------------------|
| 年级 / 学制 / 册次 | 档案 | 写进端上记忆，各入口立刻用新值 |
| 某科教材版本 | 档案该科版本 | 按学科记住；覆盖档案 |
| 章 / 课文 | 这本书没切过 → 第一章 | 按「学科 + 版本 + 年级 + 册次」记住上次位置 |

版本优先级（展示用）：

1. 学生亲手选过，且当前年级册次仍有这一版 → 用它
2. 否则用档案里该科版本（在可选列表内）
3. 再否则用系统默认表

自动回落（当前列表里没有学生记过的那一版）**不要覆盖**学生的历史选择，以免下次该版重新出现时丢了记忆。

## 6. 学期定位

三件事绑在一起：**学制、年级、册次**。只在编辑态可改；改其中一项，立刻重算本学期科目表。浏览态只展示当前值，控件不出现。

### 6.1 学制

可选：六三制 / 五四制。编辑态点「学制」下拉，弹层里选。

| 学制 | 初中年级 | 小学（可见、置灰） |
|------|----------|--------------------|
| 六三制 | 七、八、九年级 | 一至六年级 |
| 五四制 | 六、七、八、九年级 | 一至五年级 |

五四制六年级算初中，可选。

切学制时：

- 当前年级在新学制下仍是初中 → 年级不动
- 当前年级不再是初中（例如五四制六年级切到六三制）→ 落到该学制**第一个初中年级**（六三制七年级）
- 当前学科不在新年级科目表 → 学科顶栏落到**语文**

### 6.2 年级

小学、初中都在年级下拉里。初中在上、可点；小学在下、置灰，避免学生以为没有小学。

本期只开放初中。编辑态点「年级」下拉，再选初中年级，立刻切换。

选年级时：

- 更新年级
- 科目表换成新年级 × 当前学制
- 当前学科不在新年级列表 → 学科顶栏落到语文

### 6.3 学期

小学、初中都出现：上学期 / 下学期（数据层仍对应上册 / 下册）。页头摘要和浏览态摘要都展示当前学期。

编辑态点「学期」下拉立刻更新。当前学期对应册次在新版本没有时，按阅读版 4.4：落到该版本第一本可用册次；没有上下册时用全一册。

### 6.4 页头摘要

| 学段 | 摘要 |
|------|------|
| 初中 | `{年级} · {学期} · {学制}` |
| 小学 | `{年级} · {学期} · {学制}` |

只读，不另做下拉。

## 7. 本学期科目

### 7.1 列表从哪来

由 **年级 × 学制** 算出，与学科顶栏、首页选科同一张表。

**六三制**

| 年级 | 学科 |
|------|------|
| 七年级 | 语文、数学、英语、道法、历史、生物、地理、科学 |
| 八年级 | 上列 + 物理 |
| 九年级 | 语文、数学、英语、物理、化学、道法、历史、科学 |

**五四制**

| 年级 | 学科 |
|------|------|
| 六 / 七年级 | 与六三制七年级相同 |
| 八年级 | 上列 + 物理、化学 |
| 九年级 | 语文、数学、英语、物理、化学、道法、历史 |

对外学科名：道德与法治写「道法」。内部仍用「道德与法治」。

右上角角标写「N 科」，N = 当前列表长度。

### 7.2 科目卡

四列网格，铺满「本学期课本」卡片剩余高度，不单独滚动整页。浏览态科目卡只展示，没有下箭头，点了无反应。

每张卡：

| 元素 | 规则 |
|------|------|
| 图标 | 按学科固定配色（语文笔、数学计算器、英语语言、道法天平……） |
| 学科名 | 对外名，如「道法」 |
| 版本 | 浏览态只显示当前版本；编辑态再加下箭头。当前学制 + 年级 + 册次下没有课本时写「暂无课本」，不出现版本名，也不能打开版本弹层 |
| 点击 | 浏览态无效。编辑态打开该科版本弹层；再点同一张卡则关闭 |

不必每科都改。没点过的科继续用档案或默认表。

### 7.3 版本弹层

贴在被点卡片附近的白色小对话框，背后半透明遮罩。挂在平板视口上，不跟着卡片被裁切。

| 元素 | 规则 |
|------|------|
| 标题 | `{学科对外名} · 教材版本` |
| 关闭 | 遮罩、右上角 ×、再点同一张卡 |
| 列表 | 当前年级 + 册次 + 学制下**真正有课本**的版本；没有课本的版本不出现 |
| 当前项 | 高亮 + 对勾 |
| 点某一版 | 只改这一科，立刻关闭弹层 |
| 仅一版 | 仍可打开；列表底写「当前年级册次仅此版本」 |
| 无课本 | 科目卡写「暂无课本」，不提供版本筛选 |

版本对外显示「人教版」这类名。供应商内部版本名由数据侧映射，列表不出现「统编版」。

册次不跟版本绑在同一个弹层。要改上下册，先点「编辑」，再改学期定位。

## 8. 改完之后别处怎么变

年级、学制、册次、任一科版本变化后，立刻：

1. 关掉学习页、专项页、自主练习选题页。
2. 这本书学生切过章 → 停在上次的章和课文 / 小节；没切过 → 第一章。
3. 自主练习已勾选清空。
4. 学科顶栏科目 Tab 换成新年级学制下的列表。
5. 首页选科、学科教材全解、学科自主练习读同一份版本。

学科 Tab **仍然可以**：

- 点学科名切科
- 左右滑切相邻学科
- 当前学科加粗带下划线

学科 Tab **不可以**：

- 点顶栏 `{年级} · {册次}`（只读，无箭头）
- 在教材全解改版本（版本名只读，无箭头）
- 改学制

## 9. 记忆

原型先写在端上。演示重置时一并清掉，下次再读李华档案。

| 记什么 | 范围 | 说明 |
|--------|------|------|
| 年级、册次、学制 | 全局一份 | 学期定位 |
| 教材版本 | 按学科一份 | 亲手选过的才写；自动回落不写 |
| 章 / 课文位置 | 按「学科 + 版本 + 年级 + 册次」 | 不在本页改，跟学的行为走 |

云端同步本期不做。

## 10. 边界

| 情况 | 处理 |
|------|------|
| 档案缺年级 / 学制 / 册次 | 用李华默认：七年级 · 上册 · 六三制 |
| 档案缺某科版本 | 系统默认表 |
| 记住的版本当前列表没有 | 展示档案或默认；不覆盖历史记忆 |
| 切年级后当前科消失 | 学科顶栏落到语文 |
| 五四制六年级 → 六三制 | 年级落到七年级 |
| 当前册次在新版本没有 | 落到该版本第一本可用册次 / 全一册 |
| 当前册次没有内容 | 学科侧写「该册次内容即将开放」；我的课本该科写「暂无课本」，版本筛选不出现没有书的版本 |
| 小学年级 | 可选；支持上学期 / 下学期切换，按当前学期重算课本 |
| 重复进入本页 | 展示上次留下的学期定位和各科版本 |
| 只改一科版本 | 其他科不动 |

---

## 11. 本期不做

- 小学完整课本数据补齐
- 在学科 / 首页改年级、册次、学制、版本
- 编辑态里的「保存」或二次确认（改完立刻生效；「完成」只退出编辑）
- 一次把全部科目改成同一版本
- 版本与册次绑在同一个弹层
- 进度云端、多设备同步
- 知识图谱当主目录
