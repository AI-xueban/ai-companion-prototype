页面目标

  1. 定位：按课本章节学的主场。默认停在「课本同步学」，左侧可进「个性化学习」（本文不展开）。
  2. 顶栏年级·册次：只读胶囊，无箭头。改学制/年级/册次/版本只在「我的 · 我的课本」。
  3. 学科切换：点学科名立刻切；左右滑切相邻科；当前科加粗带下划线。不展示滑动引导文案。
  4. 教材全解标题行：教材全解 + 版本名（只读）+ 章/单元胶囊。
  5. 列表：展示当前章全部子级。点课文/小节/课 → 进学习页（英语例外，见②）。
  6. 单元测试：钉在底部，测当前章/Unit，文案只写「单元测试」。
  7. 自主练习：右侧竖卡；打开后藏底栏与左侧模式栏。
  8. 专项：英语七～九：词汇/口语/语法；数学：同步提高；其他学科无。
  9. 空态：当前章/单元无小节 → 缺省图 +「该章节下暂无内容」（演示可切「空态演示章节」），不弹报错。
硬约束：学科页不能改年级 / 册次 / 学制 / 版本。三入口文案故意不统一（首页「同步课本」/ 学科「课本同步学」/「自主练习」）。
验收：初中进学科默认课本同步学；小学进学科显示即将开放；首页科目页不放自主练习竖卡。

交互规则

  1. 打开时定位到当前章/单元。
  2. 点章/单元：弹层内高亮预选，主列表先不动。
  3. 点「确认」：主列表换成该章全部子级并关弹层。
  4. 点「取消」或遮罩：不切换。
  5. 生物等 catalog：弹层只选单元；展开后的章/课只展示不可点、不高亮。要进某章，关弹层后去主列表点。
  6. 英语：点 Unit 即选中并关弹层（无课文层）。

学习与播放规则

进入
  1. 非英语点课文/小节 → 学习页（产品界面无「学习页」四字）。
  2. 英语点技能格或 Section 视频 → 直接播，不进学习页。
  3. 英语不加一课一练（含沪教 Section 手风琴）。
  4. 小节无内容 →「该小节内容即将开放」。
视频
  1. 按列表顺序；点第几条从第几条播；播完不自动跳下一集。
  2. 看满 45 秒算达标（发奖）；无播放地址也可点开播。
  3. 播放记录：未播过「未学习」；播过未到 80%「学习中」；进度 ≥80%（含倍速）「已学完」。
  4. 后面还有 →「重新播放 / 播放下一个」；末集或仅一条 →「重新播放 / 进入一课一练」。
理科三段归类（看展示文案，命中即停）
  1. 含经典题型/题型/易错/练习/一课一练 → 同步巩固练。
  2. 含拓展/新课标 → 拓展提升。
  3. 其余（含知识精讲）→ 名师带你学。

③ 三种练习：一课一练 · 单元测试 ·（自主练习见④）

L3 答题 · 藏底栏
随时可进，不解锁 · 菁优出题 · 做过默认不抽 · 不用邻近难度凑数

一课一练

  1. 范围：当前这一课叶子；英语无此练习。
  2. 入口：仅学习页最后一条（及播完「进入一课一练」）。
  3. 无设置窗。固定 5 题 · 中等 · 同步练习。
  4. 未做 N≥5 → 直接答题；0<N<5 / N=0 → 异常弹窗。
  5. 已练完再点：仍显示已练完，换新卷。未作答过任何一题为「未练习」；作答过但中途退出未提交为「练习中」（不保存作答）。

单元测试

  1. 范围：当前章 / Unit 全部叶子。
  2. 入口：教材全解底部「单元测试」。
  3. 先出设置窗：题量 / 难度 / 场景（默认同步练习）。
  4. 推荐量：语文 10；英语 12；两科均可自行选择 5–20 题。其他=小节数×3（夹 8–20），所有单元测试最多 20 题。
  5. 点「开始测试」后再数 N；异常窗盖在设置窗上。

选题与回流

  1. 范围永远是整册，目录以菁优为准。
  2. 首页进入：左侧可切科；默认滚到该书上次学到的章并勾对应小节。
  3. 学科进入：不能切科；用教材全解正在看的章/小节。
  4. 勾父级 = 全选叶子；节下知识点胶囊可单独勾/取消。
  5. 切科或切版本后，已勾清空。
  6. 点「开始练习」→ 与单元测试同一套设置窗与异常窗（文案「本章」改「所选范围」）。
  7. 中途退出 → 选题页。
  8. 做完 → 学生选：该科同步页（首页路径）或学科教材全解，或回首页。

与学科主场的差异

  1. 副标题只展示当前年级、册次，不能改。
  2. 科目页 = 该科教材全解，但没有左侧模式栏、没有自主练习竖卡。
  3. 单元测试与专项仍保留。
  4. 返回：科目页 → 选科页 → 再返回才回首页。

自主练习只留：首页右侧卡 + 学科主场右侧竖卡。不要在首页科目页再放一个。
