## 2. 主链路 B：三种练习

### 2.1 练习类型对照

| 练习 | 范围 | 进答题前 | 入口 |
|------|------|----------|------|
| 一课一练 | 当前课叶子 | **无**设置窗；够 5 题直接进 | 学习页末条（英语无） |
| 单元测试 | 当前章 / Unit | 设置窗 → 组卷 | 教材全解底部 |
| 自主练习 | 勾中的整册叶子 | 选题页 → 设置窗 → 组卷 | 首页卡 / 学科竖卡 |

统一库存逻辑：只数「范围 ∩ 难度 ∩ 场景 ∩ 未做过」的 N；不用邻近难度凑数。

### 2.2 一课一练

```mermaid
flowchart TD
  Tap[点一课一练或播完进入] --> CountN[中等·同步练习·未做 N]
  CountN --> Branch{N?}

  Branch -->|N ≥ 5| Quiz[直接答题 · 固定抽5]
  Branch -->|0 < N < 5| Short[弹窗：目前只能出 N 题]
  Branch -->|N = 0 且库里有题| NoNew[弹窗：这一课没有新题了]
  Branch -->|库里从来没题| NoBank[暂时没有题目·入口仍在]

  Short --> S1[确认按 N 题开始]
  Short --> S2[降低/提高难度再看看]
  Short --> S3[先不练了 → 停学习页]

  NoNew --> R1[升/降一档出新题]
  NoNew --> R2[再练做过的题]
  NoNew --> R3[先不练了]

  Quiz --> Done[提交后入口改「已练完」]
  Quiz -.->|作答过至少一题后中途退出| Mid[入口改「练习中」·不保存作答]
  Quiz -.->|一题未作答就退出| Idle[入口仍是「未练习」]
  Done --> BackA[回教材全解或首页科目页]
```

### 2.3 单元测试 / 自主练习（设置 + 异常）

```mermaid
flowchart TD
  Entry{入口} -->|单元测试| Setup[设置弹窗<br/>题量·难度·场景]
  Entry -->|自主练习| Select[选题页勾叶子]
  Select -->|开始练习| Setup

  Setup -->|开始测试/练习| Build[组卷中…]
  Build --> NCheck{未做 N vs 目标 K}

  NCheck -->|N ≥ K| Quiz[答题]
  NCheck -->|0 < N < K| Insuf[异常窗盖在设置上<br/>确认按N / 升降难度 / 返回修改]
  NCheck -->|N = 0| Exhaust[当前小节/本章没有新题了<br/>升降 / 再练做过 / 返回修改]
  NCheck -->|范围从无题| Empty[暂时没有题目]

  Insuf -->|返回修改| Setup
  Exhaust -->|返回修改| Setup
  Insuf -->|确认按N| Quiz
  Quiz --> Exit[见返回表]
```

**自主练习选题差异**

| | 首页进来 | 学科进来 |
|--|----------|----------|
| 切科 | 左侧可切 | 不能切 |
| 默认章位置 | 该书上次学到的章 | 教材全解正在看的章 |
| 未勾不能开始 | 是 | 是 |

## 6. 建议联调走查脚本（10 步）

1. 初中账号进学科 → 确认顶栏只读年级·册次、可切科。  
2. 打开章筛选 → 预选不立刻换列表 → 确认后换列表。  
3. 数学点小节 → 学习页三段 + 一课一练 → 播视频 → 末集进练习。  
4. 英语沪教七/八点 Section → 视频列表（无一课一练）→ 播视频；九年级点技能格直接播。  
5. 单元测试：开设置 → 开始 → 看正常进答或异常窗。  
6. 学科右侧进自主练习 → 不可切科 → 勾选 → 设置 → 答题。  
7. 首页同步课本 → 选科 → 科目页无自主练习卡 → 返回两级回首页。  
8. 首页自主练习做完 → 回流二选一。  
9. 我的课本改年级/版本 → 回学科看顶栏与目录是否刷新、深层页是否被关。  
10. 小学账号：首页无两卡；学科「即将开放」。

更细的弹窗文案与按钮文案，直接对照阅读版第 8 节。
