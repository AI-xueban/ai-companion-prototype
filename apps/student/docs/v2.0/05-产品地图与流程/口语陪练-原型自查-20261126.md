# 口语陪练原型自查 · 2026-11-26

## 结论

当前版本有参考产品的气泡、三个功能和评分入口，但没有完整承接“听懂 → 组织表达 → 说出 → 发现具体问题 → 修正再说”的学习闭环。原型可以采用示例数据；问题在于示例也没有展示有差异的真实使用情境，通用分数、套话和循环对话让它只能演示按钮。

本次以用户已确认的浅紫左右对话布局为准，保持第一版报告布局，不读取已被用户停用的PRD，不新增功能装饰。复核当前本地代码与实际浏览器，不把旧交接的“通过”当成当前验收结论。

## 首次自查已修正的三个确定错误

1. **纯文字报告误评分**：修正前只发译文、累计开口0词，仍显示“勇敢开口”、综合40、流利度85、语调78。现在文字会话标题与行为一致，无录音的综合、发音、流利度、语调显示“—”，不把缺失评测当0分。保留原报告布局。其他演示分数仍是示例，不宣称真实AI评分。
2. **提示使用标记错误**：原来只在点击提示开关时记使用，默认提示已展示却不计，关闭提示反而计；现在提示实际可用且展示后记录，未用过提示的轮次不在之后打开开关时补出历史提示。实测默认提示在复盘标出；开场生成时关闭提示，发送后再打开，历史提示数为0。
3. **生成强拉滚动**：原来每个新词都触发scrollTo底部；现在只在跟随最新内容且高度变化时平滑滚动，用户上滑/触摸/拖动/键盘回看暂停跟随，回到底部恢复；新发送与主动打开提示恢复跟随。对话区可键盘聚焦。实测第4句生成时Home回看，生成结束后scrollTop仍0，未被拉到底部。

## 2026-11-26 改为每次10轮结束（最新确认规则）

来源：用户明确要求“问答不要两轮循环，以一次对话10轮结束”。本条替代此前“不限轮数”的决定。

- 一轮按小晤提问与用户的一次有效发送计，包含中译英直接发送/跟读；每次最多10轮。第10次发送保存完整会话后自动进入第一版练习报告，不再生成第11问。允许此前已确认的主动提前退出与3分钟闲置结束。
- 46个情景都提供10条不重复的双语示例，按场景类型推进，末两轮为总结与告别。使用speakingFollowUps.ts统一常量与问答配置，移除按prompts长度取模的循环逻辑。示例脚本仍非真实AI上下文服务。
- 对话标题旁用轻量文字显示第n/10轮，不增加底框或进度徽标。再聊一次创建新会话并回到1/10。闲置结束后的新发言回到首问、重新计数，历史已回答部分保留。
- 验证：所有46情景均恰好10条、英文问题互不重复、英中问题与参考回答四字段完整，离线检查通过；TypeScript --noEmit通过。浏览器实走课后运动9次录音示例+第10次译文直接发送，结束前AI问题数10且去重数10；自动报告显示10轮，复盘10行，练习记录仅1条10轮记录，再聊一次回到首问/1轮。
