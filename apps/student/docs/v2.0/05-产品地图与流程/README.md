## 建议评审顺序

1. **浏览器打开** [04 HTML](./04-课本同步学-页面流程说明.html)：按「页面 → 流程条 → 说明」过一遍（最像墨刀说明稿）。
2. 需要全站上下文时再看 [01 页面地图](./01-全站页面地图.md)。
3. 联调对照 [02 流程图](./02-学科-课本同步学流程图.md)；口述/勾验收用 [03 复述](./03-学科-课本同步学-需求复述.md)。

在资源管理器中双击该文件，或在项目根目录执行：
