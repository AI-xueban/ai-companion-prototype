# 学习广场与作品创作

日期：2026-11-12。适用：`codex/push-student-teacher-20261020`，当前原型未提交。业务关联：CONTENT-001、QUIZ-001、HW-001、IAM-001及既有金币服务。

## 用户确认的本轮范围

来源为本聊天用户最新消息：学生身份切换使用产品工作台中已有平板；删除旧独立网页的“我的学习树”和“我的金币”；学生可上传本人在平板做过的题目/作业的解析，也可通过AI创作；学习广场增加年级、班级、科目分类，并能查看教师资源广场中开放的学习资源；作品创作前科目可多选，当前班级的该科目老师或班主任审核后才展示。

## 页面与入口

保留现有平板舞台、五底栏和金币钱包。首页工具区新增“学习广场”；“我的星迹”增加“我的作品”。进入后为覆盖式业务页面，隐藏原五底栏，顶部包含学习广场、我的作品、班级作业和创作入口。

广场分“全部内容／学生作品／教师学习资源”，叠加年级、班级、科目筛选。作品按创建者年级和班级归类，多科目作品匹配其中任一科目；教师资源按适用年级、科目匹配，通用学习资源不因选择班级而被排除，定向资源按指定班级匹配。分类筛选不会改变学生教材或学籍设置。学校未开放内容浏览时沿用现有内容管控入口，不开放浏览。

## 创作流程

两种创作均先选择至少一个科目，再进入内容编辑。

- 解析投稿：选择本人已完成的题目或已提交作业→写讲解或选择解析附件→填写标题→提交审核。来源必须存在、归属本人且科目包含在所选科目中。未完成、他人来源与未记录来源不可投稿。无可选来源时提供重新选科目、去做班级作业入口。
- AI创作：选择科目→输入创作想法→生成可编辑草稿→本人补充内容→提交审核。不强制关联题目，但遵守相同审核流程。

完成记录从实际QuizPage有效提交及本模块班级作业提交写入，不以页面上展示过或点开过认定“做过”，也不导入未经核实的历史示例。现实现覆盖本次新增有效完成记录；全历史作业和其他答题入口的回填应逐一对接事件。

## 审核与展示

学生作品状态为`pending→approved/returned`。待审或退回内容不进入公共广场。审核匹配提交作品的班级，审核人必须是当前班级班主任，或该班任教科目与作品科目存在交集的老师。

本轮执行口径：多科目由任一匹配科目老师或班主任审核，不要求所有科目逐个会签。这是对用户“该科目老师或者班主任”的实施解释，已在本轮工作说明中明示，尚待用户验收。转班、教师调整、重审和版本锁定的服务端规则待后续接口设计。

“我的作品”显示待审、通过、退回状态和反馈。当前支持教师退回与学生查看反馈，尚无原作品修改后重新提交入口；正式迭代需补齐版本化重提。当前教师资源工作台为独立评审壳，通过同源存储与真实学生平板联动，并未替换工程内原TeacherApp。

## 教师资源开放

教学资源广场师生均可浏览，学生从平板学习广场的“教师学习资源”分类进入，不再标记“仅教师可见”。教师从资源详情明确开放学习版后，该学习内容才进入学生的“教师学习资源”分类；未开放资源、教研备注和教师答案不自动公开。演示使用字段白名单生成学习投影，正式环境应创建独立学生资源视图与资源包，不向学生接口返回私有原稿。

示例互动课件为可操作浮力实验，滑块可改变排水体积与浮力；没有实现任意上传HTML运行或所有文件类型的实际媒体预览。

## 金币及跨端边界

不新增独立金币模块。作品审核通过后，在学生模块同步时使用`grantContributionReward`与原`onRewardGranted`回调加入现有钱包。本机示例每作10金币，同一作品仅结算一次，受既有每日150总上限约束；该数值仅为原型展示，不代表用户确认新的运营奖励政策。

当前在同一浏览器、同一来源下通过`ai_friend_student_community_v1`和`hivemate_platform_v3`保存演示数据，演示重置会清理这两个键。身份、班级、审核和奖励仍是本机逻辑，不作为正式授权保障。附件只记录名称；AI只生成示例文字。原生小程序、后端任务、媒体存储、真实模型、离线队列与跨设备同步没有在本轮接通。
