## 当前确认规则

1. 难度和语速只调整AI，不调整整个话题或用户评分。主题选择页移除这两项；对话内独立展示AI陪练设置，标签为AI表达难度、AI语速。
2. 每条用户发言的测评紧贴该发言下方，默认只显示关键信息（语法、发音参考分），带展开/收起图标。点击可查看这条发言的具体评价，不能作为独立悬浮条出现在其他位置。
3. 点词解析卡优先展示在对应单词上方，向下箭头锚定所点词，不放在其下方。
4. 回答提示默认是一句完整、符合问题的英文示例，可附中文和回听。点击更多提示才展开句式，不能初始只给句子开头。
5. 学习机录音操作：待机显示点击说话；点击后进入录音，显示波形、时长与结束并发送。点击结束并发送后才提交本轮回答。
6. 每次对话不可跳过，不显示跳过按钮，静音也不能自动推进到下一轮。没有有效音频时留在本轮提示重试。
7. 用户与AI使用不同身份头像和气泡对齐；录音中只展示过去已完成发言的测评，不给尚未提交的语音打分。

## 页面与闭环

- 主题页恢复第一版主题卡片、插画、英文名、关键词与入口布局；不设置话题难度和语速，AI参数仍只在对话页调整。四个示例场景：校园生活、兴趣爱好、周末计划、咖啡馆点单。
- 对话待机：AI发言及译文、回听、上方单词解析、对应用户发言下的折叠测评、完整回答提示、更多提示、AI陪练设置、点击说话。
- 对话录音：录音波形、计时、结束并发送；用于说明展开测评及更多提示的状态。
- 报告：本次参考分、开口数据、亮点与改进、逐句测评及热身词；再聊一次沿用场景，换个主题回主题选择。
- 整合版四视图为第一版主题选择、第二版对话、第一版报告总览、第一版报告复盘。录音状态作为对话局部状态示意。

## 本次设计假设（尚未新增确认为业务规则）

- AI设置从下一句生效，避免改写已发生的对话；该生效时点是设计建议。
- 结束练习是退出整个会话并查看已有结果，不能跳过当前题后继续下一轮。
- 网络/识别失败保留已经完成的内容，本轮提供重试；未收到有效回复前不推进轮次。
- 麦克风失败提供重试和返回；不使用虚构语音作为真实练习数据。
- 综合分为参考值，逐句收起状态只展示关键评分；展开内容措辞和维度待后续实现时确认。

## 最新确认：页面版本与无录音提醒

来源：本对话用户在交互修订图之后的明确指示。本节覆盖上文有冲突的旧示例。

- 选择主题使用第一版视觉布局，练习报告恢复第一版完整总览与复盘，对话保留第二版。
- 每次对话不限长度，取消固定轮数及总时长上限；不按六轮自动结束。对话进度只呈现当前轮次，不出现总轮数分母。报告中的轮数仅为本次实际完成数据。
- 用户原文：超过3分钟没有点击过录音，就在页面提示“你太长时间没有跟学伴聊天啦，请换个话题聊吧”。目的为减少长时间停留后继续同一话题带来的上下文串联负担。
- 触发口径：进入对话页开始计时；每次点击开始录音刷新最近录音时间。停留超过180秒且期间没有新的录音点击，在页面内显示原文提示和换个话题入口；点词、回听、更多提示、设置等操作不重置无录音计时。
- 录音进行中不触发提醒、不截断长录音；录音发送或识别处理中暂不弹出提醒。返回待机时重新开始空闲等待（此项为避免长录音刚发完即提示的实施建议）。
- 提醒不自动跳转或自动清空对话，已有发言与测评保留；主动换个话题后开启新会话，不向新主题带入旧主题消息。提示本身不会自动解决服务端上下文，需要实施时明确会话边界。
- 未点击新录音前保持一条提醒，避免重复叠加。点击录音后收起提示并重新计时。
- 已确定每轮不可跳过，提示不能作为跳过一轮并继续下一轮的通道。

## 2026-11-19 小晤逐词回复流程
- 来源：用户本轮要求发送后模拟小晤思考，再逐词生成；开启提示时，小晤说完才给出提示。
- 回复采用 thinking → typing → ready 三阶段。发送后显示约1.1秒思考及三点动画，再按英文词输出，逗号与句末略作停顿；新增词轻淡入，速度随当前AI语速设置变化。进入情景的开场句同样逐词出现。
- 中文译文、词典入口与翻译操作在整句完成后出现。当前回答提示在生成完成后出现；听力开启时还等待当前句的浏览器语音播放结束（失败时恢复提示，保留已有错误反馈）。历史提示不受当前句等待影响。
