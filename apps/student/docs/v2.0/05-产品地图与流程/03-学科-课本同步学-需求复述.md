## 1. 我们在解决什么问题

初中生需要两件事：

1. **跟着课本章节学**：看同步微课、做一课一练、做单元测试。  
2. **自己勾目录练**：在整册里选题出卷（自主练习）。

产品用三个入口承接，**文案故意不统一**：

| 位置 | 文案 | 作用 |
|------|------|------|
| 首页右侧 | 同步课本 | 选科后按章节学 |
| 底栏学科 | 课本同步学 | 按章节学的主场；只切学科 |
| 首页右侧；学科右侧竖卡 | 自主练习 | 整册自选出卷 |

首页点进同步课本后的**科目页不放自主练习**。

## 2. 目标用户与场景

| 用户 | 典型场景 |
|------|----------|
| 初中生（六三 / 五四） | 今晚把数学某一小节微课看完并做一课一练 |
| 同上 | 章末做单元测试，自选题量难度 |
| 同上 | 期末前在整册里勾多章自主练习 |
| 换教材 / 换学期 | 只在「我的课本」改书，学的时候不被误切 |

**小学**：首页不放同步课本 / 自主练习；进学科 Tab 显示即将开放。

## 3. MVP 范围（本期做什么 / 不做什么）

### 做

- 初中学科列表随年级 · 学制变化（道法对外写「道法」）。
- 教材全解按课本章节（不按知识图谱界面）。
- 学习页（非英语）+ 视频连播选择 + 一课一练。
- 英语沪教七/八：Unit 下列 Section，点进 L2 视频列表，无一课一练；九年级技能格直达视频。
- 单元测试、自主练习设置弹窗与库存异常弹窗。
- 英语专项（词汇 / 口语 / 语法）、数学同步提高。
- 改书唯一入口：我的课本；换书关闭深层页并重置勾选 / 章定位规则。
- 学习进度按「学科 + 版本 + 年级 + 册次」分本记（端上记忆；阅读版写明本期不做进度云端）。

### 不做

- 知识图谱作为课本同步学主界面。  
- 小学完整同步内容。  
- 进度云端。  
- 用邻近难度自动凑题。  
- 三种练习「解锁」门槛（随时可进）。

## 5. 关键规则复述（短句版）

### 5.1 书与入口

1. 改学制 / 年级 / 册次 / 版本：**只能**去「我的 · 我的课本」。  
2. 学科顶栏、首页选科、教材全解版本名：**只读**。  
3. 学科顶栏可切学科（点击或水平滑）；年级胶囊不可点开。  
4. 首次进入优先读学生档案；学生改过的版本按科记忆。  
5. 章 / 课文位置：该书未切过 → 第一章；切过 → 记住再进来停原处。

### 5.2 学

6. 点课文/小节 → 进学习页；英语沪教七/八点 Section 进视频列表（无一课一练）；九年级点技能格直接播。  
7. 视频按列表顺序；点第几条从第几条播；**播完不自动跳下一集**，给学生选择。  
8. 看满 45 秒算达标（发奖）；无播放地址也可点开播。  
9. 播放记录三态：未播过「未学习」；播过未到 80%「学习中」；进度 ≥80%（含倍速）「已学完」。  
10. 语文大卡 / 理科三段列表，末尾都是一课一练；英语不加一课一练。  
11. 单元测试钉在教材全解底部，测的是**当前章 / Unit**，不是当前这一课。

### 5.3 练

12. 题目来自菁优；做过的题默认不再抽（「再练做过的」例外路径除外）。  
13. 一课一练：固定 5 题 · 中等 · 同步练习；无设置窗；不够则异常窗。  
14. 单元测试 / 自主练习：先设置窗（题量均为 5–20；五档难度、六类场景，默认同步练习），点开始后再数 N。  
15. 库存不够：确认按 N 开始（N≥1），或升/降难度、换场景、返回修改；从无题则「暂时没有题目」。  
16. 三种练习不解锁、不因缺书藏入口。

### 5.4 回

17. 首页同步路径学完/退出 → 该科科目页；学科路径 → 教材全解（专项回专项页）。  
18. 自主练习中途退出 → 选题页；做完 → 二选一回流（同步页或首页 / 学科全解或首页）。

### 5.5 换书打断

19. 五元组任一变：关学习页 / 专项 / 自主选题；按书恢复章位置；清空自主勾选。

## 6. 状态与异常（验收高频）

| 状态 | 学生看到 |
|------|----------|
| 章/单元无小节 | 缺省图 +「该章节下暂无内容」（演示：空态演示章节） |
| 小节无内容 | 「该小节内容即将开放」 |
| 专项无内容 | 空态 |
| 0 < N < 目标 | 「目前只能出 N 题」+ 确认 / 换难度 / 放弃或返回修改 |
| N = 0（有做过） | 「没有新题了」+ 换档 / 再练做过 / 放弃或返回修改 |
| 范围从无题 | 「暂时没有题目」，入口仍在 |
| 一课一练入口未作答过任何一题 | 「未练习」 |
| 一课一练作答过但中途退出未提交 | 「练习中」（不保存作答） |
| 一课一练正常作答并提交 | 「已练完」（再点仍显示已练完，换新卷） |
| 一课一练已练完再点 | 仍显示已练完，再点换新卷 |
| 同步微课未播过 | 「未学习」 |
| 同步微课播过未到 80% | 「学习中」（含倍速） |
| 同步微课进度 ≥80% | 「已学完」（含倍速；再看不改回） |

掌握态 / 错题晋级算法见阅读版第 11 节原文；课本同步学界面**不画图谱**。

## 7. 验收清单（设计研发可勾）

### 信息架构

- [ ] 三入口文案与位置符合上表；首页科目页无自主练习。  
- [ ] 改书仅我的课本；学科/首页无年级册次版本编辑。  
- [ ] 小学隐藏首页两卡；学科即将开放。

### 教材全解

- [ ] 版本只读；章筛选预选确认制。  
- [ ] 英语点 Unit / 技能格行为符合阅读版 6.2 / 6.3。  
- [ ] 单元测试文案仅「单元测试」。

### 学习与视频

- [ ] 语文大卡 / 理科三段归类规则正确。  
- [ ] 播完选择正确；不自动连播下一集。  
- [ ] 微课播放记录：未学习 / 学习中 / 已学完；满 80%（含倍速）为已学完。  
- [ ] 英语沪教七/八点 Section 进 L2 视频列表、无一课一练；九年级点技能格直达视频。

### 练习

- [ ] 一课一练无设置窗；固定 5 · 中等 · 同步练习。  
- [ ] 一课一练入口三态：未练习 / 练习中 / 已练完。  
- [ ] 单元测 / 自主：设置窗默认与推荐量正确；异常窗盖在设置上，「返回修改」只关异常。  
- [ ] 不使用邻近难度自动补齐。  
- [ ] 首页/学科自主练习切科与默认章规则正确。

### 返回与换书

- [ ] 返回表（阅读版第 10 节）全路径正确。  
- [ ] 换书关闭深层页、清空勾选、章定位正确。

## 8. 口述稿（2 分钟版）

> 学生跟哪本书，由学制、年级、学科、版本、册次五个值决定；改这些只在「我的课本」。  
> 学的时候有两条路：首页「同步课本」选科进去，或学科 Tab「课本同步学」主场。两边教材全解是一套：挑章、进课、看微课、做一课一练，章末做单元测试。英语沪教七/八先点 Section 再看视频列表，没有一课一练；九年级点技能格直接播。  
> 还想自己选题，就用「自主练习」：首页或学科竖卡进选题页，勾叶子再设题量难度场景出卷。  
> 题不够时不悄悄降难度凑数，而是弹窗让学生确认少题、换档或返回改。  
> 做完按入口回流；换书会关掉正在学的深层页并清掉自主勾选。
