# 伙伴 Tab · 相对旧小晤 Space 的近期增量

| 项 | 内容 |
|----|------|
| 范围 | **只记这两三天相对旧会话页的新增/变更** |
| 不写 | 发消息、语音输入、音浪、流式字、拍照上传态、会话反馈 sheet、情绪小游戏壳等（仍以 [小晤Space-交互需求文档](./小晤Space-交互需求文档.md) 为准，**不必重写**） |
| 完整首页 + Agent | [伙伴Tab-小晤同学-产品需求文档PRD](./伙伴Tab-小晤同学-产品需求文档PRD.md) |

---

## 1. 入口与页面结构（新增）

| 变更 | 说明 |
|------|------|
| 默认落地 | 进伙伴先 **小晤同学首页**，不再一进来就是聊天输入 |
| 一屏 | 小晤同学首页禁止上下滚动 |
| 进聊三入口 | L1 话题 / L2 其他推荐（六火花）/ L3 随便聊（含点人物） |
| 返回 | 会话「返回」回小晤同学首页，可出现「继续」 |

## 2. 小晤同学首页内容与交互（新增/改）

| 变更 | 说明 |
|------|------|
| L1 | 主推 1 + 次推 1～2；小标题 tag + 完整句；主推去掉「去聊聊」 |
| L1 换一换 | 只换话题组，不动 L2/L3；可下拉刷新 |
| L2 | 「其他推荐」+ 六入口同行；浅黑弱样式；点开即开讲 |
| L3 | 「随便聊」做主按钮 |
| 顶栏 | **去掉衣柜**及换装能力 |
| 禁止上首页 | 讲题/作文/口说/计划/错题入口；题干原文不上卡 |

## 3. 进会话时多带的信息（新增，对 Agent）

相对旧「直接开聊」，现在要点入口带上启动上下文（详见小晤同学 PRD · B5）：

- `entry`：l1 / l2 / l3 / continue  
- `opener_text`、话题或火花 id  
- 会话目标（围着话题聊 / 玩火花 / 自由聊 / 情绪陪 / 继续）  
- 短学情 hint、关系摘要（可选，不上 UI）

发消息、语音、拍照等**交互动作本身不改文档**，仍走 Space。

## 4. Agent / 推荐（新增，不在旧 Space 里）

见小晤同学 PRD · **B 章**（数据怎么用、兴趣、生成话题、偏题、记忆、安全等）。  
Space 文档**不展开**这些。

## 5. 与旧 Space 冲突时

| 议题 | 以谁为准 |
|------|----------|
| 默认是否进聊天、有无衣柜、首页结构 | **本增量 + 小晤同学 PRD** |
| 发送、语音、拍照、反馈、游戏壳 | **小晤Space-交互需求文档** |
| 会话回合 / 图片额度异常演示 | **[小晤同学-额度异常演示规则](./小晤同学-额度异常演示规则.md)** |
