## 需求设计方向（锁定）

| 层 | 角色 | 内容气质 |
|----|------|----------|
| 在场 | 小晤人设 | 角色在场即可；不单独放口播句 |
| L1 今日邀约 | **主推 1 + 次推 1–2** | 情境化对话邀约，吸引开口；**不是讲题入口** |
| L2 想一起玩会儿 | 能力/兴趣广度 | 「陪你 / 一起」词条；点开即开讲 |
| L3 | 自由聊 | 「找小晤陪聊」 |

**L1 主推规则**

- 必须保留一张主推大卡（最佳推荐位）
- 内容随情境变：好奇、情绪陪伴、兴趣等
- **禁止**主推「应用题卡住了 / 一起拆开看」等讲题功能话术（讲题走会话拍照或灵境）
- 情绪不佳时：主推优先情绪相关邀约（如「今天要是有点闷，要不要先跟我说说？」）

**L2 已锁定六入口（陪伴语感）**

1. 陪你笑一个  
2. 一起识成语  
3. 聊个世界之最  
4. 分享冷知识  
5. 陪你猜谜  
6. 一起念绕口令  

分隔文案：`其他推荐`  
L3 CTA：`随便聊`（居中主按钮，非通栏）

**明确不做（不占伙伴首屏推荐）**

- 讲题 / 这题卡住了 → 会话拍照或首页灵境解题  
- 改作文 / 口说练习 / 今日计划 → 不在 L2  
- 错题再讲 → 独立错题本 Tab  
- 「聊天」「查一查」独立入口、技能名词墙、类型标签

### 层级说明

| 区 | 内容 | 规则 |
|----|------|------|
| 在场 | 角色立绘（背景） | 无口播句、无输入框；顶栏无衣柜 |
| L1 主 | 头顶对话气泡 | 内容主推；尖角朝下指向角色 |
| L1 次 | 左右肩侧小卡 | 绕人物两侧 |
| L2 | 底栏弱化标签 | 能力广度，不抢主路径 |
| L3 | **随便聊** | 与主推并列的重要入口：居中胶囊按钮 |
| 整页 | 一屏收齐 | **不可上下滚动** |

---

## 交互要点

- 点 L1 / L2 / L3 → 进入会话
- 换一换：**只重抽 L1** 主推/次推；L2/L3 不动
- 讲题等需要时，在自由聊或会话中自然发生
