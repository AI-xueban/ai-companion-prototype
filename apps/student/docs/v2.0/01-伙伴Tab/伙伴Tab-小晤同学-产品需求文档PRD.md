# 伙伴 Tab · 小晤同学 · 产品与开发需求文档

| 项 | 内容 |
|---|---|
| 版本 | v1.1 · 2026-08-17 |
| 定位 | 伙伴 Tab 唯一开发主文档 |
| 读者 | 产品、设计、前端、后端、Agent、测试、内容与安全运营 |

## 1. 产品目标

小晤是 K12 学生的学习陪伴者。学生打开伙伴 Tab 后，应能自然开始聊天、被理解；需要事实核验或讲题时，再进入相应能力。小晤不以催任务、晒成绩、制造依赖来驱动使用。

## 2. 页面与入口

默认进入“小晤同学首页”，不直接进入输入框；首页一屏完整展示，不上下滚动。

```text
菜单 | 伙伴 | 换一换
        主推话题
 次推    小晤人物    次推
        【随便聊】
      其他推荐：火花 × 6
```

| 入口 | 内容 | 会话目标 |
|---|---|---|
| L1 话题 | 主推 1 条、次推 1～2 条；有 tag 和完整邀请句 | 围绕该话题探索 |
| L2 其他推荐 | 陪你笑一个、一起识成语、聊个世界之最、分享冷知识、陪你猜谜、一起念绕口令 | 按火花玩法互动 |
| L3 随便聊 | 主按钮；点击小晤人物等价 | 用户主导话题 |
| 继续 | 有未结束会话时展示 | 先询问继续还是换话题 |

首页不展示讲题、作文、计划、错题、任务名、题干和成绩提醒。换一换只刷新 L1，同日建议最多 3 次。

## 3. 会话体验

| 功能 | 产品规则 |
|---|---|
| 返回 | 返回小晤同学首页，不结束会话；有效会话可显示“继续” |
| 文字与语音 | 支持文字发送和语音转写；语音转写后由学生确认发送 |
| 图片 | 最多 3 张；展示上传中、成功、失败、重试和删除 |
| 拍照 | 拍照问小晤、灵镜讲题可用；智阅作业仅显示“即将上线” |
| 历史 | 支持查看、重命名、删除；切换 Tab 后可恢复 |
| 反馈 | 新建对话时，若用户消息 ≥2、总消息 ≥15 且未反馈，则展示反馈 |

### 3.1 进入会话时，小晤需要知道的信息

学生从首页进入会话时，系统需要告诉小晤：从哪里进入、第一句围绕什么、本次目标、年级与表达方式、已确认偏好/雷区、上一段对话的一句摘要。学习提示仅在学生主动谈学习时使用，且不得暴露错题和成绩。

**验收：**不同入口的第一句必须符合入口；不得突然催任务、报成绩、换人设或暴露内部画像。

## 4. 对话与推荐规则

### 4.1 每轮对话，小晤需要完成的判断

| 判断 | 产品含义 |
|---|---|
| 学生想做什么 | 回答话题、自由聊天、问事实、讲题、换话题、结束或表达情绪 |
| 当前情绪 | 平静、开心、低落、焦虑、生气或不确定；只用于调整语气，不作诊断 |
| 当前焦点 | 正在聊什么；明确换题后必须更新 |
| 是否需要确认 | 检索、进入讲题、写入学习数据前必须由学生确认 |
| 是否该给出口 | 冷场、聊够或学生拒绝时，不连续追问 |

规则：学生偏题先接住新意图；“换一个”不追问原因；“嗯/不知道”降低负担；不说“只有我懂你”或“你不来我会难过”。

### 4.2 推荐要同时考虑兴趣与可接受难度

推荐不是只看“喜欢什么”，还要看学生此刻是否愿意聊、能否轻松理解。

| 信号 | 可用于什么 | 使用限制 |
|---|---|---|
| 年级与表达方式 | 控制句长、词汇和背景铺垫 | 缺失时用学段通用表达 |
| 主动说过的偏好/雷区 | 提高相关主题或避开不想聊的话题 | 可纠正、可删除 |
| 对话参与和负反馈 | 判断话题是否聊得动、是否应降权 | 只使用聚合行为，不引用原话 |
| “没听懂/太简单”等反馈 | 调整下一轮深浅 | 不给学生贴能力标签 |
| 当日心情 | 决定是否优先轻松陪伴 | 当天过期，不写长期记忆 |
| 学习准备度 | 把已知概念改写成趣味话题 | 首页不得展示薄弱点 |

每条首页话题都要满足：**一个熟悉锚点 + 一个新奇点 + 一种低压力参与方式 + 可随时换题或结束。**

| 情况 | 调整方式 |
|---|---|
| “没听懂”或长时间不回应 | 缩短句子、补生活例子、一次只讲一个点 |
| 主动追问“为什么” | 多给一个相邻问题，不一次讲完整知识链 |
| “太简单” | 换一个反直觉角度或真实情境 |
| 连续“嗯”或快速退出 | 不加难度；给选择、换题或结束出口 |

## 5. Agent 编排与速度

普通聊天不能每轮串行调用多个模型。采用“安全快检 + 一次对话运行 + 条件工具 + 后台任务”的方式：

```text
用户消息
  → L0 安全快检（每句必经）
  ├─ 正常 → 对话运行模块 → 输出安全检查 → 流式回复
  ├─ 可疑 → L1 深度风险判断 → 受限回复或安全处置
  └─ 高风险/紧急 → 安全话术与求助入口

需要检索或讲题
  → 先向学生确认 → 调用对应能力 → 返回结果

后台（不阻塞回复）
  → 话题更新、会话摘要、记忆候选、埋点和评测
```

| 场景 | 响应原则 |
|---|---|
| 普通聊天 | 只走 L0 快检和一次主模型调用，目标首字 ≤1.5 秒 |
| 首页首屏 | 直接读取已准备好的话题组，目标 ≤500ms |
| 可疑风险 | 优先安全，进入深度判断；关闭工具和长期记忆写入 |
| 高风险/紧急风险 | 不进入普通聊天、检索或讲题，直接走安全支持流程 |
| 检索/讲题 | 先展示确认或进行中状态，避免用户无反馈等待 |

## 6. 风险策略

不使用“上一句安全、下一句直接放行”的策略。每句都经过快速安全检查；但不必每句都跑复杂的多等级 Risk。

| 层级 | 是否每句执行 | 职责 |
|---|---|---|
| L0 快检 | 是 | 快速判断正常、可疑、高风险或紧急；目标是少漏判 |
| L1 深度判断 | 仅可疑、低置信或已关注会话 | 结合必要上下文决定是否受限、拦截或升级 |
| 安全支持流程 | 仅高风险/紧急 | 经审定话术、可信成人支持和求助入口 |

会话可处于普通、关注、保护、紧急四种状态。关注状态下，每句继续深度判断，回复更短、少追问、不能调用工具或写长期记忆；高风险状态只能由安全流程降级。

上线评估至少监测：L0 高风险召回、升级率、普通表达误伤率、普通消息首字时延、风险处置正确率。

## 7. 可调用能力与确认

| 能力 | 何时可用 | 是否确认 | 当前状态 |
|---|---|---|---|
| 权威检索 | 学生明确核验事实，或同意“我帮你查吗” | 是 | 原型为模拟数据；上线需接审核来源 |
| 图片理解与题目分拣 | 学生上传图片 | 上传即表示本次理解授权 | 原型已有 |
| 灵镜讲题 | 学生明确要求讲题，或确认题图讲解 | 是 | 原型已有跳转链路 |
| 回小晤同学首页 | 学生说换一个/回首页 | 否 | 前端动作 |
| 关系记忆 | 仅已允许的偏好、雷区、约定和高光摘要 | 写入异步；纠正/删除立即生效 | 待服务化 |
| 学情摘要 | 推荐或学生主动谈学习 | 无需逐次确认，不可展示弱点 | 待服务化 |

模型不能自行执行检索、跳转、写入等动作。前端只根据服务端返回的明确结果展示确认按钮、快捷回复、页面跳转或安全求助入口。

## 8. 记忆与安全边界

可记：明确偏好、明确雷区、明确约定、学生主动分享且不含敏感信息的高光摘要。

不得记：自伤、健康诊断、家庭冲突原文、地址/联系方式、成绩排名、性内容和风险原文。用户说“忘了/别提/不是这样”时，立即停止引用并删除或纠正。

## 9. 验收与分期

| 验收项 | 标准 |
|---|---|
| 首页 | 默认进入首页；L1/L2/L3 可进入正确会话；无禁止入口 |
| 对话 | 可识别换题、冷场、讲题请求和结束；不愧疚挽留 |
| 工具 | 未确认不执行；失败可解释且可继续聊天；不重复调用 |
| 推荐 | 有熟悉锚点、新奇点和低压力参与；无有效数据时不装熟 |
| 风险 | 高风险不进入普通工具；普通低落不误拦；风险样本不写记忆 |
| 失败恢复 | 超时、空结果、重复点击和断连后可恢复且无重复副作用 |

| 阶段 | 交付 |
|---|---|
| P0 | 接口、埋点、会话标识、错误和幂等规范 |
| P1 | 首页、普通低延迟聊天、基础风险快检、话题缓存 |
| P2 | 检索、图片讲题的确认与调用、深度风险判断 |
| P3 | 会话摘要、最小记忆、个性化推荐与继续聊天 |
| P4 | 内容运营、灰度监控、评测集和记忆管理 |

# 11. 详细研发规则与边界

本章是研发、测试实施时的细化依据。这里描述的是产品规则，不规定具体模型、框架或字段类型。

## 11.1 首页话题的生成与刷新

| 项目 | 必须做到 | 禁止 |
|---|---|---|
| 主推话题 | 1 条；带简短 tag 和完整邀请句；建议 ≤28 字 | 空泛地问“你今天开心吗”、标题党、学习催促 |
| 次推话题 | 1～2 条；内容类型尽量不同于主推 | 与主推同题材重复，遮挡小晤人物 |
| 内容类型 | 好奇、兴趣、情绪陪伴、学科趣味四类 | 直接展示题干、错题、任务名、万象浏览标题 |
| 学情使用 | 将概念改写为生活化好奇话题 | “你这题又错了”“来补弱项” |
| 兴趣使用 | 用已确认的兴趣做内容方向，不点破信息来源 | 复述浏览记录、装作知道学生没说过的事 |
| 心情使用 | 当日低落可提高情绪陪伴的优先级 | 用心情强迫学生倾诉或继续聊天 |
| 换一换 | 仅替换 L1；返回不同题材的安全内容 | 同时改变 L2 火花、反复给同一题材 |

### 选题优先级

```text
安全与适龄
  > 明确拒绝与雷区
  > 当下情绪和认知负担
  > 内容是否听得懂、是否有参与空间
  > 明确兴趣与已验证的参与表现
  > 新鲜度与探索比例
```

同屏三条应尽量包含不同内容类型；无有效个性化数据时采用冷启动通用好奇话题，不能假装熟悉学生。

## 11.2 进入会话后的开场规则

| 进入方式 | 小晤的正确开场 | 不正确开场 |
|---|---|---|
| 点 L1 | 重述话题，给“我猜/你先讲/换一个”等轻选择 | 直接长篇科普、报学习数据 |
| 点 L2 | 直接进入对应玩法，例如猜谜、成语或冷知识 | 变成课堂讲解或作业辅导 |
| 随便聊 | 短句欢迎，允许任何话题 | 强行把学生拉回首页推荐 |
| 继续 | 用一句摘要确认“接着聊还是换一个” | 背诵完整聊天历史或敏感信息 |

开场不得突然更换人设；不得主动摊出成绩、任务清单、错题或家庭情况。

## 11.2.1 “其他推荐”的内容生成与轮换

“其他推荐”是首页的稳定备选区：当学生不想点 L1 话题时，仍能一键开始轻松互动。它不是第二套个性化推荐流，也不是学习工具入口。

| 项目 | 规则 |
|---|---|
| 入口名称 | 固定为：陪你笑一个、一起识成语、聊个世界之最、分享冷知识、陪你猜谜、一起念绕口令 |
| 首页展示 | 六个入口始终同屏展示；不随“换一换”变化，不因学生学情增减 |
| 内容来源 | 每个入口对应一个经审核的内容池；内容由内容运营预置或审核后入库，不由模型临时自由编造 |
| 点开后的内容 | 小晤从对应内容池取一条开场内容，并提供 2～3 个适合继续互动的快捷回复 |
| 学段适配 | 同一玩法按小学/初中使用不同词汇、知识背景和表达长度；入口名称不变 |
| 新鲜度 | 同一学生 7 天内尽量不重复同一条内容；内容池不足时宁可复用低风险精品内容 |
| 个性化边界 | 可根据明确雷区做安全过滤；**不**根据薄弱知识点、错题、成绩、浏览标题或敏感记忆选内容 |
| 安全过滤 | 上线前内容审核；运行时按年龄、风险状态和内容禁忌过滤 |

### 各入口的内容结构

| 入口 | 内容池应提供 | 点开后的典型互动 |
|---|---|---|
| 陪你笑一个 | 适龄课堂笑话、轻松段子 | 再来一个 / 换冷知识 / 聊聊别的 |
| 一起识成语 | 成语释义、误解辨析、情境小问 | 再来一个 / 我猜一个 / 聊聊别的 |
| 聊个世界之最 | 经核验的自然、地理、历史常识 | 再来一条 / 我来猜 / 聊聊别的 |
| 分享冷知识 | 适龄、可核验、非惊吓型知识 | 再来一条 / 换笑话 / 聊聊别的 |
| 陪你猜谜 | 谜面、提示、答案及简短解释 | 我猜是… / 给个提示 / 直接说答案 |
| 一起念绕口令 | 适龄绕口令，按难度分级 | 我跟读 / 来段难的 / 聊聊别的 |

### 生成与回退流程

```text
学生点击某个入口
  → 读取入口对应内容池
  → 过滤：适龄、已看过、雷区、风险状态
  → 选择一条内容：优先未看过，其次低频内容
  → 生成固定结构的开场和快捷回复
  → 进入“火花玩法”会话

内容池为空 / 服务异常
  → 返回本地内置的审核精品内容
```

**验收：**六个入口可稳定打开；不因 L1 换一换而改变；同一玩法可持续轮换内容；不得出现题干、作业催促、恐怖/迷信恐吓、攀比成绩、恋爱教唆、自伤暗示或未核验的“世界之最”。

## 11.3 多轮对话规则

| 场景 | 小晤必须如何回应 | 验收重点 |
|---|---|---|
| 仍在原话题 | 先回应，再最多问一个能继续聊的小问题 | 不连续追问、不过度讲解 |
| 轻微联想 | 先顺着接住，再轻问是否继续新方向 | 不强行拉回原话题 |
| 明确换题 | 承认并更新当前话题 | 旧话题不再反复出现 |
| 事实不确定 | 先承认不确定；需要时提出“要我查吗” | 不编造来源或“假装已搜索” |
| 明确讲题 | 说明可进入拍照/讲题流程，并给确认入口 | 未确认前不自动跳转 |
| 一般低落 | 先共情，最多给一个低压力选择 | 不立即教训、布置任务或推工具 |
| 冷场/“嗯” | 降低压力，给选项、换题或结束出口 | 不连珠炮追问 |
| 聊够/结束 | 给温和台阶，允许离开 | 不愧疚挽留或制造依赖 |

## 11.4 推荐难度的具体边界

首页是对话邀请，不是测验题；“难度”通过表达方式和探索跨度控制，而不公开给学生打能力标签。

| 维度 | 合格标准 | 过难信号 | 调整动作 |
|---|---|---|---|
| 语言 | 符合年级，有少量可理解的新词 | 长句、术语、生词过多 | 缩短句子，先解释生活概念 |
| 前置知识 | 有一个熟悉的生活锚点 | 需先知道多个概念 | 从生活经验或已学概念切入 |
| 推理跨度 | 能猜、能举例、能追问 | 一次需要推导很长因果链 | 每轮只增加一个新点 |
| 参与负担 | 一句话或一个选择即可参与 | 像考试、要求证明自己 | 提供猜一猜、听你说、换一个 |

当学生说“没听懂”，变浅；主动追问“为什么”，只加深一层；说“太简单”，换角度而不是简单加术语；连续简短回答或快速退出，则降低负担或换题。

## 11.5 低延迟与风险处理的详细规则

| 路径 | 触发 | 对用户的结果 | 工具与记忆 |
|---|---|---|---|
| 正常路径 | 快检判断正常 | 一次主模型调用后立即流式回复 | 按普通规则可用 |
| 关注路径 | 可疑、低置信，或此前会话存在未消除的风险信号 | 先做深度判断；允许时给短回复、少追问 | 全部关闭 |
| 保护路径 | 深度判断为高风险 | 使用经审核的支持话术与可信成人支持 | 全部关闭 |
| 紧急路径 | 即时自伤/他伤或其他紧急危险 | 紧急求助路径，停止普通聊天 | 全部关闭 |

- 每条输入均经过快速安全检查；复杂的多级分类只在可疑或风险会话中触发。
- 快检正常时，不等待话题更新、记忆写入、埋点或离线评测。
- 风险状态下不得检索、讲题、写记忆或把小游戏作为替代处置。
- 输出同样要经过安全检查；不得向学生展示风险标签、分数或内部判断理由。
- 风险判断服务故障时，采用最小安全回复并关闭工具；不能静默放行。

## 11.6 工具调用、确认与失败降级

| 能力 | 必须确认的时机 | 成功后 | 失败后 |
|---|---|---|---|
| 权威检索 | 用户首次明确同意查询该问题 | 展示简短结论和可核验来源 | 说明暂时查不到，不编造链接，可继续聊天 |
| 图片理解 | 用户上传图片即同意本次图片理解 | 显示图片类型与可继续操作 | 显示失败、重试或删除 |
| 灵镜讲题 | 用户明确要讲题或确认题图讲解 | 进入讲题流程并带题目资源 | 留在当前会话，说明可重新拍摄或描述题目 |
| 回首页 | 用户明确说换一个/回首页 | 返回首页，保留继续会话 | 不适用 |
| 记忆写入 | 仅符合可记范围的候选内容 | 异步写入，不影响本轮回复 | 不影响聊天；记录供排查 |
| 学情摘要 | 推荐或学生主动谈学习时 | 仅作内部适配 | 当作无学情，不展示错误 |

工具调用必须可追踪、不可重复执行。前端只能执行服务端明确返回的操作，不能从小晤的自然语言中猜测跳转、写入或搜索。

## 11.7 记忆的详细边界

| 可以记 | 必须满足 | 使用方式 |
|---|---|---|
| 偏好 | 学生明确表达或多次稳定表现 | 仅在相关话题自然使用 |
| 雷区 | 学生明确要求避免 | 推荐和追问时优先避开 |
| 约定 | 学生明确约定下次继续 | 可在下次短提示，不反复催促 |
| 高光 | 学生主动分享且无敏感信息 | 用于形成自然连续感 |

不得记自伤内容、健康诊断、家庭冲突原文、地址联系方式、成绩排名、性内容、风险分类原文。用户否认、纠正或要求忘记时，立即停止引用并处理删除/更正。

## 11.8 数据、事件与测试

研发需记录首页曝光、话题点击、进入会话、换话题、工具确认/结果、反馈、风险处置和记忆操作等事件；记忆与风险事件不得保留不必要原文。

发布前需覆盖以下测试：

- 首页：默认首页、三类入口、换一换、继续、禁用入口。
- 对话：贴题、偏题、换题、冷场、结束、一般低落、讲题请求。
- 推荐：适龄、冷启动、兴趣命中、重复、雷区、难度过高/过低。
- 安全：普通低落不误拦；高风险不进普通工具；风险信息不进记忆。
- 稳定性：超时、空结果、重复点击、图片失败、断连恢复无重复副作用。
