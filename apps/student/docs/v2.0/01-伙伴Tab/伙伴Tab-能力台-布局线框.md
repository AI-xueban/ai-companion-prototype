## 0. 一句话定位

- **首页**：今天学什么。  
- **伙伴**：小晤能帮你做什么。  
- 切到「伙伴」**不再直接进入发消息聊天**。默认落在能力台。聊天是下一跳。

---

## 1. 页面层级

```
伙伴 Tab
 ├─ L0  能力台（默认落地）          ← 本次线框重点
 │    ├─ 角色口播
 │    ├─ 今日好奇（3 条）
 │    ├─ 技能卡（标题固定，副标题会变）
 │    ├─ 继续对话（有未完成会话才出现）
 │    └─ 底部输入（不自动聚焦）
 │
 └─ L1  能力会话（复用现有 LumiSpace 聊天壳）
      ├─ 来自好奇卡：小晤先开口
      ├─ 来自技能卡：带技能名的会话
      └─ 来自输入框：通用陪伴聊天
```

返回规则：L1 点返回 / 系统返回 → 回到 L0，不销毁未完成会话。

## 2. L0 能力台 · 总装线框

v0.2 改为 **人物居中、信息环绕**，不再左右分栏。可打开 [`partner-layout-wireframes.html`](./partner-layout-wireframes.html) 看图。

```
┌──────────────────────────────────────────────────────────────────────────┐
│  [☰]     小晤的空间                                      [换一换]         │
├──────────────────────────────────────────────────────────────────────────┤
│                     ┌ 脑洞大卡 · 头顶 ─────────────────┐                 │
│                     │ 镜子左右反了，为什么上下不反？    │                 │
│                     └──────────────────────────────────┘                 │
│      ┌ 学科 · 左肩 ┐              ╭──── 角色 ────╮     ┌ 兴趣/脑洞 · 右肩┐│
│      │ 0为什么不能  │              │              │     │ 企鹅脚 / 冷是… ││
│      │ 做除数？     │     讲题     │     小晤     │ 开口 │               ││
│      └─────────────┘     作文     │   口播一句   │ 错题 └───────────────┘│
│                          计划      ╰──────────────╯ 聊天                  │
│                          缓一缓                      查一查                │
├──────────────────────────────────────────────────────────────────────────┤
│     首页     │     学科     │     错题     │    伙伴    │     我的       │
└──────────────────────────────────────────────────────────────────────────┘
```

- 上弧：3 张好奇卡（头顶最大，左右肩较小）。
- 左右和下沿：8 个**技能胶囊**（短标题 + 短副标题），不要 8 张大卡把人挡住。
- 虚线椭圆只是线框注释，正式 UI 不必画出轨道。
- 进入 L1 后环绕卡收起，人物仍居中。

### 2.1 区域职责

| 编号 | 区域 | 变不变 | 点击后 |
|------|------|--------|--------|
| A | 画面中心角色 + 当日口播 | 口播按天变，当天内不闪 | 不跳页；可后续做轻互动 |
| B | 上弧今日好奇 3 卡 | **每天变**；可换一换 | 进 L1，小晤先问这句 |
| C | 环绕技能 8 胶囊 | **标题不变**；副标题短、按天/学情变 | 进对应技能会话或现有流程 |
| D | 顶栏 ☰ | 不变 | 历史抽屉（衣橱本期不放在能力台） |
| E | 继续对话条 | 仅有未完成会话时出现，浮在头顶上方 | 回到原会话，不新开 |

### 2.2 布局约束（设计坐标）

| 项 | 建议 |
|----|------|
| 画布 | `768 × 512`，3:2 横屏 |
| 角色 | 画面几何中心，头部和上半身完整可见 |
| 好奇卡 | 不压脸；头顶主卡宽约 250px，肩侧卡约 168px |
| 技能胶囊 | 贴椭圆外沿，最小点击区域 ≥ 44px，不叠在角色身上 |
| 能力台输入 | **本期去掉**。不进聊天、不弹键盘；自由输入只在 L1 会话出现 |
| 衣橱 | **本期不放在能力台顶栏**；需要时可进 ☰ 抽屉 |
| 环绕数量 | 好奇 3 + 技能 8；再多会变成装饰，点不准 |

## 3. 今日好奇 · 三卡编队

3 条问题的槽位固定，内容按推荐规则填。万象视界**没有题目**，只提供标签当兴趣种子。

```
默认编队（有兴趣）          无兴趣 / 兴趣被否定
┌──────────────┐            ┌──────────────┐
│ 1 脑洞（大）  │            │ 1 脑洞（大）  │
├───────┬──────┤            ├───────┬──────┤
│ 2 学科 │ 3 兴趣│            │ 2 学科 │ 3 脑洞│
└───────┴──────┘            └───────┴──────┘
曝光：脑洞约 1/3             曝光：脑洞 2/3 ≈ 一半+
```

目标曝光（按天、按次平均）：

| 来源 | 占比 | 说明 |
|------|------|------|
| 开放脑洞 | **约 50%** | 适龄怪问题，不必挂课本 |
| 学段学科 | **约 30%** | 按当前年级/学期/在读学科生成 |
| 万象兴趣 | **约 20%** | 用内容**标签**生成可聊的问题，不引用万象正文当题 |

## 4. 分状态线框

### 4.1 状态 A · 冷启动（没看过万象、没点过好奇）

兴趣槽作废。2 脑洞 + 1 学科。不写「猜你喜欢」。

```
┌─────────────────────┬────────────────────────────────────────────┐
│                     │  今日好奇                         [换一换] │
│      小晤           │  ┌──────────────────────────────────────┐ │
│                     │  │ 镜子左右反了，为什么上下不反？        │ │
│  嗨，我是小晤。      │  │ 脑洞                          [猜一下]│ │
│  今天想不想猜一个    │  └──────────────────────────────────────┘ │
│  怪问题？            │  ┌────────────────┐ ┌────────────────┐   │
│                     │  │ 0 为什么不能    │ │ 冷是一种东西，  │   │
│                     │  │ 做除数？        │ │ 还是热变少了？  │   │
│                     │  │ 七年级·数学     │ │ 脑洞            │   │
│                     │  └────────────────┘ └────────────────┘   │
│                     │  （无「因为你看过××」）                     │
└─────────────────────┴────────────────────────────────────────────┘
```

### 4.2 状态 B · 有万象兴趣（看过 `#生物` 等）

第三槽改为兴趣衍生问题。卡面上**不展示后台标签**（万象学生端本来也不展示标签）。可用一句人话暗示来源。

```
┌─────────────────────┬────────────────────────────────────────────┐
│                     │  今日好奇                         [换一换] │
│      小晤           │  ┌──────────────────────────────────────┐ │
│                     │  │ 镜子左右反了，为什么上下不反？  脑洞  │ │
│  你上次看企鹅那条，  │  └──────────────────────────────────────┘ │
│  我又想到一个。      │  ┌────────────────┐ ┌────────────────┐   │
│                     │  │ 0 为什么不能    │ │ 企鹅脚踩冰面，  │   │
│                     │  │ 做除数？  学科  │ │ 为什么不会冻住？│   │
│                     │  │                 │ │ 和你看过的有关  │   │
│                     │  └────────────────┘ └────────────────┘   │
└─────────────────────┴────────────────────────────────────────────┘
```

点击兴趣卡 → L1 小晤先问。聊完**可**出「万象里有相关短片，要不要看」；没有对应内容则不出。

### 4.3 状态 C · 兴趣连续被否定

同标签连着被「换一换」或曝光未点 → 关兴趣槽，回到状态 A 的编队。角色口播改成换题材，不解释算法。

```
 口播：那换个更怪的。
 三卡：脑洞 + 学科 + 另一条脑洞（禁止再出企鹅/宇宙同族）
```

### 4.4 状态 D · 有未完成会话

能力台仍是落地页。继续条插在顶栏下、好奇区上，不直接把人丢进输入框。

```
┌─────────────────────┬────────────────────────────────────────────┐
│                     │  ┌──────────────────────────────────────┐ │
│      小晤           │  │ 继续：镜子为什么只左右反？     [→]   │ │
│                     │  └──────────────────────────────────────┘ │
│                     │  今日好奇 …（仍展示，可开新话题）           │
└─────────────────────┴────────────────────────────────────────────┘
```

### 4.5 状态 E · 三卡全天未点（第二天）

仍出 3 条，不空屏。脑洞 2 + 学科 1；学科改成生活问法。口播改邀请，不催点。底部输入始终在。

```
 口播：不想猜也行，直接打字也行。
 学科卡例：如果作业只能写一行，你写哪一行？
```

## 5. L1 进入聊天 · 第一屏

### 5.1 从好奇卡进入（推荐主路径）

问题**不是**学生自己发出的。小晤先开口。底部给轻选项。

```
┌──────────────────────────────────────────────────────────────────┐
│  [← 返回能力台]     今日好奇                          [☰]        │
├─────────────────────┬────────────────────────────────────────────┤
│                     │                                            │
│      小晤           │   小晤  镜子左右反了，为什么上下不反？      │
│      说话态         │        你先猜，还是要我直接讲？             │
│                     │                                            │
│                     │   [我猜是…]  [直接告诉我]  [换一个]         │
│                     │                                            │
├─────────────────────┴────────────────────────────────────────────┤
│  [📷]   说说你的想法…                                    [🎤]    │
├──────────────────────────────────────────────────────────────────┤
│                         BottomNav（可选：会话中仍显示）            │
└──────────────────────────────────────────────────────────────────┘
```

| 动作 | 结果 |
|------|------|
| 返回 | 回 L0；本会话保留，出现「继续对话」 |
| 我猜是… | 聚焦输入，placeholder 换成「我猜是因为…」 |
| 直接告诉我 | 小晤开始讲，进入正常流式回复 |
| 换一个 | 本会话结束或插入新问题；当天该条降权 |
| 自己打字发送 | 按用户消息续聊 |

### 5.2 从技能卡进入

顶栏标题换成技能名。开场白和 placeholder 换成该技能用语。

```
┌──────────────────────────────────────────────────────────────────┐
│  [←]     陪我开口说                              [☰]             │
├─────────────────────┬────────────────────────────────────────────┤
│      小晤           │  小晤  Unit 3 用 4 句就能聊完周末。         │
│                     │       要先跟读，还是直接开口？              │
│                     │  [先跟读]  [直接聊]                        │
├─────────────────────┴────────────────────────────────────────────┤
│  [📷]   试着说一句 How was your weekend…                 [🎤]    │
└──────────────────────────────────────────────────────────────────┘
```

第一期跳转约定（可评审时改）：

| 技能 | L1 去哪 |
|------|---------|
| 讲讲这道题 | 现有拍照 / AI 讲题流（角色会暂时离开会话壳） |
| 帮我改作文 | 现有作文实验室 |
| 订正错题 | 可跳错题 Tab，或拉一条错题进会话（待定） |
| 安排今天学 | 入口进首页同一份今日计划草稿，伙伴页不做第二套晨检 |
| 开口说 / 聊聊天 / 缓一缓 / 查一查 | 留在小晤会话壳 |

### 5.3 从底部输入进入

有文字或语音发送后，进入通用陪伴聊天（接近现行 `LumiSpace`）。空聚焦不跳页。

## 6. 技能卡线框（标题死、副标题活）

```
┌─────────────────────────────┐
│  开口说                     │  ← 标题，长期不变
│  Unit 3，用 4 句聊完周末     │  ← 副标题，按天 / 学情变
└─────────────────────────────┘
```

| 技能标题（固定） | 副标题示例（会变） |
|------------------|--------------------|
| 讲讲这道题 | 拍一张卡住的题 |
| 陪我开口说 | Unit 3，用 4 句聊完周末 |
| 帮我改作文 | 把连续三个「然后」改顺 |
| 订正错题 | 有数据：一元二次还差 2 道 / 无数据：最容易错在设未知数 |
| 安排今天学 | 还有 25 分钟的话，先做哪件 |
| 聊聊天 | 想说就说 |
| 缓一缓 | 烦、累、考前紧张 |
| 查一查 | 直接用今日好奇那句 |

副标题没有学情时，用题库轮换，不要空着。

## 7. 「换一换」与都不感兴趣

线框上只在好奇区右上放一个文字按钮，不做「都不感兴趣」大按钮。

```
今日好奇                              [换一换]
```

| 行为 | 页面变化 |
|------|----------|
| 点换一换 | 三卡同时换成新一批；必须换题材族，不能三条都是天文 |
| 被刷掉的问题 | 当天不再出现，同标签 24h 降权 |
| 连续 2～3 次刷掉兴趣 | 第三槽改脑洞，进入状态 C |
| 一天换一换上限（建议） | 3 次；第 3 次后按钮变「明天再换」或置灰 |
| 学科连续被无视 | 隔天仍保 1 条学科，但问法更生活，避免作业感 |
| 什么都不点 | 见状态 E；输入框仍可进聊天 |

## 8. 万象视界怎么接（线框层只保留出口）

```
万象图文/视频  --浏览-->  后台标签（#宇宙 #生物 #双语…）
                              │
                              ▼
                     生成可聊问题（伙伴题库）
                              │
                              ▼
                     点卡 → L1 对话
                              │
                              ▼
                     聊完可选：去看相关内容 → 万象详情
```

禁止：把万象标题当问题卡、把万象当题库、冷启动写「因为你喜欢宇宙」。
