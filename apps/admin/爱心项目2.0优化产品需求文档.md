# 后台爱心项目优化需求文档v2.0.1（简化版）

更新日期：2026-09-16  
适用页面：后台「金币运营 / 捐赠与爱心池」  
原型入口：`可下载打开地址/万象视界管理后台原型.html`

## 1. 本次目标与范围

本次采用简化方案，在现有页面上完成两项调整：

1. 明确“爱心池余额”改成「当前爱心池总额」卡片的文案与说明，下方说明由「当前结余」改为「当前项目总额」。
2. 新增「往期项目」Tab，用于查询结项档案、补充项目成果和管理学生端公示状态。

捐赠记录、爱心池台账保留现有功能；「月报与公示」补充每月自动生成、不区分项目的月度统计规则。原完整方案中的余额结转、结项拨付模型、当前阶段多字段编辑、结项时上传成果与选择公示等，不作为本版本新增要求。

## 2. 页面结构

页面由顶部统计卡片、当前爱心项目卡片和业务 Tab 组成。

统计卡片依次为：当前爱心池总额、累计捐赠金币、平台配套资助、今日捐赠金币。

业务 Tab 顺序为：

1. 捐赠记录。
2. 往期项目（本次新增）。
3. 爱心池台账。
4. 月报与公示。

切换 Tab 保留顶部统计卡片和当前项目卡片。「往期项目」管理项目结项档案，不替代「月报与公示」的月度数据功能。

## 3. 当前爱心池总额字段与说明

### 3.1 展示文案

| 位置 | 本版内容 |
| --- | --- |
| 卡片标题 | 当前爱心池总额 |
| 金额 | 使用 ¥ 前缀，以人民币展示 |
| 金额下方说明 | 当前项目总额 |
| 被替换的旧说明 | 当前余额 |

当前标题仍为「当前爱心池总额」；「当前项目总额」是金额下方说明，并非本次替换后的卡片标题。

### 3.2 业务含义与金额口径

按「当前项目总额」的文案含义，本卡片应表达当前有效爱心项目已筹集的学生捐赠金额，不是募集上限，也不是扣除拨付后的账户可用余额。

学生捐赠按 `100 金币 = 1 爱心值 = ¥1` 折算。平台配套资助由右侧独立卡片统计，不叠加在本卡片金额中；右侧说明保留「通晤纪累计投入」。

按此含义，业务口径应为：当前项目捐赠金币合计 ÷ 100，与当前项目卡片已筹金币的人民币折算值一致。累计历史捐赠由「累计捐赠金币」卡片承担，不与当前项目金额混用。

### 3.3 原型实现差异（待对齐）

当前原型已替换说明文案，但统计卡片金额仍按全部历史捐赠金币合计折算，未按当前项目过滤；当前项目进度则优先读取当前阶段已筹金币，两者可能不一致。

本次文档更新不代表已修改原型金额计算。开发对接前需确认并统一金额口径，不能将累计历史捐赠与当前项目总额视为同一概念。本版不据此新增财务拨付或余额结转方案。

## 4. 当前项目与结项衔接

### 4.1 保留当前项目操作

当前项目卡片展示名称、阶段周期、状态、已筹金币 / 募集上限、剩余金币及进度条。

操作保持「调整上限」「结项并开下阶段」，不改为统一编辑名称、周期和上限的入口。

「调整上限」弹窗展示当前上限，输入新上限；新上限为正整数且不得低于当前已筹金币。保存后更新当前项目卡片。

### 4.2 结项并开启下一阶段

1. 弹窗展示即将结项项目名称、阶段周期、已筹金币、募集上限及剩余金币。
2. 必填新阶段名称、新阶段周期、新阶段上限。
3. 新阶段周期保留原型的文本输入方式；可识别为年月范围时，结束月份不得早于开始月份。上限为正整数。
4. 保留运营手动结项能力，不新增「必须募满才可结项」限制。
5. 确认后生成已结项档案，保存结项编号、名称、周期、已筹金币、募集上限和结项时间；关联捐赠记录保留可查。
6. 新阶段成为当前项目，状态为募集中，已筹金币从 0 开始；本版不新增结余自动结转。
7. 新结项档案默认未公示、成果为空。结项弹窗不要求上传成果或选择公示。
8. 成功后切换至「往期项目」Tab，提示「已结项，可在往期项目中上传项目成果」。取消不生成档案或新阶段。

## 5. 往期项目 Tab

### 5.1 数据范围、筛选与分页

仅展示已结项阶段，不展示当前项目或已取消项目。新结项项目排在列表前部。

| 筛选项 / 操作 | 规则 |
| --- | --- |
| 项目名称 | 输入项目名称或结项编号，支持模糊匹配 |
| 结项时间 | 全部、今日、近 7 天、近 30 天、本月；按结项时间筛选 |
| 查询 | 应用条件并回到第 1 页 |
| 重置 | 清空关键词，结项时间恢复全部，并回到第 1 页 |

进入 Tab 直接展示已结项列表；无数据时显示「暂无已结项项目」。支持分页，默认每页 10 条，展示筛选结果总条数。

### 5.2 列表字段与布局

| 字段 | 说明 |
| --- | --- |
| 结项编号 | 结项档案唯一编号 |
| 项目名称 | 结项时的项目名称 |
| 阶段周期 | 结项时的阶段周期 |
| 捐赠金币 | 结项时归档的已筹金币 |
| 折合人民币 | 捐赠金币 ÷ 100，不叠加平台配套 |
| 募集上限 | 结项时的募集金币上限 |
| 状态 | 已结项 |
| 公示状态 | 未公示 / 已公示 |
| 捐赠笔数 | 关联到该结项项目的捐赠记录笔数 |
| 结项时间 | 实际结项时间，最后一个业务字段 |
| 操作 | 查看详情、上传项目成果、公示 / 取消公示 |

不提供删除入口。操作按钮垂直居中，单元格分隔线与整行一致，按钮文字不拆行。窄窗口下允许表格横向滚动，避免名称、金额、时间和操作列相互挤压。

### 5.3 查看详情

点击「查看详情」打开弹窗，展示列表业务字段、公示时间、成果图片和文字说明。

无公示时间时显示「—」；无成果时显示相应空状态。详情不展示逐笔捐赠记录，捐赠明细仍通过「捐赠记录」Tab 查询。

### 5.4 上传项目成果

1. 点击「上传项目成果」打开成果编辑弹窗，展示项目名称、周期和募集数据。
2. 支持新增、移除成果图片；支持 jpg、png、webp、gif，最多 9 张，单张不超过 10MB。
3. 支持填写项目完成情况和成果文字说明，再次进入时回显已保存内容。
4. 保存更新该往期项目成果；取消不保存本次修改。
5. 成果保存与公示独立：保存不自动公示，也不改变已有公示状态。
6. 成果图片与文字说明均为选填：可只上传图片、只填写说明，也可两项均为空。允许清空已有图片和说明后再次保存，不得因成果为空阻止保存或公示。详情按对应空状态展示。

### 5.5 公示与取消公示

| 当前状态 | 操作与结果 |
| --- | --- |
| 未公示 | 显示「公示」；二次确认后变为已公示，记录公示时间，学生端可展示该往期项目 |
| 已公示 | 显示「取消公示」；二次确认后变为未公示，清空当前公示时间，学生端不再展示 |

取消确认不改变状态。公示状态调整不得改变结项时间、募集数据或捐赠归属。「上传项目成果」弹窗仅维护成果，不包含公示开关。

### 5.6 导出

提供导出入口，导出当前筛选条件下的全部往期项目，不仅限当前页。字段与列表业务字段一致，不包含操作列。

当前原型生成 UTF-8 CSV，可使用 Excel 打开，不将其描述为已实现原生 `.xlsx` 导出。

## 6. 月报与公示

### 6.1 自动生成规则

1. 系统按自然月自动生成月报，每月一条记录，不由运营手动创建，不以项目结项或公示作为生成条件。
2. 默认在次月 1 日生成上一个完整自然月的月报，统计时区统一为北京时间（Asia/Shanghai）。
3. 统计范围为该月 1 日 00:00:00（含）至次月 1 日 00:00:00（不含），按业务数据实际发生时间归入月份，而非按项目周期或结项时间归属。
4. 不区分项目：同月多个项目的数据合并为一份月报；跨月项目的数据分别计入各自发生月份，不能将项目全部数据计入结项月。
5. 无业务数据的月份仍自动生成记录，当月捐赠金币、参与人数展示为 0。
6. 按月份保证记录唯一，任务重试不得重复生成；生成失败支持补跑，补跑仍按原统计月份取数。
7. 自动生成后默认为草稿；运营发布后显示「已发布」并记录发布时间。生成记录不等于自动发布。

月报仅统计所属自然月内实际产生的数据，不按项目拆分。


## 8. 验收标准

- [ ] 标题为「当前爱心池总额」，下方说明为「当前项目总额」，不再显示「当前余额」。
- [ ] 金额采用人民币格式，平台配套独立展示；开发对接前确认当前项目金额口径，原型累计统计差异明确记录。
- [ ] Tab 顺序为捐赠记录、往期项目、爱心池台账、月报与公示。
- [ ] 结项成功生成往期档案并跳转；新阶段从 0 开始，往期档案默认未公示、无成果。
- [ ] 往期项目支持关键词、结项时间筛选、查询、重置、分页、总条数和空状态。
- [ ] 列表字段完整，操作列居中、分隔线对齐，窄窗口可横向滚动。
- [ ] 详情展示结项数据、公示信息和成果，不展示逐笔捐赠记录。
- [ ] 成果上传限制有效，可保存与回显，取消不保存，保存不自动改变公示状态。
- [ ] 成果图片和文字说明均非必填，单项为空或两项均为空可保存、可公示，清空已有成果后可保存。
- [ ] 公示 / 取消公示需确认，学生端可见性随状态联动，结项数据不变。
- [ ] 导出包含筛选下全部业务记录，不包含操作列。
- [ ] 每月自动生成上一自然月的一条月报，默认草稿，无数据月份也生成；任务重试或补跑不重复生成。
- [ ] 月报不按项目拆分，同月不同项目合并统计，跨月项目按数据实际发生月份分别统计。
- [ ] 统计范围采用北京时间、月初含至次月月初不含；不混入其他月份或累计历史发生量。
