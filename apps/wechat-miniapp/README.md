# AI 学伴微信小程序

本目录是独立的原生微信小程序应用，与 `apps/student`（React + Vite 原型）平级维护。

## 当前范围

- 小程序当前仅提供家长、教师两类工作空间；学生账号仅用于关联学习数据，不提供学生端入口。
- 教师页面放入分包，避免影响家长端的首屏加载。
- 页面只能根据权限做展示控制；数据范围、绑定关系与操作授权必须由服务端校验。

## 启动方式

1. 用微信开发者工具导入本目录。
2. 在开发者工具中填写真实小程序 AppID；仓库中的 `appid` 仅为占位值。
3. 后端接入前，页面会展示骨架和占位状态；不要把真实密钥、AppID 或用户数据提交到仓库。

## 目录约定

```text
miniprogram/
├─ pages/auth/       授权、平台账号登录与账号绑定
├─ pages/student/    学生端能力
├─ pages/guardian/   家长端能力
├─ pages/teacher/    教师端能力（独立分包）
├─ services/         API 与微信能力适配
├─ stores/           当前身份、当前学生与会话状态
├─ permissions/      前端路由和功能可见性判断
└─ types/            小程序专用业务类型
```

详细的身份、关系和服务端鉴权边界见 [`../../docs/微信小程序/01-账号与权限模型.md`](../../docs/微信小程序/01-账号与权限模型.md)。
