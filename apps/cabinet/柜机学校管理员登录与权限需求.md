# 柜机学校管理员登录与权限需求

版本：v1.2  
日期：2026年10月20日  
适用原型分支：huwei-cabinet

## 1 需求目标与范围

后台已支持新增学校管理员。本次复用学校管理员账号，使其能够通过手机号及短信验证码登录本校柜机，以柜机管理员身份使用指定的五项管理功能。

本次包含首页管理员登录入口、手机号验证码登录页、学校管理员身份与学校校验、管理员首页入口权限及账号字段对应关系。登录后的业务操作沿用柜机现有功能页面和流程，不重新设计各功能内部页面。

## 2 账号字段对应关系

| 柜机用户信息字段 | 后台学校管理员字段 | 说明 |
| --- | --- | --- |
| 用户账号 | 登录名（手机号） | 用于识别管理员账号及接收短信验证码 |
| 用户昵称 | 姓名 | 作为柜机侧管理员的姓名显示 |
| 用户类型 | 学校管理员对应的柜机管理员身份 | 登录成功后授予本需求规定的五项功能权限 |

用户密码、用户卡号不纳入本次新增字段对应需求。此次新增的登录方式使用短信验证码，不要求管理员在登录页输入密码或卡号。账号同步、存储的技术方式由研发结合现有系统确定，不另建一套独立维护的管理员账号。

## 3 首页入口

柜机首页底部增加「管理员登录」，位于「问题反馈」右侧，与「人脸注册」「问题反馈」同一排，沿用辅助入口的样式与视觉层级。

点击「管理员登录」进入独立登录页。学生原有借还和人脸注册流程保持现有规则。

## 4 管理员登录页

### 4.1 页面内容

| 元素 | 内容及行为 |
| --- | --- |
| 标题 | 管理员登录 |
| 说明 | 使用本校学校管理员绑定的手机号登录 |
| 手机号 | 输入学校管理员的登录名（手机号），限制为11位数字 |
| 短信验证码 | 输入短信验证码 |
| 获取验证码 | 校验手机号格式后发起验证码请求，发送后显示重新获取倒计时 |
| 登录 | 校验手机号、验证码及管理员身份权限，成功后进入柜机管理首页 |
| 返回首页 | 返回柜机首页 |

登录页不展示顶部管理图标、「柜机管理 · A03」及底部「仅限本校授权管理员登录管理」提示。

### 4.2 登录流程

1. 学校管理员从柜机首页进入「管理员登录」。
2. 输入后台学校管理员的登录名（手机号）。
3. 点击「获取验证码」，接收并输入短信验证码。
4. 点击「登录」，服务端校验验证码、学校管理员身份、账号可用状态及所属学校与柜机学校的对应关系。
5. 校验通过后，以学校管理员对应的柜机管理员身份进入「柜机管理」。

仅允许本校学校管理员登录。验证码正确不等于具备管理权限；非学校管理员、账号不可用或没有当前学校柜机权限时，不得进入管理页。管理员身份及权限须由服务端确定。

### 4.3 异常反馈

| 场景 | 页面反馈 |
| --- | --- |
| 手机号为空或格式错误 | 请输入正确的11位手机号 |
| 未获取验证码 | 请先获取验证码 |
| 验证码为空 | 请输入验证码 |
| 验证码错误或失效 | 验证码错误或已失效，请重新获取 |
| 验证通过但账号无当前柜机权限 | 当前账号无此柜机管理权限，请联系平台管理员 |
| 验证码发送失败 | 验证码发送失败，请稍后重试 |
| 网络异常 | 网络连接异常，请稍后重试 |

获取验证码按钮在倒计时内不可重复触发。手机号变更后，原手机号收到的验证码不能用于新手机号登录。登录失败时保留手机号，允许重新填写验证码。

## 5 登录后的柜机管理首页

页面基于现有柜机管理首页呈现功能菜单，标题为「柜机管理」。左上角为「← 返回」，标题在同一行水平居中；不再单独展示「学校管理员」小标题。

五项入口采用两列布局，依次为：

| 行 | 左侧 | 右侧 |
| --- | --- | --- |
| 第一行 | 开箱测试 | 格口详情 |
| 第二行 | 摄像头配置 | 人脸底库 |
| 第三行 | 设备管理 | 留空 |

点击入口进入柜机对应的现有功能页面，内部操作沿用原有流程。首页不使用此前原型自定义的16格口列表及「打开柜门」「修改设备状态」面板。

管理员信息展示中的姓名取学校管理员「姓名」字段，账号取「登录名（手机号）」字段，不使用固定的示例姓名或示例手机号作为真实用户信息。

点击左上角「返回」结束当前管理员会话并返回柜机首页；再次进入管理功能需要重新登录。

## 6 学校管理员权限

| 现有柜机功能 | 学校管理员是否允许使用 |
| --- | --- |
| 开箱测试 | 允许 |
| 格口详情 | 允许 |
| 摄像头配置 | 允许 |
| 人脸底库 | 允许 |
| 设备管理 | 允许 |
| 激活设备 | 不允许 |
| 用户管理 | 不允许 |
| 退出软件 | 不允许 |

学校管理员首页只展示允许使用的五项功能。「返回」用于结束管理员会话，不属于「退出软件」。

权限限制应覆盖入口、页面跳转和实际操作请求，不能仅隐藏按钮。未登录或不具备权限时，即使通过其他路径进入页面或发起请求，也不得执行受限操作。本次只调整学校管理员的权限，不据此改变其他既有管理员角色的权限。

格口本地状态与后台借出记录仍按既有规则处理：修改格口设备状态不能直接解除学生借出状态，也不能直接使设备重新可借；涉及借出记录变更仍由后台核实处理。

左侧原型控制台展示模拟手机号、模拟验证码及操作步骤，作为演示说明，不放入柜机正式业务页面。

| 项目 | 当前原型演示值 |
| --- | --- |
| 模拟手机号 | 13800000000 |
| 模拟验证码 | 123456 |
| 操作步骤 | 输入手机号 → 获取验证码 → 输入验证码 → 登录 |

当前原型的验证码校验和管理菜单为前端演示，未接入真实短信、后台学校管理员账号、服务端权限或柜机硬件。五个菜单入口只说明衔接现有功能页面，尚未复刻内部页面。正式版本必须使用实际账号及验证码服务，不能使用演示验证码进行身份认证。

## 8 短信验证码实现与参数规则

### 8.1 服务端实现要求

复用教师端手机号登录已接入的短信平台，新增「柜机管理员登录」短信模板，短信签名优先沿用教师端已审核签名，具体可用性由研发确认。柜机登录不得使用教师端登录短信内容。柜机端只负责输入手机号、请求发送验证码及提交登录，不持有短信服务密钥，不生成或自行判定真实验证码。

验证码由服务端安全随机生成、发送和校验，与手机号及登录用途绑定，并记录有效期、发送时间和错误尝试次数。验证码校验成功后立即失效，不能重复使用。重新发送成功后，以最新验证码为准，旧验证码失效。验证码不得明文写入日志，也不随发送接口响应返回柜机。

### 8.1.1 短信模板

模板用途：柜机管理员登录。

> 【现有短信签名】您正在登录AI学伴柜机管理员账号，验证码为${code}，5分钟内有效。请勿向他人泄露验证码，非本人操作请忽略。

${code}为动态验证码参数，具体占位符格式按现有短信平台要求配置；「现有短信签名」替换为平台实际已审核签名，不作为字面内容发送。复用教师端已有发送能力，使用独立的柜机登录模板标识，并按短信平台流程完成模板配置与审核。短信文案中的5分钟须与服务端实际有效期一致。

### 8.2 发送与登录流程

1. 柜机提交手机号、当前柜机标识及登录用途，请求获取验证码。
2. 后台确认学校管理员账号可用、具备当前柜机所属学校权限，并检查发送频率；未通过校验不得发送登录验证码。
3. 后台生成验证码并保存校验信息，调用平台短信服务发送至该手机号；发送成功后柜机启动60秒倒计时，发送失败时提示重试。
4. 管理员输入验证码，柜机提交手机号、验证码及当前柜机标识。
5. 后台校验验证码，并再次检查账号状态、学校归属和功能权限；全部通过后一次性消费验证码，返回管理员登录凭证及本需求限定的五项功能权限。

发送频率、重发间隔和错误次数限制由服务端执行，不能只依赖柜机倒计时。验证码验证和消费须避免同一验证码被并发重复使用。账号存在性和学校权限校验失败时，发送阶段使用统一提示「暂无法发送验证码，请确认账号或联系平台管理员」，不区分账号不存在、被停用或学校不匹配。

### 8.3 已确定参数

| 参数 | 正式要求 |
| --- | --- |
| 验证码格式 | 6位随机数字，允许首位为0 |
| 验证码有效期 | 生成后5分钟，过期需重新获取 |
| 重发间隔 | 同一手机号同一登录用途60秒后可重新获取 |
| 验证成功 | 立即失效，不可重复使用 |
| 重新发送 | 发送成功后新验证码生效，旧验证码失效 |
| 发送频率及连续输错限制 | 优先沿用平台现有规则，由服务端校验；平台无规则时须在上线前明确阈值及解除方式 |

### 8.4 仍需对齐的事项

| 事项 | 要求 |
| --- | --- |
| 短信服务、签名和模板 | 复用教师端现有短信平台；签名优先沿用教师端已审核签名，具体可用性由研发确认；新增「柜机管理员登录」短信模板，研发确认模板配置、审核状态及模板标识 |
| 发送频率和连续输错阈值 | 记录平台现有阈值及限制解除方式；无现有规则时补充确认，不自行假定数值 |
| 无操作自动退出时长 | 待确认 |
| 账号信息与权限更新生效机制 | 同步或实时查询方式待研发明确 |

## 9 验收要点

1. 首页底部三个辅助入口顺序为「人脸注册」「问题反馈」「管理员登录」。
2. 管理员登录页文案、输入项与返回路径符合本需求，不展示已删除的图标及提示。
3. 本校有效学校管理员使用其登录名（手机号）及正确验证码可登录；非本校或无权限账号不能登录。
4. 柜机用户账号对应学校管理员登录名（手机号），用户昵称对应姓名。
5. 登录成功后进入五项功能菜单首页，左上角返回与居中标题在同一行，不展示旧格口管理首页。
6. 仅显示并允许使用开箱测试、格口详情、摄像头配置、人脸底库、设备管理；激活设备、用户管理和退出软件均不可用。
7. 五项入口衔接现有柜机功能页面及流程；直接跳转或请求不能绕过权限。
8. 点击返回结束管理员会话，回到首页后不能继续使用原会话执行管理操作。
9. 正式版本不显示模拟账号说明，不接受固定演示验证码，不使用示例姓名作为真实用户昵称。

10. 正式验证码为6位数字、5分钟有效、60秒可重发；成功验证或成功重发后，旧验证码不能继续登录。
11. 短信发送及校验通过后台完成，柜机不返回真实验证码或持有短信密钥；发送频率与输错限制由服务端执行。
