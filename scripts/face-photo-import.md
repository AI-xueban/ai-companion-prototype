# 姓名照片批量改为编号照片（Windows PowerShell 5.1+）

脚本读取姓名与后台已生成编号的对应表，将“张三.jpg”改为“2026001.jpg”，保留照片内容和图片格式，输出改名后的独立图片及 ZIP。每个班单独提交一个照片 ZIP，并准备该班对应的 Excel（.xlsx）或 UTF-8 CSV 学生名单，列名为“姓名、学生编号”。无需学校、昵称或后缀字段。请提供该班的完整名单，编号按文本保存并保留前导零。

重名学生在姓名后添加任意不同后缀，完整姓名作为系统姓名保存。脚本直接匹配完整姓名，不解析括号或后缀。照片文件名（去掉扩展名）与名单姓名须一致，包括全角/半角括号和标点；仅清理首尾空格并进行 Unicode NFC 规范化。

```csv
姓名,学生编号
张三,2026001
小明（01）,2026002
小明（02）,2026003
```

对应照片为“张三.jpg”“小明（01）.jpg”“小明（02）.jpg”。学校只需提供姓名和对应照片，管理员从后台导出姓名与自动生成编号的对应表，并保存为此 CSV，无需重新编编号。

在仓库根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/rename-face-photos-by-student-id.ps1 -Photos "一年级1班_学生照片.zip" -Students "一年级1班_学生名单.xlsx" -Output "一年级1班_照片匹配结果"
```

每次生成该班的“编号照片”文件夹（内含实际改名后的图片）、“编号照片.zip”和“匹配明细.csv”（记录原文件与新文件名）；其他班单独运行，使用不同输出目录，逐班上传。输入和生成的 ZIP 均不得超过50MB（按1MB = 1,048,576字节校验）；超过输入限制会终止，超限输出 ZIP 会移除并报错。核对明细后，在后台选择与名单对应的学校，上传编号 ZIP 并导入。输出目录必须为新目录，原照片不会修改。

添加不同后缀的重名学生可以正常匹配。完整姓名仍重复、找不到完整姓名、同一编号有多张照片、错误图片文件头时列为失败，不猜测身份。支持 JPG/JPEG/PNG 和子目录；不按上传路径解压到磁盘。单图5MB、ZIP 50MB、总解压512MB、最多10000条目。只校验图片文件头，不执行人脸检测或完整解码。旧 ZIP 中文乱码时请重新按 UTF-8 打包。

退出码2表示有失败或没有成功项，成功项仍会打包；运行错误会终止，请不要使用错误运行的输出。

学校提交要求见 [学校学生名单与照片提交规范](school-student-photo-spec.md)。当前分支 face-pages.js 导入仍为模拟逻辑，没有真实上传接口；脚本完成文件匹配与打包，真实入库和识别数据替换需由正式后台接口完成。

Excel 使用第一个工作表，表头必须包含“姓名”和“学生编号”。学生编号列请设置为文本格式，避免编号前面的0丢失。旧版 .xls 请先在 Excel 中另存为 .xlsx。
