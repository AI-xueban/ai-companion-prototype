# 学生名单和照片提交要求

请每个班单独提供以下两个文件：

1. 一份学生名单（Excel），填写学生姓名。
2. 一个照片压缩包（ZIP），放入该班所有学生的照片。

## 照片怎么命名

每位学生提供一张清晰的本人正面照片，支持 JPG、JPEG、PNG。

照片文件名必须与名单里的姓名一致，例如：

| 名单里的姓名 | 照片文件名 |
| --- | --- |
| 张三 | 张三.jpg |
| 小明（01） | 小明（01）.jpg |
| 小明（02） | 小明（02）.jpg |

如果同一个班里有重名学生，请在姓名后加上不同的班内序号，例如“小明（01）”“小明（02）”。名单和照片必须使用相同的完整姓名。不同班级分别提供名单和照片 ZIP，无需核对其他班的重名情况。

## 文件大小

- 每张照片不超过 **5MB**。
- 每个班一个 ZIP，大小不超过 **50MB**。
- 如果超过大小限制，请先缩小照片，保持面部清晰，再打包。

## 提交前检查

- 名单里的每位学生都有一张照片。
- 照片文件名与名单姓名一致。
- 重名学生已经加上不同的区分说明。

建议文件命名为“一年级1班_学生名单.xlsx”和“一年级1班_学生照片.zip”。提交时注明学校名称。
